# E 独立饱和渗流与流固耦合原型

本目录从 **v22 当前源码**直接复用材料类型、本构能量和 PK1，提供 E 私有研究算子；不改变旧 solver、公共入口、默认材料、A/B/C/D 或旧归档。源码身份以 `benchmarks/research_e/protocol.json` 和每次运行的 `baseline-before.json` 为准，不能将本原型称为新的生产 Lite 版本。

## 入口

从 `/root/workspace/mpm-lite` 运行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 .venv/bin/python -m benchmarks.research_e.run
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m unittest discover -s tests/research_e -v
```

每次生成 `docs/results/parallel-v22/E/<UTC>_E_full/`，已有目录会被拒绝覆盖。包含执行前协议、源码包、输入/源码/成果散列、基线前后核验、原始 NPZ、自动验收 JSON、报告、图和 GIF。依赖均取当前 `.venv`，无需安装或改变锁文件。

运行器在系统盘不足 5 GiB 时停止启动新实验；执行人员应先按用户授权把可核实的非关键数据迁移到 `/root/autodl-tmp`，保留路径兼容和迁移清单，不删改其他研究任务。E 当前单次输出约数 MB，先验预计上限 20 MB；GPU 不参与，资源信息和同机负载随结果记录。

## E1 模型和量纲

固定参考域 `[0,1]` 或 `[0,1]^2`，二维为单位厚度平面应变。演示材料是研究尺度，未作真实材料标定；不复用 v22 夹持盒体的空间准确性声明。

| 量 | 单位及约定 | 有效域 |
| --- | --- | --- |
| X、x、u | m；`x=X+u`，u 为总位移 | 有限值 |
| F | 无量纲，`I+grad_X(u)` | 有限变形适配器要求 det(F)>0 |
| mu、lambda、k_f | Pa；现有 Hencky 基体＋双边二次纤维 | mu>0，lambda+2mu/3>0，k_f>=0 |
| p | Pa，表压；负值不自动裁剪 | 单相饱和、无空化/相变模型 |
| K | m²，本征渗透率 | 对称正定；仅消除机器舍入级反对称量 |
| mu_f | Pa·s，动力黏度 | >0 |
| rho_s、rho_f | kg/m³ | >0；零流体仅独立阻力单相极限支持 |
| n、n0 | 孔隙体积分数，非饱和度 | 0<n<1；饱和度固定 1 |
| alpha | 无量纲 Biot 系数 | [0,1]，主场景 1 |
| S | Pa⁻¹，物理储水系数 | >=0；不是压力惩罚或数值稳定化 |
| q | m/s，Darcy 相对体积通量 | `q=n*(v_f-v_s)` |
| face_flux | m³/s，单位厚度下积分面通量 | 沿坐标轴正方向，非统一外法向 |
| V | m³，正参考体积 | >0；不能与当前体积 J·V 混用 |

Darcy 关系为 `q=-(K/mu_f)*(grad(p)-rho_f*g)`。边界输入中的 `flux` 是**外法向通量密度**，算子转换为带坐标方向符号的积分面通量。质量源为每单位参考体积每秒的注液体积；正号代表流入。压力边界功为负的边界压力乘外流量，重力功通过同一流动右端记录。

弹性方向是参考 `a0`，在非线性材料中始终与各自的 F 配对；当前纤维方向为 `F*a0/|F*a0|`。渗透率有独立特征值和方向：E8 使用 F 的极分解旋转 `K=R*K0*R^T`，不把弹性结构张量直接当 K。未启用孔隙率相关的经验渗透率律。

## E2 材料接口

`FullMaterial.evaluate(F)` 返回完整配对积分总能和逐点 PK1；`tangent_apply` 返回同一法则的解析方向切线。Hencky 切线使用谱矩阵对数的 Fréchet 导数，在重复特征值处取连续极限。无新增塑性等历史。

ISO/F0/F45/F90、刚体旋转、多个扰动尺度、混合方向和非均匀 F 都有控制。共同 F 的 A2/A4 对照复用原函数；非均匀 F 坚持逐点积分，输出平均 F 的反例，未作流体或材料压缩。

## E3–E4 离散弱式与压力规范

`Grid` 支持规则一维/二维盒体。流动采用最低阶 Raviart–Thomas 面通量 RT0 与单元常压 P0；完整积分 `mu_f*K^-1` 的张量，包括斜向交叉项。每个内部面只有一个通量自由度，所以相邻单元作用的流量严格相反。

令 H 为通量阻力质量阵，B 为单元积分散度，压力边界/重力右端为 r：

```text
H f - B^T p = r
B f = source * cell_volume
```

纯 Neumann 问题先检查总源与边界流量兼容，再用一个体积加权均压约束处理唯一常数规范；不平移压力对角线。混合块不是 SPD，使用稀疏直接分解；可交接的压力 Schur 作用为 `B H^-1 B^T`。

骨架使用连续 Q2 位移、每单元 3^d 完整材料积分；G 是 alpha 乘积分散度。Q2/P0 在本轮规则网格上直接检查 `G A^-1 G^T` 的谱与棋盘模态：自由牵引边界无压力零模态，全夹持仅有预期常数规范。该数值证据不外推到任意非结构网格或退化单元。

## E5 双向交换

保留两相惯性的均匀两质量块是独立方程层级：

```text
D = V*n²*mu_f*K^-1
j_f = -dt*D*(v_f_new-v_s_new), j_s = -j_f
m_f*(v_f_new-v_f_old)=j_f
m_s*(v_s_new-v_s_old)=j_s
```

`implicit_drag` 隐式解相对速度，返回实际施加的两相冲量。物理损失是 `dt*w_new^T D w_new`；数值损失是 `0.5*sum(m*|delta_v|²)`。解析指数衰减、密度比与刚性大步长分别测试。Darcy/Biot 已消元相对动量，**不再叠加这份阻力冲量**，避免重复施力和重复耗散。

## E6–E7 孔弹性时间步及账本

孔弹性采用既有固体法则在 F=I 的小应变线性化，骨架/流体惯性均忽略，固定参考空间。反力为总牵引的约束反力。代码只支持齐次位移约束以及给定压力或零流量边界；未实现非零给定通量的耦合边界功，调用时显式拒绝。

```text
A u - G^T p = load
G (u_new-u_old) + C (p_new-p_old) + dt B f = dt source_volume
H f - B^T p = r
C = S * diag(reference_volumes)
```

主路径单体求解；对照一次分区和 fixed-stress 迭代分区。fixed-stress 的 L 只用于迭代，收敛后消失，不计入物理储水。真实混合残差不合格的试探不可提交。

能量恒等式（按后向 Euler）为：

```text
E = 1/2 u^T A u + 1/2 p^T C p
D_Darcy = dt f^T H f >= 0
D_numeric = 1/2 delta_u^T A delta_u + 1/2 delta_p^T C delta_p
W = load_new^T delta_u + dt*(p^T source_volume + f^T r)
E_new-E_old + D_Darcy + D_numeric - W = residual
```

动能在该准静态层级为零，不能解释成保惯性 MPM 动力学已经验证。质量缺陷按每个单元的体积增量统计，乘固定 rho_f 即质量单位；固体颗粒质量固定。储水 S>0 时含可压缩流体质量内容，小应变 n 的几何诊断与精确有限 J 状态分开。

独立参考为一维单面排水固结的 Fourier 级数，以及二维 45° 张量的解析制造解。四档 dt 输出相同时间点，保留加载、保持、卸载、末端保持的原始反力、压力、应力和各阶段误差；没有删首步或平滑。

## E8 状态事务与重启

`SaturatedState` 采用不可压颗粒和不可压流体的**指定有限变形状态实验**：`n=1-(1-n0)/J`，固体质量 `rho_s*(1-n0)*V` 恒定，流体质量必须与 `rho_f*n*J*V` 一致。给定净注液增量不匹配时拒绝试探，不能裁剪 n。

`begin_trial` 先清除旧试探，校验所有新 F/n/K/质量/速度/压力后才建立新试探；`commit` 仅接受有效试探；`rollback` 不改 committed。读出的状态都是副本。失败注入涵盖负 J、非法孔隙率、缺少供液和非有限压力。重启包携带 schema/model/config/state 和散列，重新验证全部不变量，不自动迁移任意旧快照。

E8 的循环为指定仿射变形，通过均匀体积源供给孔隙体积变化；空间 K 用 `K_ref=J*F^-1*K*F^-T` 拉回，空间流量用 `q=F*Q/J` 恢复并与解析值核对。**未求解有限变形全耦合力平衡**，未将此结果当成非线性 Lite 动力学验收。

## E9 稳健性范围

36 组覆盖渗透率比 1/10/100/1000、纤维角 0/45/90°、纤维刚度 0/20/200 的全组合；网格 4/6/8、储水 0/0.001/0.01、加载速率 0.5/1/2、边压 0/0.05 采用确定性交替。不是所有参数的全笛卡尔积。密度比 0.1/1/10 只进入独立保惯性阻力块，不能声称准静态 Biot 验证了密度惯性效应。

每个工况保存局部质量、约束反力、能量分项、压力和应力分区范围、F/n 可行性、末态完整场和每步账本。斜向高对比粗网格可以稳定但不够准确；解析 Darcy 的精度声明只到渗透率比 100 和所测网格，比值 1000 只有稳健性证据。

## E10–E11 交接与暂缓

待 C/D 集成：移动载体/粒子、APIC、真实动力学交叉质量、全步重启、GPU、Lite 压缩与新空间。仅受拉多纤维、非饱和/毛细、塑性损伤和自由液面应分别另立物理合同，不能继承二次纤维共同 F 下的四阶矩精确性。
