## 1. 正式空间：边界和完整质量已有结果，动态仍需研究

使用当前正式包`cross-direction-snapshot6`，包哈希`885a2870a9908f5fd5a0904173a5c1244695e4b7e5a80bf953ff445fda644a30`；225个载体标量 + 144个局部函数，完整369标量。不是最早的q4-v22空间，也不是10标量小模型。

自由载体采用材料坐标C1遮罩：

\[
B_c(X,x)=\chi(X)SH(x)B_{old},\quad
D_XB_c=\chi(D_xSH\,B_{old})F+(D_X\chi)SH\,B_{old}.
\]

遮罩在x≤0.25或x≥0.75的夹持区为零，过渡宽度2/64；固定载体与局部函数保留原材料坐标定义。规则身份包含坐标、宽度及端点多项式延拓。固定边界分量仍能作为独立提升字段，但**尚未通过动态边界冲量和压力功验收**。

完成了两端夹持体积采样、过渡带三档有限差分和三步影子点导数检查；复现原未重采样载体的零边界及朴素SH的约0.0113936泄漏。新候选采样自由值/梯度均为零。

完整惯性仍为

\[
M_{ab}=\int_{\Omega_0}\rho B_aB_b\,dV.
\]

所有受变化影响的载体—载体、载体—局部、载体—固定块重新积分，未改变的固定/局部块沿用已认证旧积分。采用张量分块，避免构造所有积分点×全部函数的巨型数组。q7/q8比较针对变化的块，不宣称对沿用块做了新的独立认证。重新检查三个物理零模态；静态消元后216个自由标量、648个向量分量。缩放质量条件数约8.75e5，仍然偏大，后续不能忽略预条件和求解残差。

| 检查 | 结果 |
|---|---:|
| 变化后完整质量q7/q8相对差 | 3.202e-17 |
| 缩放独立质量最小特征值 | 1.568e-05 |
| 三步历史导数相对差 | 5.955e-11 |
| 正反系数循环位置差 | 5.055e-06 m |
| 静态核查峰值1.85 | 1.85 GiB |

稳定化风险已形成可复算反例：原势能是绝对载体状态的`U_s=0.5 Y^T K_s Y`，新更新映射的累计系数却不再唯一对应原绝对物理状态。只保留Ks公式不能证明保持原模型。本轮没有擅自删除稳定化、加阻尼或替换为增量势能。详见结果中的`S1-formal/stabilization-decision.md`。Gate A未通过。

## 2. 小模型：分离规则，备用历史从初始化维护

继承BASE的8个SH模态载体+2个材料局部函数、两个压力控制体。材料参数μ=10、λ=20、kf=200、ρ=1、α=0.8，储水系数0.01；压力为表压，初始0.2、排水边界0。左端固定，材料坐标保持身份。惯性使用完整质量，不采用对角集中。保留已有float64研究精度，没有新增Warp依赖或GPU验证。

明确三种规则：

- 质量与压力几何固定q4，128点；材料默认q4，共享对应点历史。
- 备用材料q6，432点；仅计算材料能、内力、切线相关量，不改变质量或压力几何。
- q2仅作低分辨率拒绝诊断，16点；生产默认不使用q2。

每个备用点从t=0保存并推进x、F：

\[
x_q^{n+1}=x_q^n+B_q^nd,\qquad
F_q^{n+1}=F_q^n+D_XB_q^nd.
\]

普通规则共560个历史点；启用q2诊断时共576点。跨网格影子点、三步历史、检查点恢复通过。旧检查点若缺少备用历史会明确拒绝，不从粒子猜测历史，也不自动补单位F。材料本构目前仍是平滑单方向范围，尚未完成一般方向分布/内部塑性历史扩展。

## 3. 真实拒绝与整步重算

以相同旧状态的q4/q6或q2/q6候选比较能量、组装内力及逐单元PK1弱应力积分。工程预算为相对5%，能量绝对底限1e-10、力/弱应力1e-7；不是以大量帧追求苛刻小误差。

诊断q2首步实际内力差约5.28%，超过预算。该试步未写入已提交状态，随后从相同时间、速度、压力和所有旧历史用q6重算。结果与直接q6整步计算逐数组一致。正常规则和备用规则的质量、压力几何逐字节一致。

准备、重试、求解、载入、提交阶段的故障注入均不改变已提交状态摘要；真正无效的历史直接拒绝，不用回退掩盖输入损坏。独立进程完成了无粒子冻结包的完整耦合重试，并恢复演化检查点得到相同最终摘要。

切换能量单独记账：

\[
\delta U_Q=U_{backup}(F_n)-U_{primary}(F_n).
\]

在已有历史后显式重新启用q2的诊断分支中，`δU_Q=-3.427e-10 J`，与Darcy耗散和速度投影功分开。该重新启用仅为验收，不是运行时自动来回切换。备用q6失败不继续无限增阶；未认证为独立空间参考。
