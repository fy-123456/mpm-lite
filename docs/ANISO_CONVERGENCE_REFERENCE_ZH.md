# 可靠积分下的时间收敛与空间参考（2026-09-23）

后续已完成[时间与空间参考继续加密](ANISO_REFINEMENT_ZH.md)：候选六条路径达到速度/F/P 相邻差 1% 门槛，参考扩展到 grid 81/97；参考不确定性仍大于局部模式设计所需尺度。本文保留前一阶段的结果。

## 结论与试验协议

执行两个任务：固定公共细分的可靠积分规则，检查同一运动空间的 dt/2 收敛；建立更细空间、更小 dt 的参考，在相同材料参考位置比较 x、F、PK1 应力 P，定位模板移动区、夹具附近和其余梁体的误差。

已完成 28 条轨迹（含共同初态准备）、1,592 个更新步，以及 40 项专项/相关回归测试。可靠积分下六组时间差均递减，但最细相邻 dt 仍差约 2.6%–4.9%；细参考自身的空间差也仍明显。相对控制的增强 F 差主要集中在切换附近，新增模式的梯度交叉项可以解释其增减；相对细参考的总误差则遍布梁体。目前可确认误差来源的区别，不能宣称时间/空间已经充分收敛或增强后所有指标都改善。

为隔离误差来源，先在旧模板上生成统一切换前快照（t=.001），随后全部候选与参考从同一历史位置场、速度场重新开始，推进到 t=.004。切换后的运动空间固定；不因每条轨迹不同的历史重建出不同的试验空间。保留未增强、增强和不切换控制。此协议与上一轮各 dt 独立推进到切换时刻不同，结果不能不加说明地拼接。

各次运行内材料点固定，采用旧历史/活动模板分界公共细分的 5 阶规则。跨网格比较采用共同质量样本和独立公共探针，以免不同初态或不同点分布混入误差。参考结果会做空间与时间分辨率检查，明确其仍为数值参考而非真解。

首轮磁盘：系统约 8.0 GiB、数据约 31 GiB，未触发迁移或暂停。每步沿用容量守卫；保存可恢复的系数检查点，避免存储整段大型点云。

### 实现阶段验证

新增 `FrozenResidualQ1` 固定切换时的余量函数，只把固定空间中的增量加到当前历史上；没有把当前历史误当作固定余量的锚点。新增 6 项专项测试通过，覆盖多步场/梯度相容性、跨网格同一初态、位置与速度场的无 pickle 系数保存/恢复、区域误差平方份额、完整质量范数，以及固定余量与逐步重建余量的短程求解对照。连同相关回归共 40 项通过，记录见 [tests.txt](results/convergence-reference/v1/tests.txt)。

为使细网格参考可承受，仍使用原 L-BFGS/Armijo，但做精确质量坐标变换：M_r=L Lᵀ，y=Lᵀz，惯性项变为 1/2‖y−yhat‖²。这只是变量变换，不改质量、势能或时间离散；专项测试与原缩放方法核对了同一步解。全部路径使用同样的坐标变换和 1e-9 残差阈值。

共同质量规则采用覆盖所有候选/参考模板分界的 Gauss 2 阶样本，对这些固定标量模式的乘积可作精确积分；共同误差探针另用 Gauss 3 阶，独立于每条轨迹的 Gauss 5 阶能量积分。记录切换时初速度投影差，以识别模板不能保留旧速度所产生的影响。

### 可靠积分下的时间扫描

grid 17 的不切换/未增强/增强三条固定空间路径，相邻 dt 的速度质量范数差均递减。四档 dt=.25/.125/.0625/.03125 ms，增强路径的相邻差约 8.44%、5.20%、2.92%，按绝对质量范数估计的阶数约 .65、.81。已看到趋近一阶的趋势，但还不是误差低于 1% 的已收敛真解。

### 相对同网格控制的误差定位

在新的共同初态协议下，相对同网格不切换控制，grid 17 未增强/增强的 F 差（以控制的 ‖F−I‖ 归一化）约为 0.602% / 1.189%；grid 33 则为 1.126% / 0.798%。因此“增强后 F 差必然增大”并不是普遍结果；旧报告 grid 33 的初态由自己的旧模板生成，不能与本轮共享 grid 17 初态的结果直接拼接。

两档增强路径相对控制的 F 差平方，约 97.8% / 99.3% 集中在 x∈[.4375,.5625] 的切换附近（该区占总体积 25%），不是集中在左夹具。相对细参考的总误差分布则明显不同，见下表。

最终状态的 5/7 阶公共积分复查：两档增强路径的能量、恢复力与切线作用差均低于 1e-6；最敏感的是 grid 17 的恢复力差，约 9.92e-7。主参考的三项差均低于 3.4e-12。共同误差探针单独从 Gauss 3 提高到 Gauss 5，grid 33 增强相对主参考的 x/F/P/v RMS 变化均低于 1.35e-7；没有将误差观察规则直接当作材料积分规则。

## 新增模式为什么可能增大相对控制的 F 差

保持切换历史不动，只将最终累计增强位移投影到受同一夹具约束的新 Q1 空间：

\[
x_{\rm proj}=x_\star+\Pi_{Q1}(x_{\rm en}-x_\star),\quad
G=F_{\rm en}-F_{\rm proj},\quad D=F_{\rm proj}-F_{\rm target}.
\]

则相对指定目标的平方误差变化满足

\[
E_{F,\rm en}^2-E_{F,\rm proj}^2
=2\langle D,G\rangle_V+\langle G,G\rangle_V.
\]

这里 $\langle\cdot,\cdot\rangle_V$ 是体积平均内积。结果如下：

| 网格 / 目标 | 交叉项 $2\langle D,G\rangle_V$ | 新增梯度项 $\langle G,G\rangle_V$ | 平方差变化 |
|---|---:|---:|---:|
| 17 / 同网格控制 | +3.1563e-9 | +3.0131e-8 | +3.3288e-8 |
| 17 / 主参考 | -4.6508e-8 | +3.0131e-8 | -1.6376e-8 |
| 33 / 同网格控制 | -8.0773e-8 | +6.9939e-8 | -1.0834e-8 |
| 33 / 主参考 | -1.0179e-7 | +6.9939e-8 | -3.1847e-8 |

粗网格新增梯度主要增加了与控制路径的区别，却对细参考的误差起到抵消作用；细网格对两种目标都出现抵消。区域分解表明主要变化仍来自切换附近。它解释了为什么“相对控制的 F 差变大”和“相对细参考的 F 差变小”可以同时发生，不需要归因于位置/F 历史失配。

这是对同一最终增强场的代数诊断，投影后的场没有重新经历动力学求解，**不能视为关掉模式后的因果对照轨迹**。动态模式耦合、初速度投影和剩余时间误差仍包含在实际轨迹中。切换时初速度投影相对差，grid 17 未增强/增强为 0.1025% / 0.0735%，grid 33 为 0.03624% / 0.02599%；不切换路径约为机器精度。

## 验收、限制与下一步

全部轨迹通过现有数值门槛：最大质量坐标残差 9.96e-10，最小 det(F)=.995817，最大夹具速度约 2.0e-20，最大能量预算闭合差约 5.2e-22；每条释放轨迹的机械能递减。历史场重新求值与逐步保存的 x/F 最大绝对差约 5.46e-12。新增模式仍为 3 个独立标量模式、9 个向量自由度。积分复查、探针复查和平方误差分解闭合检查全部通过。

这些门槛检验数值一致性和试验有效性，不等于要求每个物理指标都已收敛。当前主要限制是：细网格时间扫描尚未进入清晰的一阶渐近区，主参考空间差仍大，且初态本身是固定 grid 17 离散历史。终态 5/7 阶积分检查不能作为整条非线性轨迹的严格误差上界，但与此前公共细分诊断、此次共同探针复查一起，已明显削弱“旧积分不足是当前全部差异来源”的解释。

建议下一轮先做两项有独立验收标准的加密：同一 grid 33 空间继续 dt/2，直到相邻速度差达到预先选定的容差；参考空间继续细化，同时同步检查其时间误差，直到参考变化小于要比较的增强收益。更换参考网格时应把新分界加入共同质量与误差积分规则，继续保持同一初始历史。当前不应仅根据 F 相对控制变大就删除或局部化余量模式；若之后仍确认切换区存在显著绝对误差，再试受有限转动完整性约束的局部增强。历史压缩和反复切换仍留待这些误差尺度厘清后研究。

逐步容量检查结束时系统约 7.46 GiB、数据约 29.19 GiB，合计约 36.65 GiB，未触发迁移或暂停。原始字节数保存在结果文件中。grid 49 参考用时约 367 s，grid 65 两档分别约 890 s / 470 s；后两者曾并行运行，不能把这些单任务墙钟时间相加当作总耗时。

## 固定空间、范数与诊断公式

记切换时统一历史为 $x_\star$，将当时的余量 $e_\star=x_\star-N\bar x$ 固定。后续每步使用

\[
\Delta u=N\Delta u_a+C e_\star,\qquad
\Delta F=\sum_a\Delta u_a\otimes\nabla_XN_a+C\nabla_Xe_\star.
\]

累计位置仍为 $x^{n+1}=x^n+\Delta u$，梯度仍为 $F^{n+1}=F^n+\Delta F$。冻结的是增量空间，不是材料状态；$F$、应力与恢复力每步都更新。形状历史按精确系数合并保存，两模板系数的线性组合可在任意参考点求值。

令扩展标量基为 $\widetilde N$、满足总场夹具的系数为 $v=Rz$，则

\[
M=\sum_p m_p\widetilde N(X_p)^T\widetilde N(X_p),\qquad
M_r=R^TMR=LL^T,\qquad y=L^Tz.
\]

变换后优化的仍是同一势能 $\Phi=\frac12\|y-\hat y\|^2+\sum_qV_q^0\psi(F_q^n+dt\,B_qRL^{-T}y,A_{0,q})$。没有以对角质量替换完整质量，也没有改变时间离散。

报告空间误差使用体积加权 RMS，$F/P$ 使用 Frobenius 范数：

\[
E_f=\left[\frac{\sum_qw_q\|f(X_q)-f_{ref}(X_q)\|^2}{\sum_qw_q}\right]^{1/2},
\quad f\in\{x,F,P,v\}.
\]

时间差则使用共同质量样本的完整质量范数：$E_v(dt)=\|v_{dt}-v_{dt/2}\|_M/\|v_{dt/2}\|_M$；常密度下 RMS 的体积归一化在比值中抵消。观测阶数用两次**绝对**速度差计算 $p=\log_2(D(dt)/D(dt/2))$，不将逐次变化的归一化分母混入阶数。

区域份额使用 $S_\Omega=\int_\Omega\|\delta F\|^2/\int_{\rm beam}\|\delta F\|^2$，不是把各区 RMS 直接相加。夹具区为 $X_x<.3125$（体积 12.5%），切换区为 $.4375\le X_x\le .5625$（25%），其余梁体为 62.5%。额外保存 32 个轴向分箱的 $x/F/P/v$ 误差曲线。

初态是共同的 grid 17 离散历史，参考解回答的是“同一已保存历史随后如何演化”，不是将初态替换成连续解析梁后比较。这一点避免了初始形状误差混入模板切换诊断，也限制了本轮对连续梁真解精度的结论。
