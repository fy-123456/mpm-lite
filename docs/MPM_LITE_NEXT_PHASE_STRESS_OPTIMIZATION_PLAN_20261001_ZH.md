**四、统一工程验收、成本与实验上限**

在相同物理位置和共同权重下，分区场误差采用

\[
e_r(y)=\sqrt{\frac{\sum_{a\in r}w_a\|y_a-y_a^{ref}\|^2}{\sum_{a\in r}w_a}},
\qquad e_r(y)\le a_y+0.05\|y^{ref}\|_r.
\]

| 检查 | 预登记的基本要求 |
| --- | --- |
| 位移／速度／PK1／纤维／反力 | 绝对项分别为 5e-5 m、1e-4 m/s、0.02 Pa、0.02 Pa、1e-4 N，加 5% 参考尺度；全域、夹持、过渡、内部分开报告 |
| 实现等价 | 沿用被复用算子的量纲绝对项与约 2e-5 相对项，误差指标开工前登记；不能用 5% 场景预算掩盖本应等价的质量或转置错误 |
| 材料充分／压缩 | 能量 1e-10 J、组装内力 1e-8 N 加 2%；切线作用 1e-8 的既定单位绝对项加 3%；弱矩按原单位与 1e-10 绝对项加 2% |
| 求解／几何 | 真实残差满足已有条件，数值有限；约束误差≤1e-8；min det(F)>0.1 是硬底线，相对当前约 0.99 出现明显下降仍要分析 |
| 能量 | 原始能量差、路径积分差、求解差、边界功、稳定化和规则切换分别记账；沿用已冻结物理尺度的 1% 数值预算，不只展示扣账后的极小缺口 |
| 压力／总应力 | 与独立参照比较采用 1e-5 Pa＋5%、0.02 Pa＋5%；固定固体无源排水过冲单独要求≤1e-5 Pa，不以一般 RMS 门槛替代 |
| 含量／耗散 | 逐单元含量差≤1e-12 m³＋登记尺度的 1%，原始能量闭合≤1e-9 J＋1%；耗散非负，单位用 m³ 而不是未乘密度的 kg |
| 来源与恢复 | 哈希、坐标／模型身份、提交代次、失败后旧状态不变不放宽；初始 predictor=None 单独检查存在性，不进行无意义相减 |

位移使用 u=x−X，应力空间比较使用共同单元积分，不能仅靠显示探针。压力采用共同参考体积的单元均值。不同材料规则的 Gauss 点不同，不把各自 min det(F) 的差直接当作几何误差。

不同步长反力按同区间冲量平均：

\[
\bar R_{[a,b]}=\frac{\sum_{n\subset[a,b]}\Delta t_nR_n}{b-a}.
\]

事件在原始步级输出上识别，预登记幅值门槛、时间分辨率和匹配方法；显示帧不承担时间精度验收。不移相、不平滑后替代原始曲线。2% 应力／纤维与 1% 反力仍是长期目标，本轮不以全部达到为结束条件。

**S2.2｜明确应力目标、联合评分与保留工况。**

- **做什么：**设计集仅使用已经公开的 F45／0.005、0.00375 m。以共同位置的 PK1／纤维响应定义目标，示意为
  \[
  J(C)=\sum_{s\in\mathcal D}\sum_r w_r
  \left(
  \frac{\|P_C(q_s(C))-P_s^{ref}\|_r^2}{s_{P,r}^2}
  +\eta\frac{\|p_{f,C}(q_s(C))-p_{f,s}^{ref}\|_r^2}{s_{f,r}^2}
  \right),
  \]
  其中 q_s(C) 是该空间的平衡解，p_f=a_0^TPa_0；各尺度、权重和设计集先冻结。登记最多两个候选与尚未访问的 0.00425 m 保留幅值，开工重新检查其未被用于设计。

  \[
  \delta P\approx\mathbb A:\nabla\delta u,\quad
  \min_\alpha\|e-D\alpha\|_W^2,\quad D^TWD
  \]
  作有限候选筛选，但不能只取对角贡献或把该最小二乘解当作最终平衡。只使用合法仿射／边界约束，正则化仅用于设计病态处理，不能给物理质量或 Ks 加项。
- **交付：**S2/design-protocol.json、联合评分定义、参考来源、保留工况状态；参考不够覆盖的设计状态明确标注来源，不冒充 R4 认证。

**S4.1｜建立小储存的独立压力时间诊断。**

- **做什么：**在固定固体、无源、初压0.01 Pa、右储库0.002 Pa、沿 x 两／四单元条件下，复用已通过的半单元阻力形式。比较 storage=0.2 与已用于秩检查的0.0002，令
  \[
  C=\operatorname{diag}(S V_{0,k}),\qquad L=BH^{-1}B^T,
  \quad C\dot p+Lp=b.
  \]
  用小矩阵指数计算独立半离散解，并检查中点更新 G。
- **为什么：**目前小储存只证明有限混合矩阵可解，没有证明0.01 s步长下压力单调或瞬态准确。
- **如何验收：**分别报告 C 正性、H 耗散、半离散生成矩阵符号、时间更新及边界响应；不能把正定／满秩当作压力正性。使用无裁剪的原始压力与通量。
- **交付：**S4/small-storage-diagnostic.json，给出失去正性的明确条件或可用范围。

**S4.2｜让实际驱动使用显式、可审计的小步长。**

- **做什么：**新驱动将时间数组传入实际 step、解析对照、源／边界积分、检查点与恢复身份，去除对0.01 s的隐式依赖。先在固定固体结构下检查保守条件
  \[
  h\le2\min_i\frac{C_{ii}}{L_{ii}},
  \]
  预登记至多一个更小步长，例如取该上界的0.8倍再与0.01 s取小值。
- **为什么：**只改配置文件但 advance 仍调用 step(0.01)，会产生错误的测试结论；小储存的可用时间尺度可能远小于正常储存。
- **如何验收：**上界只用于已满足结构条件的固定固体离散；还要直接验证 G 与非齐次边界响应。小储存四步按实际更短终点与解析解对比，不强跑到0.04 s凑成几百步。不得用改大 storage、平滑边界或裁剪压力获得通过。
- **交付：**S4/time-protocol.json、explicit-grid-check.json、monotonicity-and-time.json；保持原固体 AVF／压力中点方法。

**S4.3｜恢复三维固体耦合并检查交换功。**

- **做什么：**在 S2 最终空间上使用充分材料，正常储存封闭／排水各四步；小储存只做一个采用 S4.2 时间表的四步排水分支。沿用同一体积定义与离散梯度：
  \[
  m_k=\alpha(V_k-V_{0,k})+C_kp_k,\quad
  \bar g_k^T\Delta q=\Delta V_k,\quad
  \Delta m+hB\bar z-hs=0.
  \]
- **为什么：**压力趋势改善必须同时保留完整惯性、局部含量及固液能量交换；固定固体正性不能直接外推到受源项和骨架变形驱动的场景。
- **如何验收：**检验交换功抵消与耗散 h·zᵀHz≥0；输出固体 PK1 和总 PK1 \(P_s-\alpha pJF^{-T}\)。混合求解按真实残差验收，不能把整个系统当作固体 SPD／CG。小储存失败时检查源、体积响应、缩放与迭代；超预算无根因则保持受限资格，不更改物理参数掩盖失败。
- **交付：**S4/coupled-checks.json、四步原始场、分区应力及能量／含量分账。

**S4.4｜验证新时间表下的完整提交与恢复。**

- **做什么：**在小储存分支第2步退出，由新进程恢复至第4步；与相同配置的连续轨迹比较。对 q/v/predictor、压力、含量、通量、累计源／边界历史共同注入提交前及指针发布后故障。
- **为什么：**时间表变化会影响累计交换量、恢复索引和能量积分；旧0.01 s夹具不能独立证明新入口正确。
- **如何验收：**失败保持旧提交，发布后异常只接受一次；恢复不重做已提交时间区间。不得跨 storage、单元数或时间表修改旧状态身份；若小储存未通过S4.3，则在已通过正常配置验证接口并明确小储存仍未认证。
- **交付：**S4/rollback-restart.json、publication-check.json、场景／参数／时间资格范围。

**S4.5｜划清三维扩展边界。**

- **做什么：**分别给出固定固体单调性、小储存瞬态、三维固体耦合、一般三维压力空间的能力状态。整理后续三维压力所需的面朝向、体积、完整张量迁移率、边界功和制造解接口；本轮不直接接入生产主场景。
- **为什么：**当前 \(a_{\rm eff}=1/(A^{-1})_{xx}\) 来自横向零流量约束，不能直接推广成任意三维网格上的两点通量。
- **如何验收：**不将旧独立六面RT0张量检查冒充新半单元方案的一般三维认证；连续压力精度和生产 C/E 接入继续保持 false，除非另有独立明确证据。改变流体时间方法属于后续新推导范围，不在本轮顺带引入。
- **交付：**S4/coupling-decision.json、three-dimensional-next-scope.md；小储存不合格也不阻止纯固体交付。

**S5.1｜冻结最终数值实现并准备唯一充分周期。**

- **做什么：**固定 S2 空间、最终时间表、S3 实现和 S4 独立耦合代码，先通过必要的已有针对性回归，再冻结数值源码清单。对证据列出可继承／需补充矩阵。若已存在完全匹配的充分完整轨迹，核查后复用；否则在冻结代码上运行一条充分轨迹至1.6 s，保存所需资格状态和≤12帧。
- **为什么：**旧 qualification-final 只覆盖特定空间和实际网格。S5需要真实受载状态，不能先发资格再补轨迹；该充分周期也应供S6复用。
- **如何验收：**该轨迹计入全轮最多一条最终充分周期的额度。复用旧物理证据须有实现等价和模型身份证明；数值源码改变后不能直接继续旧检查点而改写身份。若必须桥接同物理状态，另立新来源记录并补局部对照。
- **交付：**S5/final-model-lock.json、evidence-reuse.json、充分轨迹或有效复用证明；数值冻结后只修改报告不改变求解器。

**S5.2｜先确认充分性，再确认主场景 q5。**

- **做什么：**在最终实际轨迹的0、0.5、1.1 s以及独立0.8 s状态，按混合方向和当前实际敏感方向比较 q7/q8，再比较 q5/q7；若最终充分阶数已提升则使用相应相邻规则。所有模型用相同完整质量。
- **为什么：**新空间／时间改变会改变材料状态与积分敏感性；缩放旧状态不能代替新轨迹资格。
- **如何验收：**能量、组装内力、共同分区弱矩和切线作用满足统一预算。充分规则不足只允许一次更高相邻阶检查，仍不足则停止该配置晋级。资格冻结实际空间、质量、材料、边界、幅值、时间数组和状态来源。
- **交付：**S5/full-rule-qualification.json、q5-qualification.json、qualification-scope.json；q5未通过则日常使用充分规则。

**S5.3｜重新核对范围拒绝和整步回退。**

- **做什么：**入口同时记录请求规则、实际规则及采用理由；超出已证明的场景／时间范围使用充分规则，来源或维度非法直接拒绝。对本轮改动涉及的材料准备前后、提交前、双规则失败、发布前后，以及程序错误分类做有限检查。
- **为什么：**缓存、时间表和新空间组合后，旧回退成功并不自动证明新路径安全；回退不能吞掉编程错误。
- **如何验收：**试算中途不切换积分；失败整步回到同一已提交状态后重算，记录规则切换能量。双规则失败保留旧代次；KeyError／身份损坏不当作普通压缩误差无限重试。新进程恢复包含失败历史、预测器和累计能量。
- **交付：**S5/runtime-policy.json、fault-and-restart.json、经过实际调用的配置与恢复命令。

**S5.4｜按缺失状态补一个敏感幅值范围。**

- **做什么：**继续只针对 F45／0.0075 m。若物理模型、时间与实现等价关系允许，复用最新0—0.5 s充分前缀及0.5—0.55 s已测窗口；否则只生成本配置必要的充分前缀。默认在0.6 s开始的卸载阶段选一个4—8步窗口，再选一个没有参与资格选择的4—8步检查窗；实际起点、桥接区间和步数在查看候选结果前登记，充分轨迹各段合计新增≤96步，通常止于0.75 s以内。只有已经存在本配置后期充分状态时才选择自由振动窗。
- **为什么：**重复已通过四步窗口的增量价值低；需要覆盖真实缺口，又没有必要增加一条敏感完整周期。
- **如何验收：**所有新窗口均来自该配置真实充分轨迹，不能在不同载荷／空间间搬坐标。从已存在的同配置前缀续建必须有合法来源桥接；即便有旧q5窗口，也不能冒充缺失的充分轨迹。若到达更晚窗口超过已登记预算，明确本轮不扩展该范围；无完整覆盖证据时完整敏感周期仍 full_only，不根据少量窗口自动改主入口。
- **交付：**S5/sensitive-scope.json，区分已继承、新增窗口、未测范围及 full_only 决定；不混入跨角度、跨几何或耦合 q5。

**S6.1｜完成与最终源码一致的针对性回归。**

- **做什么：**复用当前17项中仍适用的检查，只补新时间表、应力候选来源、暖缓存和压力步长相关风险测试；核对最终固体／耦合恢复证据与数值源码清单。

- **如何验收：**全部必要检查通过；仅报告修改不使数值证据失效。若数值源码确需修复，只重跑受影响检查并在预算中解释，不能跑完后修改求解器仍沿用旧验收。

- **为什么：**短窗无法完全反映累计效应，但超过这组完整周期的重复运行通常不能增加相应价值。
- **如何验收：**共同时间分区场和冲量反力满足工程预算；几何无翻转、振动／能量无异常增长；材料哨兵、回退次数和真实残差可追溯。报告实际构建、暖运行、显示、IO、RSS及GPU内存；与32.89 s比较时明确是否同物理空间／时间表。显示倍率注明，不平滑掩盖异常。

**六、关键决定与失败后的继续路径**

| 条件 | 明确处理 |
| --- | --- |
| 时间参照不足或联合指标未通过 | 保留0.0125 s，记录范围；继续空间和性能阶段，不追加无边界的步长扫描 |
| R4重载／参考不充分 | 停止空间晋级，保留swap6；已有可靠空间仍可做性能、压力和日常资格 |
| 两候选主状态无可信改善 | 不访问保留幅值，不加第三候选，不重新生成无意义动态前缀 |
| 空间变化后原时间收益消失 | 在新空间重新作决定；保留默认时间或退回旧空间，不能组合两个相互不适用的“通过” |
| 暖性能收益不足或内存失控 | 保留当前共享／无压缩／场缓存实现；不把不同物理空间成本混成实现加速 |
| 小储存压力超预算／根因未定 | 保留正常储存的受限耦合资格，小储存不认证；纯固体继续交付 |
| q5资格未覆盖最终路径 | 使用充分规则；不放宽来源、整步事务或材料充分性要求 |
| 显著几何、能量、质量秩或缓存污染异常 | 暂停该候选，有限根因分析；能够定位则修复后重查，无法定位则记录后保留已通过基线 |

每阶段结束更新新的实施文档；出现路线改变立即记录输入、观察、推断、实际决定和下一步。原计划快照、预登记指标和失败证据持续保留，避免事后重新定义成功。
