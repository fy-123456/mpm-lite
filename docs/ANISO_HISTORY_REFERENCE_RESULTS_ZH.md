# 中心历史迁移、独立力学参考与方向平均误差

> 后续已加入可选小应变空间稳定化与生产 GPU 四阶方向矩，完成预弯曲梁迁移和新性能对照。详见[空间稳定化与四阶矩结果](ANISO_STABILIZATION_MOMENTS_ZH.md)。本页保留上一轮历史迁移修复的数据。

本轮基于统一增量势能版本完成短程验证与历史迁移修复。默认改为 **粒子携带跨步历史，每步开始重采样中心，Newton/PCG 内保持中心状态冻结**。旧模式可用 `--history-mode grid_locked` 复现。求解器仍为带曲率检查、正定近似回退和原势能线搜索的 PCG。

结论：规定运动下的历史丢失已修复，短程自由运动稳定；均匀拉伸/剪切应力与独立解析计算一致。**单中心梁弯曲存在真实零刚度模式，平均方向张量也有显著本构误差**，因此尚不能把整个方法称为完成力学精度验收。本轮没有把未经充分验证的梁稳定化或新本构悄悄加入默认路径。

结果目录：[CSV、JSON、回放数据及图表](results/history-reference/)。测试和运行环境：Python 3.11、Warp 1.10.1、float64、RTX 3090；GPU 自动选择占用较低的 `cuda:1`。实验前及步间检查磁盘，系统盘约 15 GiB、数据盘约 41 GiB，未触发迁移或暂停。多数受控试验 8–16 步，循环试验 32–128 步；未作长时间稳定性承诺。

## 1. 历史迁移：定位原因并修复

旧实现把历史绑定在世界网格坐标上：持续活跃中心保留旧 F/A0，新激活中心 F=I。这会使穿过网格的材料丢失预变形，方向场也滞留在空间中。仅测试稀疏块编号变化和重置记账无法排除此错误。

新增 [history.py](../engine/aniso_phase1/history.py)，在步开始用参考体积权重计算

$$
F_c^n=\frac{\sum_p w_{cp}V_p^0 F_p^n}{\sum_p w_{cp}V_p^0},\qquad
A_{0,c}=\frac{\sum_p w_{cp}V_p^0 A_{0,p}}{\sum_p w_{cp}V_p^0}.
$$

粒子已有的 C2P 仿射梯度更新继续携带 $F_p$；固定参考方向 $A_{0,p}$ 随粒子移动，不随空间旋转修改。当前方向由 $F A_0 F^T$ 的主方向展示。新增的粒子访问发生在时间步之间，内层没有粒子本构或粒子积分。**这仍是中心本构积分，但已经不是中心独占历史的方案**；增加了一次粒子历史散射，性能需以后重新测量。

重用 trial F 缓冲，不新增同规模稀疏 F 数组。重采样 F 非有限或 det≤0 时拒绝推进，不用静默重置 I 掩盖问题。初始预应变能计入初始总能量；CSV 区分 `state_transport_delta` 与旧 `state_reset_delta`，并保留 `volume_remap_delta`。各项相加的预算闭合只是记账一致，不等于物理能量守恒。

### 三组受控运动

[controlled.py](../engine/aniso_phase1/controlled.py) 使用实际稀疏 P2C/隐式步/C2P 路径，但所有节点速度被规定，以隔离历史传递误差。125 粒子，物体边长 .07，预变形 diag(1.12,.96,1.03)，平移 .14，或 .4 s 内转动 45°。两个历史模式具有相同初始中心预变形。非均匀方向由材料位置决定，在 0°–90° 间平滑变化。

65³ 网格、dt=.05、8 步终点：

| 工况 | 旧模式 F 相对误差 | 旧模式弹性能误差 | 新模式历史表现 |
|---|---:|---:|---|
| 预拉伸平移跨单元/稀疏块 | 7.23% | −100% | F、应力、弹性能恢复到舍入误差量级 |
| 预变形旋转，精确旋转增量 | 10.49% | −10.44% | 旋转后的 F、应力与参考一致 |
| 非均匀方向场平移 | 7.23% | −100% | F 与粒子加权方向张量一致；旧 A0 均方根误差约 .991 |

新模式的 F/A0 误差约 1e−16；33³ 网格和 dt=.025 的分开对照也通过。这里共同 F、规定运动可以精确表示，因此这些小误差是特殊受控场景的结果，**不是一般非均匀变形的收敛阶证明**。方向参考使用独立的主机粒子加权计算，区分“正确迁移平均方向”和“平均方向本构是否准确”。CSV 记录跨步能量变化、应力误差、活跃块、重激活与独立参考；JSON 记录最大弹性能跳变。平滑方向混合下能量随中心权重改变的部分不能一概算作历史丢失。

作为比较，加入仅用于诊断的中心半拉格朗日输运：已知运动反向追踪、三线性插值，空支撑使用最近占用中心延拓。平滑方向场在 65³/dt=.05 时 A0 误差约 .131；33³/dt=.05 为 .303；65³/dt=.025 为 .303。多次插值造成扩散，减小 dt 并未改善这一原型，因此本轮优先粒子重采样。该原型不是生产中心输运实现，也没有性能结论。

**旋转误差拆分：**精确 $Q=\exp(\Delta t W)$ 更新保持刚体旋转客观性；若按 $I+\Delta t W$ 更新，则

$$
(I+\Delta t W)^T(I+\Delta t W)=I+\Delta t^2W^TW,
$$

会产生人为拉伸。45°/8 步与 16 步的欧拉增量测试分别增加约 94.98%、42.75% 弹性能，而历史相对各自离散参考仍正确。这里故意采用较粗旋转步长暴露时间误差，不能称为“正常的小能量误差”，也不能误判为本构不客观。本轮没有修改生产变形梯度积分器。

另外运行了**无规定速度、无边界的预拉伸自由平移**：65³ 网格、64 粒子、8 步、T=.08 s，最大位移 .0834、最小粒子 det F=.934、累计线性迭代 70，机械能变化 −.4233%，无求解失败。这补充检查真实力学求解，但不代替长程及复杂接触验收。

限制：简单平均 F 对强烈非均匀旋转可能退化；当前有 det 检查，但未实现流形平均、多材料分离、塑性/损伤历史重采样。这些情形不在本轮通过范围内。

## 2. 独立参考、循环加载与能量

### 均匀拉伸和简单剪切

生产应力来自 Warp 中心核；参考应力独立由 NumPy 对 $C=F^TF$ 的特征分解计算 Hencky 基体和相同二次纤维项，不调用生产 PK1。拉伸终点 F=diag(1.06,1,1)，剪切 F12=.1；17³/33³ 网格、dt=.05/.025 的六个短试验应力相对误差约 1e−15–2e−14。这证明仿射补丁测试与本构一致，不能单独证明弯曲精度。

### 加载—卸载—重新加载

增加 `--loading-cycles` 与 `--smooth-loading`，使用余弦位移，两次完整循环，每次最大指定位移 .002。CSV 同时输出指定位移、粒子夹持端实测位移、总/弹性/惯性反力、加载功和 $E(t)-E(0)-W_{ext}(t)$。余弦模式的 `loading-speed` 表示单程平均速度，峰值速度为其 π/2 倍。

固定 9³ 网格、dt=.005，单程时间 T 改变：

| T (s) | 首次峰值位移处总反力 (N) | 重加载同位移总反力 (N) | 首次弹性反力 (N) |
|---|---:|---:|---:|
| .04 | .09011 | .09915 | .14313 |
| .08 | .13545 | .13956 | .17210 |
| .16 | .16424 | .16467 | .18221 |

降低速度后惯性影响减弱，首次/重新加载差异缩小。另有 T=.32、dt=.02 的 64 步检查，弹性反力 .18528，但该行同时改变 dt，不能当作单独的速度收敛证据。

分开检查离散影响：T=.16 时，9³ 网格 dt=.01→.005 的总反力 .17369→.16424；dt=.01 时网格 9³→17³ 的总反力 .17369→.18511。物理尺寸、最大位移、材料和加载时间保持相同。仍有约 5%–7% 差异，属于初步加密检查，不宣称已经收敛。

数值耗散仍明显。例如 T=.16、9³、dt=.005，两循环总功 $1.2808\times10^{-4}$，最终机械能 $4.4311\times10^{-7}$，功平衡差 $-1.2764\times10^{-4}$。模型是弹性材料，**这些循环损失不是材料滞回**；需结合 CSV 中传递、积分、边界和重采样项解释。外力功采用离散步末反力乘边界位移增量，也包含功积分误差。

这一案例的累计差额可以按实际记账阶段拆开（能量单位）：

| 阶段 | 对功平衡差的贡献 |
|---|---:|
| 隐式步 + 边界投影 − 边界加载功 | −7.0135e−5 |
| G2C/C2P 回传 | −4.3976e−5 |
| P2C 与 C2G | −9.0803e−6 |
| 历史重采样与体积重加权 | −4.4480e−6 |

主要损失来自隐式/边界功的离散差额与速度回传，当前案例不是单纯由重采样主导。第一行是合并阶段差额，不能进一步唯一归因于某一个时间积分或边界步骤。

### 稍长能量观察

固定块体延长到 80 步、dt=.002、T=.16 s，最终机械能变化 **−.5617%**，过程中最大绝对变化 **2.6961%**。全部步成功，最小中心 det F=1.011。时间是此前 .02 s 的八倍，但仍只是短程结果，不能推广成长时间能量有界结论，也不能沿用旧模式 .835% 为新默认模式的结果。

### 梁弯曲：独立参考发现的实际问题

[beam_reference.py](../engine/aniso_phase1/beam_reference.py) 在 F=I 处取同一本构的小应变切线，建立独立 Q1 六面体有限元：1 点中心积分与 2×2×2 全积分对照。梁长 .5、截面 .125×.125、固定一端，另一端总横向载荷 −1e−4。对实际生产稀疏 matvec 减去质量项、除以 dt²，并施加相同自由度投影，与独立中心刚度比较。

| 网格 | 自由 DOF | 中心积分零/近零模态 | 全积分对应模态 | 全积分端位移 | 实际刚度与独立中心刚度相对误差 |
|---|---:|---:|---:|---:|---:|
| 17³ | 216 | 32 | 0 | −5.69794e−4 | 3.65e−16 |
| 33³ | 1200 | 64 | 0 | −6.06623e−4 | 2.99e−16 |

零模态判断阈值为最大特征值的 1e−9 量级。载荷确有零模态分量，因此中心积分静态问题不是一个可以直接拿伪逆位移通过验收的问题。根因已定位为**空间欠积分**。动态质量项使 $M+\Delta t^2K$ 正定，不会消除 K 中的这些模式；更严格 PCG 容差也无效。

仅在参考程序中测试 $K_\eta=(1-\eta)K_{center}+\eta K_{full}$：η=.05 的两网格端位移 −6.66321e−4、−6.37059e−4；η=.2 为 −6.38687e−4、−6.29989e−4。说明补充空间刚度有帮助，但这不是生产稳定化的验收。下一步应从同一势能加入一致的局部补充积分/小时玻璃控制，并重测补丁、弯曲、反力与能量；本轮不把会改变力学离散的诊断混合矩阵直接上线。

## 3. 方向平均的误差与表示选择

[direction_moments.py](../engine/aniso_phase1/direction_moments.py) 对共同 F 和归一化权重比较粒子纤维求和、平均结构张量、四阶方向矩。针对当前拉伸/压缩均起作用的二次模型 $\psi_f=\frac{k_f}{2}(I_4-1)^2$：

$$
\overline{\psi_f}-\psi_f(F,\overline A_0)=\frac{k_f}{2}\operatorname{Var}(I_4).
$$

F=diag(1.1,1,1) 的**纤维项**相对误差（不包含基体）：

| 方向分布 | 平均张量能量误差 | PK1 应力误差 | 材料切线误差 |
|---|---:|---:|---:|
| 统一方向 | 舍入误差 | 舍入误差 | 舍入误差 |
| 0°/90° 各半 | 50.00% | 67.57% | 67.37% |
| 0°–90° 平滑 16 方向 | 34.69% | 40.31% | 34.69% |

另测简单剪切和 F=diag(√1.1,√.9,1)。后一工况混合方向的平均 I4=1，平均张量错误预测零纤维能量/应力，实际纤维能量非零，能量与应力误差达 100%。这说明仅记录方向离散度并不足以证明本构准确。

推荐当前二次模型的下一步表示为 **二阶矩加四阶方向矩**：

$$
A^{(2)}=\sum_p\omega_p A_p,\quad A^{(4)}=\sum_p\omega_p A_p\otimes A_p,\quad
\overline\psi_f=\frac{k_f}{2}[C:A^{(4)}:C-2C:A^{(2)}+1].
$$

本轮主机原型的能量、应力、切线在九组对照中均恢复到最大 6.55e−12 相对误差。共同 F 下这对当前二次模型是精确压缩；不同粒子 F、仅受拉纤维或指数纤维能不能套用此结论。四阶矩可利用方向张量对称性压缩存储，但生产实现、显存/耗时评估及正定近似切线尚未完成。多纤维族适合少数已知族；更一般模型可考虑局部粒子积分回退。本轮保持默认本构不变，避免把历史修复与材料模型改动混在一起。

## 4. 复现、可视化及验收范围

在项目根目录执行；受控回放无需 GPU：

```bash
.venv/bin/python -m demos.aniso_validation --scene directions --port 8081
# --scene translate：预拉伸平移；--scene rotate：预变形旋转
```

浏览器打开 http://127.0.0.1:8081。左旧右新，短线表示当前中心纤维主方向；颜色表示**整帧总体历史误差**，不是局部空间误差热图。该入口是已保存的规定运动回放，不是自由动力学。

最新实时拉伸演示（默认粒子历史重采样，GPU 自动选择）：

```bash
.venv/bin/python -m demos.aniso --scene tensile --grid 9 --device auto \
  --dt .005 --loading-time .08 --loading-speed .025 \
  --loading-cycles 2 --smooth-loading --play
```

浏览器打开 http://127.0.0.1:8080。可查看反力/位移、能量曲线并导出 CSV；CLI 可加 `--fiber-angle 45` 或 `90`。两循环完成后边界位移保持零，模拟可继续，使用暂停按钮结束观察。

```bash
# 短程研究数据，可 --part migration/reference/directions 分开运行
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m benchmarks.aniso_history_reference --device auto
MPLCONFIGDIR=/tmp/mpm-matplotlib .venv/bin/python -m benchmarks.aniso_history_plot
# 回归测试；GPU 编号按实际空闲显存选择

```

验证：67 项回归测试通过（22.066 s）；另有 CPU 目标测试 13 项通过。最新实时 CLI 参数 headless 8 步通过。两个 Viser 入口做了本地 HTTP/启动/自动播放冒烟检查，不等同于浏览器截图验收。测试容差以发现历史丢失、错误运动和失稳为目标，不要求一般场景达到机器精度。

后续优先顺序：先处理已确认的梁欠积分模式；再把四阶方向矩接入同一增量势能、残差和切线；随后再做较一般的非均匀 F/旋转迁移和相同误差水平的性能对照。此前性能数据不包含本轮新增的粒子历史散射，不能直接拿来声称新默认方法的加速比。
