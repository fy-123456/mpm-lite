# 一致 Q1、准确积分 MLS 与细网格参考：同载荷力学精度对照

## 1. 本轮问题与适用范围

承接[一致传递原型](ANISO_CONSISTENT_TRANSFER_ZH.md)，检验较简单的 Q1 空间是否已经足以表示梁的主要力学响应。

本轮为 **F=I 附近的小应变静态对照**，使用同一本构的精确参考切线；不含质量、时间积分或额外稳定化。所有结果重算，不将旧加载下的位移与新反力拼接。候选是 grid 17、33 的一致原型 Q1 线性化与准确积分的全局混合 MLS；Q1 grid 65 为细参考，再用 grid 97 检查参考自身变化。

原型的 Q1 插值和材料切线均与新静态装配逐项核对，不仅因为名称相同就认定它们等价。本轮不改变任何生产默认，不声称修复 MLS 历史传递，也不将 Q1 参考称为连续体精确解。

## 2. 公平比较的物理设置

- 梁参考域：$[.25,.75]\times[.4375,.5625]^2$，长 0.5，截面 $0.125^2$。
- 本构：相同 Hencky 等向部分与二次纤维项，$(\mu,\lambda,k_f)=(10,20,200)$，参考纤维统一沿 x 方向。
- 左端材料面 $x=.25$ 的三分量位移严格为零。Q1 用节点消元；MLS 用物理面迹约束的零空间，不加入罚刚度。
- 右端 $x=.75$ 施加 y 方向均匀面力，总力 $F_y=-10^{-4}$。
- 体积、材料、夹具、总载荷相同；每种空间分别准确离散同一个连续加载泛函。

端面平均位移与面力互为功共轭量：

$$\ell_i=\frac1{A}\int_{\Gamma_t}N_i\,dA,\quad f_{iy}=F_y\ell_i,\quad \bar u_y=\sum_i\ell_i u_{iy},\quad f^Tu=F_y\bar u_y.$$

端面积分同时切开 Q1 单元边界与 MLS 半格分区。首轮测试发现，单独沿用 MLS 面分区会跨过 Q1 形函数折点，造成面力分配偏差；已修复并增加节点权重回归。对规则 Q1 截面，角点、边点、内点的面力权重分别成 1:2:4，不能将总面力平均分给所有端面节点。

实际输出总反力、总反力矩、独立面点的夹持残差、自由空间平衡残差与 $2U=f^Tu$。固定总载荷下总反力接近，只能说明平衡，不能证明柔度准确。

因此另外比较**同一端面平均位移** $\bar u_y^*=-5\times10^{-4}$ 下所需的总面力/支反力：

$$k_{\mathrm{eff}}=F_y/\bar u_y,\qquad F_y^*=k_{\mathrm{eff}}\bar u_y^*.$$

这是线性系统中均匀面力与平均位移之间的缩放关系，也等价于对平均位移施加一个标量约束；不是把整个加载端变成刚性夹具。

## 3. 比较不同自由度空间的模式刚度

不能把不同长度的节点向量直接代入同一个 Rayleigh 商。本轮先定义同一物理场，再映射到各自空间：$p_h=I_h p$，比较

$$\rho_h(p)=\frac{p_h^TK_hp_h}{\int_\Omega \nabla p:H_0:\nabla p\,dV}.$$

这里 $H_0=\partial P/\partial F|_{F=I}$。取 $s=X-.25,t=Y-.5,z=Z-.5$，所有模式在左端面严格为零：

| 模式 | 共同物理位移场 |
|---|---|
| 伸长 | $(s,0,0)$ |
| 剪切 | $(0,s,0)$ |
| y 向弯曲 | $(-2st,s^2,0)$ |
| z 向弯曲 | $(-2sz,0,s^2)$ |
| 扭转 | $(0,-sz,st)$ |

MLS 可再现这些二次多项式，Q1 需要分片近似其中的平方项。分母用多项式精确积分；分子包含空间表示与积分的共同结果。还比较这五个模式的组合所构成的 5×5 刚度 Gram 矩阵的广义特征值。

**这只是主要物理模式的受限检查，不是整个离散空间的最差谱，也不能代替实际梁解。** 另输出同一物理位置的位移 L2 差与材料能量范数差：

模式 JSON 中的 `physical_field_relative` 是固定公共探针上的加权场差，只用于检查模式表示；它不同于下面按全部空间分区积分的梁解 L2 差。

$$e_u=\frac{\|u_h-u_r\|_{L^2}}{\|u_r\|_{L^2}},\qquad e_E^2=\frac{\int\nabla(u_h-u_r):H_0:\nabla(u_h-u_r)\,dV}{\int\nabla u_r:H_0:\nabla u_r\,dV}.$$

比较积分域切开候选 Q1、MLS 和细参考的分界，采用 4 阶规则；粗 MLS 额外做 3 阶读数对照。两者均为同一本构、统一方向时的度量；本轮没有扫描非均匀或混合纤维场。

## 5. 实测结果

**本例中，grid 33 的一致 Q1 已达到整体位移/平均反力约 2%～3% 的差异水平，可作为后续一致传递研究的基线；grid 17 的 Q1 则明显偏硬。MLS 在相同网格间距下更接近细参考，但其生产传递门槛仍未解除。** 这是统一 x 向纤维、小变形、当前梁尺寸下的结果，不能直接外推到混合方向、细长梁或大转动。

原始数据：[全部结果](results/mechanics-comparison/v1/results.json)、[CSV](results/mechanics-comparison/v1/summary.csv)、[细参考加密](results/mechanics-comparison/v1/reference-check.json)。

### 5.1 实际梁位移与同位移反力

| 空间 / 网格 | 端面平均位移 | 相对 grid 65 位移差 | 同平均位移支反力相对差 | 相对 grid 97 位移差 |
|---|---:|---:|---:|---:|
| Q1 / 17 | -0.0005651773 | -8.252% | +8.994% | -8.702% |
| MLS / 17 | -0.0006047683 | -1.825% | +1.859% | -2.307% |
| Q1 / 33 | -0.0006022269 | -2.237% | +2.289% | -2.717% |
| MLS / 33 | -0.0006139374 | -0.336% | +0.337% | -0.825% |
| Q1 / 65，主参考 | -0.0006160091 | — | — | -0.491% |
| Q1 / 97，加密检查 | -0.0006190473 | — | — | — |

负的位移相对差表示下挠幅值偏小，即更硬。主参考在平均位移 -0.0005 时的支反力为 $8.11676\times10^{-5}$；四个候选依次为 $8.84678,8.26763,8.30252,8.14415$，单位均为 $10^{-5}$。

grid 65→97 的参考位移仍变化 **0.491%**；没有连续真解误差上界。因此 MLS / 33 的 0.336% 不能作为“已知真实误差只有 0.336%”来宣传。用两个细参考分别判断，Q1 / 33 和两组 MLS 都通过本例适度的 5% 整体位移/反力筛选；Q1 / 17 未通过这个精度筛选，但数值求解本身正常。

**相同网格间距不等于相同成本。** Q1 的节点数为 81 / 425，MLS 为 275 / 931，并有更宽支撑。不能仅凭此表认定 MLS 在相同自由度、耗时或显存下更优。CSV 中的时间含装配、参考核对和误差积分，仅用于追溯本次实验，不是公平性能对照。

### 5.2 主要模式与局部变形差异

共同伸长、剪切、扭转模式的刚度比均接近 1。弯曲模式：

| 空间 / 网格 | y / z 弯曲刚度比 | 五模式组合的刚度比范围 |
|---|---:|---:|
| Q1 / 17 | 1.002976 | 约 1～1.002976 |
| Q1 / 33 | 1.000744 | 约 1～1.000744 |
| MLS / 17、33 | 约 1 | 约 1～1 |

这说明主要平滑模式没有被严重漏算或加硬，也说明**五个简单模式接近，不足以保证整个梁解准确**：Q1 / 17 的弯曲模式刚度只高约 0.30%，实际载荷下的端面位移却偏小约 8.25%。真实解包含截面翘曲、剪切和边界附近的变化，并不只位于这五个多项式构成的空间内。

与 grid 65 在共同物理位置比较：

| 候选 | 位移 L2 相对差 | 材料能量范数相对差 | 靠近夹具的前 1/4 梁长占平方能量范数差的比例 |
|---|---:|---:|---:|
| Q1 / 17 | 8.065% | 28.726% | 19.94% |
| MLS / 17 | 2.340% | 15.790% | 42.30% |
| Q1 / 33 | 2.252% | 14.958% | 19.66% |
| MLS / 33 | 0.977% | 12.112% | 59.10% |

局部应变差异比平均位移更敏感。MLS / 33 的差异更集中在夹持附近，Q1 差异则没有这种集中趋势，不能把所有空间误差都归因于夹具。

进一步检查发现，**两个细 Q1 参考自身的能量范数差仍约 9.750%**，尽管位移 L2 差只有 0.514%。65 与 97 网格也并非嵌套，差值不是严格误差界。这说明当前参考足以支持适度的整体柔度筛选，但不足以认证局部应力精度；不继续追加大量加密来追求本轮未要求的严格应力收敛。

粗 MLS 的误差积分从 3 阶改为 4 阶，能量范数读数仅变化约 $3.2\times10^{-7}$（绝对比值）；材料刚度从对齐 4³ 改为 5³，相对矩阵差约 $8.95\times10^{-16}$。因此，上述主要差异不能靠继续增加当前 MLS 的材料积分阶数来消除。

### 5.3 正确性、运行与验收边界

四个候选的力平衡、力矩平衡、自由残差、物理夹持与能量—功关系检查均通过，最大归一化平衡残差约 $1.6\times10^{-13}$。精度筛选失败与程序/求解失败分开报告。新 Q1 静态算子、形函数和梯度与一致原型一致；面力分配的错误由新增回归捕获并修复，未通过调整材料参数或增加稳定化来调位移。

本轮没有动态帧推进，不包含隐式耗散、粒子传递或历史重划分。可视化展示静态场及受控模式；“同平均位移”视图使用线性缩放，反力随之变化。

新增 5 项回归与一致原型、对齐积分、边界处理的相关测试合计 **23 项通过、0 失败**，包含实际稀疏算子的 CPU 检查。可视化服务短时启动检查返回 HTTP 200（818656 字节），正常退出码 0；没有将 HTTP 检查当作浏览器人工视觉验收。数值图已生成并检查，未改动生产默认。

## 6. 后续推荐

1. 将 **grid 33 的一致 Q1** 保留为整体响应的可用基线，继续验证一次受控模板切换/历史重建，而非默认替换生产算法。
2. 保留准确积分 MLS 作为空间精度对照。它的材料积分精度已足够，下一步瓶颈仍是质量、传递及历史表示的一致性，不能通过加积分点解决。
3. 若任务转向夹具附近应力或失效预测，再针对局部场建立更可靠的参考；本轮不声称这部分已经收敛。
4. 在空间表示与更新闭环稳定后，再比较相近整体误差下的实际成本，包含粒子处理和模板维护。本轮不新增完整 MPM 加速结论。
