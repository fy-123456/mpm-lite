## 3. 方程、验收与实验预算

### 3.1 固体与时间

保持位移表达、完整质量和原稳定化：

\[
u_h=u_c+\sum_{i=1}^{144}\phi_i a_i,\qquad F=I+\nabla_Xu_h,\qquad P=\partial\Psi/\partial F,
\quad M_{ij}=\int_{\Omega_0}\rho_0N_iN_j\,dV_0.
\]

独立坐标变换后使用完整`M_new=Tᵀ M_ambient T`，包括载体与富集交叉项，不加人工质量。材料q5/q7切换时M7完全不变。

自由方程沿用AVF：`q1=q0+hW`，`2M(W−v0)+h(f̄int−fext)=0`；速度由`2W−v0`再作当前受约束端点处理，反力保留端点冲量。平均内力来自变形路径上的积分，不新增阻尼。

线性化解释为`Kφj=ωj²Mφj`、`Tj=2π/ωj`；线性单模态的中点数值频率为`ω_num=2 atan(ω h/2)/h`。这些式子解释相位问题，不能代替非线性全场比较。能量闭合与相位正确分别验收。

### 3.2 压力与功交换

保持原物理参数：储存`S=0.0002`、耦合系数`α=0.8`、初压`0.01 Pa`、边界压`0.002 Pa`、完整迁移率张量及物理左半域体积源密度`0.001/s`。冻结张量实际数值和单位，不能只写参数名。

\[
\alpha\Delta V+C_p\Delta p+hBz=hs,\qquad
H(F_{mid})z-B^T\bar p+g_b=0,\qquad C_p=\operatorname{diag}(SV_0).
\]

固定几何消去通量后为`Cp ṗ+L p=b`，`L=BH⁻¹Bᵀ`。通过增广矩阵指数同时得到压力和各边界累计流量的离散时间参照；矩阵指数精确求解离散网格，不代表连续空间真解。

实际耦合中保留固体压力力`−αΣ p̄c ∇̄Vc`，检查`∇̄Vc·Δq=ΔVc`，压力交换功抵消及`h zᵀHz≥0`。混合系统保留行列缩放与一般LU，并复核未缩放原方程残差；不能因纯固体部分可用SPD算法就直接套CG。

### 3.3 工程预算

在同一物理位置、同一时刻及同一应力度量下，分全域、内部、过渡区和夹持区报告体积加权RMS：

\[
e_O=\sqrt{\frac{\sum_iw_i\|O_i-O_{ref,i}\|^2}{\sum_iw_i}},\qquad
b_O=a_O+0.05\|O_{ref}\|_w.
\]

| 量 | 绝对项a | 补充要求 |
| --- | --- | --- |
| 位移、速度 | `5e-5 m`、`1e-4 m/s` | 保留峰值、方向和位置，显示倍率不入账 |
| PK1、纤维PK1 | `0.02 Pa` | 纤维指标为`a0ᵀPa0`，不混称Cauchy应力 |
| 区间反力 | `1e-4 N` | 先比较公共区间冲量`ΣhR`，同时保留原始反力和峰值时刻 |
| 压力 | `1e-3 Pa` | 非均匀网格按真实体积交叠映射 |
| 含量、累计边界体积 | `1e-10 m³` | 总量及各边界方向分别报告，保留早期绝对差 |

材料同状态沿用已有能量`1e-10 J+2%`、内力`1e-8 N+2%`、归一化方向切线`1e-8+3%`及弱应力矩分量预算。新压力网格的时间误差须低于对应工程预算的25%，再判断空间差。

重要事件的相位预算在观察新短窗结果前固定，采用`min(0.00625 s, 0.1 Tlocal)`及双向唯一配对；没有事件、欠采样、配对不唯一均为未观测/未分辨。辅助事件另报原始结果，不计入重要事件通过，也不能把其旧失败改为通过。

有限值、正确边界、真实残差、完整质量、能量与质量账、非负耗散、整步回滚、来源一致为底线。继承当前有量纲求解容差；`detF>0.1`是硬底线，仍需对明显偏离当前约0.99正常范围的塌陷深入定位。一般数值比较不要求机器精度；只改变索引的等价优化应验证实际索引顺序及所影响计算一致。

## 6. S2：固定观测时刻，针对早期排水细化（5步）

### S2.2 设计唯一嵌套网格对

**做什么：** 依据已有方向误差及固定几何尺度`ℓn(t)≈sqrt((nᵀ mobility n/S)t)`，预登记一组最多16/32单元的粗/细网格，细网格包含粗切面。单元预算优先放在排水边界附近，采用正的渐变宽度；必要的跨方向分配依据旧数据和尺度确定。登记切分后才求新结果，不扫描多组间距选通过者。

**为什么：** 平均向域内部加点未必能表达初期薄边界层，各向异性也要求检查实际方向。

**如何验收：** 相同物理边界和源域、体积覆盖一致、正宽度、明确嵌套、单元数≤32，内存可承受。预算内无法分辨重要方向时记`reference_limited`，不改S、迁移率或初边值使问题变慢。单方向网格接近不等于全三维连续精度认证。

**交付：** `S2/grid-design-protocol.json`，含切分、方向选择、尺度、预计最短时间尺度和内存。

### S2.3 验证真实拓扑、几何和源项

**做什么：** 在新的适配器中将网格预算扩至32，同步支持面编号、内面符号、RT0基函数、完整迁移率、三方向通量及固体/压力单元交叠积分。源项按物理左半域交叠体积积分，不按数组前一半赋值。

**为什么：** 网格变化不仅是数组长度变化，错误面归属和积分覆盖会直接破坏流量或压力功。

**如何验收：** 常量/仿射压力、有限剪切制造解通过；内面贡献相消、总V0和源量相同、H正性及张量交叉项正确。核对当前正式固体静止几何H/V，不能只测独立夹具。非法切分、超预算和负J须拒绝。

**交付：** `S2/topology-and-geometry-check.json`及覆盖变更的测试。失败先修复，不进入压力实验。

### S2.4 分开检查时间误差与网格差

**做什么：** 两网格分别用增广矩阵指数求压力、累计源量及各向排水，然后各运行最多64个固定压力步。内部节点可依新最快特征值及误差需要细化，但须精确落在全部物理观测点；细网格压力按真实交叠体积限制到公共区域。

**为什么：** 先确认每张网格的时间推进正确，才能把剩余差异归给空间离散。

**如何验收：** 每张网格在固定观测点的时间误差≤工程预算25%；质量账`1ᵀCp[p(t)−p(0)]+Qboundary−Qsource`闭合，耗散非负，无非有限值和异常振荡。全部24个非零观测点比较压力、含量及排水；三个旧失败点单列绝对差、相对差和预算比例。64步不足时记时间参照未分辨，不误判为空间通过。

**交付：** `S2/exact-time-reference.json`、`S2/fixed-time-check.json`、`S2/grid-comparison.json`。

**做什么：** 用静止态及小幅、满足边界的变形扰动，核对`V(q)`、方向导数、体积离散梯度、当前F下H和完整压力力。继承一般混合LU及缩放，但独立计算原方程残差；对缩放前后的线性系统作同状态核对。

**为什么：** 固定网格压力通过，还不足以证明压力对固体做功和固体体积变化彼此一致。

**如何验收：** 体积梯度与有尺度的有限差分/方向作用一致，`∇̄V·Δq=ΔV`在数值预算内；压力交换项相抵，H正且Darcy耗散非负。保留变形后完整张量交叉项。不能用缩放残差掩盖原方程某块超差，也不能沿用固体SPD/CG假设。

**交付：** `S5/volume-work-check.json`、`S5/mixed-operator-check.json`，包括CPU/GPU所参与计算的实际范围。

### S5.3 运行两个网格的短耦合并分别验收

**做什么：** 每网格按同一已登记前缀运行不超过8步，原始记录压力、含量、边界流量、源量、固体反力、固体/总PK1、体积、动能、压力功、边界储液池功和耗散。压力按公共物理区域比较，不直接reshape平均。

**为什么：** 只看压力平滑或总能量接近，会漏掉源项、功交换和应力度量错误。

**如何验收：** 工程场量、分块原残差、质量、能量、非负耗散、J及边界分别通过；实际结束时刻与协议一致。区分`solid_PK1`和`total_PK1`，反力重建包括完整压力作用。最多保存每网格4显示帧。本步只授予短耦合范围，不等于整个固定压力终点或日常完整加载场景通过。

**交付：** `S5/coupled-scene-check.json`、逐步账本和公共点比较。发现明显异常先定位；不改材料或储存参数来取得稳定结果。

### S5.4 验证耦合状态的完整事务和新进程恢复

**做什么：** 对一个具名网格覆盖提交前异常、子状态准备失败、指针前/后写入异常；失败必须恢复q、v、预测器、p、区间流量、含量、累计边界量、累计源量及规则身份。选两步在新进程拆分恢复，与最多额外两步未中断见证比较。

**为什么：** 流体历史未回滚会在后续造成质量和压力功漂移，单看位移无法发现。

**如何验收：** 指针前失败状态与指针不变；指针后故障只接受一次；新进程重核来源和边界，并与见证的全部物理状态/历史一致。一般程序错误不能伪装成可重试数值失败。价值对象事务通过不等于外部C/E对象原子集成通过。

**交付：** `S5/transaction-and-restart.json`、`S5/coupling-scope-decision.json`。`coupled_q5=false`、`production_C_E_integration=false`仍保留。

## 10. S6：唯一最终主场景、q5与发布（4步）

### S6.1 冻结最终数值来源并检查受影响依赖

**做什么：** 冻结正式空间、252或364步表、S4性能选择和本轮实际源码。针对协议拒绝、算子、事件分级、非均匀映射、缓存及事务运行覆盖变更的检查。为未来发布重新建立29步证据映射，按真实结果推导状态，不能沿用旧seal.py的固定阶段状态。

**为什么：** 来源、时间表、空间或性能路径变化都可能使旧证书失效；封存阶段不能混用不同实现产生的结果。

**如何验收：** M7/原材料与稳定化不变，所有新源码在清单中，原封存哈希不变。依赖变化必须有同状态等价或有预算重验的证据；检查数量由覆盖需要决定，不为凑数量重复测试。此后若改数值源码，相关测试、许可和案例身份须重新评估。

**交付：** `S6/numeric-lock.json`、`S6/targeted-tests.json`、`S6/dependency-closure.json`。

### S6.2 运行唯一q7完整周期并验证实际前缀

**做什么：** 在最终实现下，仅运行一条选择时间表的q7完整周期至1.6 s，252或364步，最多12显示帧。检查所有原始步及各加载阶段的反力、应力、速度和能量。若选择364步，按S1.5检查真实初态与前缀，需要时使用预留192步复验第二短窗。

**为什么：** 局部参照初态正确，不代表整个修改时间表传播到后续仍然正确；最终周期是采用新默认的必要证据。

**如何验收：** 形态、边界、原始残差、J及能量正常；原始峰值位置/时刻没有无解释的异常。252步且数学路径不变时可核对父版系数；364步必须按公共物理时刻和公共区间冲量比较，禁止直接zip两条不同长度历史。重要观测范围内的实际前缀检查通过才采用364步，全局时间精度仍未认证。

**交付与失败处理：** `S6/full-scene.json`、`S6/raw-physical-check.json`、`S6/actual-prefix-review.json`。364步场景或前缀门槛失败，不追加第二条新q7完整周期；新数据保留为研究结果，日常入口继续指向本文BASELINE的252步封存案例。必须使用父版实际来源及只读入口，不能把旧案例重新标成新源码运行。

### S6.3 重新认证q5并验收唯一日常周期

**做什么：** 只在最终q7路径通过后，对真实q7轨迹重新做q7/q8充分性、q5/q7能量/内力/弱应力矩/切线检查，覆盖加载峰值、两个短窗及至少一个未用于证书设计的附加时刻；方向覆盖混合扰动与实际敏感模态。冻结精确时间节点、空间、M7、材料、初态和最终数值来源，再运行唯一q5完整周期。

**为什么：** 旧许可绑定旧来源和旧时间路径；同一空间也不能自动继承。材料压缩只改变材料积分。

**如何验收：** q5/q7在全部公共状态及区间反力满足工程预算，实际3个材料哨兵通过。故障注入验证整步回到初态、q7重算、缓存场使用正确活动规则，以及新进程恢复；旧空间/旧来源/错质量/跳过时间节点/未知初态/不同加载/越界终点应拒绝。q5未通过时新默认用已通过q7；q7未通过则本步不触发。

**交付：** `S6/qualification.json`、`S6/q5-scene.json`、`S6/scope-rejections.json`、`S6/fallback-and-restart.json`。敏感完整周期与耦合q5不开放。

### S6.4 更新文档、可视化和带范围的发布

**做什么：** 汇总29步及预算实际用量，记录每项passed_scoped/limited/not_triggered/failed。可视化包括最新可用主场景、原始反力/能量、短窗相位、压力早期误差及候选研究范围；形变倍率说明与数值数据分开。记录源码/输入/协议/案例/成果/文档哈希及真实数据盘链接。

**为什么：** 后续使用者需要知道具体哪条路径能用，研究成功、局部成功和正式默认必须能追溯。

**如何验收：** 所有步骤有证据；未触发不写通过。若新主路径未获资格，发布为研究结果并明确`default_release=BASELINE`，只读查看委托给父版入口，不能将旧案例包装成新实现。实际检查PNG、GIF帧解码、HTML数据和本机HTTP资源；未做浏览器交互不得声称按钮已测。最终全量审计来源、快照、成果、文档及祖先，封存后禁止原地续算。

**交付：** `requirement-audit.json`、`capability-matrix.json`、`release.json`或明确的研究发布清单、独立实施文档、`S6/visualization-check.json`。发布模式及通过门槛在S0预登记，不能在失败后修改旧发布以隐藏失败。

## 11. 依赖和停止规则

| 发生变化或失败 | 必须采取的处理 | 可以继续的独立工作 |
| --- | --- | --- |
| 最新父版/源码/空间与本文不一致 | 先核查差异，更新新基线和受影响验收 | 只读分析，不盲目运行旧协议 |
| S1重要性无法证明或细化无实用收益 | 保留252步，报告未分辨事件 | 固定压力、候选短动力学、性能 |
| 364步在完整前缀下失去短窗资格 | 保留研究数据，默认继续父版252步；不追加完整试验 | 已完成的独立压力与候选研究 |
| 新压力网格时间或空间门槛失败 | S5不触发，保留所有节点原始差异 | 纯固体S3/S4/S6 |
| 候选空间映射/动力学失败 | 不推广候选，不修改正式空间 | 正式空间全部工作 |
| 性能候选改变方程、缓存失效或收益不足 | 不采用，恢复本轮基线实现选择 | 正式场景和有条件耦合 |
| 时间表/数值来源改变 | 重新认证当前轨迹q5；旧证书只属于旧案例 | 已证明等价且标明继承的研究证据 |
| 负J、质量秩异常、错误压力功或部分提交 | 深入定位；未解释则停止依赖分支 | 来源独立且不受影响的检查 |

不把“同空间”当作“同初态”，不把“时间误差小”当作“网格正确”，不把“新静态空间更准”当作“可直接换日常动态空间”，也不把“方程等价”当作“旧来源许可仍有效”。

## 13. 本轮实施完成的判定

完成本计划意味着：最新版本和输入可核查；关键观测量及时间范围预先确定；已有失败压力节点获得有依据的改进或明确瓶颈；现有候选取得可追溯的短动力学结论；性能采用有证据；满足前置条件时才有短耦合；最终主路径、q5及回退分别有证据；所有限制和未触发分支均记录。
