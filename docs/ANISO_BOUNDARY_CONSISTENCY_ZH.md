# group4x8 的空间插值、夹持与加载一致性

> 接入门槛结论：[对齐积分的生产接入验收](ANISO_QUADRATURE_PRODUCTION_GATE_ZH.md)。3³ 材料积分验证通过，但真实 Lite 传递/历史不匹配，直接 MLS 集中质量还会出现负值；暂不接入生产，不宣称完整 MPM 加速。

> 最新验证：[对齐材料积分的参考、压缩与成本结果](ANISO_QUADRATURE_VALIDATION_RESULTS_ZH.md)。两个网格与有限变形核对支持对齐 3³ 点作为候选；生产传输/历史兼容和整步加速尚未建立。

> 后续测试计划：[材料积分的参考、压缩与成本验证](ANISO_QUADRATURE_VALIDATION_PLAN_ZH.md)。按同空间稠密参考、刚度模式检查、采样压缩及公平成本比较推进；该页为待实施计划，不表示新增实验已经通过。

本轮完成静态诊断：固定原材料、粒子、`group4x8` 的采样位置/参考体积/方向矩，不加质量或稳定化，分别改变夹持、加载读取方式；随后单独检查一个全局插值候选。没有修改生产场景的边界、历史传递或默认求解路径。

结论是：**节点夹持确实没有准确固定 MLS 材料面，但它只能解释部分偏软。** 对现有局部材料场，约束每个参与拟合的局部面、配合 MLS 加载，可降低位移偏差；仍不能宣称整体空间精度通过。简单把局部 MLS 混合成全局场，会暴露新的积分不足，暂不接入生产。

实现：[trace_probe.py](../engine/aniso_phase1/trace_probe.py)、[aniso_boundary.py](../benchmarks/aniso_boundary.py)。数据：[results/boundary-consistency](results/boundary-consistency/)。上一轮：[分组积分与稳定化组合](ANISO_GROUPED_QUADRATURE_ZH.md)。

## 1. 明确原实现实际使用的插值

原分组材料积分使用每个中心自己的固定多项式拟合：

\[
 u_c(x)=\sum_iN_{ci}(x)u_i,\qquad G_c(x)=\nabla u_c(x).
\]

不同中心的拟合不保证在同一位置给出同一位移。因此，仅说“采用 MLS 位移”还不够，需要说明读取哪个局部拟合，或如何组合它们。

本轮引入一个明确的材料面读取方式：

\[
 \bar N_i(x)=\sum_cw_c(x)N_{ci}(x),\qquad
 \bar u(x)=\sum_i\bar N_i(x)u_i,
\]

其中 \(w_c\) 是原三线性中心分区，和为 1。为完整覆盖边界，允许对没有材料体积的中心构造节点拟合，但不增加材料体积或积分点。局部值和梯度复用相同的 P2+xyz 拟合，生产梯度 API 保持不变。

这一读取方式保持常数、仿射和相应多项式再现，但**不自动把原来的局部材料算子变成全局连续位移场的算子**。

## 2. 固定材料刚度，单独比较边界和加载

所有 `local` 案例使用完全相同的 \(K_{group}\)。夹持有四种：

- `nodes`：原节点夹持，x≤0.25 的节点系数归零。
- `blended_face`：精确约束材料夹持面上的 \(\bar u(x_g)=0\)。
- `patch_faces`：进一步要求每个参与的局部拟合都满足 \(u_c(x_g)=0\)，避免不同拟合的位移互相抵消后平均为零。这是针对现有多局部场的较强约束，不等于已经推导完成通用动态边界法。
- `sparse_face`：仅少量面采样点归零，作为漏约束控制。

材料面约束通过 SVD 去除冗余行，求零空间 \(Z\)：

\[
 Cu=0,\quad u=Zy,\quad CZ=0,
\]
\[
 \Pi(y)=\tfrac12 y^TZ^TKZy-y^TZ^Tf,\qquad
 (Z^TKZ)y=Z^Tf.
\]

没有惩罚刚度、质量正则化或按参考位移调参数。密集面用每格 6 个间隔（含边缘），再用不同的 7 个间隔检查；6→8 加密的约束秩一致，解的相对变化小于 5e-12。少量采样点归零则不保证整片面固定。

加载与位移始终使用同一映射 \(L\)：

\[
 \bar u_{tip}=Lu,\qquad f=L^T\bar f,
 \qquad f^Tu=\bar f^T\bar u_{tip}.
\]

分别使用原 Lite 读取和 MLS 读取；固定相同物理端面、均匀面力、总力 -1e-4。端面平均位移和加载功由同一个泛函定义。独立全积分 Q1 参考也改成相同的均匀面力与面积平均位移。

因此，本轮原配置的位移偏差为 43.9%/17.5%，与上一轮 42.7%/16.6% 略有区别：**参考梁的端面载荷从“等节点力”统一为“均匀面力”了**，不是生产结果发生了变化。

## 3. 两个网格的结果

物理梁尺寸 0.5×0.125×0.125；μ=10、λ=20、kf=200，统一 x 方向纤维；PPC=2³。粗/细网格分别 256/2048 粒子、1280/5184 个材料点。没有时间推进。Q1 本身仍有离散误差；下列百分比表示与该数值参考的差异，不是已知连续体真解误差。

| 配置（相同材料 K） | grid 17 位移 | 偏差 | grid 33 位移 | 偏差 |
|---|---:|---:|---:|---:|
| 原节点夹持＋Lite 加载 | -0.0008133246 | 43.91% | -0.0007073603 | 17.46% |
| 只改为 MLS 加载 | -0.0008280836 | 46.52% | -0.0007180861 | 19.24% |
| 混合材料面夹持＋MLS 加载 | -0.0007743429 | 37.01% | -0.0006817939 | 13.21% |
| 各局部材料面夹持＋MLS 加载 | -0.0007310603 | 29.35% | -0.000669181 | 11.12% |
| 独立 Q1 参考 | -0.0005651773 | — | -0.0006022269 | — |

只改加载没有消除偏软；精确夹持可改善结果，但仍有明显剩余误差。仅约束混合位移为零时，各局部拟合在夹持面还可能有相反的非零位移；这也是加入 `patch_faces` 对照的原因。

力控制下，夹具 y 总反力都应为 +1e-4，不能以总反力相同证明刚度相同。为了比较反力，利用线性系统的齐次性，把加载端面平均位移统一为 -5e-4，得到所需加载力：

| 配置 | grid 17 加载力幅值 | grid 33 加载力幅值 |
|---|---:|---:|
| 原节点夹持＋Lite 加载 | 6.147607e-05 | 7.068534e-05 |
| 只改为 MLS 加载 | 6.038038e-05 | 6.962954e-05 |
| 混合材料面夹持＋MLS 加载 | 6.457088e-05 | 7.333595e-05 |
| 各局部材料面夹持＋MLS 加载 | 6.839382e-05 | 7.47182e-05 |
| 独立 Q1 参考 | 8.846782e-05 | 8.302519e-05 |

这是**端面平均位移控制**，并非将整个加载面刚性锁定；由原线性解精确缩放获得，没有另跑动态加载。

原节点夹持下，独立 MLS 面检查位移约 9.8e-6/5.2e-6；各局部面约束后，混合面与各局部面的位移均低于 2e-19。所有静态案例的合力、力矩及功一致性也已记录。

## 4. 全局场候选为何没有推广

若真的把 \(\bar u\) 作为材料位移场，必须使用完整梯度：

\[
 \nabla\bar N_i
 =\sum_c\left(w_c\nabla N_{ci}+N_{ci}\nabla w_c\right).
\]

不能漏掉分区权重的导数。该分支明确改变材料 K，结果与“只改边界”的试验分开保存；`group4x8` 的位置、体积与方向数据保持不变。

导数、仿射再现、夹持约束和反力平衡都通过了，但采用完整材料面夹持＋MLS 加载后，位移偏差反而约为 **155.9%/34.9%**。其最小刚度特征值仍为正，却比局部场小很多。这再次说明“没有零特征值”不能代替空间精度检查。

针对这个明显异常，固定粗网格的同一份解 u，不重新求解，只改变能量读取密度：

| 读取方式 | 弹性能 | 相对原 group8 |
|---|---:|---:|
| 原分组八点 | 7.23045e-8 | 1 |
| 原粒子位置读取同一全局梯度 | 6.93896e-7 | 约 9.60 |
| 同组均值/协方差模板，3³ 点 | 2.17678e-6 | 约 30.11 |
| 同组均值/协方差模板，4³ 点 | 9.14198e-7 | 约 12.64 |

模板加密保持同组均值、二阶空间矩、正体积和总体积，但不代表真实材料分布的精确积分；3³/4³ 读数也没有收敛。**这些对照证明新全局场在采样点之间出现了原八点能量没有可靠控制的变化，不能把原分组规则对平滑已知 F 的成功直接推广到这个求解空间。** 未通过增加稳定化、改变材料参数或随意加密到看起来正确来掩盖问题。

另外，`sparse_face` 的约束点虽然可精确归零，点间面位移却可能很大；它没有通过完整夹持面验收。查看器保留这些失败对照，生产求解未启用它们。

## 5. 验证与下一步

- 静态查看器已通过 HTTP 200 与限时启动/退出检查；未进行浏览器截图检查。
- 18 项测试通过，覆盖局部形函数值/梯度一致、完整全局梯度有限差分、材料面约束、反力/功平衡，以及原分组和二次重建回归。
- 真实 GPU 稀疏材料核上，局部和全局候选都按非局部材料面约束投影；势能梯度、解析切线有限差分误差小于 1e-9，去质量 matvec 与独立静态装配相对差约 1.2e-13。
- 所有静态矩阵都去除了质量与稳定化。约束通过消元完成，保留对称性；未对增广拉格朗日乘子系统直接使用 PCG。
- CPU 完成小型静态装配/谱分析；GPU 核对自动选用最低显存设备，本轮为 cuda:0。继续采用既有容量保护，无触发迁移或暂停。

后续建议分两条处理：对现有局部材料场，先保留本轮精确材料面约束作为参考，继续检查局部场之间的相容性和材料支撑；若要改成全局场，应先研究与该空间匹配的积分及缺失模式控制，再考虑动态接入。**本轮不支持“只把节点夹持换成 MLS 面夹持就能解决全部偏软”的结论。**

## 6. 最新命令

重新生成两个网格的静态对照、异常能量读取与 GPU 核对：

```bash
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m benchmarks.aniso_boundary \
  --grids 17 33 --energy-control --gpu-check --device auto
```

查看本轮的静态形状、夹持误差及反力对比：

```bash
.venv/bin/python -m demos.aniso_boundary --port 8084
```

浏览器打开 `http://127.0.0.1:8084`；远程机器先用 `ssh -L 8084:127.0.0.1:8084 yin@服务器地址`。蓝色为所选方案，绿色为全积分 Q1，红色为独立夹持面检查点。默认放大 50 倍，只改变显示。切换 MLS/Lite 显示读取不会重新求解，也不会改变表中的加载共轭位移。

原生产 `demos.aniso` 命令保持原行为；本轮的静态查看器不能视为已经接入新动态夹持。
