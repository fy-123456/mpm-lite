# 插值—传递—质量—历史重建：小规模一致闭环原型

后续[模板切换验证](ANISO_TEMPLATE_REMAP_ZH.md)已完成：嵌套细分保留历史并可推进短程运动，非嵌套移动节点/粗化的应力与历史偏差未通过，不提交为动态状态。

后续力学精度验证已完成，见[一致 Q1、准确积分 MLS 与细网格参考](ANISO_MECHANICS_COMPARISON_ZH.md)。相容历史闭合不等于空间解准确；本例 grid 33 的整体响应达到约 2%～3% 差异，局部应力精度仍需另外验收。

## 1. 本轮范围与设计选择

对应[材料积分计划](ANISO_QUADRATURE_VALIDATION_PLAN_ZH.md)与[生产接入未通过的原因](ANISO_QUADRATURE_PRODUCTION_GATE_ZH.md)，本轮先构造一个能实际更新多步的独立一致性基线。

采用**随材料移动的 Q1 模板 + 一致质量投影 + 相容弹性历史**。这是 Lagrangian 有限元式研究原型，不是把原来的 Eulerian MLS 修好，也没有把生产 `group4x8` 或默认求解器替换成新方案。不同插值空间之间的精度还需要独立比较。模板会随材料变形，不具备固定背景网格 MPM 的自动重划分优势。

选择它的原因：Q1 权重非负、支撑紧凑，充分采样时质量可解；其形状、空间梯度与参考梯度能严格对应。先确认在一个可控空间中闭环成立，再判断生产空间需要保留哪些能力。它不是已选定的最终算法。

## 2. 同一套插值如何贯穿全部环节

保存材料参考坐标 $X$、粒子参考体积与参考纤维方向；一帧内形函数 $N_i(X)$ 固定。

$$x_h(X)=\sum_iN_i(X)x_i,\qquad F_h(X)=\sum_i x_i\otimes\nabla_XN_i(X).$$

在当前空间读取速度时：

$$v_h(x_h(X))=\sum_iN_i(X)v_i,\qquad G_h=(\sum_i v_i\otimes\nabla_XN_i)F_h^{-1}.$$

因此同一更新严格满足：

$$x_p^+=x_p+\Delta t\,v_h(x_p),\quad F_p^+=(I+\Delta t\,G_h)F_p,$$

$$F_h^+=F_h+\Delta t\sum_i v_i\otimes\nabla_XN_i.$$

只要初始 $x_p=x_h(X_p)$ 且 $F_p=F_h(X_p)$，粒子乘法更新与材料场预测相同。Q1 是插值型基函数，固定整个左端面的节点就严格固定该面任意点；测试还读取面内非节点位置，避免只验证节点值。

## 3. 质量、传递与历史恢复

使用正粒子质量构造：

$$M=N^T\operatorname{diag}(m_p)N,\qquad Mv=N^T\operatorname{diag}(m_p)v_p.$$

对应粒子加权最小二乘投影。实际惯性使用完整一致质量；正的行和集中质量只用于变量缩放，没有替换实际动能。每轴至少两个粒子，并显式检查质量谱；欠采样直接拒绝，不截断负质量、不静默添加正则项。

对于已经位于该空间的粒子速度，P2G/G2P 往返精确；一般粒子速度的 PIC 投影会损失未被空间表示的动能。无夹具投影分别测试总动量、角动量及动能不增加。带夹具的外部冲量不能算作自由系统动量误差。

历史恢复只从粒子位置读取节点位置：

$$M\widehat x=N^T\operatorname{diag}(m_p)x_p,\qquad \widehat F_q=\sum_i\widehat x_i\otimes\nabla_XN_i(X_q).$$

**恢复时不读取更新前的节点解作为答案**；独立保存的 $F_p$ 用于相容性检查。若它与恢复几何的梯度不一致，明确报错。这一边界至关重要：原型没有解决任意独立预应力、塑性历史、断裂或重划分后的历史表示，不会把这些状态擅自改成几何梯度。

在本空间可表示的变形增量上检验：

$$\mathcal R\mathcal T\,\delta F\approx\delta F.$$

方向在材料参考坐标中随点携带；空间积分点分别读取自身方向，未将整个中心的方向统计复制给所有点。

## 4. 材料能、求解与验证

复用相同的 Hencky 等向能与二次纤维能参数 $(\mu,\lambda,k_f)=(10,20,200)$，批量实现能量和精确一阶 Piola 应力，并与现有本构逐点对照。

$$\Phi(v)=\tfrac12(v-\hat v)^TM(v-\hat v)+\sum_q V_q^0\psi(F_q(x+\Delta t v),A_q).$$

$$r=M(v-\hat v)+\Delta t\,\nabla_xU.$$

没有额外稳定化。使用全积分 Q1 的独立小应变刚度检查无质量的夹持空间，并对照新能量梯度的有限差分。对有限变形势能检查方向导数、切线对称性。

此 CPU 原型使用带显式 Armijo 回溯的 L-BFGS：它只需精确能量/梯度，适合先隔离传递问题。**没有实现新的解析矩阵自由 Hessian 或生产 PCG 路径**；生产求解器推荐并未因此改变。反转试探步必须回溯，终止必须满足缩放残差，而非只检查能量变化。

初次 grid 17 实验定位到 SciPy L-BFGS-B 首次单位长度试探导致单元反转：返回无限能量后退回初值，却报告相对函数值收敛（残差约 $2.99\times10^{-4}$）。独立残差检查拒绝了该步。修复为显式回溯的有限内存 BFGS；未放宽本构、质量或历史检查来绕过问题。

## 5. 实验与产物

实验使用 grid 17/33，固定参考域 $[.25,.75]\times[.4375,.5625]^2$、体积/质量 $0.0078125$、相同初始弯曲、平滑纤维方向场。测试均匀伸长、弯曲、平移、随机可表示模式和三个最软的全积分 Q1 参考模式。整体姿态变化采用精确旋转，不将 Euler 时间积分误差误判为客观性误差。

短程释放执行真正的“恢复 → 粒子速度投影 → 隐式求解 → 粒子位置/F 更新 → 再恢复”循环；不在帧间直接保留节点状态冒充历史恢复。

本轮使用 CPU。启动时 NVIDIA 驱动无法连接，未声称完成 GPU 验证。磁盘预检约系统 11 GiB、数据盘 36 GiB，无需迁移；实验入口继续检查容量，系统盘低于 2 GiB 时迁移可重建缓存，合计低于 5 GiB 时停止。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m unittest tests.test_aniso_consistent_transfer -v

```

浏览器打开 `http://127.0.0.1:8086`；若浏览器在另一台机器，先做 SSH 端口转发：`ssh -L 8086:127.0.0.1:8086 yin@服务器地址`。回放显示独立原型数据，不启动生产 MPM。默认显示位移放大 10 倍，可调为 1 倍。

回放已完成本机 HTTP 冒烟检查：返回 200（818656 字节），定时退出码 0。受限沙箱不允许绑定网络套接字，因此这项检查在允许本机绑定的环境中执行，并绕过环境代理访问 localhost。新增绑定预检，避免无法创建服务时一直等待。没有将 HTTP 成功宣称为浏览器截图或人工视觉验收。

结果写入 `docs/results/consistent-transfer/`：JSON 为完整验收记录；CSV 为每步能量、残差、历史恢复及夹具误差；NPZ 为逐帧回放数据。测试结果见下节，不能由机器精度的闭环一致性推断空间解已经接近连续真解。

## 6. 结果与后续边界

**一致性基线通过；生产接入未在本轮完成。** 9 项新增测试与相关既有测试合计 **28 项通过**。两个网格各执行默认、时间步减半、积分阶数提高、粒子密度提高，共 **8 组短程实验**。所有闭环检查通过；验收没有把低耗散或完整 MPM 加速计为已通过。

基准为每轴 2 粒子、每材料单元 $3^3$ 积分点、$\Delta t=.001$、6 步：

| 指标 | grid 17 | grid 33 |
|---|---:|---:|
| 模板节点 / 粒子 / 材料积分点 | 81 / 256 / 864 | 425 / 2048 / 6912 |
| 一致质量最小特征值 | $1.253\times10^{-6}$ | $2.117\times10^{-7}$ |
| 一致质量条件数 | 114.72 | 121.38 |
| 独立同空间夹持全积分刚度最小特征值（均匀纤维、去质量） | 0.00473 | 0.00112 |
| 非零变形模式增量恢复最大相对误差 | $1.22\times10^{-9}$ | $2.08\times10^{-9}$ |
| 模式重建弹性能最大相对误差 | $1.90\times10^{-12}$ | $1.10\times10^{-12}$ |
| 平移 + 精确 45° 旋转后能量相对变化 | $-3.30\times10^{-13}$ | $-1.03\times10^{-13}$ |

| 夹持面位置最大误差 | $2.67\times10^{-15}$ | $3.89\times10^{-15}$ |

平移的理论 $\delta F=0$，不对零分母报告相对增量误差。弱模式是本轮 Q1 参考空间的模式，不是把原 MLS 最弱模式无损转成了 Q1。表中的高精度来自相容空间内的代数闭合，不意味着 Q1 能准确表示任意连续弯曲或更高阶模式。

提高至 $4^3$ 积分点后，初始材料能的相对差约 **0.0550% / 0.000590%**；最终机械能差约 **0.0761% / 0.00206%**。这表明本场景 $3^3$ 已足以作为一致性检查规则，不是对所有大变形状态的积分保证。每轴粒子数 2→4 时总质量和物理时间保持不变，质量条件数改善到约 64.27 / 69.44；恢复检查继续通过。粒子加密也改变质量积分，所以动态轨迹不要求完全一致。

### 6.1 释放耗散仍然明显，但来源已分开

固定物理时间 $T=.006$：

| 网格 | dt=.001，6 步，机械能变化 | dt=.0005，12 步，机械能变化 |
|---|---:|---:|
| 17 | -23.4484% | -18.4595% |
| 33 | -32.4082% | -24.9257% |

初始能量分别约 $3.7110\times10^{-6}$、$3.5499\times10^{-6}$。这些是该预弯曲形状释放的机械能比例，不能称为“已经达到低耗散”。网格更细会包含更高频率模式；本轮没有完成动态时间精度收敛，不应把两网格能量差全部判为纯空间误差。

对于本次无外载、零速度夹持的闭环，显式记录：

$$\Delta E=\Delta K_{projection}
-\tfrac12(v-\hat v)^TM(v-\hat v)
\underbrace{+[U(x^+)-U(x)-\nabla U(x^+)\!:\!\Delta x]}_{\text{弹性能离散余项}}
+v^Tr+\Delta U_{history}+\Delta K_{readback}.$$

其中内积对所有节点与分量求和；$r$ 是原势能梯度，$\Delta x=\Delta t v$。质量/历史恢复与求解误差分别记账。弹性能余项在沿更新路径凸时非正，但不对任意有限变形预设该符号。

dt=.001 时，以初始能量为分母的累计贡献：

| 来源 | grid 17 | grid 33 |
|---|---:|---:|
| 惯性离散余项 | -10.4803% | -13.4984% |
| 弹性能离散余项 | -12.9681% | -18.9099% |
| 求解残差做功 | -0.000019% | +0.000051% |
| 速度投影 / 历史恢复 | 接近舍入误差 | 接近舍入误差 |

结论是：**本原型的闭环传递不再主导损失，但后向欧拉在该释放场景中仍明显耗散。** 不能将此结论外推为旧 MLS/Lite 传递问题已经消失。原始预算与对照数据分别见 [默认两网格](results/consistent-transfer/v1/results.json)、[减半时间步](results/consistent-transfer/half-dt/results.json)、[积分加密](results/consistent-transfer/order4/results.json)、[粒子加密](results/consistent-transfer/ppc4/results.json)。

### 6.2 下一阶段

下一步应比较该一致基线与原 MLS 空间的弯曲精度、夹持响应及总成本，再选择“更紧凑且传递兼容的空间”还是“MLS 配套可解的一致质量与更丰富的历史”。材料模板大变形畸变、稀疏网格重划分、APIC 仿射动能、多材料/接触不在本轮验收范围。材料内层只访问固定积分点，但历史/质量投影仍依赖粒子数，尚无完整 MPM 加速结论。
