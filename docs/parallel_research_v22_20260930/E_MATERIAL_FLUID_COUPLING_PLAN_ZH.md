# 任务 E 各向异性材料与流固耦合计划

本计划只规定后续工作，本次未修改本构、加入流体求解器、运行新实验或安装依赖。基线为已完成的本地 v22，身份与并行规则见 [00 基线与并行合同](00_BASELINE_AND_PARALLEL_CONTRACT_ZH.md)。源码包 SHA256 为 `136529c866133aac10af77126c839f12a2769073ee5ec964f46dcadeca7adee4`，共同核验 488 个源码条目、131 个成果条目；本地没有 Git 元数据，不使用虚构提交号。

允许 float64、Warp 及当前 CPU／GPU 工具链，优先现有依赖。目标仍为本仓库 MPM Lite 研究，不迁移到 NovaPhy，不把另一个项目的原生 CUDA 成绩并入本计划。

## 范围、起点与物理选择

第一条实施主线固定为：**各向异性饱和渗流 → 固液动量双向反馈与阻力耗散 → 可变形骨架耦合**。起步固定现有固体空间和完整材料积分，先独立验证流体压力／Darcy 问题。不能同时更换空间、时间算法、材料、接触、孔隙率和压力离散，再将误差归因于某一个环节。

现有 [constitutive.py](../../engine/aniso_phase1/constitutive.py) 使用基体能量与双边二次纤维能量 `0.5*k_f*(I4-1)^2`；纤维受压时仍有响应，不是已标定的真实织物。现有 [AnisotropicLiteImplicitSolver](../../engine/aniso_phase1/solver.py) 明确只支持一个材料族；[方向矩研究](../ANISO_STABILIZATION_MOMENTS_ZH.md) 中四阶矩的精确性只适用于共同 F 和该二次纤维能量。非均匀 F、受拉开关、指数纤维或塑性历史均需重新验证压缩表示。

原生产路径已有 water 材料枚举和体积压力响应，见 [types.py](../../engine/types.py)、[helper_constitutive_model.py](../../engine/kernel/d3/helper_constitutive_model.py)；这不能证明已经具有不可压压力投影、饱和渗流或各向异性固液双向耦合。[旧研究概况](../ANISO_FLUID_RESEARCH_OVERVIEW_ZH.md) 可作物理背景，但其 9 月 27 日数值状态不能替代 [v22 最新报告](../ANISO_LITE_GRIP_HIGH_ORDER_ZH.md)。

v22 的空间候选全域应力差仍为 12.96%，新空间未接入移动动力学；E 不以这个候选作为耦合准确性的真解。耦合原型优先使用小规模、独立验证的完整固体积分／空间，对接口研究与生产 Lite 接入分别验收。

## 模型合同必须先明确

| 量或方程 | 本轮必须明确的含义 |
| --- | --- |
| 弹性方向与渗透方向 | 弹性结构张量决定骨架应力；渗透张量决定流体相对运动。两者可以共享材料方向，但数值参数、演化律和验证分别定义 |
| 饱和度与孔隙率 | 本轮饱和度固定为 1，不新增无物理用途的饱和度演化状态；孔隙率 n 为孔隙体积分数，不把二者当同一变量 |
| 渗透率 | 明确采用本征渗透率 K（单位 m²），Darcy 通量 `q=-(K/mu_f)*(grad(p)-rho_f*g)`；若存储的是导水率，须另列单位与换算，不能混用 |
| 相速度与通量 | `q=n*(v_f-v_s)` 是相对体积通量，不是流体真实速度；所有阻力、边界流量和守恒统计使用同一约定 |
| 耦合动量 | 流体与固体承受大小相等、方向相反的交换力／冲量；压力、外力与阻力的归属清楚，避免重复计算 |
| 孔隙率演化 | 若采用不可压固体颗粒假设，可用 `n=1-(1-n0)/J_s`，但仅在该假设及合法 n 区间内成立；非法状态拒绝或缩步，不靠裁剪 n 隐藏守恒错误 |
| 渗透张量演化 | 固定材料方向到空间方向的旋转／变形映射需显式定义，并保持 K 对称正定；不把弹性 A0 原样当作渗透率 |
| 压力与可压缩性 | 分清压力拉格朗日乘子、有限储水系数和惩罚体积压力；本轮基准不能靠任意增大体积模量替代稳定的压力离散 |

建议先采用低相对雷诺数、饱和、单流体、无相变、无毛细作用的模型。Darcy 简化、相惯性保留和骨架惯性的组合在每个基准中单独说明；不同方程层级的结果不直接当作同一算法的性能对照。

## 分步实施

### E1 冻结固体与耦合假设

**做什么：**固定小规模固体空间、完整材料积分、材料参数、夹持与初态；定义相质量、孔隙率、速度、压力、渗透率及单位；采用私有 adapter

**为什么：**先隔离流体／耦合误差，不让 v22 尚未解决的空间误差污染结论

**产出：**模型合同、状态表、输入哈希与维度检查

**如何验收：**单相极限恢复所选固体离散，零流体／零耦合时不改变其能量和内力；每个参数有单位和合法范围

**失败处理：**合同不自洽先修定义，禁止边实现边悄悄更换方程

### E2 材料与方向接口检查

**做什么：**以现二次纤维模型为控制，检查 ISO/F0/F45/F90、混合方向和旋转；完整积分保留方向—变形配对；暂不压缩新增流体状态

**为什么：**材料坐标、空间坐标和参考历史混用会直接污染耦合应力

**产出：**能量／应力／切线接口、材料方向变换测试、共同 F 与非均匀 F 控制

**如何验收：**客观性、势能方向导数、内力切线一致；共同 F 下可验证已有 A2/A4 精确性质，非均匀场不套用该结论

**失败处理：**退回完整积分；不平均相互不相容的 F、方向或历史使结果“平滑”

### E3 固定骨架各向异性 Darcy

**做什么：**在规则域实现 SPD 渗透张量的稳态压力与通量，做轴对齐、旋转 45°、多渗透率比和边界通量问题；先用解析／制造解

**为什么：**这是可独立推进、无需移动固体的最小各向异性流体基准

**产出：**压力场、通量场、质量守恒与网格收敛报告

**如何验收：**三档网格，压力／通量 L2 差建议最细 <1%；旋转问题按同一坐标合同等价；纯 Neumann 问题固定压力规范并检查兼容条件

**失败处理：**先查张量旋转、单位、法向与压力零空间；不靠压力对角平移消除建模错误

### E4 压力离散与近不可压稳定性

**做什么：**对混合位移／速度—压力表示选择可验证的稳定离散或一致稳定化；测棋盘压力、储水系数趋小和渗透率对比；区分物理储水与数值稳定化

**为什么：**原 water 压力本构不能自动提供稳定的饱和耦合压力空间

**产出：**离散弱式、压力规范、Schur／块算子接口和独立组装小例

**如何验收：**无额外压力零模态；合理网格加密下降；稳定化参数与网格有明确关系，不能只凭曲线平滑判定

**失败处理：**若出现锁定／振荡，保留失败例并调整离散；不得任意加大可压缩性掩盖问题

### E5 双向阻力与耗散

**做什么：**先做两个均匀相质量块／均匀场的相对速度衰减，再接离散网格；隐式处理刚性阻力，记录相交换冲量

**为什么：**最小模型可以隔离动量作用反作用与阻力刚性，不依赖复杂边界

**产出：**解析指数衰减对照、总动量账本、阻力耗散账本

**如何验收：**孤立系统总动量守恒；耗散非负；小步长收敛到解析衰减；大步长稳定性与准确性分别报告

**失败处理：**力不平衡查映射对偶与相质量；出现负耗散拒绝该步，不能用额外阻尼补偿

### E6 单向到双向孔弹性基准

**做什么：**固定同一骨架空间，从给定压力加载到流体压力／骨架位移共同求解；先一维固结，再二维／三维斜向渗透；各自声明线性化、惯性和储水假设

**为什么：**用可复现基准验证压力—体积变化反馈，再进入非线性

**产出：**固结压力、位移、流出体积、参考曲线和空间／时间加密数据

**如何验收：**同一物理模型的解析或独立离散参考；最细压力／位移相对差建议 <2%，全局质量缺陷建议 <1e-6；瞬态早期另给绝对误差

**失败处理：**分别定位固体、流体和交换误差；不以力平衡接近代替压力／位移验收

### E7 统一时间步与能量账本

**做什么：**建立动能、骨架弹性能、外功、储水能（若模型包含）、Darcy／黏性耗散、数值误差账本；比较一次分区、迭代分区和必要时单体求解；向 C 提交耦合子步骤要求

**为什么：**流体反馈可能使独立稳定的两个求解器组合后不稳定；不能沿用固体无耗散表述

**产出：**耦合残差定义、子迭代准则、时间细化与失败回滚协议；最终总事务由 C 负责

**如何验收：**独立解析流体基准至少三档 dt，完整固体加载循环遵循 00 的四档要求；物理耗散非负；质量、动量、能量分别合格；时间误差与空间误差独立，迭代未收敛不能提交历史

**失败处理：**缩步／增加合法耦合迭代或回滚；数值损失单列，不归入物理阻力耗散

### E8 骨架变形与状态携带

**做什么：**保持同一固体空间，加入 n、K 和方向随变形更新；对体积变化、刚体旋转、恢复与重启分别验证；冻结／trial／commit／rollback 覆盖所有相状态

**为什么：**非线性渗流最容易在历史转移、孔隙率和渗透方向上破坏守恒

**产出：**状态更新图、可接受初态条件、重启与失败注入测试

**如何验收：**`0<n<1`、`det(F)>0`、K 正定；刚体旋转只改变坐标表示；重启与连续运行一致；失败步不改 committed 状态

**失败处理：**非法状态拒绝并保留诊断；不裁剪 n/K 后继续声称守恒；任意旧快照迁移未验证则显式拒绝

### E9 耦合范围与稳健性矩阵

**做什么：**扫描渗透率比、纤维角度、骨架刚度比、流固密度比、加载速率、边界压力和网格；保持完整材料积分

**为什么：**避免仅在单一 F45 盒体或弱耦合条件下有效，分清方程简化的范围

**产出：**参数矩阵、失败地图、关键无量纲参数及适用区间

**如何验收：**每类工况都有独立质量／动量／能量指标和压力／应力分区检查；不能用平均指标隐藏局部穿透或压力振荡

**失败处理：**高对比失败先缩小声明范围；不自动引入塑性、毛细或改夹持模型“改善”已有基准

### E10 Lite 接口与 GPU 集成

**做什么：**将已验证流体／交换算子交由 D 适配；先冻结固体空间接设备实现，再对通过 A/C 验收的新空间做另组实验；最后与 B 协作研究新材料的分组积分／状态压缩

**为什么：**科学模型正确、Lite 压缩可接受和 GPU 高效是三项独立结论

**产出：**E 独立结果、D 接口包、完整积分／压缩控制组及 CPU／GPU比较

**如何验收：**先恢复 E1–E9 关键结果，再验压缩的质量／能量／历史误差；完整端到端时间含压力、交换、映射、同步和材料更新

**失败处理：**不能通过时保留完整积分版本或独立 E 原型；不因 GPU 方便改动耦合方程，不更新旧默认

### E11 交付与后续物理分支

**做什么：**汇总通过范围、真实误差、成本和限制；将仅受拉多纤维、非饱和／毛细、塑性损伤和自由液面表面耦合列成独立后续合同

**为什么：**防止“材料+流体”演变为没有可验收终点的全物理项目

**产出：**可复核结果索引、状态/接口说明、采用与暂缓清单；后续模型问题表

**如何验收：**饱和渗流与双向耗散主线单独验收；未做的物理明确不支持；新本构不能继承二次纤维四阶矩精确性

**失败处理：**主线未通过时不靠展示复杂场景宣称完成；可选分支不阻塞已验证部分交付


## 建议的数值与物理验收约定

上述 `1%`、`2%`、`1e-6` 是待运行前冻结的建议门槛，不是当前已实现结果。采用无量纲化和固定基准尺度；压力或总动量为零时同时报告单位明确的绝对误差，不能只用随瞬态变化的小分母。

建议在 float64 小型解析基准中，将孤立阻力交换的总动量相对缺陷目标设为 ≤1e-10，完整耦合循环质量缺陷目标设为 ≤1e-6；能量账本残差相对已定义能量尺度目标设为 ≤1e-6。具体门槛需结合离散残差、时间步和累计步数冻结；不得把有限时间积分误差强行要求为机器零，也不能放松门槛直到所有算例通过。空间／时间收敛和局部场精度仍必须另外检查。

作用反作用检查在**实际施加到两相的离散冲量**上执行，不能只比较理论公式。阻力耗散按相对速度与交换力的同一时间离散计算；骨架弹性可储能，流体阻力可耗能，两者均与数值投影损失分开。边界通量、外部压力功和重力势能的符号在 E1 中统一。

压力系统存在规范自由度时明确施加零均值或指定压力；混合系统通常不能未经证明当作 SPD 问题使用 PCG。允许 D 研究块 Schur 预条件或适合的 Krylov 方法，但不通过修改物理压力约束制造正定性。

## 独立产出与集成完成的界限

E1–E9 的独立成功说明所选固体空间上的饱和渗流与耦合模型得到验证，不意味着生产 Lite 已支持该物理。E10 还需验证粒子／中心／网格状态组织、历史、边界、设备与失败行为；新局部空间的移动动力学必须另有 C 的证据。E11 的后续可选物理不纳入本轮主线完成条件。

完成报告至少给出固体和流体 DOF、材料／动能／流体积分点数、相质量、孔隙率范围、渗透率特征值、压力与应力误差、耦合迭代、各项能量及端到端成本。新结果使用新 `run_id`，不覆盖 v22 或其他方向结果；没有执行的测试、CUDA 验证和真实材料标定全部明确列为未完成。
