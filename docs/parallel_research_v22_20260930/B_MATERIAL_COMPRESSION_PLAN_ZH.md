## 目标、已有证据与边界

目标是在同一个已冻结的材料空间、材料法则和材料历史下，减少每次残差及切线计算的材料评估量，同时给出误差、失败回退和完整成本的证据。B 不改变空间基函数、运动学、物理质量、惯性积分、边界功或历史迁移公式；后四项由 C 负责。不能通过恢复中心均值、减少局部自由度或修改材料参数换取速度。

目前有三条必须保留的事实：

- [v22 空间报告](../ANISO_LITE_GRIP_HIGH_ORDER_ZH.md)已经完成静态研究，最终 Q4 重叠支撑相对当前参考的全域/内部应力差为 12.96%/13.35%，空间 2% 门槛未通过。B 可以在此固定空间研究材料积分误差，但不能把“压缩接近未压缩”称为连续体精度通过。
- [四阶方向矩](../ANISO_STABILIZATION_MOMENTS_ZH.md)对共同 F 和当前双边二次纤维能是精确压缩；非均匀 F 的位置—变形—方向相关性不由四阶方向矩自动恢复。[联合采样](../ANISO_JOINT_SAMPLING_ZH.md)已有正权分组与条件矩原型。
- [材料积分生产接入检查](../ANISO_QUADRATURE_PRODUCTION_GATE_ZH.md)曾否定“只换材料积分、保留不相容传递”的组合；[v10 局部历史](../ANISO_LITE_LOCAL_HISTORY_ZH.md)又明确恢复了逐粒子材料积分。本方向以同空间充分积分为正确性对照，不能沿用早期中心路径的加速数字。

材料势能基准写成

\[
U_{\mathrm{full}}(q)=\sum_{p=1}^{N}V_p\,\psi(F_p(q),A_p).
\]

候选采用固定正权样本或分组条件矩：

\[
U_{\mathrm{B}}(q)=\sum_{s=1}^{n_s}\widehat V_s\,
\widehat\psi_s(F_s(q)),\qquad \widehat V_s>0.
\]

能量、应力和切线必须来自同一个候选势能。不能单独拟合力后保留另一份能量，也不能用正定近似切线冒充精确材料导数。当前材料允许物理上的非凸切线；B 验收的是导数正确性及相对于未压缩离散的误差，不要求任意压缩状态的精确 Hessian 正定。

## 十一步实施安排

### B1 冻结同空间基线与可独立运行的小问题

**做什么：**读取 v22 已保存的基、网格、材料及结果元数据，选定 Q4 重叠支撑最终第六轮作为主要固定空间，另保留小型仿射/弯曲空间。记录空间、材料、积分及边界签名。只把未压缩材料算子接入本地适配器，暂不压缩。

**为什么：**B 的误差必须只来自材料积分；不应等待 A 的下一代空间才能工作，也不能把空间变化造成的应力变化算入压缩收益。

**产出：**基线清单、适配器协议、小问题输入、同空间未压缩结果格式；旧 v22 结果只读引用，新结果另建 run_id。

**验收：**无压缩适配器与原材料算子的能量、PK1、力和切线作用在相同输入下吻合；初态、自由度顺序、单位和参考体积完全可追踪。复用函数得到相同结果属于接线检查，另保留独立公式检查。

**失败处理：**先修正适配器或排序/单位问题；不减少自由度、不改旧源码、不启动压缩批次。

### B2 认证材料积分对照并拆开误差预算

**做什么：**在固定 v22 空间，按材料场分片建立充分积分；对线性多项式工况使用可证明足够的阶次，对非线性 Hencky 工况比较相邻更高阶规则。同步比较能量、材料力及切线作用，不只比较总能量。动能积分保持输入不变。

**为什么：**v22 的五点规则对所报告线性分片多项式比较足够，不代表任意有限变形的 Hencky 势能都被精确积分。

**产出：**积分自检表、统一量纲/归一化定义、压缩误差与积分误差分别保存的报告。

**计划门槛：**拟将对照积分不确定性控制在相应 B 误差预算的 10% 以内；此比例是本轮工程预算，不是理论误差界。最终预算在正式训练前冻结。接近零能量/应力时同时报告绝对误差，分母使用预先定义的物理尺度，禁止靠单位阵 F 或随结果变化的下限掩盖误差。

**失败处理：**继续对同一空间加密积分或将该工况标记为对照未认证；不得用它宣布压缩验收通过。

### B3 建立训练、验证及隐藏对照快照集

**做什么：**包含共同 F、非均匀拉伸、剪切、弯曲、有限刚体转动、不同纤维方向及方向混合；取加载、保持、卸载的冻结状态。至少设置“相同方向均值但不同方向分布”和“相同 F 均值但不同位置—F—方向配对”两组反例。按整条载荷/方向族划分训练集、开发验证集和最终封存隐藏集，记录各自身份。开发验证集用于 B6/B7 选规则和预算；最终隐藏集只在候选与协议冻结后打开一次。

**为什么：**随机拆分同一轨迹的相邻帧容易产生数据泄漏；仅拟合总能量会遗漏局部应力与高阶模式。

**产出：**不可变样本清单、训练/开发验证/最终隐藏三类标签、方向与应变范围、隐藏集验收入口。v22 最终独立空间参考不得用于反复调参后再充当独立测试。

**验收：**所有输入均可在同空间未压缩算子独立求值；刚体转动对应关系明确；非法 detF 场景单列为拒绝测试，不能与有效材料状态混在误差统计中。

**失败处理：**补齐缺失的载荷/方向族后重新冻结协议；若正式验收后调整规则、预算或扩充训练集，创建新规则版本并另设未使用的隐藏集；原隐藏集降为开发数据，保留原结果。

### B4 先实现正权位置—方向联合分组

**做什么：**以参考材料单元/不重叠材料分区建立正权样本，保留空间位置、方向分布和变形梯度关联。先比较实际代表点与分组空间矩＋条件二/四阶方向矩；保证参考总体积及预定低阶空间矩。对跨越方向突变或材料界面的分组直接拆分。

**为什么：**重叠的是运动学基支撑，不是材料体积；按每个重叠 patch 重复积分会双计材料。正权可避免人为负材料体积，但正权本身不保证积分充分或切线精度。

**产出：**可重复的分组器、正权规则、支持域覆盖与矩误差报告，样本数至少包含三个预先指定预算档。

**验收：**所有权重正、总参考体积闭合、材料区域不遗漏/不重复；共同 F 二次纤维对照恢复四阶矩的已知恒等式；非均匀 F 的误差按快照真实报告。

**失败处理：**增加局部组数或回到该材料分区的充分积分。禁止用负权、方向重置或丢弃难例换取目标样本数。

### B5 将能量、PK1 与精确切线接成同一算子

**做什么：**为同一压缩势能实现 energy、PK1、tangent_action。冻结一次 Newton/线性求解中用到的样本位置、权重和分组；试探状态由调用方的 F 映射产生。逐项验证变分导数、有限转动客观性、自由度排序和失败回滚。

**为什么：**状态驱动的规则选择若在 Newton 内变化，却忽略规则的导数，会破坏残差和切线一致性。

**产出：**CPU float64 参考算子、本地合同适配器、独立差分/虚功检查、trial/commit 记录。

**验收：**差分用多个扰动尺度检查收敛区间；沿用 00 的 CPU float64 小问题建议门槛：能量方向导数相对差 1e−6、切线方向差 1e−5、对称性差 1e−10，近零量使用预先声明的绝对尺度。精确切线和修改搜索切线分开命名；关闭压缩时恢复 B1 对照。GPU 路径尚未运行时明确标为未验收。

**失败处理：**先回到冻结规则与最小材料模型定位；禁止通过放宽最终求解残差或把有限差分结果当生产切线来掩盖不一致。

### B6 做固定状态精度—样本量扫描

**做什么：**冻结每个训练所得候选规则，在开发验证快照上比较总体能量、组装内力/残差、分区应力弱形式矩及预定方向集的切线作用。如果候选提供压缩应力重建，还需在共同物理探针上比较其重建 PK1；没有重建算子的候选只声明弱形式应力精度，不声明逐点压缩应力精度。切线方向同时包含随机向量、仿射、二次弯曲、软模态和应力敏感模式；报告最大值和失败工况，不只报告平均值。

**为什么：**积分能量接近不保证局部应力或刚度接近。求解器实际使用的是 force 与 tangent_action，不能只验材料点公式。在同一 F 上重新调用同一本构得到相同 PK1 是恒等接线结果，不能证明压缩积分准确。

**计划门槛：**快照能量、组装内力以及分区应力弱形式矩误差各不超过 1%，切线作用误差不超过 2%；若提供应力重建，其共同探针 PK1 误差也不超过 1%。组装内力在相同自由度排列与约束提升下比较，并保留夹具反力分量；应力矩使用预先冻结的常量/线性/局部虚应变探针。上述是 B 的阶段预算，不是已获得结果，也不是连续体空间 2% 验收。不能用被选压缩点上的本构恒等值代替验收；近零量采用 B2 的绝对预算。

**产出：**各预算档的通过/失败矩阵、样本压缩率、材料调用次数、规则构造与算子时间。

**失败处理：**只加密失败材料分区，或输出“该预算不可行”。若充分积分也失败，回退到 B2/B5；不继续宣布压缩成功。

### B7 仅在需要时比较正权经验积分候选

**做什么：**若 B4 在可接受成本下仍达不到 B6，再研究非负权重拟合；拟合目标包含同势能的能量、力及切线作用训练特征，加入参考体积/低阶矩约束。在线仍从拟合后的单一势能求导。

**为什么：**这一候选可能更紧凑，但对训练分布更敏感，应与无响应拟合的联合分组作独立对照，不能混称为同一方法。

**产出：**训练特征、约束、权重稀疏度、开发验证误差和离线构造成本；记录是否使用材料参数和响应训练。

**验收：**候选比较沿用同一开发验证集和 B6 门槛。最终选定 B4 或 B7 候选后，冻结规则、样本预算、阈值与回退策略，再由独立复核者打开 B3 最终隐藏集，检查未见方向、应变幅值与局部模式；即使不执行 B7 候选，也必须做这次最终验收。样本点数下降本身不算通过。

**失败处理：**开发阶段失败可保留 B4 最佳已验规则并停止该分支；最终隐藏集失败则该版本泛化验收不通过。若继续修改，按 B3 建立新的独立隐藏集，不沿用已看过的测试答案声明泛化通过。

### B8 设计可审计的重分组请求与局部回退

**做什么：**先研究整个窗口固定规则；确有必要再引入步间重分组。B 只给出新规则建议及同一物理状态的 ΔU_rule、应力/切线变化、误差指示和规则签名，由 C 决定历史/几何迁移及是否提交。新旧规则在同一 F、位置和方向下双算一次。

**为什么：**变化的积分表示本身会改变离散能量；它不是物理外功，也不能记成时间积分误差。B 不拥有权威几何/F 历史迁移或单方提交权限；可以提出本方向压缩样本内部状态的适配，由 C 按总事务顺序验证并提交。

**产出：**规则提案对象、逐分区回退标记、规则变化能量账本、接受/拒绝记录。

**计划门槛：**单次及累计规则变化必须满足正式轨迹前冻结的绝对能量预算，并单列占总误差的比例；不能仅要求净和很小，因为正负跳变可能抵消。

**失败处理：**拒绝新规则并保留旧规则，或在该区域回到充分积分；不得静默改 F、清空局部历史或添加能量抵消常数。

### B9 在 C 的共同动力学上验证完整循环

**做什么：**C 接口可用后，在相同空间、初态、动能、边界和时间算法下，只切换充分材料积分/压缩材料积分；完成加载—保持—卸载—末端保持，包含固定规则与规则变化两个独立实验。采用完整预定时间步档，不截短细档轨迹。

**为什么：**固定快照误差不代表反馈后的长期误差；C 没有完成新空间动力学时，B 不得自行拼接旧 v20 动力学。

**计划门槛：**相对同空间未压缩循环，分阶段和全程 PK1、原始反力以及阶段末/终态关键量的压缩增量误差以 1% 为目标，同时满足共同合同的全循环及各阶段 2% 时间门槛、最细相邻差收缩要求和 B8 的规则变化预算。近零反力绝对差单列。该检查只是压缩增量误差，不能将其与 A 的空间误差直接相加成严格误差界。

**产出：**完整轨迹、原始反力、每步状态/能量/规则变更日志及独立快照复算。

**失败处理：**先关闭重分组隔离误差，再提高失败区域积分预算；保留完整失败轨迹。若 C 本身未通过时间验收，B 仅报告受限对照，不宣布完整循环压缩通过。

### B10 联合 D 做真实成本与 CPU/CUDA 验收

**做什么：**CPU 对照通过后，将可批量材料评估和切线作用交给 D 的可选 Warp/GPU 后端。测量预处理、分组、主机/设备传输、材料评估、Newton/Krylov、诊断及回退的分别耗时；在相同误差与物理时长下比较端到端成本。

**为什么：**旧研究已证明小规模中心方案不一定快；规则构造、散射、增加迭代或频繁回退可能抵消积分点减少。

**产出：**CPU 与 CUDA 分开的数值验收、暖机后同步计时、独占设备的交错重复、峰值内存与数组占用分开报告；性能阶段关闭强制同步诊断但保留同结果复核。

**验收：**材料调用次数、实际迭代和每步总代价均可复核；任何加速结论同时给出规模、材料复杂度、误差水平及回退比例。未达到加速则如实交付正确性结果，不设置强制“必须加速”的通过阈值。

**失败处理：**D 后端不等价时保留 CPU 路径；性能比较受其他任务竞争时该批不作正式性能证据，另排独占时段，不重跑无关正确性批次。

### B11 交付可复现候选及接入/停止结论

**做什么：**封存规则、基线及版本签名、全部协议、失败与回退、CPU/CUDA 状态和成本表；向 A/C/D/E 提交明确能力边界。只有完整联合条件通过后，才在另行集成阶段讨论共享入口。

**为什么：**独立压缩通过不能替代整体算法验收；需要让后续集成明确复用哪一份规则、输入和证据。

**产出：**B 结论报告、材料算子包、规则资产、机器可读验收、重放命令及成果哈希。

**验收：**无压缩基线可重现；缺少 C 完整循环或 A 空间认证时对应总项必须为“未验收/未通过”，不能由局部测试数量替代。

**失败处理：**未达标规则继续作为实验选项保留；默认生产路径、旧报告和旧结果不变。

## 并行节奏与依赖

- 可立即独立推进 B1–B6：使用已归档 v22 固定空间及小问题，不等待 A/C/D/E 的新增实现。
- B7 由 B6 的失败证据决定，不预设必做；B8 的离线同状态规则变化检查可与 C 的运动学推导并行。
- B9 必须等待 C 提交与所测空间一致的动力学接口；A 若交付新空间，B 先记录新空间签名并重新验证积分，不把旧规则自动标为兼容。
- B10 与 D 协同，由独立复核者核对数值，D 汇总集成误差及成本；E 的新材料或耦合模型作为另一个版本输入重新验收，不自动沿用当前二次纤维模型的压缩结论。共享文件只在 D 的集成时段修改。
- 所有长实验预估内存、磁盘、核心数和设备；设置并发上限，性能批次独占测量资源。恢复运行按协议和源哈希匹配，不覆盖成功或失败记录。

最终成功条件是：在公开适用范围内，以明显较少材料评估满足预定同空间误差预算，并在完整反馈轨迹中保持一致性；是否提高整体 MPM 效率及是否达到连续体精度，分别由总成本和 A/C 的联合数值证据决定。E 的新物理接入后另作联合物理验收。
