## 3. 执行顺序、数学含义和统一验收

### 3.1 单进程顺序及分支

顺序固定为：**Q0 版本／实验准备 → Q1 内部参考 → Q2 函数预算 → Q3 时间相位 → Q4 材料资格与性能 → Q5 最小三维耦合 → Q6 最终集成和封存**。

- Q1 参考受限：Q2 仅保留设计诊断，不晋级；Q3/Q4 继续使用原 144 函数。
- Q2 有候选通过：先通过新空间质量和短动态资格，才允许 Q3 使用新空间；旧 q5 资格暂不启用。
- Q3 未获得有意义改善：保留现有 0.0125 s，不为了显示“进展”强行换时间表。
- Q4 q5 资格失败：保留充分积分；某项性能改动无净收益则关闭该改动。
- Q5 数学定义、秩或守恒在预算内无法通过：保留单独实验及问题报告，不接入日常固体主场景；Q6 仍封存已经通过的固体改进。

“参考受限”“无净收益”“未晋级”都是允许的结果，但必须列明被阻断的结论。任何分支都不准把不通过改写成精度通过。

### 3.2 不混淆空间、材料积分和时间积分

位移、变形梯度和 PK1 应力的关系为

\[
u_h=\sum_iN_ic_i+\sum_j\phi_ja_j,\quad F=I+\nabla_Xu_h,\quad P=\partial\Psi/\partial F.
\]

空间基函数决定能表达什么；材料积分决定如何计算该空间内的能量和力；时间积分决定如何推进其动力学。应力依赖位移导数，不能以形状相近替代应力比较。

材料积分与质量分别为

\[
U_{\rm mat}(q)\approx\sum_\ell w_\ell\Psi(F(q,X_\ell)),\qquad
M_{ij}=\int_{\Omega_0}\rho_0\psi_i\psi_j\,dV.
\]

原空间的材料 q5/q7 切换不改变 M5。新高阶参考的质量必须按新基函数重新检查，不能强制所有新空间也用 M5。固定原载体 Ks 的能量与导数含义，不给新增函数擅自添加惩罚，不用人工质量掩盖秩问题。

### 3.3 实用误差预算与不可省略的检查

对同位置的场量，沿用加权 RMS：

\[
e_r=\sqrt{\frac{\sum_{k\in r}w_k\lVert y_k-y_k^{\rm ref}\rVert^2}{\sum_{k\in r}w_k}},
\qquad e_r\le a_y+0.05\lVert y^{\rm ref}\rVert_r.
\]

| 对象 | 默认实用预算／要求 |
| --- | --- |
| 位移 | `a_y=5e-5 m`，加 5% 参考尺度 |
| 物理速度 | `a_y=1e-4 m/s`，加 5% 参考尺度 |
| PK1 与纤维方向 PK1 指标 | `a_y=0.02 Pa`，加 5% 参考尺度；纤维指标固定为单位参考方向的 `aᵀPa`，不混用 Cauchy 应力 |
| 反力 | `1e-4 N + 5%`；不同步长按同区间冲量平均比较 |
| 材料 U／内力／弱矩 | 沿用当前资格中的混合绝对项与 2% 相对项；切线作用相对项 3% |
| 原物理算子的适配／CPU-GPU 一致性 | 沿用约 `2e-5` 相对预算及量纲明确的绝对项；这类一致性检查与物理空间误差分开 |
| 变形、边界和求解 | 无 NaN/Inf；沿用 `min_detF>0.1`、边界 `1e-8` 和原真实残差条件；发现相对基线突变仍需分析 |
| 能量 | 保留材料、稳定化、动能、边界功、求解误差、路径积分误差及规则切换能量分账；原单类累计数值能量预算为能量尺度的 1% |
| 事务／来源 | 原已提交状态不能被失败试算改变；身份、哈希、原子发布语义不能因“数值测试宽松”而放宽 |

分区继续包括全域、夹持、过渡和内部。统一参考坐标位置、权重、应力度量和单位；新热点另加少量固定探针，不能在看到候选结果后移动探针规避误差。近零量采用绝对预算，不以近零值归一化制造巨大百分比。

以上是工程使用预算，不是应力 2%、反力 1% 的科研精度认证。不得把 q5 与 q7 的极小差异当作对真实解的误差，也不得只报告能量账本闭合余项而隐藏已单列的路径或求解误差。

## 9. Q5：以守恒闭合为先，建立最小三维耦合

### Q5.1 冻结一个可解释的三维共同模型

- **做什么：**沿用 [耦合接口说明](MPM_LITE_POST_RELEASE_COUPLING_INTERFACE_20261001_ZH.md) 的候选模型，先固定参考几何、固体空间、压力／流量空间、边界、Biot 系数 α、正储存系数 S、渗透率 k 和流体黏度 μ。现有二维参数可作为有单位的数值验证起点，明确不代表材料标定。
- **为什么：**当前二维已通过，但没有三维 C–E 力／流量交换；应先明确变量和物理意义再连接接口。
- **如何验收：**定义 m 为单位参考体积的流体体积含量增量；只有恒定密度且明确乘密度时才能换算为质量。选定一个封闭和一个排水边界小问题，参数、单位、源项和初态均登记。物理定义不一致时停止耦合分支，不改变固体主版。
- **交付：**`Q5/physical-model.json`、离散方程和参数表。

### Q5.2 从同一势能推导双向力与储存

- **做什么：**从

\[
\Psi(F,m)=\Psi_s(F)+\frac{[m-\alpha(J-1)]^2}{2S},\quad J=\det F
\]

推出

\[
p=\frac{m-\alpha(J-1)}S,\quad P=P_s-\alpha pJF^{-T},\quad
\dot m=\alpha\dot J+S\dot p.
\]

构造参考通量 `Q=-(J/μ)F⁻¹ k F⁻ᵀ ∇_X p`；压力力和体积变化使用同一离散 J、权重和导数。

- **为什么：**只有双向功共轭，才能避免耦合接口凭空产生或丢失能量。有限变形导数随 F 改变，二维常量 G 不能直接复用。
- **如何验收：**对少量有限变形方向检查能量导数与压力力、储存导数，真实矩阵作用与方向差分一致；有限时间增量的压力功必须使用与推进一致的离散梯度／积分，不能把连续链式法则直接当作离散能量证明。原固体 Ks 和完整惯性另列，不偷偷重定义。
- **交付：**`Q5/coupling-kernel-check.json`；第一版统一使用充分积分，固体 q5 证书不覆盖耦合积分。

### Q5.3 先检查混合空间秩和求解器适用性

- **做什么：**在小三维补丁上组装真实位移—压力—流量系统，检查压力零空间、边界约束及储存项作用。首先验证固定储存下的可解性，再做一个较小储存参数诊断，避免用较大物理储存掩盖空间不相容。
- **为什么：**当前固体独立自由度有限，大量逐单元压力自由度可能无法被位移空间正确约束；完整混合系统也不一定是 SPD。
- **如何验收：**秩亏能用已明确的物理零空间解释，约束后真残差达标；先使用一般稀疏直接求解建立小问题参照，再讨论块预条件。不能直接沿用固体 CG，不通过未经推导的压力罚项修补秩亏。
- **交付：**`Q5/mixed-rank-solver.json`；不通过时仅保留核与诊断，不接主场景。

### Q5.4 分离检查固体极限、流动极限和压力功

- **做什么：**依次测试零压力恢复固体、固定固体恢复流动、耦合封闭边界和排水边界；每个只运行 4—8 个小步。用同一耦合离散的固体压力功和流体体积功检查相消；检查体积含量变化、出入流量及源项。
- **为什么：**这些极限可以分别定位固体、流动或双向交换错误，避免完整场景失败后难以归因。
- **如何验收：**所有检查同时报告物理储存／边界功／Darcy 耗散和离散数值耗散；尺度正常时耦合质量及能量闭合目标为 1% 以内，并预登记量纲明确的近零绝对项。正定渗透率和 J>0 下 Darcy 耗散非负；二维旧报告仅作方法依据，不能算本步证据。
- **交付：**`Q5/limits-and-closure.json`，分别给出各极限结果和适用范围。

### Q5.5 验证整步事务，再决定是否接主场景

- **做什么：**外层同时管理固体 q/v、压力、流量、储存历史和加载时刻；在子求解完成后、整体提交前注入一次失败，再做真实新进程恢复。
- **为什么：**固体回滚但流体历史已前进，会造成隐藏的质量和能量漂移。
- **如何验收：**所有子状态在同一代次提交，任一失败恢复同一基态；恢复轨迹与不中断对照在预算内。只有 Q5.1—Q5.4 全部通过，才交付一个独立的最小三维耦合案例；先不替换日常纯固体默认入口。
- **交付：**`Q5/coupling-decision.json`；若受限，列清根因候选、已做检查和未实现范围。

## 10. Q6：最后做一次集成验收和来源封存

### Q6.1 冻结最终源码、空间、时间和规则

- **做什么：**汇总各阶段选择，包括不采用的候选及原因；固定最终数值源码和依赖哈希，明确空间包、质量、材料充分阶次、压缩资格、时间表、缓存和边界。检查旧基线仍完整，更新实施文档及真正存在的 CLI。
- **为什么：**避免验证后又修改数值入口，使结果对应不上交付代码。
- **如何验收：**最终身份不混用旧源码与新协议，能力分别列场景稳定性、相位、时间精度、空间参考、空间精度、规则资格、恢复、性能和三维耦合；新 CLI 已做短程验证，不公布仅拟建的命令。
- **交付：**最终配置与验收协议、当前实施记录。

### Q6.2 跑选定的完整固体周期并检查真实物理场

- **做什么：**在最终源码上只跑选定主方案的一个完整 1.6 s 周期，通常 128—256 步、约 12 帧。若正式采用 q5，另做同空间、同时间表的充分积分对照；若有相同冻结身份的现成果可直接复用。三维耦合保持独立的小步案例。
- **为什么：**短窗、参考及微型性能通过之后，还需确认加载、保持、卸载串联的实际运行效果。
- **如何验收：**检查所有阶段原始反力、速度、PK1／纤维场、det(F)、能量、规则哨兵和恢复；所有共同时间物理场及同区间冲量按工程预算比较。实际查看少量总览图，不以动画代替物理检查。若源码在验证后改变，只重跑受影响检查；不能将旧案例身份重写成新源码。
- **交付：**`Q6/final-scene.json`、少量 HTML／PNG／GIF，注明位移显示放大倍率和实际积分规则。

### Q6.3 封存并验证可继承性

- **做什么：**保存最终源码快照、成果清单、输入锁、本文快照、逐步骤执行审计和独立能力表；新发布索引以本轮直接父应用为来源。禁止继续向封存运行配置／推进案例，可视化输出写归档外。
- **为什么：**下一轮必须能够确认“最新到底是什么”，也能安全继承而不覆盖本轮。
- **如何验收：**重算全部新增源码与成果哈希及祖先链；核对链接实体可加载、旧发布未变；必要时另建仅两步的发布继承验证，不把该验证目录误标为新正式版。
- **交付：**`release.json`、`artifact-sha256.json`、`final-source-sha256.json`、`requirement-audit.json`、`capability-matrix.json` 和最新可视化命令。

## 11. 实验预算、异常处理和文档要求

### 11.1 预算上限

| 阶段 | 默认限额 |
| --- | --- |
| Q0 | 只读完整审计；新入口 2—4 步及一次恢复，不重跑旧完整周期 |
| Q1 | 两个新增参考 R2／R3；每个先估算，目标 600 s 内，硬上限 1,200 s；旧 R0/R1 数据可验证复用 |
| Q2 | 原空间加最多两个 144 函数候选；一个主状态、一个保留状态；最多一个候选进入 4—8 步动态资格 |
| Q3 | 两个 0.2 s 短窗、最多三档步长；新空间才需要一次最长 1.2 s 的共同前缀；不跑全部候选完整周期 |
| Q4 | 少量代表／独立状态；4—8 步回退与恢复；最多一个敏感变体；两个性能窗口，各最多三组对照，一次热点改动 |
| Q5 | 小三维补丁，分离极限／封闭／排水各 4—8 步；不做大规模三维长周期 |
| Q6 | 一个最终主周期；采用 q5 时最多再加一个匹配的充分规则周期，能复用同身份成果则不重跑；约 12 帧／周期 |

CPU RSS 默认不超过 16 GiB，GPU 计划内存不超过启动可用显存的 70%；参考构造应为临时量预留空间。高阶张量节点增长较快，应先估算稀疏矩阵、材料点和临时数组；超限优先缩小局部区域或停止该参考分支，不直接放开预算。

每个主要阶段和长任务前后检查磁盘余量。系统盘低于 5 GiB 时在最近已提交状态暂停推进，完成可追踪迁移后恢复。本文编写时只读检查了容量，没有迁移数据。

### 11.2 异常如何决定继续或跳过

| 情况 | 必须采取的行动 |
| --- | --- |
| 路径、参数未传递、CSR 布局、单位或普通接口错误 | 定位并修复，做针对性短验证后继续，不能借此跳过整个方向 |
| det(F) 突降、能量异常、秩改变、身份不匹配或失败后状态改变 | 保存最小复现、源码和输入身份，优先检查至多三类有依据的原因：实现／积分／模型或离散 |
| 根因明确且不改变物理定义 | 自行作局部修复，重验受影响路径，不重跑全部历史成果 |
| 涉及 Ks、惯性、压力功、质量或历史语义改变 | 先推导和做最小对照；不能用阻尼、罚项或人工质量掩盖问题 |
| 有界分析仍无根因 | 保留记录，停止依赖该结论的晋级，继续不依赖它的步骤；能力表明确未通过或未实现 |
| 没有明显收益或参考仍不可靠 | 保留原已验收方案，以“未采用／受限”交付，不为完成任务强行替换 |
