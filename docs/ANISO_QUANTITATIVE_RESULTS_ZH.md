## 1. 能量误差已经能够解释和量化

两层 APIC 动能为

`K = 1/2 Σ_p m_p (|v_p|² + tr(G_p D_p G_pᵀ))`，
`D_p = dx² diag(f(1-f)+1/4)`，`f=fract(x_p/dx-1/2)`。

这是实际粒子→中心→节点仿射速度表示的能量，`1/4` 是中心到节点的二阶矩。关闭 APIC 时仿射项为零；域边缘截断支撑时拒绝使用该闭式公式。弹性能为 `U=Σ_c V_c ψ(F_c,A0_c)`，使用参与当前步求解的中心参考体积和 committed 状态；机械能 `E=K+U`。当前能量账本限无重力场景。

Viser 显示 K/U/E 曲线，CSV 导出各项能量及变化量；每步 ΔE 拆成 P2C、C2G、边界投影、隐式求解、最终投影/阻尼、G2C/C2P 回传、中心体积重加权和历史状态重建。所有项均带符号，预算闭合是记账正确性检查，不是守恒证明。诊断需同步设备，性能测试关闭诊断。

能量实验统一使用 8³ 网格、μ=10、λ=20、k_f=200、密度 1000，每粒子参考体积 .001；固定块体 64 粒子，仿射场 125 粒子。各场景内部参数扫描保持相同粒子配置。

## 2. 指定速度拉伸与卸载

新增 `tensile` 场景，静止夹具 x≤.25，加载夹具 x≥.75，要求网格 9 或 17 使夹具对齐节点。加载位移由指定速度积分，随后反向等时卸载。小位移下使用固定空间夹具区域，同时记录粒子夹具实际平均位移；没有将它宣称为任意大位移、严格粒子无滑移的夹具模型。

反力采用实际离散动量平衡：

`F_act = Σ_grip [ m_i(v_i^{n+1}−v_i^{raw})/dt + Σ_c V_c τ_c ∇w_ic ]`。

`v_raw` 是 C2G 边界投影前的速度，因此包括初始边界投影冲量。反力正号表示夹具施加的 +x 力，CSV 分别记录弹性项和惯性项。每步加载功用末端反力乘该步指定夹具位移；固定端速度为零。

## 4. 同本构粒子 quadrature 公平对照

`ParticleQuadratureImplicitSolver` 在每次残差和 matvec 中逐粒子计算相同本构。保持 Lite 的质量/速度传输与 Kirchhoff 残差形式，粒子梯度 `Σ_c w_pc ∇w_ci` 合并成 27 节点 stencil，在每步重建、Newton/线性迭代内冻结。粒子 F 是基线的有效状态；中心版 matvec 不访问粒子本构。粒子恰位于中心时两版的一步位置/速度/F 一致；粒子基线的实际稀疏有限差分检查通过。

这是控制其他因素的 quadrature 对照，仍继承公共中心预留数组，不是内存/吞吐已经最优化的传统 MPM。显存数据如实包含公共预留成本，不能将全部常驻内存差解释为积分点数量差。

统一参考块 `[.25,.75]³`、体积/质量 .125、密度 1、μ=10、λ=20、k_f=200、45° 纤维、相同初始仿射速度梯度、FLIP=.9、T=.01 s、dt=.001、相同本构与收敛条件。网格改变时保持物理支撑；PPC 改变时每粒子体积为 `.125/Np`。初始加载是自由块体的仿射初速度，区别于上节的夹具加载。

每组独立进程，缓存预热后在启动时选中的同一 GPU 上交错重复三次。表格使用三次稳态平均步耗时的中位数，首步另外记录，不将编译算进稳态；诊断关闭，墙钟计时前后同步设备。显存为 CUDA 内存池峰值，不包含所有驱动/JIT 外部成本，整卡读数另存 JSON，不冒充进程峰值。

此范围内网格加密使两版相对数值参考的位移/F 误差降低；PPC 的 F 误差并非单调下降，不能据此宣称 PPC 收敛阶。固定 17³ 网格的高 PPC 组显示中心版耗时对粒子数更不敏感，但低 PPC/不同网格下的速度优势取决于迭代和运行负载，应同时查看误差与三次波动区间。粒子版通常有较小的参考误差，因此单步更快不等于同精度一定更快。本轮建立了这些权衡的可复现证据，没有将有限参数表推广为普遍性能结论。

原 PPC 探针也修正了总质量/体积：固定 `.02³` 体积、密度 1000，每粒子体积 `.02³/Np`。此前固定单粒子体积的历史表格不再作为公平证据。旧网格脚本的一步误差探针仍可作诊断，公平的同时间收敛比较以本节为准。
