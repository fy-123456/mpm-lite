## 1. 交付目标与范围

### 1.1 本轮要交付什么

在原 Lite 稀疏网格及粒子→中心→网格→中心→粒子传递框架中，交付：

1. 一个推荐的各向异性弹性材料配置和使用入口。
2. 一个实际 Lite 拉伸场景，展示各向异性关闭、开启以及纤维方向变化的差别。
3. 材料导数、方向性、旋转客观性、关闭各向异性和必要状态生命周期检查。
4. 一份反力—位移对照、有限时间步敏感性检查及支持范围报告。
5. 可复现的无头运行命令与已有 Viser 查看入口。

预期验收措辞：

> 原 MPM Lite 路径已支持并验证单材料、均匀单纤维方向的各向异性弹性，在给定场景和参数范围内展示了开启前后以及不同纤维方向的响应。定量精度仍受中心材料压缩、原有传递、边界和时间离散限制。

上述措辞是**将来通过验收后的目标**，不是本文件新完成的实验结论。

### 1.2 本轮不做什么

- 不改用最近研究的独立 `SpatialMPM` 求解器。
- 不引入完整一致质量、空间 B 样条、弱节点仿射约束或速度残差基函数。
- 不把 MLS、粒子材料积分、group4x8 等研究候选作为交付前提。
- 不扩展混合纤维方向精确表示、多材料、各向异性塑性、损伤、断裂或新的接触模型。
- 不做大规模网格扫描、长期循环、全面空间收敛或加速比研究。
- 不要求解决原算法所有的中心压缩、边界、传递和耗散误差。

这些工作继续保留在研究模块和已有报告中，不删除已有成果。

## 3. 执行顺序与规模上限

建议顺序：

1. 冻结支持范围和推荐配置。
2. 核对执行链并整理使用入口。
3. 完成最小材料与算子检查。
4. 核对方向、中心压缩和粒子历史生命周期。
5. 运行四组实际 Lite 拉伸展示。
6. 完成有限端到端回归和一档时间步检查。
7. 整理文档、结果和演示入口，结束本轮交付。

主场景规模先限定为四组材料配置、两档时间步，共八条正式轨迹。不因某个指标不理想自动增加方向、网格、材料模型或长期扫描。必要的启动冒烟和失败修复重跑单独记录；已有有效结果尽量复用。

本轮优先使用一个能容纳夹具及足够自由节点的小网格，不同时启动多个分辨率。拉伸入口支持夹具对齐网格 9 或 17；正式配置在步骤 1 固定。

## 4. 步骤 1：冻结支持范围、配置和对照基线

### 要做什么

1. 固定三维、单材料族、弹性、单一均匀参考纤维方向。
2. 建立一个命名明确的交付预设，初始配置如下。
3. 核对实际代码中的默认值，不依赖 GUI 隐含状态。
4. 记录代码快照标识；若工作区无 Git 元数据，保存相关文件哈希，不伪造提交号。
5. 所有正式对照共享同一份配置，仅允许改变 `k_f`、纤维角度及指定的粗细时间步。

| 配置项 | 建议起点 | 说明 |
|---|---|---|
| 求解器 | `AnisotropicLiteImplicitSolver` | 原 Lite 路径 |
| 材料积分 | `quadrature=center` | 保留中心压缩 |
| 方向模型 | `mean_tensor` | 首轮只承诺均匀方向 |
| 历史模式 | `particle_resample` | 使用当前推荐历史路径 |
| 力离散 | `variational` | 保留现有统一势能路径 |
| 稳定化 | `none` | 首轮不增加研究选项 |
| 线性求解 | 当前带曲率保护的 PCG | 保留已有正定近似回退及原势能线搜索 |
| 基底材料 | 现有示例的 μ=10、λ=20 | 起点，不是已验收范围 |
| 纤维强度 | 0 与 200 | 可复用现有示例参数 |
| 纤维角度 | 0°、45°、90° | 位于 XY 平面 |
| 网格 | 优先现有夹具对齐的小网格 | 9 或 17，正式运行前选定一个 |
| APIC/FLIP、采样、密度 | 复用当前场景并显式记录 | 四组必须一致 |
| 重力 | 0 | 与现有能量诊断支持范围一致 |
| 阻尼 | 使用一致、显式记录的设置 | 不以人为大阻尼掩盖问题 |

时间步、加载速率和总时长先用已有配置作小规模启动检查，再在正式四组运行前锁定。正式阈值和设置不能看完结果后为通过而静默修改。

### 为什么做

必须区分“增加材料方向性”和“换一种离散算法”。固定配置后，四组差别才能归因于纤维项，避免多个研究选项同时变化。

### 产出

- 一份正式配置记录，包含全部物理参数、数值参数、设备和精度。
- 一份明确的支持/不支持清单。
- 一个同路径 `k_f=0` 基线定义。

### 如何验收

- [ ] 四组配置差异可自动或人工逐项核对，除允许项外完全相同。
- [ ] 配置没有导入独立 `SpatialMPM` 或其他研究求解器。
- [ ] 材料、长度、时间、密度的单位约定一致。
- [ ] 不把建议起点误写成已经验证的参数范围。

### 不通过时如何处理

若启动检查失败，先判断是否为输入、配置或直接接入问题。若暴露中心自由机制或明显伪模态，不能靠大阻尼或惯性掩盖；可使用已有且针对问题验证过的处理，但必须记录配置变更并对所有组一致应用。若必须发展新算法才能运行，应报告该预设不具备交付条件，不自动扩张任务。

## 5. 步骤 2：核对材料接线，整理一个清晰入口

### 要做什么

按一次成功时间步检查下列执行链：

```text
创建材料参数与方向
    ↓
播种粒子 F、参考方向 a0 / A0
    ↓
P2C 形成中心材料快照
    ↓
C2G 与节点预测状态
    ↓
Newton trial F → 应力 → 残差 → 切线作用
    ↓
线性求解、曲率保护、原势能线搜索
    ↓
原 Lite G2C/C2P 更新与成功提交
```

具体核对：

1. CPU 参数正确传入设备材料计算，不存在 GUI 改角度但实际材料未更新的问题。
2. 应力、材料能和精确切线使用同一组 μ、λ、k_f、A0、trial F。
3. 原 Lite 的各向同性“应力→中心伸长”反演不能在各向异性路径中误用；保留现有子类避开该逆映射的设计。
4. 更新仍调用原 Lite 传递，弹性粒子使用正确的 F 更新，不误触发旧塑性材料返回映射。
5. 优先给现有子类提供推荐创建示例；只有入口明显重复时才增加薄工厂，不搬移整套求解代码。
6. 对未支持的材料组合和非法方向作清晰拒绝，不静默退回其他材料。

### 为什么做

公式单独正确还不够；只有进入每一步真实计算才构成可用功能。同时，保留成熟代码路径比重新组织整套求解器更容易控制变更范围。

### 产出

- 一个推荐创建入口或现有入口的最小使用示例。
- 一份“输入→材料→求解→提交”的接线核对记录。
- 必要的局部修复清单；已有正确部分不重写。

### 如何验收

- [ ] 推荐入口可完成材料创建、播种、边界设置和一个非零变形时间步。
- [ ] 运行记录表明实际采用 center/Lite 传递及各向异性材料算子。
- [ ] 同一状态改变 k_f 或方向后，方向材料响应确实改变。
- [ ] 无效方向、非法参数或不支持的组合被明确拒绝。
- [ ] 未启用新入口时，原 `MPMSolver` 的默认路径没有发生非预期变化。

### 不通过时如何处理

修复具体断点或参数传递，不以更换插值、质量或参考求解器绕过。若涉及结构重构，先评估能否用现有子类入口完成相同交付。

## 6. 步骤 3：复用本构，实现最小材料与切线验收

### 要做什么

保留当前材料，不新增能量模型。现有模型为

\[
\psi(F,A_0)=\mu\sum_i(\log\sigma_i)^2
+\frac\lambda2\left(\sum_i\log\sigma_i\right)^2
+\frac{k_f}{2}(I_4-1)^2,
\]

\[
A_0=a_0a_0^T,\qquad I_4=A_0:(F^TF).
\]

纤维应力和切线作用为

\[
P_f=2k_f(I_4-1)FA_0,
\]

\[
\delta P_f=2k_f(I_4-1)\delta F A_0
+4k_f[(FA_0):\delta F]FA_0.
\]

复用现有材料、Warp、变分算子测试，建立下面的必要检查清单。已有用例覆盖的项目不重复写测试。

| 检查 | 操作 | 验收含义 |
|---|---|---|
| 能量→应力 | 对少量固定合法 F 和扰动 H 做中心差分 | 应力是所用能量的导数 |
| 应力→切线 | 比较解析切线作用与应力中心差分 | 隐式线性化正确 |
| 初始状态 | F=I | 能量和应力符合参考态定义 |
| 方向归一化 | 输入等方向不同长度向量 | 得到相同归一化 A0 |
| 无向纤维 | 比较 a0 与 -a0 | 响应相同 |
| 关闭纤维 | k_f=0，改变方向 | 材料退化且方向无关 |
| 刚体旋转 | 合法 R，比较 F 与 RF | 满足客观性 |
| 非法状态 | 零方向、非正 Jacobian 等 | 拒绝，不产生有效提交 |
| CPU/GPU | 相同输入比较材料和切线作用 | 两端使用同一个模型 |

差分关系：

\[
\frac{\psi(F+\varepsilon H)-\psi(F-\varepsilon H)}{2\varepsilon}\approx P:H,
\qquad
\frac{P(F+\varepsilon H)-P(F-\varepsilon H)}{2\varepsilon}\approx\mathbb C:H.
\]

旋转关系：

\[
\psi(RF,A_0)=\psi(F,A_0),\qquad P(RF,A_0)=RP(F,A_0).
\]

用于方向拉伸的解析例子：F=diag(s,1,1)，a0=(cosθ,sinθ,0)，则

\[
P_{f,xx}=2k_f s(s^2-1)\cos^4\theta.
\]

在该指定均匀变形下，0°/45°/90° 的纤维应力增量比为 1:1/4:0。验收比较的是**纤维增量**，不是加上各向同性基底后的总应力比例。

### 为什么做

这些检查直接排除导数、坐标和参数接线错误。材料点解析结论不依赖空间网格，因此无需先获得高分辨率参考解。

### 产出

- 必要用例及其已有测试位置的映射表。
- CPU 和可用 CUDA 的运行记录、误差和使用的容差。
- 若有缺口，仅新增对应的小型用例。

### 如何验收

- [ ] 所有必要检查通过已有有效测试门槛；执行前把数值容差记录在清单中。
- [ ] 差分误差按量纲和尺度归一化；接近零的量使用绝对误差，不除以近零参考值。
- [ ] 精确切线通过导数检查；用于下降方向的正定近似切线另行检查，不要求等于精确 Hessian。
- [ ] GPU 未运行时明确标记“未验证”，不将跳过写成 GPU 通过。
- [ ] 说明当前二次纤维模型在压缩时也响应，不宣传为仅受拉纤维。

### 不通过时如何处理

先查公式、指标定义和设备实现；有限差分可用相邻的少量 ε 检查舍入影响。不得通过放宽容差掩盖系统性错误，不启动空间收敛扫描。

## 7. 步骤 4：核对参考方向、中心快照和粒子历史

### 要做什么

1. 固定推荐 `particle_resample` 历史模式。
2. 说明粒子 F/A0 如何构成每步中心冻结材料状态。
3. 确认 Newton/CG 重复计算只使用规定的冻结状态，不改变已提交历史。
4. 确认成功后粒子更新与中心提交时序；失败不更新粒子 x/v/F 和模拟时间。
5. 复用相关重编号、重采样和失败回滚用例，区分 `grid_locked` 与当前推荐模式。
6. 用一个均匀仿射一步检查确认 F 更新与方向坐标正确。
7. 显示纤维采用当前物理方向
   \[
   a=\frac{Fa_0}{|Fa_0|},
   \]
   不在每步把已转动的方向重新当成参考方向。

### 为什么做

各向异性不仅需要强度参数，还需要一致的参考方向和变形历史。方向重复旋转、中心状态与粒子状态混用，都可能让材料响应错误。

原 Lite 使用中心压缩，一般非均匀场中平均、本构和更新不交换。本轮不能承诺 F_center=F_particle，也不能把独立完整质量 MPM 的机器精度恒等式套到原 Lite。

同样，混合方向下通常有

\[
\mathbb E[(A:C-1)^2]\ne(\mathbb E[A]:C-1)^2.
\]

因此首次支持范围是均匀单方向；已有四阶矩和混合方向研究不作为本次交付门槛。

### 产出

- 历史所有权及提交时序说明。
- 均匀仿射、成功提交和强制失败回滚的检查结果。
- 中心/粒子差异的解释，不把该诊断值直接叫成材料公式误差。

### 如何验收

- [ ] 均匀仿射用例满足对应已有精度门槛。
- [ ] 重复残差/切线计算不会修改粒子和已提交状态。
- [ ] 失败步的粒子 x/v/F、模拟时间和步数不推进。
- [ ] 推荐模式的必要历史用例通过；旧模式结果不能冒充新模式结果。
- [ ] 纤维显示随实际 F 转动，显示放大不反向改变模拟或纤维方向。

### 不通过时如何处理

修正生命周期或坐标错误。若是中心压缩固有差异，记录限制而不自动切换为新 MPM；但不允许把实际历史丢失或失败后提交包装成压缩误差。

## 8. 步骤 5：四组实际 Lite 拉伸场景

### 要做什么

复用 `demos/aniso.py::Scene` 的 tensile 场景和 `tensile.py`。正式对照为：

| 编号 | k_f | θ | 作用 |
|---|---:|---:|---|
| ISO | 0 | 0° | 同一路径各向同性基线 |
| F0 | 固定正值 | 0° | 沿加载方向纤维 |
| F45 | 同上 | 45° | 斜向纤维 |
| F90 | 同上 | 90° | 横向纤维 |

具体操作：

1. 采用相同位移控制、网格、粒子位置、密度、夹具和传递参数。
2. 优先复用现有平滑加载的一段单调拉伸；卸载为可选展示，不新增多周期研究。若需要保持段，应先核对现有加载函数是否支持，不能把不存在的功能写成现成命令。
3. 检查夹具位置与网格对齐、加载位移单位、实测夹具位移与命令位移的差别。
4. 先运行无头轨迹，保存结果，再使用同一配置回放或展示。
5. 输出反力—位移曲线、代表性变形和物理纤维方向，不只保存末帧。
6. 保存求解状态、残差、detF、加载功和已有能量诊断；记录弹性/惯性反力分量。

位移控制下，方向刚度主要反映在反力：

\[
R_{\rm total}=R_{\rm elastic}+R_{\rm inertial}.
\]

显示等效刚度 R/u 时，跳过接近零的位移点；动态反力不直接命名为静态模量。

### 为什么做

四组使用相同位移，动画可能看起来相似，但反力会体现材料方向性。拉伸比弯曲更适合本次最小交付，避免把已知中心欠积分弯曲问题混入第一组展示。

### 产出

- 四组完整轨迹的配置、CSV/JSON 指标和需要的回放数据。
- 一张反力—位移叠加图及相同坐标/显示比例下的场景图。
- 失败或暂停位置记录，若全部成功则明确记录完整步数和物理时间。

### 如何验收

- [ ] 四组完整运行至约定终点，无 NaN、非法 Jacobian、虚假成功或失败后继续提交。
- [ ] 实测夹具运动与命令一致性有数据支撑；使用已有离散反力/动量检查，不只看形状。
- [ ] 方向响应符合材料模型；实际块体不强制满足材料点的 1:1/4:0 比例。
- [ ] 可见方向效应大于步骤 6 测得的数值时间扰动。
- [ ] 若惯性显著，明确按动态响应解释；要称为准静态时，必须提供相应的惯性分量证据。
- [ ] 图中坐标、单位、角度、刚度和显示放大一致且明确。

### 不通过时如何处理

先核对加载、方向显示、边界和反力定义，再查求解或材料接线。若惯性掩盖方向效果，可调整这一个场景的加载速率并对四组统一重跑。不能只选成功帧、不保留失败记录，也不通过切换参考求解器来替代实际 Lite 展示。

## 9. 步骤 6：有限端到端回归与时间步敏感性

### 要做什么

#### A. 三种“关闭各向异性”检查分别记录

1. 材料退化：k_f=0 时回到同一个 Hencky 各向同性能量/应力。
2. 同一路径方向无关：推荐配置下 k_f=0，改变 a0，粒子轨迹和材料响应不应出现系统性方向差别。用现有小规模回归，不再增加整套方向扫描。
3. 旧路径保持：原 MPMSolver 未启用各向异性时行为不发生非预期改变。

不得混淆：当前子类默认采用变分离散和粒子重采样，而旧 Lite 的中心重建/离散不同。不能承诺一般变形下两者逐元素相同。已有 `test_kf_zero_matches_legacy_one_step` 是指定 grid_locked 初态的一步回归，不是一般等价证明。

#### B. 一档减半时间步

四组分别运行 Δt 和 Δt/2，相同物理时长、加载函数和其余配置。将曲线对齐到共同物理时间或单调加载位移，不按帧编号比较。

例如定义反力曲线的相对差异：

\[
E_{\Delta t}=\frac{\|R_{\Delta t}-R_{\Delta t/2}\|_w}
{\max(\|R_{\Delta t/2}\|_w,R_{\rm floor})}.
\]

其中 w 为固定的时间/位移积分权重；R_floor 为正式运行前规定的物理尺度下限。接近零的反力同时报告绝对差异。

初拟展示验收目标为主要加载段 E_Δt≤5%；这是本次功能展示的时间敏感性目标，不是空间真解误差门槛。角度比较的差异应明显超过对应两条曲线的时间扰动之和；若没有超过，就不能把该角度差异当作已分辨出的功能效果。可以出现某些角度彼此接近，不强迫所有曲线都分离。

该指标、比较区间和阈值需在正式运行前固定。两档时间步只能说明本场景的时间敏感性，不足以宣称渐近收敛阶或全面时间收敛。

#### C. 复用必要测试

### 为什么做

### 不通过时如何处理
