# 修复后 F45：完整加载三档时间步与梯度历史对照

本轮按顺序执行两组实验：先对已开启边界冲量修复的原 Lite 路径进行完整 F45 加载，再只干预粒子变形历史所用的梯度，定位传递差异对反力时间敏感性的影响。生产求解器、默认配置与材料模型未改动。新增代码集中在实验运行器、诊断账本及其测试。

## 1. 冻结条件与执行顺序

方案见 [protocol.json](results/lite-aniso-mainline/v4/protocol.json)。CPU float64；保持网格 9、dx=0.125 m、192 粒子、密度 1、mu=10、lambda=20、kf=200、纤维 45°、中心积分、particle_resample、variational、mean_tensor、无稳定化、APIC、FLIP=0.9、无重力、无阻尼。开启 `boundary_impulse_transfer`，反力停止容差 1e-7 N。

加载命令不变：

\[
u(t)=\frac{0.005}{2}[1-\cos(\pi t/0.5)],\qquad0\le t\le0.5\ \mathrm s.
\]

终点位移 0.005 m。每组时间步为 0.001、0.0005、0.00025 s，即 500、1000、2000 步。两组合计 7000 步。每组在 t=0.05、0.1、0.25、0.5 s 保存冻结快照。

执行顺序：50 项必要测试 → 原修复路径三档 → 检查其物理验收与时间差趋势 → 梯度历史对照三档 → 汇总。GPU 已有其他负载，本轮不运行 CUDA。磁盘按既有资源守卫检查，主实验最多两个独立 CPU 进程，每进程单线程；补充冻结传递诊断使用一个单线程进程。没有使用子代理。

预先门槛：网格合力 x 残差及粒子三维合力误差 ≤1e-7 N；粒子/网格总动量差 ≤1e-14 kg·m/s；夹具网格速度误差 ≤1e-12 m/s；平均粒子夹具位移误差 ≤0.001 m；J>0；Newton 达到有效残差目标；冻结分解误差 ≤1e-12。反力时间步相对差采用既有 5% 门槛。

## 2. 三档时间步能说明什么

将三条曲线统一到粗时间步的物理时刻，在 t=0.05..0.5 s 用梯形积分计算 RMS。分别计算总反力、弹性反力、惯性反力：

\[
D_{01}=\operatorname{RMS}(R_{\Delta t}-R_{\Delta t/2}),\qquad
D_{12}=\operatorname{RMS}(R_{\Delta t/2}-R_{\Delta t/4}),
\]

\[
e_{01}=\frac{D_{01}}{\max(\operatorname{RMS}R_{\Delta t/2},0.001\ \mathrm N)},\qquad
e_{12}=\frac{D_{12}}{\max(\operatorname{RMS}R_{\Delta t/4},0.001\ \mathrm N)}.
\]

报告绝对差、相对差以及

\[
\rho=D_{12}/D_{01},\qquad p_{obs}=-\log_2\rho.
\]

只有当解已处于渐近区并近似 \(R_{\Delta t}=R_0+C\Delta t^p\) 时，\(p_{obs}\) 才能解释为收敛阶。本轮不会把三点拟合自动当作已证明收敛，也不会把两档曲线差当作对连续真解的误差。补充报告两次曲线差的相关方向（时间内积余弦），帮助判断差异形状是否一致。

原路径前 0.1 s 的反力与重合时刻的 x/F 快照对照 v3 修复开启的结果，要求误差 ≤1e-12，以排除诊断改变实际解。

## 3. 梯度历史对照只改什么

原路径的粒子梯度为中心梯度的插值：

\[
G_p^{prod}=\sum_cS_{pc}G_c,
\qquad F_p^{prod}=(I+\Delta tG_p^{prod})F_p^n.
\]

位置通过中心速度的 PIC 插值推进：

\[
v_{PIC}(x_p)=\sum_cS_c(x_p)v_c,\qquad
x_p^{n+1}=x_p^n+\Delta t v_{PIC}(x_p^n).
\]

对照使用该位置插值的精确空间导数：

\[
G_p^{PIC}=\sum_c v_c\otimes\nabla S_c(x_p^n),\qquad
F_p^{ctrl}=(I+\Delta tG_p^{PIC})F_p^n.
\]

每一步先完成相同的中心求解及生产传递，再仅以 \(F_p^{ctrl}\) 替换粒子历史。该步 x、v、用于 APIC 的 ptc_G、已提交中心 F、中心内力与切线不修改。下一步 P2C 才读取改变后的粒子 F。因此第一步两组反力应完全相同，后续反力差反映历史干预传播后的动力学差异。

这是实验账本中的显式干预，不是新的生产默认，不是已经建立离散功一致性的替代积分法。上轮制造解显示 \(\nabla v_{PIC}\) 未必比原梯度更接近解析真值；本轮不预设该对照能提升精度。

中心能量账本仍统计中心材料能，粒子 F 干预的材料影响在下一步重采样时进入账本。不能用账本闭合宣称这项实验干预守恒。

## 4. 同一状态的冻结诊断

每个选定时刻，先冻结该步干预前的实际生产更新。固定当前 P2C 体积权重 W，有：

\[
\overline{F_p^{prod}}-F_c^{new}
=\underbrace{\Delta t[\overline{G_pF_p^n}-\bar G_p\bar F_p^n]}_{C_{cov}}
+\underbrace{\Delta t(\bar G_p-G_c)\bar F_p^n}_{C_{grad}}.
\]

另计算移动权重项

\[
C_{move}=[W(x^{n+1})-W(x^n)]F_p^{prod}.
\]

跨时间步同时报告每步增量和增量除以 dt。单步差随 dt 下降并不等于累计影响消失：每秒的重采样次数也会增加。

为了看梯度差异如何传到非线性材料，使用相同中心 A0、相同当前中心体积，比较：

\[
P(F_c^{new}+C_{cov}+C_{grad})-P(F_c^{new}+C_{cov}),
\]

以及相同变形状态的弹性能差。这是固定状态中移除梯度项的有限差分诊断，不是把中心 F 强行覆盖回粒子的算法。非线性应力/能量的梯度项与协方差项有限差一般不能简单相加。

同时比较生产与 PIC 历史更新的中心平均 F、应力和能量，并在当前夹持区/自由区分别统计梯度差。快照保存旧粒子 F/x、两种粒子梯度、两种 F 更新、中心速度/坐标、中心 F/P、权重分解与粒子体积，以便独立重算。

## 5. 必要测试

原有 47 项检查加 3 项新测试，共 50 项全部通过：

- 同一步的历史对照只改变粒子 F，x/v/APIC G/中心 F/反力逐位一致；F 与独立插值导数更新相同；失败步不触发历史干预。

**判读与下一步：**

1. 已修复边界冲量的原路径在这三档没有显示收敛：相邻总反力差由 12.535% 增至 15.354%，绝对差也增加约 44.65%。观测阶为负只说明当前三档未进入可确认的收敛区，不能据此证明 dt→0 必然发散。所有物理检查通过，最大粒子合力误差 6.581e-10 N；不能继续把主要时间差归咎于遗漏边界冲量或当前停止条件。
2. 历史梯度干预改变了完整反力曲线（相同 dt 的 RMS 变化约 2.90%–4.12%），说明历史传递确实影响结果。但相邻差仍为 11.764%→15.062%，没有消除时间步依赖。这只否定“直接把 F 更新梯度换成位置插值导数即可解决”的方案，不否定进一步设计兼顾中心、粒子和离散功的传递算子。
3. 在原路径的同一冻结状态，PIC 导数候选的中心/粒子 F 平均差比原更新大约 13.9%–19.6%。位置与 F 的运动学一致，不自动意味着与中心材料求解一致；局部梯度项虽然主导已观测的历史更新差异，也不能把它的 RMS 比例解释成全局反力误差占比。
4. 补充无力冻结测试确认了另一独立机制：固定每步 FLIP/PIC 混合的速度平滑强度会随每秒传递次数变化，见下一节。这与完整轨迹的累计传递动能变化趋势一致，但尚未量化其对 F45 反力差的独立贡献。

下一轮优先做“按物理时间保持近似相同混合衰减率”的完整三档加载对照，再单独检查 APIC 梯度回传的频率效应。保持本轮边界冲量修复与反力容差，避免同时改历史梯度、材料积分和加载速度。候选若只改善时间差，仍需空间参考与材料功核对，不能直接宣称真实反力精度达标。

最终状态：物理检查 通过；冻结诊断 通过；两组最细相邻反力差同时达到 5% 否。完整指标见 [summary.json](results/lite-aniso-mainline/v4/summary.json)，独立证据核对见 [artifact-check.json](results/lite-aniso-mainline/v4/artifact-check.json)。


## 7. 补充定位：固定 FLIP 系数的传递频率效应

完整基线三档的速度传递累计动能净变化（P2C+C2G+G2P）分别为 -1.021e-5、-1.616e-5、-2.371e-5 J，对应加载功的约 15.20%、20.89%、25.83%。这提示速度传递也具有显著的步长敏感性；由于各轨迹和加载功本身不同，这些比值不是全局误差的因果占比。

为验证机制，另行冻结 [补充协议](results/lite-aniso-mainline/v4/frozen-velocity-protocol.json)：采用基线最细档约 t=0.25 s 的粒子几何与 F，固定粒子位置和 F，移除边界、外力及材料求解，给定同一个非均匀正弦速度及解析初始梯度。调用实际 P2C/C2G/G2C/C2P 内核，令网格新旧速度相同、粒子推进 dt=0，仅重复传递。20/40/80 次代表同一标称 0.02 s 区间内三档步长对应的传递次数；这不是实际积分了 0.02 s 的拉伸试验。

无网格速度增量时，粒子速度混合满足

\[
v_p^{new}=\beta v_p^{old}+(1-\beta)v_p^{PIC}.
\]

对于简化的固定线性 PIC 映射 T，某模态若满足 Tv=λv，则每次传递的倍率为 b=β+(1−β)λ，按物理时间计的衰减率为

\[
\gamma=-\log(b)/\Delta t.
\]

固定每步 β，改变每秒传递次数就会改变这种平滑强度。实际 APIC 还同时传递梯度，因此上述标量模态公式只是解释频率机制；以下数字来自实际耦合内核。

| 传递次数 / 标称 dt | 固定 β=0.9：非均匀速度范数保留 | 按标称 dt 调整 β：范数保留 | 纯 FLIP β=1：范数保留 |
|---|---:|---:|---:|
| 20 / 0.001 s | 90.68% | 90.68% | 100% |
| 40 / 0.0005 s | 85.18% | 90.22% | 100% |
| 80 / 0.00025 s | 80.38% | 89.97% | 100% |

调整形式仅作诊断：β(dt)=0.9^(dt/0.001)，即 0.9、0.948683、0.974004。它减小了冻结传递的频率差异，但没有在完整拉伸中验证，也不是对所有空间模态都精确匹配衰减率的公式。

所有冻结测试的 x/F 逐值保持，总动量误差 <3e-19 kg·m/s；纯 FLIP 的粒子速度逐值保持。然而纯 FLIP 的 APIC 梯度仍会变化，总动能并非保持，因此不能据此直接把 β=1 设为生产默认。

这个补充实验确认：**即使没有材料求解和 F 历史更新，仅增加传递次数，固定 FLIP/PIC 混合也能改变速度场。** 因而速度传递平滑是已确认的另一种时间步依赖机制；它对实际 F45 反力差的贡献大小还需要完整加载的独立系数对照。

## 8. 复现

在仓库根目录，使用新的输出目录，按顺序运行：

```bash
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
.venv/bin/python -m benchmarks.aniso_f45_refinement freeze --output /tmp/f45-refinement-repeat
.venv/bin/python -m benchmarks.aniso_f45_refinement tests --output /tmp/f45-refinement-repeat
.venv/bin/python -m benchmarks.aniso_f45_refinement run --stage baseline --jobs 2 --output /tmp/f45-refinement-repeat
.venv/bin/python -m benchmarks.aniso_f45_refinement trend --output /tmp/f45-refinement-repeat
.venv/bin/python -m benchmarks.aniso_f45_refinement run --stage pic_history --jobs 2 --output /tmp/f45-refinement-repeat
.venv/bin/python -m benchmarks.aniso_f45_refinement analyze --output /tmp/f45-refinement-repeat
```

分析退出码 2 表示至少一项冻结验收未通过，应读取 summary，而不是把完整运行等同于精度通过。历史对照是实验运行器专用模式，未增加到生产演示的默认选项。

每条轨迹保存逐步 JSONL、CSV、21 帧独立 x/F、4 份 JSON/NPZ 冻结审计和运行状态。此前 v1/v2/v3 成果原样保留。该实验不提供空间参考真解，不替代网格加密、慢加载或其他纤维方向的验证。
