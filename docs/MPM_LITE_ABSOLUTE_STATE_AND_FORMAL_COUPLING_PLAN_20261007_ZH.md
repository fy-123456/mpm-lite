## 2. 从实际源码发现的下一轮关键缺口

本节依据当前源码，不把上一轮解释当作已经实现的接口。

1. [formal.py](../engine/aniso_phase1/research_constrained_history_next/formal.py)中的`stabilization()`仍使用`Y = reference + full_carrier`；`stationary_coordinates()`明确仅适用于静态系数。新点历史如何对应这一Y尚无动态定义。
2. 同文件`mass()`组装的是相容初态的质量：SH采样点按初始坐标建立，利用张量结构计算。它不接收当前x/F，不能直接作为任意后续状态的“新质量”。更新后还可能失去原张量可分结构。
3. [model.py](../engine/aniso_phase1/research_constrained_history_next/model.py)将材料q4/q6与固定q4质量/几何分离，但限定在小模型。正式积分点数、规则及内存上限必须另行登记，不能照抄128/432。
4. `compare()`在试步终点检查能量、组装内力和逐单元PK1弱应力积分。切线已有测试诊断，但不是运行控制器的逐步检查；Newton路径中间状态也没有全面认证。
5. `BoundedBridge.step()`只对该材料预算失败执行回退。一般Newton失败、输入损坏、备用规则自身失败不会自动安全重算。扩展失败类别需要明确规则，不能捕获一切异常后继续。
6. [solve.py](../engine/aniso_phase1/research_unified_lite_poro/solve.py)是小型CPU混合参考：使用稠密有限差分雅可比、AVF材料力和离散体积链。不能把30向量分量的成本外推到正式648分量，也不能直接沿用固体SPD/CG假设处理整个混合系统。
7. [checkpoint.py](../engine/aniso_phase1/research_constrained_history_next/checkpoint.py)保存小模型全部备用历史并拒绝外来身份；若增加绝对载体状态、边界历史或改变规则，必须另立schema，不能只补几个默认数组。

## 3. 本轮要建立的数学合同

### 3.1 绝对状态与试步增量分别是什么

已提交历史记为\(h_n\)，本步未知系数记为\(d\)。已有更新映射为

\[
x_{n+1}(X)=x_n(X)+B(X,x_n)d+g_n(X,\Delta b),
\]

\[
F_{n+1}=F_n+D_XB(X,x_n,F_n)d+D_Xg_n.
\]

\(g_n\)是规定边界的位移提升，\(\Delta b\)是本步边界增量。自由运动和规定运动都必须进入位置、F和压力体积。每步开始冻结的B与本步迭代中重新构造的B是不同算法，不能混用导数。

新增绝对载体状态若记为\(Y=\mathcal Y(d;h_n)\)，必须说明：它代表什么物理量、初态如何设置、如何更新和提交、与点状态x/F如何一致、存储是否有固定上限。仅令\(Y_n=Y_{ref}+\sum_kd_k\)不构成证明。

原系数势能为

\[
U_s(Y)=\tfrac12Y^TK_sY.
\]

若通过状态映射在当前坐标中表达，固定旧历史后应推导

\[
f_s=J_Y^TK_sY,
\quad J_Y=\partial Y/\partial d,
\]

\[
K_s^{eff}=J_Y^TK_sJ_Y+
\sum_a(K_sY)_a\,\partial^2Y_a/\partial d^2.
\]

非线性状态映射下，第二项不能凭习惯丢掉。若采用的是重新设计的势能，必须另列模型身份，不能仍称“原稳定化完全等价”。

### 3.2 可逆系数循环只是定位工具

在同一自由增量形式下，先d再-d一般有

\[
x_{n+2}-x_n=[B(x_n)-B(x_{n+1})]d.
\]

本式用于否定“累计系数归零必然代表同一物理状态”的简单推断。它不是要求任意显式离散步都时间可逆；以后不能通过强制该循环归零去破坏正确的历史推进。是否等价，应在可表示的相同物理场上比较能量、虚功和状态，而不是只比较系数。

### 3.3 惯性、边界及压力功使用同一运动

惯性为\(M^n=\int\rho_0(B^n)^TB^n\,dV\)。在明确冻结的单步基底内，边界加速度含交叉作用

\[
M_{ff}a_f+M_{fb}a_b+f_{int,f}=f_{ext,f}+f_{p,f}.
\]

这只是单步形式。跨步基底改变时，应明确速度表示和投影，另计动量/动能变化；不能拿上式省略所有基底变化项后直接宣称全程能量一致。

定义\(\bar G\)为沿完整试步路径积分的体积导数，则

\[
\Delta V=\bar G_fd+\bar G_b\Delta b,
\quad W_{p,f}+W_{p,b}=\alpha\bar p^T\Delta V,
\]

\[
C\Delta p+\alpha\Delta V+\Delta t\,D z=0.
\]

D是流量的离散散度，避免与形变基函数B混淆。若F沿步长参数仿射且三维，行列式路径是三次多项式，可使用对应精确的体积导数积分；若改为非线性\(\mathcal Y\)导致路径不再仿射，必须重新验证积分规则，不能无条件沿用现有Simpson链式恒等式。

### 3.4 规则回退不改变质量和压力几何

\[
U_E=\sum_{q\in\mathcal Q_E}w_q\Psi(F_q),\quad
M=\sum_{q\in\mathcal Q_M}\rho_0w_qB_q^TB_q,\quad
V_c=\sum_{q\in\mathcal Q_{G,c}}w_q\det F_q.
\]

材料回退仅改变\(\mathcal Q_E\)，保持同一次尝试的\(\mathcal Q_M,\mathcal Q_G\)、状态和控制体身份不变。备用点从相容初态维护历史；若无法从有限状态准确重建新点历史，不允许临时补点冒充无损升级。

## 4. 顺序、门槛与实际验收尺度

执行顺序：

```text
P0 再锁最新版本与实验合同
 → P1 绝对状态与势能闭合〔门槛S〕
 → P2 更新惯性、夹持边界与功〔门槛M〕
 → P3 正式规则/历史/事务与4步耦合〔门槛C〕
 → P4 独立空间参考与误差分离〔门槛R〕
 → P5 固定预算、多方向和联合验证
 → P6 实际热点、内层规模及后继交付
```

本轮采用S/M/C/R新标签，避免把上一轮“小模型Gate B通过”误认成正式耦合门槛。S不通过就暂停正式动态；此时可顺序处理不依赖正式模型的小模型失败分类、状态schema设计和只读剖析，但必须单列结果。

建议下一次实施首先以P0—P2为主要交付范围。若门槛S/M仍未通过，按用户允许的异常处理方式记录原因，交付已完成的限定成果；不要为了跑完计划而更换物理模型、增加阻尼或放松守恒判断。

验收分两类：

| 类型 | 建议尺度及处理 |
|---|---|
| 不可放松的接口事实 | 输入身份、规则/压力控制体、历史时间层匹配；拒绝后已提交状态摘要不变；无NaN/Inf、负权或失效历史；不能把不同模型当同物理参考 |
| 场景工程误差 | 沿用材料比较5%相对预算；小模型既有绝对底限能量1e-10、力/弱应力1e-7，不无量纲地搬到新单位场景 |
| 导数检查 | 三档尺度化扰动，观察收敛/平台；初步方向导数相对差约1e-3量级可作为定位目标，近零量用预登记绝对尺度；误差不收敛先检查定义和非光滑点 |
| 质量/能量平衡 | 用控制体初始体积、储水量及真实外功等登记尺度归一化；先以质量缺陷约1e-5、能量分账约1%作为拟议工程上限，再结合物理单位锁定；它们不是已有验收结论，也不是降低现有代码守卫的指令 |
| 形变可容许性 | 继承小模型`J>0.1`失效守卫并检查实际范围/突变；不能因J刚好大于0.1就称场景正确，短窗还应符合选定小变形工况 |
| 参考可靠性 | 参考自差需明显小于待判别差异，可预登记为不超过待测差异的约1/3；不满足时只报告敏感性，不签发空间误差 |

所有容差、归一化分母及近零底限在实验前冻结，不根据结果移动门槛。没有必要复刻BASE的1e-17级数值误差；也不能以“误差要求不严格”为由接受错误状态、明显能量注入或失效边界。

### P1.2 在两条路线中作出明确决定

- **做什么：**优先评估保留原材料载体和原绝对势能、将SH限定为相容传递表示的路线；验证受约束载体、局部富集和传递导数是否仍能一致。若不成立，再评估有限状态的更新载体及其新势能，明确与原模型的变化。
- **为什么：**第一条路线有机会保持原研究的物理可比性；第二条路线可以研究，但不能借“仍用了Ks”宣称原算法没有改变。
- **如何验收：**每条路线有采用/拒绝理由，以及Y的定义、映射可解性、约束、零方向和有限存储预算。只在两种表示都能精确表达的共同物理场上主张能量等价。不同场的差异不能伪装成导数错误，也不能作为原能量等价证据。
- **交付：**`stabilization-route-decision.md`及候选身份；未找到合格路线则门槛S失败，保留BASE生产默认。

### P1.3 从同一势能推导力、切线与零模消元

- **做什么：**依据选定路线推导虚功和切线，包含状态映射链式项。重新检查自由物理零方向及稳定化驻值条件，验证旧静态P/offset是否还适用；不适用则重新推导。检查无载平衡、适用边界下的平移/转动和三档有限差分。
- **为什么：**同一个数值Ks不保证同一物理力；只保留一阶链式项也可能使Newton切线不一致。零方向的静态消元可能随新的状态定义改变。
- **如何验收：**能量—力—切线形成同一导数链，消元前后真实场及虚功一致；无未解释伪力。刚体试验使用允许该运动的规定边界，不能要求固定夹持系统自由平移。区分参考方向与当前方向：叠加空间刚体转动时参考纤维矩不随之旋转，当前方向随F变换；改变参考坐标系才相应转换参考张量。2—4次相容增量和重启后保持状态合同。若原模型本身有不变性限制，记录限制而非强行调参消除。
- **交付：**独立势能/导数包、`state-closure-report.json`和门槛S决定。通过只表示状态及势能合格，不表示动力学或空间精度通过。

## 7. P2：重验更新质量、规定边界和功，签发门槛M

### P2.1 从初态质量扩展到合格的步初质量

- **做什么：**对初态、一个温和变形态和一个跨支撑态分别构造完整M，包括载体—局部和自由—固定块。若选定路线保留固定材料基底，证明M可保持常量；若使用更新基底，明确重新组装/可验证更新公式。与少量直接积分对照，不假设原张量分离仍成立。
- **为什么：**当前`mass()`只验证了初态。更新SH经过当前x后，几何依赖、积分复杂度和零方向都可能变化。
- **如何验收：**质量对称，独立物理运动质量正定；重新比较原始/缩放谱、近零方向和场梯度，不能靠加对角小量藏住秩损失。相邻规则变化与误差尺度匹配；保留原交叉块和明显病态案例。组装总点数、峰值内存、时间进入报告。
- **交付：**`state-mass-package`、谱/模态及更新策略报告；只对检查过的状态范围签发资格。

### P2.2 补齐整个夹持体的提升和边界惯性

- **做什么：**补支撑图、边界点/内部点/过渡带探针以及缺失支撑检查。构造非零规定位移、速度、加速度的小幅夹持测试；自由场与提升同时进入x、F、M及反力。保留未消元固定行用于反力核算。
- **为什么：**“固定夹持下自由函数为零”不足以证明移动夹具时的动量和功正确。
- **如何验收：**夹持内部满足规定运动，过渡导数一致；Mfb引起的惯性作用与完整系统一致；动量冲量和边界功闭合，反力有符号、单位及测量定义。不能在Load末尾硬钳粒子位置修补边界，也不能用错误坐标裁剪隐藏支撑缺失。
- **交付：**`boundary-lift-package`、支撑图、边界冲量和反力记录。

### P2.3 验证跨步速度表示和能量分账

- **做什么：**运行2—4步干固体或关闭压力功的受控短窗，检查新旧基底间速度转换。分别报告材料能、稳定化能、动能、外功、边界功和速度投影缺陷；若存在内部状态更新耗散，独立列项。
- **为什么：**把步初M用于单步求解，并不自动保证跨步改变B时的全局动量和能量一致。
- **如何验收：**无载平衡无可见漂移，受控加载响应方向正确；动能/动量缺陷解释清楚并在登记预算内。失败先区分状态闭合、质量、提升和速度投影，不增加阻尼掩盖。
- **交付：**`inertia-work-report.json`和门槛M决定。未通过不得开始正式压力耦合；通过也不授予空间精度资格。

## 8. P3：将有界回退迁移到正式耦合，签发门槛C

### P3.1 建立正式规则身份和从初态推进的备用状态

- **做什么：**继承小模型分离规则的接口语义，为正式空间登记QM/QG/QE及备用规则、控制体身份和实际点数。从合格相容初态推进主/备用x/F；若路线新增Y、内部变量或边界历史，一并拥有、冻结、保存。旧检查点仅允许明确有损迁移或从初态短窗重放，不能标成无损加载。
- **为什么：**正式空间函数支撑和阶次不同，直接照抄q4/q6和560点没有充分性依据；遗漏新增状态会使回退假装成功。
- **如何验收：**普通步、跨格和恢复后，有限数量独立影子点与记录的材料导数一致。材料规则切换时质量、压力几何和控制体历史不变；所有备用点/方向矩/Y计入内存上限。相邻材料规则先做代表态检查，但不称空间参考。
- **交付：**新schema、规则/历史包、内存与Load成本报告；旧`bounded-reserve-material-only-v1`保持只读。

### P3.2 完整位移进入体积链和压力功

- **做什么：**接入含边界提升的正式几何路径，分别计算自由体积导数和规定边界体积导数。沿同一完整路径计算离散压力力、流体含量变化和Darcy耗散，包含已有各向异性渗透张量及相同边界条件。
- **为什么：**省略边界压缩量时，固体功与流体质量可以各自看似正常，却彼此不一致。
- **如何验收：**验证ΔV、自由/边界压力功、局部及全局质量平衡；规定边界起点必须是旧状态，不能在路径起点已加全部提升。若F非仿射，增加合适的路径积分核查。压力混合系统使用适用的通用/块求解器，不能直接把整个雅可比当SPD。
- **交付：**`coupled-work-contract.md`和同输入的能量、力、体积及残差检查。

### P3.3 明确规则失败、求解失败和输入损坏的处理

- **做什么：**保留实际材料误差触发；按风险补少量固定方向的切线/路径诊断。列出可重试的材料预算失败及有证据的规则相关求解失败；输入身份错误、历史损坏和备用规则失败直接拒绝。试步中Y、主/备用历史、速度、压力、含量、边界状态、活动规则和计账均为私有。
- **为什么：**当前控制器只覆盖终点材料预算失败，不能把这项能力扩写成任意异常自动恢复。
- **如何验收：**至少一个实际欠积分拒绝例、一个受控求解失败例及一个损坏历史拒绝例；后两者分别标明是注入还是自然发生，不能混称。整步重试与从原旧状态直接备用求解一致；五阶段注入不污染已提交摘要。单步最多一次备用重算，备用失败则失败；记录δUQ，独立于Darcy耗散和投影功。独立进程从有演化历史的检查点重试通过。
- **交付：**失败分类表、事务测试、规则比较数据和独立进程重放包。不得为了制造失败随意收紧预算。

### P3.4 正式4步短窗、必要扩窗与实际调用链

- **做什么：**先用完整材料规则运行4步正式短窗，再启用已验证规则控制器做同初态对照；通过后按需要选一个12—24步窗口。核对真实Prepare→Solve→Load调用链，随后才接选定实际Lite后端。时间相位先从同一已提交状态比较两个步长。
- **为什么：**需要证明正式模型整体可运行，而不是只有孤立静态算子通过；同时避免一开始混入GPU、压缩和时间步长多种变化。
- **如何验收：**同材料位置报告位移、速度、反力、PK1/纤维应力、压力、通量、J及能量分账；观察峰值时刻、阶段趋势和退化状态。实际后端同输入核对能量、力/切线、体积及真实残差；仅CPU通过则只签CPU。Warp传递探针通过不等于主隐式求解器接入，未接入时保留`eulerian_lite_integration=false`。
- **交付：**短窗原始曲线、帧、相位比较、调用链证据及门槛C的具体模型/后端/窗口范围。

## 9. P4：建立同物理独立参考，签发门槛R

### P4.1 构造能真正变形的独立运动参考

- **做什么：**先选一处应力变化快的区域，实施两档局部h加密或局部p提升。保持正式材料、方向场、几何、边界和稳定化物理一致；参考运动空间及其组装不复用待测降阶解作为真值。先做已知子问题，再做有非零骨架响应的同加载短窗。
- **为什么：**q6积分或更密粒子只能改变采样，不能证明144个局部函数足以表达真实形变。
- **如何验收：**参考之间向一致方向靠近；位置、时间和应力测度一致，原始解及输入可独立恢复。若原稳定化无法在该参考中等价表达，标记模型差异，不给正式空间误差结论。
- **交付：**`reference-physical-contract.json`、独立源码/输入身份及两档参考结果。

### P4.2 分开改变空间、积分、时间与传递

- **做什么：**固定其余因素分别比较材料积分、运动空间和短窗步长；用解析制造场或影子点单独检查传递。沿相同材料探针报告全场/分区位移、PK1及纤维应力，同时给合反力、压力和通量。
- **为什么：**最终误差小可能是误差抵消；只看压力或总位移无法判断局部应力表达。
- **如何验收：**每张表写清唯一变化项；近零量给绝对差与尺度。参考自差小于拟区分差异的预登记余量才可用于选区；不把示意性的误差分解写成严格可加恒等式。未收敛区域仍保留，不用平均值抹掉。
- **交付：**误差来源表、可靠区域图和原始共同探针数据。

### P4.3 冻结可用参考范围

- **做什么：**给每个材料/几何/加载及观察区域签发参考可靠性，登记不可靠区域和剩余预算。先采用能支撑工程判断的部分参考，不追求一次性全域高精度。
- **为什么：**没有可靠参考时更换144函数分配，可能只是更贴合一个不可信答案。
- **如何验收：**参考包可重开，可靠范围与门槛一致；未通过时只提供敏感性报告，不开始正式72/144/288精度排名。
- **交付：**门槛R决定及可用于下一阶段的固定参考包。

## 10. P5：在可信参考上验证预算和材料扩展

### P5.1 明确一般方向分布与内部历史范围

- **做什么：**扩展到至少一个两方向混合和一个空间非均匀案例，使用有明确位置关联的二/四阶矩：

\[
A_2=\sum_k\omega_k a_k\otimes a_k,\qquad
A_4=\sum_k\omega_k(a_k\otimes a_k)\otimes(a_k\otimes a_k).
\]

- **为什么：**一般有\(A_4\ne A_2\otimes A_2\)，平均方向会丢失分布；当前平滑单方向导入不能代表一般混合材料。
- **如何验收：**在材料适用的矩表达范围内，能量、力和切线与显式方向分量求和一致；单方向退化回原规则，权重/矩合法并保留位置关联。若加入塑性或损伤，明确有限内部变量和主/备用点历史协议，另做验证，不能只保存F就声称所有本构历史一致。
- **交付：**材料适用范围表、显式求和对照和内部变量合同（如新增）。

### P5.2 再做72/144/288局部函数预算曲线

- **做什么：**固定合格载体、稳定化、边界及材料；依据可靠参考重新分配局部函数。选区评分同时考虑残差/应力需求、支撑重叠、条件性和交叉作用，冻结随机种子、并列处理和停止规则。
- **为什么：**叠加多个单独有效的函数未必继续改善结果；重叠可能增加近线性相关和计算成本。
- **如何验收：**三个预算同时报告总自由度、积分/历史规模、误差、质量条件性及Prepare/Solve/Load成本。保留非单调点、拒绝候选；每个新空间重新验证质量、边界、压力体积，另立包而非覆盖正式144输入。
- **交付：**确定性选区方法、三档预算与采用/拒绝表。

### P5.3 做同一耦合问题中的最小联合消融

- **做什么：**在同一实际有机械响应的多孔固体问题中，分别移除方向分布信息、局部富集和一致压力功机制，比较完整版本；另选一个预登记未见材料/几何/加载案例。删去压力功一致性仅作诊断，不作为可采用运行分支。
- **为什么：**论文需要证明三项内容解决各自明确问题，而非把多个已有模块并列包装。
- **如何验收：**在相同物理和可比预算下归因，报告局部应力、反力、含量/耗散和成本；每项收益有原始证据，无显著收益也如实报告。新颖性另需文献核查，本计划不自动授予“首次”结论。
- **交付：**联合消融表、未见验证及可写入论文的受限论断清单。

## 11. P6：按实际成本优化，并完成可追溯交付

### P6.1 重新剖析真实正式求解热点

- **做什么：**先细分Prepare、材料响应、压力几何/流量、残差、切线/Jacobian、线性求解、Load、备用历史、IO。BASE四步小模型统计为Prepare约0.363 s、Solve约1.840 s、Load约0.0165 s，Solve约占这些阶段总和83%；仅作为初始线索。
- **为什么：**当前稠密有限差分雅可比反复调用材料响应，不能直接认定换GPU或加缓存就能加速正式场景。
- **如何验收：**同硬件、相同物理、相同可比误差和清楚的预热范围；只对热点作一项改变，例如经导数核查的雅可比作用、混合块预条件或冻结步内不变量复用。缓存绑定状态、规则、边界、材料及时间层，回退不得复用错误状态。给少量重复波动和端到端收益；没有收益则不采用。
- **交付：**剖析报告、一个可单独回退的优化候选及精度/稳定性对照；模型门槛未过时最多做不改变物理的独立小模型剖析。

### P6.2 重验整个冻结包的规模上限

- **做什么：**至少四档粒子数固定运动空间、压力网格、全部积分点、方向表示和历史预算，独立进程完成一次正常耦合步和一次真实备用重算。计入Y、方向矩、备用点、拓扑、缓存及实际峰值内存。
- **为什么：**仅证明单次材料调用不含粒子，不能证明整个迭代、切线和回退仍解耦。
- **如何验收：**内层规模不随粒子数增长，算子不保留粒子数组/闭包或无限历史链；准备和载入的粒子依赖如实报告。采用

\[
T_{step}=T_{Prepare}(N_p)+T_{Solve}(n_{dof},N_E,N_G,N_Y)+T_{Load}(N_p,N_{history}).
\]

其中NY包含新增绝对状态，不能藏在未统计辅助对象里。数组字节与进程RSS分别报告；短样本不宣称普适线性加速。
- **交付：**规模、内存、成本及独立进程重算报告。

### P6.3 封存、可视化及是否采用的决定

- **做什么：**新建后继发布，绑定实际BASE、本文、候选规则、源码、测试、失败案例和检查点；更新新的实施记录。提供实际保存帧的可视化，显示活动规则、回退位置、边界运动及能量分账。
- **为什么：**研究候选和生产默认需要清晰区分，避免后续再次错认最新版本或把小模型证据带到正式模型。
- **如何验收：**逐步骤标记完成/部分完成/未通过及原因，旧源码和证据仍通过审计；显示放大不影响物理数据。HTTP、脚本交互、真实浏览器、CPU和GPU分别记录。正式默认替换需有具体采用包、适用范围和旧入口回退，不因短窗能跑自动替换。
- **交付：**后继`release.json`、完整审计、实施记录、可视化CLI和采用决定。S/M/C/R未过的能力标志保持false。
