### 1. 压力更新和能量账

压力参与固体做功和Darcy方程时统一采用

\[
p_\theta=(1-\theta)p_n+\theta p_{n+1},\qquad
C\Delta p+\alpha\Delta V+hBz=hs.
\]

本轮实际研究入口使用后向欧拉 `θ=1`。原固体AVF、完整M7质量、充分q7材料积分、当前变形下完整张量H及体积离散梯度不变；一般LU求解混合系统，不套用SPD/CG假设。几何相关矩阵仍是准牛顿近似，以原始方程真实残差判定收敛。

数值耗散独立记录：

\[
D_{num}=(\theta-\tfrac12)\Delta p^T C\Delta p,
\qquad
\Delta E+D_{Darcy}+D_{num}-W=\varepsilon_E.
\]

修复后粗/细支分别得到：

| 指标 | 12步 | 24步 |
|---|---:|---:|
| 最小detF | 0.999974022 | 0.999973987 |
| 最小压力 Pa | 0.186521842 | 0.186506709 |
| 最大真实残差/原预算 | 5.83e-5 | 5.22e-5 |
| 累计质量差 m³ | 2.23e-19 | 5.49e-18 |
| Darcy耗散 J | 2.9923e-11 | 2.9992e-11 |
| 数值耗散 J | 5.4782e-11 | 2.7492e-11 |
| 数值耗散/初始储能 | 0.0292% | 0.0147% |
| 数值耗散/Darcy耗散 | 1.831 | 0.917 |

两支各步源功和累计源量都严格为零；θ和累计数值耗散参与模型身份与检查点。直接按保存能量差重算的单步闭合约 `2.52e-15 J` 以内，使用原工程绝对项与能量尺度预算；初始能量以静止构型储能估算，包含极小固体数值零点差的影响。

同网格粗细比较的最坏“误差/预算”分别为：压力0.001071、各面流量0.026159、分方向排水0.023957、实际总含量4.44e-6、速度0.013417、骨架PK1应力0.000168、反力0.009310；总应力和Cauchy应力也按同探针、同区域检查通过。这里的0.026159表示占所定工程预算的2.62%，不是物理量相对误差2.62%。

数值耗散随步长减半约减半，但相对本短窗很小的Darcy耗散仍明显，不能把它称作物理耗散。能量闭合与场量短窗对照通过不等于长期压力相位准确。完整结果见 [`S5/coupled-comparison.json`](results/pressure-startup/20261004T172139Z-pressure-startup/S5/coupled-comparison.json) 和 [`energy-and-transaction.json`](results/pressure-startup/20261004T172139Z-pressure-startup/S5/energy-and-transaction.json)。

### 2. 性能优化的具体改动

原本每个压力单元的体积梯度回缩都遍历完整节点范围。对于单元c，节点侧向量只在它的精确支撑集合 `I_c` 上非零，因而

\[
R^T g_c=R_{I_c,:}^{T}g_{c,I_c}.
\]

实现只缩短稀疏转置乘法的列访问范围，复用原CSR数值和列索引，保留载体—局部交叉项、完整约束变换及当前F/H。没有近似截断非零项。四种状态的H/V/G、体积做功、数组所有权、真实实步、回滚和恢复均通过。

节点回缩一项从约0.86s降为约0.21s；完整实步均值为状态0 `3.067→2.335s`、状态1 `3.327→2.864s`。以每状态等权计算的降幅为18.90%，状态间差9.97个百分点，仅是这两个状态的实测差异，不是统计置信区间。元数据由约95.2MiB到102.68MiB，设置成本在16步内回收。稠密预计算路线预计约9.28GB，评估后未分配。实测过程GPU无其他计算进程干扰。

- **没有新保持段种子。** 现有可信轨迹止于卸载阶段，未为补种子启动长周期。
