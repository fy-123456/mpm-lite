## 2. 执行方式、共同数学条件和验收尺度

### 2.1 单进程顺序推进

顺序为：**S0 准备 → S1 时间 → S2 参考 → S3 空间预算 → S4 日常回退 → S5 性能与耦合准备 → 新版本收尾**。

同一时刻只运行一个数值任务，沿用全局执行锁；不启动并行研究 agent 或并行 GPU 实验。每阶段产出结论并冻结输入后再进入下一阶段。

如果 S2 的参考仍不可靠，S3 只完成诊断、候选设计及“不晋级”的书面决定，保留 original144；随后 S4、S5 可以在原空间继续。时间尚未认证也不阻止静态参考研究，但不得拿未经校核的动力学瞬时状态作为空间真值。

所有源码、协议、材料、空间、时间表或规则策略的改变，都产生新的案例身份。**不修改旧案例身份以强行续算，不在旧封存目录追加成果。**

### 2.2 需要保持的数学含义

用 \(w\) 表示独立位移坐标，用 \(T\) 表示恢复矩阵，避免与第一 Piola 应力 \(P\) 混淆：

\[
q_{\mathrm{full}}=Tw+c,\qquad
v_{\mathrm{full}}=T\dot w,\qquad
M_r=T^T M_5T.
\]

当前完整／独立／自由标量坐标数分别为 369／366／216，每个坐标对应三维向量。三个冗余方向的处理包含原稳定化的平衡约化，不能直接删除三列或用人工质量修补。

\[
F=I+\nabla_Xu,\qquad
U_q(w)=\sum_{p\in Q_q}V_p\,\Psi(F_p(w))+U_{s,\mathrm{original}}(w),
\qquad g_q=\frac{\partial U_q}{\partial w}.
\]

当前力接口返回**势能的正梯度**。q5/q7 改变材料积分点与权重；在同一原空间中，质量仍是完整 M5，包含载体—局部及局部—局部交叉项。这里的 q5 不是“五个积分点”。

对一步长度 \(h\)，现有 AVF 更新的核心形式为：

\[
w_{n+1}=w_n+hW,\quad \widehat v_{n+1}=2W-v_n,
\]
\[
r_f(W)=\left[2M_r(W-v_n)+h\left(\sum_\ell b_\ell g_q(w_n+c_\ell hW)-f_{\mathrm{ext}}\right)\right]_f=0.
\]

之后继续执行现有端点边界速度约束及其冲量、功和损失记账。改变步长时，路径采样、边界时刻、真实残差尺度和相关缓存键必须同步使用实际 \(h\)。

整体账本保持以下分账，而非只看总能量曲线：

\[
\Delta(K+U)=W_{\mathrm{ext}}+W_{\mathrm{boundary}}-D_{\mathrm{constraint}}
+\varepsilon_{\mathrm{path}}+\varepsilon_{\mathrm{solve}}.
\]

发生材料规则迁移时，另列同状态势能变化，不将其当作外部物理功或删除它。

### 2.3 工程验收与研究精度分开记录

本轮不追求对所有量施加机器精度门槛。沿用已封存的实用预算，新的门槛在实验前登记：

| 类型 | 判断方式 |
| --- | --- |
| 必须满足的正确性 | 无 NaN/Inf；路径及终态 `det(F)>0.1`；边界位移／速度误差不超过现行 `1e-8` 对应单位；真实残差通过；失败不改变已提交状态 |
| 能量与质量 | 沿用账本闭合 `1e-7 J`；路径和求解误差各自累计绝对值预算为 `1% × E_scale`；当前 `E_scale=1.1406507535904557e-4 J`；质量不能因材料规则切换改变 |
| 场景字段比较 | 全域、夹持区、过渡区、内部区分别用 `绝对容差 + 5% × 参考范数`；位移 `5e-5 m`、物理速度 `1e-4 m/s`、PK1／纤维分量 `0.02 Pa`、反力 `1e-4 N` |
| 同一数学算子的实现等价 | 沿用 `2e-5` 相对预算及已有近零处理；不得用场景的 5% 容差放过符号、索引、缓存或交叉项错误 |
| 材料积分资格 | 同状态能量、组装力和弱应力矩沿用 2%，切线沿用 3%，近零量沿用现有绝对下限；只对明确的空间、材料、状态范围有效 |
| 科研目标 | 原应力／纤维 2%、反力 1% 继续单独报告；工程运行通过不意味着这些目标已经达到 |

场比较报告同时给出绝对误差、参考范数、相对误差、阈值和通过项。近零参考不报告失真的巨大百分数；反力按共同时间区间的冲量平均对齐，不直接插值每步平均反力。

稳定无阻尼系统可以保持小幅振动，不把“最终必须静止”作为验收条件。不得通过增加阻尼、软化材料或增加质量来压低相位误差。

## 4. S1：优先改善时间相位

### 4.1 当前依据与本阶段目标

已有 32／64 步对照及短窗显示：场景稳定，但部分速度、应力和反力差异未通过时间比较。既有诊断中一个静止线性化模态的周期约 `0.1223 s`，占所查速度差动能约 63%；这支持相位频散解释，但不能证明所有非线性误差都由它造成。

对线性无阻尼振子，中点型更新的数值频率满足：

\[
\widetilde\omega(h)=\frac{2}{h}\arctan\!\left(\frac{\omega h}{2}\right).
\]

步长较大时 \(\widetilde\omega<\omega\)，表现为振动节奏偏慢。对上述周期，`h=0.025 s` 的频率比约 0.889，`h=0.0125 s` 约 0.968。此公式只用于解释和选择步长；实际非线性轨迹仍用原始时序验收。

### S1.1 固定观测量和事件定义

- **做什么：** 从父发布读取卸载与保持阶段的原始逐步反力、速度、能量和检查点；预登记少量内部／过渡区物理探针和一个主导模态投影。固定正负峰、过零点及幅值的识别方法，输出每个事件的原始时间区间和采样分辨率。
- **为什么：** 仅比较终态或挑选最像的显示帧，无法区分幅值误差和相位误差。无阻尼保持阶段尤其不能只看位移是否接近零。
- **如何验收：** 同一脚本对相同记录重复读取得到同一事件表；峰值时间不假装具有高于采样频率的精度；反力同时报告区间冲量和峰值。禁止平移曲线后将对齐结果作为通过证据。

### S1.2 增加明确的分段时间表入口

- **做什么：** 在新命名空间增加显式时间表配置。保留 `0、0.5、0.6、1.1、1.6 s` 阶段边界；每步把实际 `h` 传入惯性项、路径积分、边界速度、容差尺度和预条件键。协议保存展开后的全部时刻，而非只有一句“自动步长”。
- **为什么：** 当前 CLI 只有统一 `--dt` 等入口；虽然协议验证支持递增 `times`，尚无完整的分段步长 CLI。不能在文档中把未实现参数当成现有功能。
- **如何验收：** 重复／倒序／非有限时刻和遗漏加载边界被拒绝；一组 2—4 步变步长执行与逐步调用相同序列一致；变步长中断后恢复得到相同物理状态和账本。先只支持预先固定时间表，不引入在线自适应算法。

### S1.3 用两个短窗比较更细步长

- **做什么：** 优先选 `[1.0,1.2] s`（卸载结束附近）和 `[1.2,1.4] s`（后续保持）两个短窗。每个窗口从其起点同一已提交父状态分叉，比较 `0.025、0.0125、0.00625 s`；粗档可复用身份一致的父记录，细档每窗最多 32 步。材料仍为 q7、路径阶数仍为 2。
- **为什么：** 过去已做过部分 `0.025/0.0125` 窗口；本次新增的是较细比较档和较后保持窗，重点观察频率与相位是否随步长减小而接近，而非重跑全部旧诊断。
- **如何验收：** 起点 q、v、历史、时间与物理模型相同；比较包含全部共同采样时刻、事件偏移、幅值和能量。`0.00625` 只称“短窗细步比较档”。先登记工程选择条件：相对细档，`0.0125` 的主要事件偏移／速度差较粗档明显减小（建议以至少 20% 为有意义改善，低于噪声和绝对下限者按已足够接近处理），其他观测量不出现超出实用预算的新退化。

### S1.4 在两个完整周期方案中只选一个

- **做什么：** 候选 A 为全程 `0.0125 s`，共 128 步；候选 B 为 `[0,0.5] s` 用 `0.025 s`、`[0.5,1.6] s` 用 `0.0125 s`，共 108 步。依据短窗结果和已有加载阶段证据择一；默认优先 A，只有粗步加载前缀的影响已有充分说明时才选 B。
- **为什么：** 保持阶段也持续振动，只在加载拐点附近缩小步长不足以修复随后累积的相位偏差。短窗从父状态启动也无法修复起点之前的历史误差。
- **如何验收：** 写出选型理由、预计步数与成本。若两方案的加载前缀差异仍无法判断，只补一个短的加载／保持连接窗，或直接选择 A；不为选型分别跑两个完整周期。事件偏移建议控制到一档 `0.0125 s` 的量级，并给出采样不确定性；未达到时保留时间受限标记。

### S1.5 执行选定方案的一次完整周期

- **做什么：** 从一致初态运行选定方案至 `1.6 s`，最多 128 步、12 显示帧；逐步保留原始反力、能量账本和重启所需状态。在卸载前后及保持阶段检查速度、峰值时刻、应力和边界冲量。
- **为什么：** 只有从初态推进，才能观察累计相位误差与真实历史。短窗通过不能替代完整周期效果。
- **如何验收：** 全程通过第 2 节正确性门槛；原始动画没有非物理跳变；报告相对父版的场与事件差异、末期振动幅值和成本。改善必须同时解释速度／反力时序与能量，不能仅靠更平滑的图像。若短窗改善而完整周期仍受限，报告原因与范围，不宣布全周期时间收敛。

### S1.6 冻结时间方案与结论

- **做什么：** 输出 `S1/time-decision.json`、短窗比较表、完整周期摘要和图，记录 `scene_stability`、`phase_improved`、`temporal_certified` 三个独立状态。以后阶段使用同一选定方案；如无可靠收益，保留父版方案。
- **为什么：** 两档完整周期与细档短窗不足以自动构成全程渐近收敛证明；需要避免“效果有所改善”被后续写成“时间误差已消除”。
- **如何验收：** 决定可追溯到原始数据和固定门槛；不追加长周期以追逐很小差异。若存在明显增长或翻转，按第 9 节诊断后回退，不让有问题的时间方案成为下一阶段默认输入。

## 5. S2：建立更可靠的空间参考

### 5.1 当前依据与目标

现有 `reference_space.py::local_h_family()` 是在**固定 Q4 环境节点**中加入局部函数，并未真正细化环境网格。两级参考在内部区的 PK1／纤维差约 10.37%／14.11%，不足以承担“真值”角色。

本阶段优先尝试实际环境网格局部 h 加密；局部 p 提升作为有界备选。目标先证明参考逐级接近，不先追求一张误差很小的候选结果图。

### S2.1 固定参考问题与评价位置

- **做什么：** 冻结几何、原材料、边界位移、纤维方向、原稳定化定义及分区；首先采用与旧空间候选比较一致的静态峰值边值问题。预先规定公共物理探针及必要的公共区域积分规则，并保留载荷与求解残差。
- **为什么：** 不同载荷、不同应力度量、不同采样位置或动态／静态混用，都可能产生“参考变好”的假象。
- **如何验收：** 在原空间复算至相同静态解，或验证已有结果与本次问题身份一致；每个结果标明“静态参考”或“动力学参考”。静态平衡解不用于直接判定有惯性轨迹同一时刻的误差。

### S2.2 先设计两级真实 h 加密及成本预测

- **做什么：** 根据已有应力梯度和误差分区，固定少量过渡／内部单元为加密区域，建立 R0、R1、R2 嵌套序列；R1/R2 实际增加环境网格分辨率。处理非一致网格的悬挂节点约束或采用一致闭合加密；显式给出原基函数到新网格的嵌入映射。
- **为什么：** 继续在原环境节点上叠加向量不能突破环境表达能力。局部加密若没有连续性约束，又会引入裂缝或伪自由度。
- **如何验收：** 网格覆盖同一物理域、没有重叠或缺失；形函数满足连续性及仿射再现；粗空间函数及梯度可在新网格上正确重现。预估 DOF、积分点、矩阵和显存规模，超预算先缩小加密区，不先盲目分配大矩阵。

### S2.3 明确原稳定化在新空间中的延拓

- **做什么：** 将原载体表示和原稳定化能量作为共同物理定义保留；对新局部自由度写清其进入材料能和稳定化的方式。原空间嵌入后，其稳定化能量、梯度和方向切线应复现父版。新方向若存在零能模式，先诊断来源。
- **为什么：** “原 Ks 不变”不能只理解为复制一个数组。换网格、基底或约化后，矩阵尺寸和坐标含义可能变化；未经解释的新罚项会把参考变成另一个模型。
- **如何验收：** 原子空间的能量／力／切线一致；刚体运动的材料响应及稳定化响应分别报告。无法给出一致延拓时，这条参考路线记为模型不兼容；不靠调大罚项使其勉强通过，不用它评价正式空间。

### S2.4 重建完整质量、约化与充分材料积分

- **做什么：** 对新环境／空间重新组装载体—局部、局部—局部完整质量及静止切线，核查冗余／零空间后生成独立坐标。比较相邻积分阶次的质量作用、同状态 U／g／弱矩和敏感切线方向；重用旧矩阵块之前证明它们在新表示中仍等价。
- **为什么：** 原空间中的 M5 资格不能自动外推到升阶空间；现有约化也不能假定新空间恰好仍有三个相同冗余方向。欠积分或错误质量会污染后续动态验证。
- **如何验收：** 刚体／仿射检查、完整作用对照、独立质量秩及正性满足预登记尺度；代表性状态的积分相邻阶差在相应预算内。若新空间需更高质量积分，另建模型身份并记录原因；原空间 q5/q7 的质量始终不变。

### S2.5 用 R0/R1/R2 判断参考是否可靠

- **做什么：** 顺序求解同一静态问题，在全域和三个分区比较 R0→R1、R1→R2 的 PK1、纤维分量、反力和位移。记录真实残差、积分误差和运行成本。
- **为什么：** 单个更细结果并不天然可靠。需要区分求解误差、积分误差和空间差异，并观察参考之间是否收缩。
- **如何验收：** 求解／积分噪声明显小于空间差异；关键区域的相邻层差总体下降，无新增局部异常。将最后两级差记为“经验参考不确定度”，不能称严格误差上界。达到工程比较预算且对候选改善有足够分辨力，才准许 S3 作晋级判断；科研 2%／1% 另列。没有下降趋势时维持 `reference_limited`。

### S2.6 必要时仅尝试一条局部 p 备选

- **做什么：** 只有 h 路线因预算或参考停滞受限时，选择一个小区域进行真正的局部 p 提升，明确界面连续性、嵌入、积分和 Ks 延拓，复用 S2.3—S2.5 的检查。
- **为什么：** p 提升可能更适合光滑解，但同时展开 h、p、大量支撑组合会把有限研究变成无界搜索。
- **如何验收：** p 方案同样改变实际环境表达能力；单路线采用约 600 秒软预算、1,200 秒硬预算及共同内存上限。若仍不能建立可靠参考，保留失败原因和最有信息的结果，停止晋级尝试，不调宽标准制造“通过”。

### S2.7 发布可加载参考及范围说明

- **做什么：** 输出参考网格／阶次、基函数、约束映射、质量资格、积分规则、原稳定化说明、求解协议、参考解和分区不确定度，形成独立参考包。
- **为什么：** 只有图表或报告中的误差数字，无法让下一阶段复用同一个参考问题。
- **如何验收：** 新进程可加载参考包并重建一个代表性状态的场及算子；标明认证范围是固定边值问题、固定材料和固定原稳定化模型。没有额外证据时不声称连续体收敛或动态全过程参考认证。

## 6. S3：在可信参考上重新分配 144 个函数

### 6.1 进入条件与设计原则

只有 S2 提供足以分辨候选收益的参考时才执行正式晋级。144 指局部函数预算；载体、几何和材料不随优化目标暗中改变。旧 swap6／swap12 的差异减小和短程稳定已有记录，但因参考不确定性而未获晋级，本轮不把它们当作已认证空间。

### S3.1 用物理误差定位表达不足区域

- **做什么：** 将正式原空间与可信参考映射到相同物理位置／积分区域，分别计算应力、纤维、位移和反力差异，结合残差及应力梯度定位需要函数的区域。明确训练载荷和保留载荷；检查既有材料／加载登记表后才选新保留样例。
- **为什么：** 高频应力区域需要表达能力，但“应力大”并不等于“误差大”；看过的 37°、58°或 0.0075 m 案例不能重新称为未见测试。
- **如何验收：** 每个候选区域有参考差异和物理解释；误差图不混用不同采样或应力度量；保留样例在评分、选型前登记，不参与调整评分权重。

### S3.2 在评分中保留重叠函数的交叉作用

- **做什么：** 以小块候选函数及其邻域作为选择单元，使用真实局部试增／替换能量或残差收益。在线性化正定且条件合适的子问题中，可采用 Schur 补估计：

  \[
  S_b=K_{bb}-K_{ba}K_{aa}^{-1}K_{ab},\qquad
  \eta_b\approx\tfrac12\widetilde r_b^TS_b^{-1}\widetilde r_b.
  \]

  其中 \(\widetilde r_b\) 是消去已有方向后的一致残差，不把单个函数系数平方直接当作收益。
- **为什么：** 重叠函数可能重复表达，也可能协同表达。忽略交叉项会反复选到相似函数，浪费有限预算。
- **如何验收：** 对少量已登记小块，预测排序与实际短局部求解收益大体一致；奇异／非正定情况下报告原因，改用直接试验或稳定的子空间诊断。不得通过给物理算子增加人工刚度来强行使评分公式成立。

### S3.3 最多生成两个预算内候选

- **做什么：** 以原144为对照，仅生成两个有明确动机的替换方案；先小范围替换，再考虑第二方案。记录每个函数的来源、支撑、阶次、归一化及替换原因，控制连续性与支撑重叠。
- **为什么：** 在参考改善后，最有价值的是确认预算分配原则，而不是再次展开大量经验参数搜索。
- **如何验收：** 局部函数总数恰为144；完整／独立／自由映射自洽；不存在重复列引起的新秩亏；仿射／刚体检查和第 S2.4 的质量、切线检查通过。每个候选是独立空间包，不覆盖 original144。

### S3.4 按分区收益和参考不确定度决定候选

- **做什么：** 顺序比较原144与两个候选在同一静态参考问题及保留样例中的误差。预登记保守晋级条件：关键区域的改善需明显超过最后两级参考差异所给出的不确定尺度，例如超过该尺度的两倍；其余区域不得出现超出工程预算的退化。
- **为什么：** 若候选只比参考自身波动好一点，无法判断收益是否真实；全域平均变好也可能掩盖夹持或过渡区变坏。
- **如何验收：** 输出各区 U／PK1／纤维／反力、经验不确定度、绝对和相对改善、成本；这里的“两倍”是保守决策规则，不称统计置信区间。没有候选满足条件就明确保留原144，不为了完成任务强行换空间。

### S3.5 只为拟晋级候选补动态资格与加载接口

- **做什么：** 修改新模型适配器，使其读取所选包的真实 T、质量、基函数和边界，而非仅修改 `selected_space` 名称。拟晋级候选优先从物理静止初态启动，使用 S1 时间方案，先做几步检查，再至加载／保持连接段（约 `0.65 s`）。
- **为什么：** 当前 `model_package.load_reduction()` 明确只接受 original144；静态误差下降也不保证新空间的质量、模态和动力学正确。
- **如何验收：** 候选包可在新进程实际加载；同状态 CPU/GPU、真实残差、边界、能量和最低 det(F) 合格。报告模态频率变化并据此复核时间步长适用性。与原空间的轨迹差异只算差异，不能当作参考误差；不因静态晋级就宣布全周期动态精度已认证。

### S3.6 固定正式空间或保留原空间

- **做什么：** 输出 `S3/space-decision.json`，选择一个正式包供 S4/S5 使用。若需旧状态迁移，另立一次明确的物理场投影任务，检查速度、动量、动能及边界；默认通过从共同静止初态重跑避免迁移风险。
- **为什么：** 两个空间的坐标维数相同也不表示系数有相同物理含义。直接复制 q、v 会产生不受控的速度或能量跳变。
- **如何验收：** 决定包含是否晋级、理由、参考范围、动态限制和后续需验项目；旧包仍可重载。S4 使用唯一明确空间；若未晋级，后续不等待无限改进，继续使用原144。

## 7. S4：把 q5 固定规则回退接入日常运行

### 7.1 当前依据与接口边界

已有 `engine/aniso_phase1/research_sequential_next/rules.py::FixedRuleRetry` 实现固定试步、压缩失败后整步回滚、充分规则重算和成功后保持充分规则。**现有普通 `run_case()` 没有调用它。** 本阶段完成实际入口、协议、状态发布和恢复集成。

“充分规则”是对当前空间和状态范围重新确认过的规则。原空间通常是 q7；若 S3 换了空间，不预先假定 q7 仍充分。

### S4.1 在最终选定空间重新绑定适用范围

- **做什么：** 用选定空间和 S1 时间方案，检查静止、加载峰值、卸载附近的实际状态，并沿用少量混合方向／敏感切线探针。比较 q5、候选充分规则及相邻更充分规则的 U、g、弱矩和切线；质量单独绑定。
- **为什么：** 旧 q5 验证覆盖的是旧空间及限定载荷；空间重新分配后材料积分误差可能变化，不能只改空间标签继续沿用资格。
- **如何验收：** 通过第 2 节材料预算，确认充分规则自身可靠；适用表包含空间、材料、变形／加载范围、规则哈希和来源状态。两个材料算子使用完全相同的完整质量；新空间若有自己的质量规则，双方也必须一致。

### S4.2 给主入口增加显式规则策略

- **做什么：** 在新 CLI／协议中区分 `full_only`、`q5_fixed`、`q5_with_full_retry` 三种策略，绑定控制器允许的模型／规则集合、质量、源码和适用范围。现有固定 q7 用法保持可用。
- **为什么：** 能切规则的案例身份与固定规则案例不同；只在异常处理中替换算子，会造成检查点记录与真实模型不一致。
- **如何验收：** 配置可完整序列化和重载；恢复时允许已登记的 q5→充分规则迁移，拒绝未登记材料／空间／规则。新参数需以实际 `--help` 和一次加载结果为准，本计划不将其写成现成可执行命令。

### S4.3 确保整步回滚及单次成功提交

- **做什么：** 将控制器放在外层事务内。一条试步路径始终使用同一材料规则；q5 拒绝后，恢复 q、v、预测器、惯性历史、边界账本、子状态及待发布记录，再从同一已提交基态使用充分规则重算。清理与失败试步关联的缓存句柄。
- **为什么：** 只恢复位移但保留速度、历史、能量或子状态，会产生看似连续却物理错误的下一步。求解迭代中切换规则还会改变正在求根的方程。
- **如何验收：** 实际故障注入覆盖材料求值、试步检查及发布前失败；每次失败后基态 digest 不变；最终只发布一个成功代次。充分规则也失败时不提交，记录拒绝原因并停止该案例；程序错误不一律伪装成积分规则不适用。

### S4.4 明确规则切换能量及恢复语义

- **做什么：** 沿用并验证同状态规则能量变化

  \[
  \Delta U_{\mathrm{rule}}=U_{\mathrm{full}}(w_n)-U_{q5}(w_n).
  \]

  将其独立记录，并累计绝对值预算；记录迁移原因、父状态 digest、源／目标规则。充分规则成功后保持充分规则，暂不自动切回 q5。
- **为什么：** 规则变化会改变离散势能基准；把这部分差异藏进外力功或重置账本，会掩盖能量跳变。频繁来回切换也增加误差和事务复杂度。
- **如何验收：** 原 q5 状态、一次回退后的充分规则状态均可由新进程恢复；能量切换预算沿用 1% 固定尺度、单独记账；超预算迁移被拒绝；恢复后实际算子与检查点中的规则一致，累计误差和失败历史不丢失。

### S4.5 区分可运行的 q5 与精度不足的 q5

- **做什么：** 在预登记代表状态进行充分规则哨兵比较；超出已认证范围的输入默认使用充分规则。若加入运行期哨兵，先限定在少数阶段节点，将不通过转为整步拒绝／回退，计入成本。
- **为什么：** q5 即使残差收敛也可能存在积分偏差，单靠“求解器失败才回退”不是精度保证。
- **如何验收：** 适用范围外不会静默强制使用 q5；人为构造的哨兵不通过能触发同一事务路径。报告哨兵覆盖和未覆盖状态，不能宣称任意材料与大变形都有自动准确性保障。

### S4.6 完成有限集成验证并给出日常建议

- **做什么：** 用 4—8 步短程分别检查正常 q5、一次受控回退、充分规则再失败及进程重启；物理结果与从同一基态直接采用充分规则的对应重算比较。正常无故障路径才参加性能比较。
- **为什么：** 回退控制器的关键价值是实际入口可用和状态正确，不需要大量长动画证明故障分支。
- **如何验收：** 回滚、唯一提交、恢复、规则来源和账本都通过；为已验证场景推荐 `q5_with_full_retry`，未覆盖范围推荐 `full_only`。完整周期留到最终集成所需的那一次，复用 S1 中仍适用的充分规则结果。

## 8. S5：按新热点优化性能，再开展物理耦合准备

### 8.1 为什么需要重新测量

旧瓶颈中的伴随组装已被分段 CSR 显著降低；此前两步推进约从 `1.795 s` 降至 `0.379 s`。原来的“组装约占 82%”不能直接代表现在。

最近补测中，每两步的场重建约 `0.23 s`、三次代次 IO 约 `0.05—0.07 s`；这些是特定采样配置下的观察。缓存虽在同状态多方向切线中有效，普通两步净收益仅约 0.49%；LU 复用也没有稳定收益。因此先测实际调用路径再决定优化对象。

### S5.1 在最终空间、时间方案和规则策略上重新剖析

- **做什么：** 选一个正常短窗和一个卸载／保持短窗，各做最多三组交替对照；分开记录模型构造、材料 evaluate/action、质量、线性求解、边界、场重建、序列化及 IO。标明冷／热启动，GPU 计时正确同步，并记录切线和 Krylov 调用数。
- **为什么：** 空间、步长或 q5 策略改变后热点会迁移；嵌套计时和异步 GPU 计时若简单相加会产生错误占比。
- **如何验收：** 对照输入一致、数值状态和账本等价；解释计时扰动，非重叠总成本与墙钟有合理对应；真实峰值内存与分配池统计分开。输出“最值得优化的一项”和暂不优化项，不用单次最快值作结论。

### S5.2 优先处理占比最大的实际工作

- **做什么：** 若场重建占主导，缓存只依赖空间／探针的插值与梯度映射，并只对需要的输出时刻恢复全场；若 IO 占主导，减少可再生大数组的重复写入；若材料计算仍主导，优化已验证分段路径和重复构造。一次只改一类成本。
- **为什么：** 某段占总成本比例为 \(f\)，即使局部加速 \(s\) 倍，整体上限也约为 \(1/[(1-f)+f/s]\)。占比很低的切线优化可能无法改善用户等待时间。
- **如何验收：** 场数据在同一物理位置一致；所有数值步骤仍有原始诊断账本和可恢复状态；每个已提交代次的原子发布语义不降低。仅减少可再生展示数据，不能以丢失失败诊断或恢复能力换取提速。

### S5.3 只有实际需求成立时才启用切线缓存／预条件优化

- **做什么：** 依据 S5.1 的 action 次数、同状态方向复用和线性迭代统计，决定是否启用现有缓存／LU 复用。若没有多方向复用或困难迭代，维持关闭，不新增复杂预条件器。
- **为什么：** 当前普通场景并非显著受切线迭代限制；额外缓存还增加显存、失效处理与规则切换风险。
- **如何验收：** 必须验证 source／space／material／rule／state／device／dtype 身份及失效语义；有显著净收益才改变默认。建议要求端到端改善超过测量波动且达到约 10% 才称明确收益，未达时保留可选项，不继续堆叠实验。

### S5.4 固定性能版本并检查规则／事务兼容性

- **做什么：** 在短程验证性能改动与 S4 正常运行、规则回退、重启均兼容；输出同输入的正确性、总时间、重建时间、IO 与峰值内存表。
- **为什么：** 缓存和 IO 改动可能只在规则切换或重启后失效，普通快路径通过并不足够。
- **如何验收：** 与改动前结果满足实现等价预算，回退不复用旧规则切线或错误字段缓存，检查点可由新进程加载。无明确净收益的改动保持可选或撤回，不为“做了优化”改默认。

### S5.5 先写清真实耦合的共同数学问题

- **做什么：** 完成前述工作后，再明确目标三维几何、固体／压力／流量空间、参考／当前构形、边界、材料储存、渗透率、源项和惯性选择。压力功与质量交换使用同一离散耦合算子，并写出符号、单位及伴随关系。此步先交付方程与接口规范。
- **为什么：** 现有 E 二维模型内部有物理耦合，但其与 C 的联合运行只是共享时钟。把两个稳定求解器放进同一个事务，不会自动产生正确三维孔弹性。
- **如何验收：** 从一个明确连续模型推导离散项；小变形原型可用如下关系核查符号：

  \[
  M\ddot u+f_{\mathrm{int}}(u)-G^Tp=f_{\mathrm{ext}},\qquad
  G\dot u+C_p\dot p+Lp=s.
  \]

  两式的压力功在统一内积、单位和边界约定下相消，\(L\) 给出非负耗散，质量源／汇可核算。现有 E 为相应准静态混合问题，不能说它已实现该惯性三维式；有限变形还需另行给出体积变化、压力应力度量及功共轭，不能机械照搬常量 G。

### S5.6 实现前先完成混合求解器适用性与最小闭合判据

- **做什么：** 根据实际混合块结构选择一般稀疏求解或合适的块方法；检查压力零空间、约束和尺度。若共同模型尚不清楚，到接口规范和一个离散小例子的工作／质量核算即停止，不启动完整三维大场景。
- **为什么：** 耦合压力系统通常不能直接沿用固体 SPD／CG 假设；数值收敛也不保证压力功和质量交换物理一致。
- **如何验收：** 一个最小离散例子能核对总压力功抵消、源／汇平衡、非负耗散及共同步失败后的全部回滚；报告秩和实际残差。二维已有制造解仅在接口改变后做针对性回归。三维实现若进入下一轮，必须另立已闭合模型的计划，本文不承诺本轮完成三维全耦合。

### S5.7 完成一次必要的最终集成与新发布

- **做什么：** 汇总 S1—S5 的实际选择，冻结新源码和协议；在最终源码上运行一个默认完整周期，必要时增加一个敏感场景。若最终控制流程／源码与已有完整周期完全一致且身份可验证，复用该周期而不重复运行；实现发生变化则重新建立案例身份。
- **为什么：** 各阶段局部通过还需确认最终组合可用，但不需要对未改动内容反复执行长实验。新封存只针对本轮实际完成范围。
- **如何验收：** 最终完整周期最多采用已选定的 128 步量级、12 显示帧；能量、边界、真实残差、规则使用、恢复和场景表现通过。新空间若晋级，需在此完成完整周期场景验收；否则保留原空间。发布索引绑定新源码、父发布、模型、协议及成果，能力表保留时间／空间／耦合的真实限制，旧发布哈希仍匹配。

### 9.2 异常处理

| 情况 | 处理方式与验收 |
| --- | --- |
| 一般接口、路径、单位或小规模实现错误 | 自行定位和修复，补一个能揭示根因的针对性验证，继续执行；不因普通问题跳过阶段 |
| 明显异常，如翻转、能量突增、秩改变、来源不符、失败后状态变化 | 保存最小复现、输入与源码身份；最多优先检查三类有依据的假设，区分模型、离散和实现问题 |
| 根因明确且修复不改变物理定义 | 修复后重跑受影响的最小验证，再继续；不重跑全部历史实验 |
| 可能改变 Ks、惯性、压力功或历史语义的高风险调整 | 先推导和做小规模对照；没有根因或一致定义时停止该分支，保留原已验证实现 |
| 有限预算内无法定位 | 记录现象、已排查内容、剩余风险和不能使用的结论；跳过依赖该结论的晋级，继续不依赖它的后续任务 |

“受限”“无净收益”“未晋级”都是允许的研究结论；不得把它们改写成物理准确性通过。故障记录保留，不能通过删除失败数据、放宽检查或更换参考来掩盖原因。
