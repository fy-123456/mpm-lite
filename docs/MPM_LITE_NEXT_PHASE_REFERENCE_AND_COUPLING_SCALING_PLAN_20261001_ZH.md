## 三、保持的物理定义、验收标准与预算

### 1. 正式空间和物理模型本轮保持不变

正式固体仍用global-snapshot6、144局部函数、完整M7及载体—局部交叉项、原材料势能、原稳定化和消零语义。保持FP64／Warp CUDA segmented及当前已采用的构建优化。不能通过额外阻尼、人工质量、删交叉项或改材料制造“更稳定”的结果。

位移、应力和动力学关系为：

\[
\mathbf u_h=\mathbf u_{\mathrm{carrier}}+\sum_{i=1}^{144}\psi_i\mathbf a_i,
\qquad \mathbf F=\mathbf I+\nabla_X\mathbf u_h,
\qquad \mathbf P=\partial\Psi/\partial\mathbf F,
\]

\[
M\ddot{\mathbf q}+\nabla U(\mathbf q)=\mathbf f_{\mathrm{ext}}.
\]

空间参考可以单独加密，但不自动替换日常空间。新材料验证工况使用独立模型身份；不悄悄更改主F45工况。不同参考空间的M维数可以不同，不能把正式M7数组强塞到新参考空间；本轮空间参考主要做静态比较，正式惯性保持冻结。

### 2. 时间参考必须能区分候选

新空间的模式4／72／523周期约为0.123039／0.032324／0.002877 s。已有模式编号与向量可在空间、质量、线性化点身份一致时复用；需要核查质量正交和特征残差，不能移植旧空间501号模态。

线性振子中点格式有：

\[
\widetilde\omega=\frac{2}{h}\arctan(\omega h/2).
\]

这说明稳定并不保证相位准确，仅用作选参考层的机制依据，不能把该公式计算出的偏差直接当非线性场景实测误差。

场量继续使用混合误差预算：

\[
\|y-y_{\mathrm{ref}}\|\le a_y+0.05\|y_{\mathrm{ref}}\|.
\]

### 3. 压力缩放改变求解表示，不改变物理方程

原离散方程保持：

\[
H\mathbf z-B^T\bar{\mathbf p}=-\mathbf b_{\partial},\qquad
\Delta\mathbf m+hB\mathbf z=h\mathbf s,
\qquad \mathbf m=\alpha(\mathbf V-\mathbf V_0)+C\mathbf p.
\]

每次线性修正若满足\(A\delta x=-r\)，可变换为：

\[
(D_rAD_c)y=-D_rr,\qquad \delta x=D_cy.
\]

缩放后的线性残差只用于诊断。接受修正、线搜索和最终提交仍在**原物理变量**下重算真实非线性残差。当前A是准Newton搜索矩阵，不能称为已经得到精确混合切线。一般混合块不按固体SPD／CG假设求解。

能量检查保留：

\[
E_p=\tfrac12\mathbf p^TC\mathbf p,\qquad
D=h\mathbf z^TH\mathbf z\ge0,\qquad
W_{\mathrm{solid},p}+W_{\mathrm{fluid},p}=0.
\]

其中两侧压力功使用同一体积离散梯度，满足其与\(\Delta V\)的链式关系。C仍为参考体积定义的常储存矩阵，不顺带引入状态相关储存。

- **如何验收：**调用记录证明每次修正使用选定策略，反变换回原变量后重算原残差；同一非零矩阵／右端项对未缩放求解的位移、压力、通量增量在原预算内一致。缩放失败若允许退回原通用解，必须可观察且该解仍过原残差；两者失败则整步拒绝。
- **交付：**`S4/linear-solve-equivalence.json`、`S4/solver-path.json`及新适配源码。

**S4.3｜先在同一物理时间验证固定固体。**

- **做什么：**使用当前实际两单元几何、11面和完整非对角张量，正常储存0.2／小储存0.0002各4步，严格使用当前`S5/fixed-common-time.json`的同一时间节点，终点约2.494234e-6 s。分别对各自半离散矩阵指数验证。
- **为什么：**上一轮曾补过时间不一致问题；不能再次比较两个不同终点而声称储存参数对比合格。
- **如何验收：**实际时间数组相同，压力有限，累计质量、边界功与非负耗散通过；压力最大差使用既有`5e-4 Pa + 5%`预算。真实残差在原单位下检查。不同储存是不同物理模型，不能要求它们压力轨迹相同。
- **交付：**`S4/fixed-common-time.json`、缩放／未缩放及矩阵指数对照。

**S4.4｜复验真实四步耦合和完整提交。**

- **做什么：**继承当前耦合的初始q/v/p、完整M7、q7材料、体积离散梯度、C、张量H更新及实际源项，在相同4步时间表运行缩放版本。第2步后换进程；核查提交前和指针后故障。原求解轨迹可作对照，当前实现的连续恢复见证若必需最多额外2步未提交延续。
- **为什么：**线性解相近不能替代非线性迭代、压力功抵消和历史恢复验证。
- **如何验收：**逐步满足质量、原分量残差、体积链式关系、两侧压力功相消、储存能、耗散、边界／源功；原物理方程未变化。恢复后的所有固体／流体历史与同路径连续见证一致，双失败不推进，已提交只接受一次。

**S4.5｜通过后才扩一个小范围，单独声明能力。**

- **如何验收：**新增4步的原始压力、流量、质量、能量、真实残差均通过；如异常，保留已经合格的4步，分析最多3个根因假设。`production_C_E_integration`、`pressure_spatial_accuracy`、`pressure_general_monotonicity`和`coupled_q5`仍为false。无法完成缩放或扩展时按实际范围交付，不阻断纯固体后续。

**S5.1｜区分证据复用、旧许可与新许可。**

- **如何验收：**每项复用都有父证据哈希与影响解释；同模型旧充分状态可以经身份和算子等价验证后用作参照，但不能改写成“新源码产生”。越范围合法请求回退full_only，损坏哈希或外来状态明确拒绝。

- **如何验收：**新证书绑定完整8步网格、实际充分初态、最终空间／质量／数值源码；质量数组逐项相同。只登记候选资格，实际连续轨迹还必须过下一步；失败则保留两个独立窗口，不开放敏感完整周期。

- **如何验收：**跨进程前后完整状态哈希衔接，分区场、每区间反力／冲量和能量对充分轨迹通过。初始规则桥接能量单独入账，不伪装成耗散；模式／质量／边界未变化。此窗口通过仍不代表0.0075 m完整周期合格。

## 五、遇到问题时如何决策

| 情况 | 本轮处置 | 后续能否继续 |
| --- | --- | --- |
| 报告目录、类型适配、舍入边界等明确小问题 | 定位并修复新代码，保留原失败记录，做最小必要验证 | 继续 |
| 模式523事件数不同或匹配多义 | 保留未决状态，分析输出贡献、采样和匹配；不删信号凑通过 | 时间表保留当前，其他步骤继续 |
| 细层差仍超参考预算 | 标记参考受限，停止加层，保留原步长 | 继续空间／性能／压力独立工作 |
| 新静态参考不一致或超内存 | 不生成伪参考；停止该分支，正式144空间保持 | 继续 |
| 性能候选无清晰收益或损害提交 | 不采用候选，保留当前转置复用与原事务 | 继续 |
| 压力缩放条件数改善但原残差变差 | 不接受“看起来好”的条件数；检查缩放／反变换／未知量顺序，无法定位则保留原求解器 | 纯固体继续 |
| 四步缩放耦合通过、八步失败 | 分别记录，保留四步有限资格；不扩生产能力 | 继续 |
| q5连续窗失败 | 保留已认证独立窗或充分规则；不开放敏感完整周期 | 主场景继续 |
| 最终完整场景出现未定位物理异常 | 停止新日常组合晋级，保留完整证据，不重复长周期试参数 | 当前local-span继续正式可用 |
| 系统盘低于5 GiB | 暂停新增大结果，按可再生数据迁移流程释放空间 | 空间恢复后继续同一提交链 |

风险分析记录至少包含：观测证据、最多3个候选根因、排查结果、影响范围、继续或停止理由。不得把一般问题一律跳过，也不得遇到不明异常就加阻尼、裁压力、删高频方向或放宽全部容差。
