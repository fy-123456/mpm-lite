## 3. 必须统一的数学定义

### 3.1 固体状态、势能与惯性

用 T 表示代码中的 `reduction.P`，避免与第一 Piola 应力 P 混淆：

\[
a=Tq+a_0,\qquad x(X)=X+B_{mat}(X)a,\qquad
F(X)=I+D_XB_{mat}(X)a.
\]

状态 q 同时包含自由和规定坐标，分别写为 `(q_f,b)`。每步完整增量 `d=(d_f,Δb)`，不能在计算压力几何时丢掉 Δb。

\[
U(q)=\sum_{r\in\mathcal Q_E}w_r\Psi(F_r)+\tfrac12Y(q)^TK_sY(q),
\quad Y=Y_{ref}+a_c.
\]

\[
f_s=T_c^TK_sY,\qquad K_s^{red}=T_c^TK_sT_c,
\quad M=\int\rho_0(B_{mat}T)^T(B_{mat}T)\,dV_0.
\]

原材料基底固定在 X，M可以是常量；完整自由方程包含 `M_ff a_f+M_fb a_b`。本轮不删稳定化、不做质量集中、不复活未认证的更新 C1 空间。超弹性 F 可从 q 重建；塑性或损伤内部变量不能据此省略。

### 3.2 同一个体积变化连接压力力和质量

对固定材料控制体 c，用独立固定的几何规则定义：

\[
V_c(q)=\sum_{r\in\mathcal Q_{G,c}}w_r\det F_r(q),\qquad
G_c=\partial V_c/\partial q.
\]

\[
\bar G=\int_0^1G(q_n+s d)\,ds,
\quad\Delta V=V(q_{n+1})-V(q_n)=\bar G_fd_f+\bar G_b\Delta b.
\]

这里 F 沿 s 仿射，三维 detF 为三次多项式，G 沿路径至多二次，可用两点 Gauss 或 Simpson 精确积分该**离散体积链**；这不证明空间几何积分已充分，也不证明材料能量路径积分精确。

统一约定压力对固体做功为正：

\[
f_p=\alpha\bar G^T\bar p,\qquad
W_p=\alpha\bar p^T\Delta V.
\]

采用常量对称正定储水矩阵 C 的首版合同：

\[
C\Delta p+\alpha\Delta V+\Delta t\,D z=0,\qquad
H(\bar q)z=D^T\bar p-g_b.
\]

D 是朝外流量的离散散度，H 是正定流阻，`g_b` 表示边界压力功的约定。压力纯 Neumann 且 C 有零空间时必须另设压力基准，不能默认系统可逆。

上述质量式乘以平均压力，得到与固体交换功符号相反的同一个 Wp。规定边界上的压力力也进入总反力和夹持功。若以后 C 随状态变化或换孔隙率模型，须重新推导储能与质量，不能沿用常量 C 公式。

### 3.3 一致切线与能量账目

现有张量算子已有材料切线作用。对方向 w：

\[
\delta F=D_XB_{mat}T w,\qquad
K_{mat}w=T^T\sum_r w_r(D_XB_{mat})^T
[\mathbb C(F_r):\delta F_r].
\]

实现时避免积分权重 `w_r` 与方向 w 混淆。总切线加原稳定化一次；现有算子的 `tangent_action` 已含稳定化，不能再次添加。

采用中点材料力时，固体残差的方向导数包括 `2M/Δt² + K(q_mid)/2`，同时包括 `bar G`、平均压力以及 H 对当前未知量的导数。用旧切线作预条件器可以；把它当作当前精确导数则不可以。三维体积 Hessian/Jv 要按同一路径求导。

首版继续采用中点固体积分，明确记录材料路径误差；不在同一次迁移中默认切换到 AVF：

\[
\Delta(T+U+E_p)+\mathcal D-W_{ext}
=\varepsilon_{path}+\varepsilon_{solve}+\varepsilon_{chain},
\quad E_p=\tfrac12p^TCp,\quad\mathcal D=\Delta t\,z^THz\ge0.
\]

材料规则更换在同状态产生的 `δU_Q=U_backup(q_n)-U_primary(q_n)`单列在跨规则账目中，不作为 Darcy 耗散或外力功。先分别列原始能量缺陷、各误差项和闭合余差，再判断是否通过；恒等式闭合不是物理误差为零。

### P1：正式压力几何与边界交换〔门槛 G〕

**P1.1 建立控制体与体积导数。**

- 做什么：在原绝对材料坐标上构造 V、G、方向导数；控制体完整覆盖材料域且互不重复。先对几何规则与提高一阶的规则做少量同状态比较，再固定几何规则；不随材料回退切换。
- 为什么：正式局部函数阶次较高，旧模型的128个几何点没有继承资格；足够准确的体积是压力耦合基础。
- 如何验收：参考态体积等于对应盒体体积；控制体体积和等于总量；平移不改变体积；统一仿射压缩/膨胀的体积与解析 detF 一致。用少量方向有限差分核查 G，登记几何规则阶次、点数、分区和最大误差，不能只检查总和抵消。

**P1.2 实现包含规定行的离散体积链和压力功。**

- 做什么：按第3节计算完整路径 bar G；分别输出自由项、规定项及其和。对固定夹持、移动夹持、仅规定运动三个状态检查体积变化；压力功同时进入自由固体力、夹持反力和质量方程。
- 为什么：只使用自由增量会漏掉夹具压缩引起的排水和压力功，即使自由方程残差很小也会解错问题。
- 如何验收：逐控制体检查 `ΔV-bar G_f d_f-bar G_b Δb`；固体与流体交换功相消；人为只保留自由项的诊断应暴露移动边界缺项。输出 `S1/volume-work.json`，通过后标记 G，仅限注册空间及几何规则。

### P2：可负担的一致切线与混合求解〔门槛 J〕

**P2.1 适配现有切线，而非从零重复推导材料实现。**

- 做什么：将 `evaluate(Tq+a0, Tw)` 的力/切线通过 T 的转置映回；核查原稳定化只计一次。补齐压力体积链、储水、流阻/流量的导数。将空间、材料规则、全部自由/规定坐标、压力和时间层纳入相关缓存键，限制缓存条目数。
- 为什么：已有切线能减少重复工作，但坐标变换遗漏、半步系数错误和边界缓存过期会造成假收敛。
- 如何验收：在静止态、非零压缩态、混合剪切态各选少量方向，以至少两个扰动幅度比较解析 Jv 和残差方向差分；分别报告材料、压力交叉块、边界和完整混合残差的误差。只把有限差分用作诊断，不逐列构造648维以上的运行 Jacobian。

**P2.2 建立块预条件求解并先测成本。**

- 做什么：优先尝试矩阵自由 GMRES，固体块使用质量加静止/滞后切线作预条件，压力块使用含储水和流量作用的近似 Schur 补。实现线搜索、最小 J 检查、真实未缩放残差复核；只有证明对称性/正定性后才使用有相应要求的求解器。分别计时残差、Jv、预条件器构建和应用。
- 为什么：648个自由分量的一轮中心差分至少1296次残差扰动；按一次完整材料调用20秒估算仅这一部分约7.2小时。矩阵自由也可能因每个 Jv 很贵而失败，名称本身不是性能保证。
- 如何验收：先用同空间的小规模算子对照检查解方向，再做1个正式非零状态。设迭代及总材料遍历上限，报告预条件前后迭代数与实际耗时；比较实际非线性残差，不能只展示 Krylov 内部残差。若预算内无法收敛，分析尺度、约束、零模态和预条件，再判断是否将精确切线改为一次有界组装；禁止启动多小时逐列有限差分。

### P3：材料规则、状态和事务〔门槛 T〕

**P3.1 正式空间认证主/备用材料规则。**

- 做什么：把已有 q7 完整材料规则作为首个对照，不直接当空间真值。用静止、剪切/压缩、非零边界三个同状态比较一个较低阶候选规则；计算能量、组装内力、分区弱应力矩和敏感方向切线误差。必要时只在一个代表态提高阶次确认 q7 也足够稳定。
- 为什么：高阶富集与高阶非线性材料未必允许照抄 q4/q6 或生产入口中的 q5；主规则只有通过正式空间认证才能减少后续迭代成本。
- 如何验收：输出每个分区的点数、误差和成本；主规则未通过就继续使用充分规则，不能为了跑通改变质量/几何规则。试探最多两个材料规则，不遍历大量阶次。若暂时没有更便宜的规则，通过状态写“充分规则运行，压缩未采用”。

**P3.2 定义正式耦合状态及检查点。**

- 做什么：新增 q/v/p、当前时间、规则身份、累计质量/功/耗散账目与必要缓存版本；记录哪些量可由绝对 q 重建，哪些必须保存。定义提交前后、检查点和外来包拒绝语义，另立耦合 schema。
- 为什么：当前 q/v 只覆盖超弹性干固体；把压力或累计质量留在求解器临时对象中会导致恢复后改变解。
- 如何验收：非零状态独立进程恢复，比较 q/v/p、x/F、下一步残差及账目；异源空间、错规则和损坏包明确拒绝。备用超弹性积分点直接由原材料映射重建；若未来出现塑性/损伤，须另设计历史储存或投影及其误差，不沿用此结论。

**P3.3 实现分类失败、整步回滚和一次有界重算。**

- 做什么：材料预算失败时回到同一已提交 q/v/p/time 与全部账目，整步用备用规则重算；单步内部不换材料规则。普通线搜索失败先诊断并允许一次预登记的步长减半；输入损坏、身份不符、备用仍失败必须显式失败。区分实际欠积分失败和故障注入。
- 为什么：材料回退、时间步回退和错误输入的原因不同，统一捕获后继续会隐藏根因。被拒绝尝试不能累计排水量、耗散、帧或步骤数。
- 如何验收：一个实际欠积分案例触发材料重算，并与直接从旧状态使用备用规则的结果一致；一个提交前故障证明旧状态摘要及账目不变。若低阶规则没有实际失败，如实标注该覆盖未获得，不降低容差制造结论。登记规则切换 δU_Q，输出 `S3/rollback.json`。

### P4：正式四步耦合与可观察响应〔门槛 C〕

**P4.1 建立退化对照和物理趋势检查。**

- 做什么：先做 α=0/无压干固体退化对照；再以压缩为主，比较封闭不排水和可排水条件。第一窗口沿用当前小位移；若压力对反力/位移影响小于测量误差，保持材料不变，在已登记的一个较大幅值上做短窗，不把视觉放大当作物理响应。
- 为什么：只有165个探针中的微米级运动，无法单凭图像证明固液耦合有效。排水/不排水趋势比极小残差更能暴露符号或边界错误。
- 如何验收：α=0时退化到同一中点干固体；压缩时压力/外流和夹具反力变化方向符合事先推导；封闭总体质量含量守恒，可排水累计变化与边界通量一致。压力反力贡献必须可分辨，并报告相对数值不确定性；不能要求任意各向异性局部应力都逐点单调。

**P4.2 运行一个四步正式耦合短窗并输出可视化。**

- 做什么：锁定上一小步选定的工况、规则及求解器，运行4步；输出 q/v/p、分区体积、通量、全规则最小 J、夹持反力、材料/稳定化/动能/储水能/耗散和三类误差。用固定探针显示位移/J和压力控制体；保留实际比例与显示放大倍数。
- 为什么：静态算子与独立模块通过不代表同一个时间推进程序已经正确提交状态。
- 如何验收：每步有限、J大于注册拒绝阈值、真实动量和质量残差通过、耗散非负至舍入量级、压力功抵消且能量缺陷在工程预算内；无无依据的夹持漂移和反力跳变。条件允许时只追加一个关键步的半步对照，判断峰值和相位是否明显异常；不默认运行完整长周期。输出 `S4/metrics.json`、帧及独立进程恢复证据，C仅授予实际四步工况。

### P5：接入真实传递路径并核算总成本〔门槛 L〕

**P5.1 将 CPU 合同迁移到实际运行入口。**

- 做什么：先定位真实 Prepare/Solve/Load 调用链和状态所有者，明确绝对 x/F、网格速度与局部场的职责；为显式 SH 残差修正增加可选入口。保持原生产默认，通过标志启用研究路径；没有可复用接入点时先写适配器，不改变其他场景的物理空间。
- 为什么：`raw SH + 原场残差 = 原场`是已证明的点查询恒等式，尚未证明生产网格/粒子更新不重复添加增量或破坏边界。
- 如何验收：相同非零 q/v 下比较实际内核和原材料直接查询的 x/F/v、夹持区与跨格探针；检查一整步状态只提交一次。CPU通过与GPU通过分别标记；没有测试的后端保持未认证。

**P5.2 量化显式修正与场重建的负担。**

- 做什么：分开计时 Prepare、Solve、Load、材料响应、场重建、IO以及冷启动，比较直接原场重建与 SH 加修正；按实测热点再选择分块、只读缓存或算子复用。
- 为什么：显式修正可能与直接原场查询一样贵或更贵；不能用“内层不含粒子”掩盖 Load 随粒子数增长的成本。
- 如何验收：相同输入、输出频率和物理结果下报告时间/峰值内存。两条路径无明确加速时保留直接查询为参考，并标记修正为兼容接口；没有实测收益就不发布性能提升百分比。

### P6：独立参考、方向表示与固定预算联合验证〔门槛 R〕

**P6.1 先认证独立的空间参考。**

- 做什么：固定材料、加载、几何边界及原稳定化含义，选择一个热点做实际环境网格局部 h 加密或局部 p 提升，建立至少两档参考；每档分别确认积分与时间误差不主导。明确如何把同一稳定化算子/连续定义转到参考空间，不能直接复制不匹配维度的 Ks。
- 为什么：q6/q7是积分规则；增加积分点不等于增加空间表达能力。若参考同时换势能，就无法归因富集效果。
- 如何验收：在相同材料评价位置或统一积分均值上比较位移、分区应力、纤维量和反力；两档参考的差距应明显小于被评方案的差距。参考间还未接近或稳定化不可比时，R不通过，只报告参考瓶颈，暂停“2%/1%精度达标”及正式空间替换。

**P6.2 完成方向分布、空间关联和历史一致性对照。**

- 做什么：构造单方向、交叉双方向、空间变化双方向三个小工况；用方向离散求和作同状态材料对照，验证 A2/A4 表示的能量、力和切线。方向场与 X 绑定，随物理模型规定随动；不随材料压缩任意重新平均。只对确实有内变量的模型新增并验证历史演化。
- 为什么：只在45°单方向上通过不能证明多方向和非均匀材料泛化。低阶方向矩能否充分表示能量取决于材料函数，不能默认所有纤维本构只需 A2/A4。
- 如何验收：适用多项式阶次下与离散方向求和相符，非适用本构登记表示误差或增加有界表示；同状态能量导数相容、重启后方向身份不变。方向平均消融应在注册交叉方向工况显露预期差异，否则不声称“必要性”已证明。

**P6.3 在可信参考下重新分配函数并做联合消融。**

- 做什么：先冻结候选选择评分及训练工况，使用残差/应力或目标量评分，计入重叠函数交叉项、独立性和质量条件性；构造72/144/288局部函数预算，其他条件一致。以“原有模型、加入方向表示、再加入富集、完整耦合”为基本对照，并补针对三项贡献的单项移除实验；用不同材料/方向、几何、加载各至少一个未参与选区的案例检查泛化。
- 为什么：只按单函数误差排序可能选到冗余函数；只看一个成功场景无法区分材料、空间与交换一致性的贡献。
- 如何验收：每档报告总自由度、材料/几何点数、条件性、误差和总成本，输出支撑图与选择来源。联合工况同时存在方向变化、局部梯度和实际压力机械响应。空间误差2%、反力1%仅作为后续研究目标，不作为本轮短窗硬门槛；未达标明确是哪一项误差占主导。替换正式空间必须另发空间版本并重做相关合同。

### P7：粒子解耦与可复现交付

**P7.1 固定预算规模验证。**

- 做什么：在同一物理离散、压力控制体和材料/几何规则下，取三个小到中等粒子档位；验证冻结求解包一致，测量 Solve 内材料/Jv/迭代计数、内存和耗时，Prepare/Load单列。若粒子变化改变输入材料表示，则另设误差试验，不混入纯性能对照。
- 为什么：目标是固定 ndof/NQ/Np 的角色，而不是宣称所有成本与粒子数无关。
- 如何验收：内层残差、Jv和重试不访问长度为 Np 的数组；固定包下状态维数与材料调用规则不依赖 Np。报告 `T_step=T_prepare(Np)+T_solve(ndof,NQ,niter)+T_load(Np)+T_IO`。若显示粒子影响迭代次数，说明其改变了什么输入，不用近似平坦时间曲线代替结构证据。

**P7.2 独立封存与论文证据表。**

- 做什么：保存新源码快照、输入锁、协议、原始曲线、失败尝试、测试来源、检查点和可视化入口；复核旧发布未变。逐项列论文候选贡献、代码、公式、对照、适用范围及仍缺证据。
- 为什么：不同研究分支的合格结果不能自动拼成同一个已通过的方法版本。
- 如何验收：新进程可加载新包并运行已登记最小案例；发布能力标志由实际结果生成。至少区分正式 CPU 耦合、生产接入、GPU、独立参考、时间精度和论文完整性，任何未验证项不得默认 true。

## 5. 验收尺度与实验预算

用户重点是整体正确、稳定和适度成本。本计划不追求机器精度，不追加无目的长周期。以下为下一轮开工时需要冻结的建议起点，均需报告单位及归一化分母。

| 类型 | 建议尺度与检查方式 |
|---|---|
| 物理有效性 | 无 NaN/Inf；沿已检查路径 `J>0.1` 作为继承拒绝阈值；同时报告实际最小值。此阈值是失效保护，不是“接近0.1仍准确”的声明 |
| 方向导数 | 两个合适扰动幅度、少量代表方向；目标相对差约1e-3，近零方向使用有单位绝对尺度。不要求每个方向达到1e-10 |
| 体积链/压力功 | 目标归一化差不超过1e-6，并用参考体积/典型压力功设置分母下限；必须包含移动边界。这里只是代数合同 |
| 非线性动量 | 初始沿用 `1e-8 N + 1e-3 ×力尺度`，同时报告自由残差和总反力；检查固定行大载荷没有掩盖自由方程错误 |
| 质量 | 各控制体及全局分别检查；以储水变化、耦合体积变化和通量三者中的代表量及绝对下限归一化，建议1e-3工程量级 |
| 材料规则比较 | 同状态力、弱应力和切线先以约1%—3%作为工程筛选目标；能量近零不使用病态相对误差；达不到就不用该压缩规则 |
| 能量 | 原始缺陷建议控制在典型实际功/能量变化的约1%内，并单列路径、求解和规则变更贡献；初始大静态能不能充当宽松分母 |
| 场景趋势 | 排水/不排水、α=0退化、夹持、压力机械响应均需通过；趋势错误不能靠放宽误差容差或加阻尼处理 |
| 时间/空间精度 | 短窗不签发长期、严格时间或空间精度；可信参考后再单独评估研究目标 |

首批预算建议：

- 算子与导数验证优先轻量运行；正式全规则 Jv 只选少量方向，不按每个自由度扰动。
- 每个非线性步最多6次外层迭代、每次最多20次 Krylov 迭代作为初始上限；另外设置材料遍历总数和墙钟上限，先到者停止，不让两个上限相乘变成默认工作量。
- 先测一次残差和一次 Jv；单个正式工况初始墙钟上限600秒、峰值RSS上限8GiB且不超过实时可用内存的安全范围。若估计不足，先改变实现成本或交付范围，再预登记新预算；不在后台无限延长。
- 四步是耦合主窗口；退化/边界与回退检查用单步或算子检查。参考和论文消融另批登记，不能把所有组合一次跑完。
- 只有新失败、源码变更或未覆盖风险才增加测试；一次通过后不重复跑同一重实验。

## 6. 异常处理、磁盘和文档维护

1. 明确的小问题，如错误数组形状、遗漏转置、单位和缓存键问题：定位后修复，跑直接受影响的检查，再继续。
2. 明显物理异常，如压力功符号错、质量无故增长、负耗散、边界冲量漏项、J骤降：停止该路径，检查公式、时间层、控制体方向及全量/自由量映射，禁止用增大阻尼、裁剪压力或改势能掩盖。
3. 潜在高风险变更，如改变物理空间、原稳定化、质量或历史映射：先给出独立推导及最小验证。预算内无法定位根因时，记录失败输入、最小复现、影响范围和跳过原因；跳过依赖分支，不伪造通过。
4. 每个门槛完成或方向改变后更新**新进展文档** `MPM_LITE_FORMAL_PRESSURE_WORK_PROGRESS_20261007_ZH.md`（拟建），保留协议变更时间及依据。不要改动已封存的旧进展、源代码快照和结果。
5. 每次较大输出前记录 `df`/可用内存。本文核查系统盘约5.2GiB可用，数据盘约99GiB可用，本轮文档任务没有迁移数据。实施时以5GiB为保守阈值；低于阈值只迁移确认不再使用的旧缓存/大结果到数据盘，保留路径链接，先复制校验再释放源副本，不迁移活动写入目录，不删除唯一原始证据。
6. 所有数据迁移后复核引用路径和哈希。新实验优先把大输出放数据盘，封存结果不能原地重算。
