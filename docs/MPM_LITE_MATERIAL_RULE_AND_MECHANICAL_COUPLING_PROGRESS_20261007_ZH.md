## 时间敏感性的分析与下一步

对固定几何的压力网络，`C p_dot + L p = 0`，其中`L=D H^{-1} D^T`。中点法在特征值λ上的放大因子为

`r(λ) = (1 - dt*λ/2)/(1 + dt*λ/2)`。

当dt远大于相应松弛时间1/λ时，r趋向-1，稳定并不表示快模态被正确消退。本轮网络时间尺度约7.81e-5—2.34e-4秒，明显小于.025秒。该分析只针对固定几何网络，不把它当完整耦合模态谱。

同时，原完整质量/切线下的线性化耦合，在一个粗步与两个半步间重现了实际冲量变化。这支持本轮的主要误差来源为时间离散；材料q5/q7差异极小，不能靠提高材料积分阶次解决当前相位问题。系数q/velocity的相对变化不等于物理场误差，判断以同材料位置探针、压力和反力冲量为准。

下一轮顺序建议：

1. 固定本轮空间、材料、几何与网络，选择一个关键短窗研究时间尺度；先比较更小/分段时间步，明确压力快模态和固体惯性各自影响。若研究子步或L稳定方案，先重新推导同一压力功/质量/能量合同，不能只替换压力更新或加阻尼。
2. 时间不确定性低于待测排水机械差异后，再判断强耦合响应是否可信。维持原始反力和压力、相同终点及加载，避免混比步中点与步终点。
3. 仅在已限定q5适用范围内研究备用检查频率与几何复用；当前每步q7核查抵消大部分材料压缩收益，几何约占36%。新策略需保留真实失败和整步回退，不能直接减少检查并继承安全资格。
4. 独立空间参考和生产APIC状态所有权各立协议后推进。没有同物理参考时不替换正式144空间，没有投影/历史合同不覆盖生产粒子状态。

本轮没有为触发GMRES故意加大变形，没有改变物理稳定化或容差，没有实施未分析清楚的生产替换。P4一般非线性迭代资格和P5—P7相关依赖明确延期；一般接口、事务和参数合同问题已修复并验证。
