# 受控 Q1 模板切换：固定历史、模式保留与短程更新

## 1. 本轮范围与结论

承接[一致原型](ANISO_CONSISTENT_TRANSFER_ZH.md)与[同载荷力学对照](ANISO_MECHANICS_COMPARISON_ZH.md)，本轮固定预弯曲梁的粒子位置、$F_p$、参考坐标、质量和参考纤维方向，只改变 Q1 的材料参考分区。

**嵌套细分通过，可以继续短程更新；移动内部节点和粗化未通过，不提交为新动态状态。** 未通过的原因已量化，没有因难定位而跳过。结论不等于任意重划分已解决：本轮成功路线保留了全部旧空间，且增加节点与积分点。

保持原生产默认。本轮是 CPU 材料随体研究原型，不是 Eulerian 稀疏网格迁移，也不包含 APIC、塑性或接触。当前受限环境无法访问 NVIDIA 驱动；磁盘初始系统约 11 GiB、数据盘约 24 GiB，未触发迁移或暂停，实验继续使用容量守卫。

## 2. 固定什么、改变什么

源网格为 17 和 33，主结论以 33 为准；参考梁为 $[.25,.75]\times[.4375,.5625]^2$，相同非均匀弯曲、平滑材料方向场、同一本构 $(10,20,200)$。

每个源单元每轴 4 粒子，总质量/体积仍为 0.0078125。选择这个 PPC 是为了让真正增加自由度后的质量矩阵可解，不是增加物体质量。四种变化为：

| 候选 | 变化 | 作用 |
|---|---|---|
| identity | 保留原节点，重新构造全部映射 | 实现正控制 |
| refine_x | 每个 x 向单元一分为二，y/z 不变 | 新空间包含旧空间的真正模板变化 |
| shift | 内部参考节点移动，最大约 0.2 个旧网格间距，边界固定 | 非嵌套空间变化 |
| coarsen_x | 每两个 x 向单元合并 | 检查压缩历史的代价 |

新模板中仍使用同一批物质粒子、相同参考粒子坐标和体积。方向不随新分组初始化；固定快照末尾对所有权威粒子数组逐项验证未被改动。积分点上的平滑方向使用同一已知材料参考方向函数，本轮不声称解决任意离散混合方向场的重建。

## 3. 从粒子构造提案，不偷偷改写历史

采用有夹具约束的质量加权位置拟合：

$$\widehat x=\arg\min_x\frac12\sum_p m_p\left\|\sum_iN_i^{new}(X_p)x_i-x_p\right\|^2.$$

左端面位置保持已知夹具几何。由提案读取

$$\widehat F_p=\sum_i\widehat x_i\otimes\nabla_XN_i^{new}(X_p).$$

粒子 $F_p$ 保持原值。提案的 $\widehat F_p$ 只用于比较；原型已有的 `recover` 兼容检查独立决定能否推进下一步。**没有放宽检查、投影覆盖 $F_p$ 或重置为 I 来让失败方案通过。**

如果旧空间 $V_{old}\subseteq V_{new}$，旧位置场及其梯度可以同时被新空间表示；这解释了嵌套细分为何能够保持历史。若移动或删除旧折点，一般不存在同时准确恢复全部旧位置和梯度的新 Q1 场。

质量矩阵仍为 $M=N^T\operatorname{diag}(m_p)N$。测试发现，每轴 2 粒子时沿 x 细分会产生质量零模态，已明确拒绝。首轮最小特征值检查使用常数初始向量，因与交替零模态正交而漏检；随后稀疏分解拒绝了矩阵。修复为可复现的非对称随机初始向量，并保留分解失败的第二道拒绝检查，没有添加正则质量。

## 4. 将能量、应力、局部变化与模式分别检查

能量在同时切开旧、新参考节点的公共积分规则上读取：

$$\Delta U_{remap}=U_{new}^{common}-U_{old}^{common}.$$

另外分别计算两边自身积分规则的能量，记录规则差：

$$\Delta U_{rule}=(U_{new}^{own}-U_{old}^{own})-\Delta U_{remap}.$$

总能量接近可能是不同位置的正负变化相互抵消，因此另测：

$$e_{local}=\frac{\sum_q V_q^0|\psi_{new,q}-\psi_{old,q}|}{U_{old}^{common}}.$$

应力在同一批固定粒子位置按参考体积加权比较，使用 Cauchy 应力 $\sigma=PF^T/\det F$。当前方向比较归一化的 $FA_0F^T$，避免方向正负号歧义。应变差使用 $F^TF-I$，避免将刚体旋转误算为伸长。

模式比较包括伸长、剪切、两种弯曲、扭转，以及同几何均匀纤维 Q1 参考的两个最软模式。将旧节点模式传到粒子，再拟合到新空间，比较

$$e_{mode}=\frac{\|\mathcal R_{new}\mathcal T_{old}\delta F-\delta F\|_{V}}{\|\delta F\|_{V}}.$$

这里检验旧空间中的模式能否保存，不是证明新空间所有模式的精度或稳定性。

## 5. 固定快照结果

| 源网格 / 切换 | 总能量净变化 | 局部能量变化绝对值合计 | 应力相对差 | 最大模式增量差 | 可进入动态？ |
|---|---:|---:|---:|---:|---|
| 17 / 嵌套细分 | 约 $10^{-12}$ 的相对量 | 接近舍入误差 | 接近舍入误差 | 约 $3.3\times10^{-14}$ | 是 |
| 33 / 嵌套细分 | 约 $10^{-12}$ 的相对量 | 接近舍入误差 | 接近舍入误差 | 约 $5.2\times10^{-14}$ | 是 |
| 17 / 移动节点 | +0.1431% | 15.090% | 29.819% | 5.363% | 否 |
| 33 / 移动节点 | +0.01461% | 7.384% | 14.376% | 9.321% | 否 |
| 17 / 沿 x 粗化 | +16.794% | 43.521% | 43.004% | 7.737% | 否 |
| 33 / 沿 x 粗化 | +4.318% | 18.823% | 21.662% | 3.839% | 否 |

模式误差中的最大值可能来自不同模式，不能把最大值随网格变化简单解释为同一模式的收敛率。

**关键发现：细网格移动节点时，能量净变化仅约 0.015%，但应力差约 14.4%。** 粒子位置拟合的 RMS 差只有约 $1.18\times10^{-6}$，也不能据此认定历史准确。局部能量变化的绝对值合计表明，明显的局部变化被总量抵消了。

沿 x 粗化甚至可能使总能量增加，而非必然“平均后能量下降”：位置最小二乘不以弹性能或梯度为目标，改变折点后可能引入额外剪切等变化。当前实现没有通过调整能量读数或力来掩盖此问题。

## 6. 通过方案的刚体运动与短程更新

在嵌套细分上补充跨越约 2.3 个旧网格间距的精确平移和 45° 精确旋转。先精确改变快照姿态，再进行模板切换；避免 Euler 旋转积分产生的人为伸长。它们都通过严格历史兼容检查；这是材料参考模板试验，不是跨 Eulerian 稀疏块的生产迁移。

短程释放为 dt=0.0005、4 步，在第 1 步结束后重建新模板、质量矩阵并切换，再继续 3 步。与同一初态、不切换的 4 步控制比较。切换瞬间的粒子位置、速度、$F_p$ 改变量均为零，公共积分能量相对跳变约 $10^{-12}$ 或更小。

粗/细网格不切换的最终机械能变化约 -9.41% / -12.88%，切换后约 -13.35% / -14.09%。**后续轨迹和耗散可以因增加自由度而变化；它们不是切换瞬间的能量跳变。** 后向欧拉耗散仍存在，本轮不要求严格守恒，也没有将增加自由度后的轨迹差称为历史丢失。

## 7. 成本与产物

节点/材料点从 81/864 → 153/1728（源 grid 17），425/6912 → 825/13824（源 grid 33），粒子数保持 2048 / 16384。嵌套细分保留了历史，同时也提高了后续材料求解成本，不是采样压缩或加速结果。

JSON 分别记录原模板准备、新模板映射、质量检查与分解、位置恢复、诊断时间；逐步 CSV 记录粒子准备、材料非线性求解、提交/历史恢复和整步耗时。整步还包含能量账本，切换运行总耗时包含诊断；这些是单次 CPU 观察，不能直接作为生产性能排名。原模板准备作为两条路径的公共成本单独列出。

## 8. 下一步边界

目前有依据使用“保留旧空间的细分”作为安全切换基线；还没有依据进行任意移动节点或粗化。若继续压缩/重划分，应研究携带额外历史残差或局部材料样本，使旧变形不必全部被挤进新几何梯度，并重新统一推导势能、残差和切线。单纯增加积分点、放宽恢复容差或改写粒子 F，都不能解决已测到的空间不相容。

2026-09-22 后续实验：[历史＋新增量原型](ANISO_HISTORY_INCREMENT_ZH.md)已另建，保留本文严格检查。固定旧样本与完整历史位置场后，非嵌套移动可继续短程更新；解析导数和无质量谱检查通过，但刚体转动增量表达未通过，尚未进入历史压缩。
