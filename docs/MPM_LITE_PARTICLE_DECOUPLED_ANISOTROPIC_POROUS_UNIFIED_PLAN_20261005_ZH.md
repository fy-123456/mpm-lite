## 2. 方法边界、复杂度和共同方程

### 2.1 第一阶段物理范围

采用各向异性超弹性骨架、饱和单相 Darcy 渗流、非均匀参考纤维方向。保持有限形变公式，但只对实际验证的变形幅度作能力声明。历史指参考映射、形变及方向信息，不泛指塑性内部变量。

第一版采用离线选取、运行中固定的富集函数预算；求解过程中分组和积分点冻结。若网格移动或粒子跨支撑，必须明确基函数在哪个坐标系固定、传递在哪个坐标系计算。不能通过冻结粒子运动来回避这个问题。在线换基、断裂、多相流、自由表面和塑性不属于首版完成条件。

保持当前实际数值精度和后端设置，在配置中显式记录；本计划不以更换 float64 或 Warp 作为优化目标，也不另行禁止现有依赖。性能对照必须使用可比精度、硬件与停止准则。

### 2.2 粒子数解耦的准确含义

记粒子数为 Np、积分点数为 Nq、载体自由度为 Nc、富集自由度为 Ne、压力和通量规模为 Npi/Nz。必须分别统计局部标量函数数、矢量系数数和施加边界后的自由度数。

目标成本结构：

```text
T_step = T_unload(Np) + T_prepare(Np, budgets)
       + K * T_inner(Nq, Nc+Ne, Npi, Nz)
       + T_load(Np) + T_output
```

其中 K 是实际迭代次数，不假设随 Np 恒定。只要求固定预算下单次内层算子的工作量不直接随 Np 增长；整步传递、粒子存储、输出仍依赖 Np。固定组数 Gmax 与每组 Q 点时，应有 Nq ≤ Nregion×Gmax×Q。充分回退规则也需要明确预算，不能悄悄退回逐粒子内层积分后仍宣称全路径解耦。

提高 PPC 的实验保持连续物理场不变；增加材料复杂度的实验单列。若活跃区域、积分预算或迭代数变化，分别报告，不能把它们当粒子数效应或藏在恒定耗时结论里。

### 2.3 统一空间与材料表示

设 B=[Nc,Phi] 是载体—局部组合基函数矩阵，q 是其系数：

\[
u_h(X)=B(X)q,\qquad F=I+\nabla_Xu_h,
\qquad M=\int_{\Omega_0}\rho_0 B^TB\,dV.
\]

M 保留载体—局部交叉项；不能用人为对角质量掩盖病态或改变惯性。若使用增量参考写法，必须给出与上述材料坐标写法的对应关系，禁止将总 F 与增量 F 混用。

对归一化参考方向 a，A=a⊗a，C=FᵀF，当前二次纤维能可写成：

\[
\psi_f(F,A)=\frac{k_f}{2}(C:A-1)^2.
\]

组内方向矩 A2=ΣωA、A4=Σω(A⊗A) 对共同 F 给出：

\[
\overline\psi_f=\frac{k_f}{2}\big(C:A_4:C-2C:A_2+1\big).
\]

该表达的精确性只适用于共同 F 和指定材料形式；非均匀 F、位置关联和重新分组仍有近似误差。参考张量与当前方向不能混用；材料客观性要求 ψ(RF,A0)=ψ(F,A0)，空间旋转不意味着任意旋转参考 A0。

统一离散势能 Uh=Σwgψ(Fg,A2g,A4g)+Es，其中 Es 为显式登记的稳定化。内力和物理切线从同一势能求导。求解保护用的近似切线与预条件器单独命名，原残差与原势能线搜索仍用于验收。几何／压力算子使用同一形变场，但不要求与材料积分采用同一套点；应分别保证精度和功关系。

### 2.4 耦合与整步账本

以常系数储存的已选模型说明结构：

\[
M\dot v+\nabla U_h(q)-\alpha G(q)^Tp=f_{ext},
\quad S\dot p+\alpha G(q)v+Dz=s,
\quad H(q)z=D^Tp-g_b.
\]

其中 G=∂V/∂q，V 是压力控制体的体积，D 为通量散度，H 为 Darcy 阻力；符号、单位和边界功在 S1 与实际代码对齐。储存、alpha、孔隙率若改成状态相关，必须重推能量关系，不沿用常系数公式。

要求离散链关系：

\[
\overline G\Delta q=\Delta V,
\qquad -\alpha\overline p^T\overline G\Delta q
       +\alpha\overline p^T\Delta V=0.
\]

若使用路径 Simpson 规则，应确认冻结空间下 F 随路径参数仿射、det(F) 的多项式条件成立；空间或参考在路径中改变时不能自动继承精确性。

整步账本必须包括传递和重建：

\[
\Delta E=W_{ext}+W_{boundary}-D_{Darcy}-D_{time}
+\varepsilon_{solve}+\Delta E_{transfer}+\Delta E_{rebuild}.
\]

账本闭合不等于传递无损。流体含量建议作为明确的守恒状态，压力由相同储存／体积关系解释；粒子显示体积不能再被当作额外流体源。压力控制体变化时若需重映射，必须守恒并单独记账。

## 3. 验收原则和阶段门槛

### 3.1 三种通过状态分开记录

- **实现正确性：** 来源一致、单位与维度正确、导数和原残差可核对、事务完整、无非法数值状态。
- **工程可用性：** 场景有合理方向性与运动、无明显失稳、关键曲线和守恒缺陷在预登记工程预算内。
- **论文证据：** 参考不确定性受控、未见工况有效、消融可归因、误差—成本关系和 PPC 解耦可复现。

工程通过不能自动升级为论文精度通过。采用 `passed_scoped / limited / failed / not_triggered / not_run`；这些是拟定的新报告状态，不修改旧发布状态枚举。

### 3.2 不追求无意义的极小误差

1. 来源哈希、字段身份、索引、成功代次与回滚语义属于硬条件，不能因为“数值不必太严”而放宽。
2. 数值指标采用 `|差异| ≤ atol + rtol×预登记尺度`；atol 有物理单位，不能事后随结果调整。近零压力或纳米位移不报告误导性的百分比。
3. 首轮工程场量相对预算可考虑约 5% 量级，由独立参考与信号尺度确定；这不是本计划已经签发的统一门槛。材料导数、离散功和原残差的预算根据 dtype、条件数及差分平台单独设定，不能直接用 5% 代替。
4. 对可分辨信号，若声称改善量为 Δerr，应把参考不确定性控制在明显小于 Δerr 的水平；建议以 Δerr/3 为起始判断尺度，做不到则只报受限比较。
5. 不人为增加阻尼、裁剪压力、删除耦合项或更换材料来通过。负压本身不自动判失败；按所选饱和模型的允许范围、边界和参考解释，禁止无依据裁剪。
6. 准确性门槛未满足时先定位空间、时间、积分、转移和求解误差；原因可定位则修复，根因不清时停止依赖分支，保留诊断与失败证据。

- **如何验收：** 零物理步的来源检查能区分新旧文件；旧结果无写入；预算和异常策略已登记。未来若必须修改原文件，应建立独立版本并明确更改来源，不通过修改旧清单追认。
- **交付：** `S0/source-map.json`、`S0/resource-budget.json`、`S0/experiment-register.json`。

### S1：定义一个统一、可导出且不依赖粒子数组的求解接口

**S1.1｜冻结物理模型、状态所有权和坐标约定。**

- **做什么：** 明确粒子 X/x/v/F/A0/质量、组合空间系数 q/v、压力 p、通量 z、流体含量、累计交换和能量历史谁是权威状态。标明参考量/当前量、压力单元与粒子区域的对应、每个变量的单位。
- **为什么：** 两套形变或含量同时被当作真值会造成隐性漂移和重复计算。
- **如何验收：** 同一物理状态可被独立检查器重建；无总量/密度、参考体积/当前体积混用；先选固定参考控制体，若实际代码不同则明确适配而非隐式转换。
- **交付：** `S1/state-contract.md`、`S1/units-and-layout.json`。

**S1.2｜定义 Unload / Prepare / Solve / Load / Commit。**

- **做什么：** 把粒子读取限制在 Unload、必要步前准备和 Load；Prepare 导出冻结求解包。包只含有限积分状态、基函数映射、质量、边界、压力拓扑等；内层材料、几何和线性算子只接收该包及试探系数。提交前保留旧完整状态。
- **为什么：** “内层不访问粒子”必须是接口性质，不能只依赖计时推断。
- **如何验收：** 依赖图中内层不存在粒子长度数组、隐藏闭包或回调读取；冻结数据所有权明确；重复残差求值不更新历史。压力边界、材料、空间或拓扑改变时缓存失效。
- **交付：** `S1/interface-contract.md`、`S1/ownership-map.json`、缓存失效表。

**S1.3｜预登记比较对象与验收协议。**

- **做什么：** 定义朴素各向异性 Lite、当前研究空间、统一方法和充分参考的相同本构/边界条件；固定场量位置、应力度量、时间节点、绝对尺度、误差预算与训练/验证划分。
- **为什么：** 不同物理模型、不同应力定义或观察位置的差异不能归为算法改进。
- **如何验收：** 原版只在其支持的退化工况直接比较；各向异性比较使用同一本构；已使用的 F45/F60/52.5° 不再称未见工况；预算在看新结果前写入。
- **交付：** `S1/acceptance-protocol.json`、`S1/baseline-matrix.md`、`S1/heldout-register.json`。

### S2：构造有界表示、兼容空间与正确耦合算子

**S2.1｜建立固定预算的方向与历史表示。**

- **做什么：** 复用条件方向矩，设区域、组数与积分数上限；从同一粒子输入构造位置关联、F 参考、A2/A4 和正体积权重。第一版使用确定性分组，不在每次 Newton 迭代重分组。统计准备时间与存储。
- **为什么：** 方向矩保留的信息必须足够，同时 Nq 不能跟着 Np 无界增长。
- **如何验收：** 总参考体积和材料比例可核对；A2/A4 满足适用的单位方向矩关系；不同粒子排列不产生超预算差异；在同一连续场的不同 PPC 上保持声明的组数上限。预算不足明确报告，不自动退回无限分组。
- **交付：** `S2/representation-contract.json`、`S2/moment-and-volume-check.json`、`S2/representation-cost.json`。

**S2.2｜适配完整质量、边界和材料梯度。**

- **做什么：** 从一个可独立核查的小空间开始，将方向/历史包接入 B=[Nc,Phi]；保持完整交叉质量，按同一 B 构造 F、边界值和外力功。再做现有 144 局部函数包的桥接。分别记录标量函数、矢量系数和自由度。
- **为什么：** 直接把旧 MLS 材料梯度塞进新富集惯性中，会形成不一致离散；小模型有利于定位。
- **如何验收：** 质量在正确约束子空间中具有预期秩；刚体/仿射再现与边界无泄漏；能量—内力—切线在少量方向差分中一致。发现低质量但材料活跃方向不能直接删除，应检查积分、支撑和约束。
- **交付：** `S2/space-adapter.json`、`S2/mass-boundary-audit.json`、`S2/material-derivatives.json`。

**S2.3｜接入相同形变场下的 V/G/H。**

- **做什么：** 在新 B 上计算控制体体积及其导数，适配 RT0 通量、当前几何和 BD 后端；保留全非对角迁移率。通过同一离散体积变化构造压力力与流体交换。
- **为什么：** 压力功一致需要共同形变和体积语义，不能仅共用变量名称。
- **如何验收：** 少量静态状态下体积差分、G 作用和路径体积链通过；固液交换功相消；Darcy 耗散非负到数值预算；常压和固定骨架退化正确。混合系统不直接假设 SPD/CG，报告原残差及压力零空间处理。
- **交付：** `S2/coupling-equation-map.md`、`S2/volume-work-check.json`、`S2/mixed-solver-check.json`。

**S2.4｜建立内层粒子访问与工作量检查。**

- **做什么：** 为各阶段分别统计粒子读取、材料能/力/切线作用次数、积分点数、几何调用及传输字节；在小测试中将冻结包单独序列化，在不加载粒子数组的新进程中计算残差与切线。若有 GPU 指针或闭包依赖，先消除隐式依赖。
- **为什么：** 单纯给粒子访问计数器加零值不能证明 GPU 内核没有读粒子。
- **如何验收：** 源码/依赖检查与无粒子独立求值共同支持解耦；相同冻结包输出一致；缓存、预条件器和调试诊断也不在内层偷读粒子。测试不包含物理 Load，不宣称无粒子端到端仿真。
- **交付：** `S2/inner-access-audit.json`、`S2/frozen-operator-replay.json`、`S2/counter-definition.md`。

### S3：先完成一个真正贯通粒子的最小场景

**S3.1｜统一 Load 与历史再构造。**

- **做什么：** 用已接受的相同位移/速度场更新粒子运动和 F；说明原 APIC/FLIP 信息与富集速度梯度如何对应。下一步再从粒子构造表示，分别记录 Load 与重建造成的能量、动量和体积差。
- **为什么：** 如果粒子只用于显示，或其 F 没有反馈给下一步，就没有完成 Lite 粒子历史闭环。
- **如何验收：** 刚体平移/转动、仿射变形、纯往返传递通过；至少一项粒子跨载体支撑的受控测试；历史变化可分解，不能在每步把 F 强行重置到参考答案。受限固定支撑实现必须标注范围，不能推广为一般移动网格 Lite。
- **交付：** `S3/load-history-map.md`、`S3/roundtrip-check.json`、`S3/transfer-ledger.json`。

**S3.2｜运行最小三模块耦合短窗。**

- **做什么：** 使用非均匀但简单的方向场、一个局部形变区和可排水边界；先用充分积分，在 CPU 小规模模型上检查，再用实际后端做短窗。默认先 8～16 个接受步，只保存初态、关键阶段和终态。
- **为什么：** 要先证明三项贡献在同一物理步运行，再追求场景规模和性能。
- **如何验收：** 原残差、边界、detF、压力/流量、固液收支均可解释；材料方向、局部系数和压力交换不是被动占位变量。信号不足时按预登记新场景调整加载或时间尺度，明确更换身份，不放大显示后声称物理响应充分。
- **交付：** `S3/mini-scene.json`、原始场与账本、`S3/physical-review.md`。

**S3.3｜验证完整事务和规则回退。**

- **做什么：** 在一次试探状态形成后注入受控失败；验证粒子、q/v、p/含量、累计交换、分组、缓存和代次均回滚，再用原规则重算。若准备低成本积分，另检验充分规则回退是否保持预算独立于 Np。
- **为什么：** 只回滚固体状态会造成流体质量和材料历史污染。
- **如何验收：** 失败不得产生新提交；重算与从同一已提交状态直接执行一致；新进程能恢复。回退若使用粒子积分，应标明解耦例外并计费。局部受控失败不等于真实 GPU 驱动丢失恢复。
- **交付：** `S3/rollback-retry.json`、`S3/fresh-process-load.json`、`S3/fallback-scope.json`。

**S3.4｜决定是否进入论文验证阶段。**

- **做什么：** 汇总 S2～S3，确认真实粒子闭环、内部无粒子依赖、联合物理信号和短程稳定性；定位剩余问题属于表示、空间、时间还是耦合。
- **为什么：** 接线未完成时做 PPC 扫描和大规模性能测试没有论文意义。
- **如何验收：** 核心硬条件通过才进入 S4；失败可交付实现诊断，但不能标记统一方法完成。若固定材料坐标方案无法承担所需粒子闭环，应写出方法定位决策，不把粒子装饰性添加作为通过。
- **交付：** `S3/integration-gate.json`、阶段实施总结及能力矩阵。

### S4：建立有机械信号的独立参考

**S4.1｜选定物理窗口与参考路线。**

- **做什么：** 先估计机械尺度 L√(rho/E) 与排水尺度 L²/cv，核对 cv 定义和单位；选择有可分辨变形的加载—保持—卸载及排水窗口。登记目标场量、信号下限和参考路线。
- **为什么：** 80 纳米短窗不宜承担有限形变机械精度结论；更多显示帧也不能增加信号。
- **如何验收：** 物理幅度高于误差下限且未超模型范围；周期长度按物理过程确定。只有确有需要时延长窗口；原 75 微秒结果只作旧场景对照，不冒充新综合场景。
- **交付：** `S4/signal-and-timescale.json`、`S4/reference-protocol.json`。

**S4.2｜构造同物理的独立充分参考。**

- **做什么：** 优先采用小规模、充分积分、混合稳定的独立有限元或同等离散实现；与统一方法采用同一本构、几何、边界、流体模型和外力泛函。基础固结解析解仅在其小变形适用范围验证子模块。
- **为什么：** r8/r12 投影模型或同一空间换 ODE 积分器，不能证明固体空间准确。
- **如何验收：** 参考模型的材料导数和耦合符号自行检查；原研究稳定化与参考处理明确对应。稳定化若只属于数值项，另报其贡献及随加密变化，不能偷偷把不同稳定化结果称作同一问题真值。
- **交付：** 参考源码/版本、`S4/reference-physics-map.md`、`S4/reference-self-check.json`。

**S4.3｜分别控制空间、时间与积分不确定性。**

- **做什么：** 先两档固体/压力空间和两档时间步，逐项改变；若趋势不足判断，再触发第三档。比较共同位置的骨架/总应力、位移、反力、压力和区间排水；积分充分性单独核对。
- **为什么：** 同时改变所有分辨率不能定位误差；小投影模型内部一致也不是连续空间认证。
- **如何验收：** 报告每个目标量的参考不确定性；未受控区域标为 reference_limited。改进量小于不确定性时，不给出精度优越结论。近零量采用绝对尺度，不能靠分母变大掩盖误差。
- **交付：** `S4/reference-uncertainty.json`、`S4/error-decomposition.csv`、分区误差图。

### S5：在可信参考后优化方向预算与耦合导向富集

**S5.1｜定义可复现的富集选择方法。**

- **做什么：** 从训练残差/快照建立候选；先消除已有空间的重复方向，再比较材料方向响应、体积变化和压力/排水目标。各评分量先按固定尺度无量纲化，记录成本与条件数惩罚。明确纯离线选择，不使用隐藏参考作在线评分。
- **为什么：** 仅改善固体应力可能损害体积交换；简单换基若不改变子空间也不增加表达能力。
- **如何验收：** 相同输入给出相同选取；候选提供独立于现有空间的新方向；完整交叉质量、边界和材料算子重建通过。函数数保持预算，评分中的重叠交叉作用有明确处理。
- **交付：** `S5/selection-algorithm.md`、`S5/training-manifest.json`、`S5/space-audit.json`。

**S5.2｜建立预算曲线并登记采用决定。**

- **做什么：** 小模型先比较三档可承受预算；条件允许时用 72/144/288 局部函数，载体/压力空间保持不变。对比简单分配、仅固体快照和耦合导向选择；分组预算单独变化，不一次交叉扫描全部组合。
- **为什么：** 单个 144 函数结果不能证明固定预算方法的有效性，也不能揭示积分与空间各自瓶颈。
- **如何验收：** 报告全部自由度、Nq、准备时间、内层时间、应力/体积/压力/排水误差和参考不确定性。不要求每个量严格单调，但必须解释反例；新空间只以新版本发布，不覆盖旧正式空间。
- **交付：** `S5/budget-curves.csv`、`S5/error-cost-review.md`、`S5/adoption-decision.json`。

**S5.3｜在新空间复验历史与功关系。**

- **做什么：** 用入选空间重复少量关键的往返传递、体积链、边界和事务测试；运行一条有物理阶段变化的短轨迹。
- **为什么：** 旧空间的质量、相位、q5 与回滚认证不能自动转移到新空间。
- **如何验收：** 有针对性的合同检查通过；不重复无关全套实验；新身份明确列出尚未重新认证的能力，耦合 q5 仍保持未认证，除非另行执行完整条件测试。
- **交付：** `S5/new-space-qualification.json`、更新能力矩阵。

### S6：证明解耦、可归因性和泛化

**S6.1｜固定物理与预算的 PPC 扩展。**

- **做什么：** 同一连续几何、材料与方向场，选择每轴 2/3/4 粒子等三个可承受档位（3D 每单元 8/27/64，实际 Np 另报）；固定载体、富集、压力空间、组数上限、积分规则和时间协议。保证总质量与参考体积一致。
- **为什么：** PPC 增长用于增加采样密度，不能同时增加物理细节或网格分辨率。
- **如何验收：** 每次内层材料/几何工作量及冻结包大小不随 Np 无界增长；分别报告 Unload/Prepare/Solve/Load、迭代次数、内存和场量误差。准备成本随 Np 增长是允许且必须报告的结果。
- **交付：** `S6/ppc-protocol.json`、`S6/ppc-cost.csv`、`S6/inner-dependence-verdict.json`。

**S6.2｜区分算子解耦与动态求解效率。**

- **做什么：** 第一组只对固定冻结状态重复少量算子作用，检查单次成本；第二组让不同 PPC 的同物理初态真正推进短窗，测量实际迭代和整步成本。GPU 计时使用一致同步边界，预热与编译另报。
- **为什么：** 固定状态回放只验证实现复杂度，不等价于不同采样下动态求解时间恒定。
- **如何验收：** 访问证据、工作量、耗时及迭代数共同解释结果；抖动大时记结论不确定。吞吐和速度对照使用同硬件、同精度、同停止条件，不能用历史计时拼出加速率。
- **交付：** `S6/operator-scaling.csv`、`S6/dynamic-scaling.csv`、`S6/timing-method.md`。

**S6.3｜实施最小贡献消融。**

- **做什么：** 小型综合场景上比较方向/历史、富集、功兼容三个维度的组合，最多八组；先固定充分积分，避免第四个变量干扰。常规功离散基线必须数学合理、写明阶次，不能故意删除必需物理项。较大场景只保留完整方法与三个逐项去除版本。
- **为什么：** 三项同时打开后运行良好，不能证明每项贡献的作用，也不要求它们在所有场景都不可替代。
- **如何验收：** 方向/历史差异对应材料与重建误差，富集差异对应形变/体积表达，功离散差异对应能量与时间步行为；控制其他变量，记录不支持预期的结果。
- **交付：** `S6/ablation-matrix.json`、`S6/ablation-results.csv`、归因说明。

**S6.4｜检查未见工况和表示极限。**

- **做什么：** 使用预登记的未见方向、材料刚度/渗透率、加载位置及至少一种新几何或方向布局；先每类一个代表，不做笛卡尔积大扫描。另设增加方向/材料复杂度的实验，单列于 PPC 测试。
- **为什么：** 固定预算不可能无条件表示任意复杂材料；必须说明可用范围和失效模式。
- **如何验收：** 不用留出结果回调同一候选后继续称隐藏验证；如需重训则记录新训练成本和新验证集。报告全部代表工况，包括未改善项；原 F45/F60/52.5° 仅作已见对照。
- **交付：** `S6/generalization.csv`、`S6/budget-limit-review.md`、训练/验证最终清单。

**S6.5｜计算同误差总成本和离线回收条件。**

- **做什么：** 统计候选生成、参考快照、训练、质量/几何准备、在线运行、传递及 IO；对照达到相近误差的充分方法或朴素扩展。报告相同场景复用次数与几何/材料改变后的重建成本。
- **为什么：** 内层便宜不代表单次总成本便宜，尤其已有 group4x8 可能比粒子积分评估次数更多。
- **如何验收：** 同精度区间内比较；若离线成本增量为 ΔTsetup、每次在线节约为 ΔTrun，则仅在 ΔTrun>0 时报告回收次数 ΔTsetup/ΔTrun。无收益照实记录，不能选择性省略准备成本。
- **交付：** `S6/total-cost.csv`、误差—成本图、适用规模与回收说明。

### S7：形成可复现交付和有边界的论文结论

**S7.1｜完成最小回归与实际恢复。**

**S7.2｜整理图表、性质推导和文献差异。**

- **做什么：** 给出算法流程、材料导数和功关系、复杂度分解；准备参考收敛、预算、PPC、消融、总成本及综合场景图。逐项比较原 Lite、方向矩方法、局部富集/降阶和保结构渗流研究。

- **如何验收：** 每条论文结论关联公式、实现和实验范围；“精确”限定假设，“解耦”限定内层，“稳定”限定时间和工况；不将诊断投影参考写成真值，不使用未支持的“首次／普遍更快”。

## 5. 实验预算、资源与异常策略

### 5.1 小步实施，不将整篇论文实验一次启动

| 阶段 | 初始执行预算建议 | 扩展条件 |
| --- | --- | --- |
| S0～S2 | 只读审计、静态算子和小模型；不启动长轨迹 | 算子和输入合同通过 |
| S3 | 1 个最小场景，初轮 8～16 接受步；1 次受控失败和必要重算；新增物理尝试初始上限 32 | 有明确修复或物理信号理由，先更新预算 |
| S4 | 1 个固结子基准、1 个联合工况；每个误差源先两档 | 两档不足判断时才增加第三档 |
| S5 | 三档函数预算；方向组数另行小范围对照 | 参考可信，确有空间/表示瓶颈 |
| S6 | PPC 三档；一个小场景最多八组消融；未见条件每类一个代表 | 所需对比无法由已有同身份结果回答 |
| 显示帧 | 每轨迹默认 4～8 个关键帧，原始数值曲线独立保存 | 有明确视觉问题需要更密采样 |
| 结果空间 | 每阶段初始不超过 1 GiB；不重复复制祖先大数组 | 核对数据盘剩余空间后登记 |

步数建议只用于冒烟；不能把 16 步冒烟当完整加载/排水周期。后续每个阶段依据单步实测成本预登记硬上限，涵盖构造、编译、静态探针、失败与重算。预算到达后先交付结果与原因，再决定新批次；不能隐藏重复实验，也不能在没有物理证据时增加大量帧数。

同一时刻只运行一个物理实验和一个 GPU 模型。本计划不要求启动并行 agent 或并行大扫参。

### 5.2 磁盘处理

本次只读检查时系统盘约 7.08 GiB、数据盘约 10.14 GiB 可用，均为时点记录；未触发迁移，本次没有迁移任何数据。未来每阶段开始及大输出前重新检查。

系统盘小于 5 GiB 时，只迁移确认不用的可重建缓存或不重要临时数据：先检查数据盘容量，复制并校验，再切换路径/链接、检查可读性，最后释放原副本。不得搬走正在使用的缓存、未提交检查点或删除祖先索引。数据盘空间同样有限，不把迁移当作无限容量；不足时减少重复输出或暂停大输出，记录迁移前后空间与校验。

### 5.3 异常处理

| 异常 | 必查原因 | 后续动作 |
| --- | --- | --- |
| 路径、形状、单位、列表/元组错误 | 最小输入、实际类型和来源 | 原因明确，自行修复并做针对性检查 |
| 内层仍读粒子 | 闭包、GPU 指针、预条件器、诊断回调 | 先修接口；不能继续宣称解耦 |
| Load 与求解 F/体积不一致 | 坐标、梯度、增量/总量、历史投影 | 分离传递误差；根因未明时停止动态分支 |
| 非物理持续增能或收支漂移 | 压力功符号、体积链、储存、重建和边界功 | 保留最后安全状态；不靠阻尼、裁剪和清空累计量解决 |
| 混合系统停滞 | 原残差、块缩放、压力零空间、离散稳定性 | 修解法或离散的明确问题，不能强称 SPD |
| 参考不可靠或机械信号不足 | 空间、时间、投影/线性化和信号尺度 | 保留诊断结论，停止精度声明及依赖的空间选择 |
| 性能收益不稳定 | 同步边界、预热、迭代数、构造和传输 | 记结论不确定，不无限追加重复试验 |
| 未见工况失败 | 表示预算、训练覆盖、真实物理变化 | 记录失效；如重训，重新划分验证与成本 |

显著异常需要记录假设、证据、根因、改动风险及复验。难以定位时跳过受影响分支，独立工作仍可继续；一般可定位问题不能因“允许跳过”而不处理。影响物理范围、长期状态或来源链的决策先做深入分析，形成可审查的方案，不通过静默改方程降低风险。
