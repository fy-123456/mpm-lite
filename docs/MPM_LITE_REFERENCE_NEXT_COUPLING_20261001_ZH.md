# MPM-lite 最小三维耦合：实际模型、方程和验收范围

2026-10-01。对应 [本轮成果](results/reference-next/20261001T032104Z-reference-next/Q5/coupling-decision.json) 与 [实施记录](MPM_LITE_REFERENCE_NEXT_PROGRESS_20261001_ZH.md)。实现位于 `engine/aniso_phase1/research_reference_next/coupling.py`；驱动为 `benchmarks.research_reference_next.coupling_study`。

## 1. 已实现的范围

实际使用当前 original144 固体空间、完整 M5、原 Ks、F45 材料和三维参考几何。两个夹持端提升固定为零；压力驱动内部固体运动。流体采用覆盖整个三维域的一个常压力单元、一个右端排水面体积流率。封闭问题把该流率约束为零；排水问题连接零压力储库，其余面不透水。

这是实际双向三维力／体积交换的独立小问题。它尚不能解析压力空间分布，没有接成通用 C–E 生产接口，也不替换日常纯固体入口。保存帧的 `PK1` 来自固体材料；它不是含压力项的总 PK1，不能把该字段当作耦合总应力图。

| 参数 | 实际值及单位 |
| --- | --- |
| Biot 系数 α | 0.8，无量纲 |
| 储存系数 S | 0.2 Pa⁻¹；秩诊断另用 0.0002 Pa⁻¹ |
| 渗透率 k | 1e-4 m²，各向同性 |
| 黏度 μ | 1e-3 Pa·s |
| 初始压力 | 0.01 Pa |
| 体积源率 s | 耦合案例中为 `0.001 V₀ / s`；极限问题为零 |
| 步长／步数 | 0.01 s／4 步 |
| 材料及几何积分 | q7，有限变形方向与 q8 核对；不使用固体 q5 证书 |

以上参数用于有单位的数值检查，没有材料标定含义。这里的含量是参考体积上的流体体积增量；积分量单位为 m³，不能直接称作 kg。只有另行明确恒定密度后才能乘密度换算。

## 2. 从同一势能得到双向作用

连续候选模型为

\[
\Psi(F,m)=\Psi_s(F)+\frac{[m-\alpha(J-1)]^2}{2S},\quad J=\det F,
\]

\[
p=\frac{m-\alpha(J-1)}{S},\qquad P=P_s-\alpha pJF^{-T}.
\]

本次的常压力离散取 `m(X)=α[J(X)-1]+Sp`，所以参考域总含量与体积为

\[
M_f=\alpha(V(q)-V_0)+Cp,\quad V(q)=\sum_\ell w_\ell\det F_\ell(q),\quad C=SV_0.
\]

消去 p 后，流体储能是

\[
E_f(q,M_f)=\frac{[M_f-\alpha(V(q)-V_0)]^2}{2C}=\tfrac12Cp^2,
\quad f_p=-\alpha p\nabla_q V.
\]

因此压力力与体积增量使用同一材料点、权重、有限变形及导数。所有固体惯性和原稳定化保持单独计算。

达西参考迁移率为

\[
A(F)=\frac{k}{\mu}J F^{-1}F^{-T}.
\]

本单元从中心到右端面的距离取 L/2，面面积为 A₀，传导系数取

\[
T(q)=\frac{2A_0}{L}\left\langle A(F)_{xx}\right\rangle_{\Omega_0},\quad H(q)=T(q)^{-1}.
\]

它是明确的单单元有限体积近似，不声称等价于已收敛的多单元 Darcy 场。

## 3. 时间离散与账本

令 W 为区间平均速度，`q₁=q₀+hW`、`v₁=2W−v₀`，`p̄=(p₀+p₁)/2`。体积离散梯度使用两点 Gauss：

\[
\bar g=\int_0^1\nabla_qV(q_0+\theta\Delta q)\,d\theta,
\quad \bar g^T\Delta q=V_1-V_0.
\]

F 沿该路径对 θ 为一次，三维 det(F) 为三次；其梯度为二次，所以两点规则可精确积分该体积链式关系（浮点误差除外）。固体非多项式材料仍沿用原 AVF 两点路径规则，路径误差另外记账。

自由固体、储存和排水方程为

\[
2M(W-v_0)+h(\bar f_s-\alpha\bar p\bar g-f_{ext})=0,
\]
\[
\alpha(V_1-V_0)+C(p_1-p_0)+h\bar z-hs=0,
\]
\[
H(q_{mid})\bar z-\bar p=0.
\]

封闭边界把最后一式换成 `z̄=0`。压力功满足

\[
W_{p,s}=-\alpha\bar p\bar g^T\Delta q,
\quad W_{p,f}=\alpha\bar p(V_1-V_0),
\quad W_{p,s}+W_{p,f}\simeq0.
\]

Darcy 耗散 `D=hH z̄²≥0`。原始能量平衡为

\[
\Delta(E_s+E_k+E_f)+D-W_{ext}-h\bar p s.
\]

同时保存材料路径误差、求解残差功以及扣除这些数值误差后的闭合余项。报告保留原始平衡，避免仅展示扣账后的极小余数。

650×650 的混合系统使用一般稠密因子分解、实际非线性残差与线搜索；这个小参考矩阵仅约 3.4 MB，因此没有增加稀疏组装分支。该求解器没有对整个混合系统作 SPD／CG 假设，也没有添加压力罚项。两档储存系数下，约束后四种系统均满秩；这不构成多压力自由度的 inf-sup 证明。

## 4. 实际结果与事务

- 能量方向导数、压力力切线、离散体积梯度、q7/q8 几何作用通过。
- 零压力／零 Biot 系数下与已有固体 AVF 的场一致；固定固体的排水压力与独立标量中点递推一致。
- 封闭／排水各四步，最小 det(F) 分别约 0.998067／0.998031。
- 最大体积含量闭合约 1.18e-17 m³，最大原始能量平衡约 3.23e-15 J，压力交换功缺陷约 8.75e-20 J；排水耗散非负。使用的是 1% 加近零绝对项的实用门槛，这些小结果没有被设成新的普遍容差要求。
- 在子求解完成、整体提交前损坏压力并抛错，q/v、预测器、压力、流量和历史全部恢复；封闭案例两步后退出，再由新进程继续到四步，与不中断对照一致。

外层 `GenerationStore` 将所有子状态按同一代次发布。发布前失败保留旧代次；已发布的代次被识别为一次成功提交。耦合故障本轮实际注入的是提交前子历史失败，磁盘发布前／后故障由所复用的存储路径回归测试覆盖，二者分别记录。
