# 小场景跨单元诊断与改进计划

日期：2026-09-27。状态：三项首轮实现与测试已完成。上一轮结论见 ANISO_XZ_MPM_VALIDATION_ZH.md。

固定 432 粒子、初态、材料和 12 ms 场景，不展开长程扫描。保持完整质量求解，失败不提交历史。

1. 用 0.125 ms 重跑 Q1，记录每步质量最小特征值、原始节点支撑、质量条件数、应力增量、跨单元事件、网格切换、投影损失；保存事件前后两步。增加 h→0.8h，粒子保持不变。用相同冻结粒子状态做单步反事实对照。
2. 对比 Q1、二次 B 样条，以及保持常量/线性再现的弱支撑节点仿射约束。弱节点定义为质量对角项小于最大对角项的 1%；约束改变近似空间，不加质量对角正则项。原始平滑插值若质量秩不足，记录拒绝。
3. 在平滑插值与仿射约束上，试验最多三个速度残差基函数。用可解析求导的紧支撑径向场表示当前 P2G 丢失的三分量速度；新基函数同步进入质量、本构梯度和粒子更新。保持常量/线性再现，检查是否降低投影损失以及是否引入新的动态误差。
4. 仅对通过一致性的主要候选补两档时间步与一档空间加密。报告结果，无论成功或失败；未建立收敛前不迁移生产默认。

测试覆盖插值与导数、F 预测/提交、完整质量动能、线动量、历史冻结与回滚、原势能/残差/切线及 CPU/GPU 一致性。资源沿用系统盘 <2 GiB 迁移缓存、合计 <5 GiB 停止；本轮共享 cuda:0，启动时约 39 GiB 显存和 85 GiB 系统盘可用。
