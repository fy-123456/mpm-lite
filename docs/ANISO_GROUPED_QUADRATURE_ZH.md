# group4x8 材料积分与稳定化组合

> 最新静态诊断：[group4x8 的夹持、加载与插值一致性](ANISO_BOUNDARY_CONSISTENCY_ZH.md)。精确材料面约束能消除夹持遗漏并改善梁位移，但不能解释全部偏软；全局 MLS 候选暴露新的积分不足，未替换生产路径。新增两个网格的位移/反力数据及 `demos.aniso_boundary` 查看器。

本轮新增实验性 `--quadrature group4x8`：每步重建分组、位置、条件方向矩和参考映射，然后在 Newton/PCG 内冻结。它替换中心材料积分，保留原 Lite 速度传递和粒子历史更新。默认仍是原来的中心积分。本页的静态梁误差与历史重建误差表明，目前不能把新选项称为已收敛的通用替代方案。

实现：[grouped_quadrature.py](../engine/aniso_phase1/grouped_quadrature.py)。复现：[aniso_grouped.py](../benchmarks/aniso_grouped.py)。原始记录：[results/grouped-quadrature](results/grouped-quadrature/)。上一轮固定快照材料能/应力对照见[配对采样](ANISO_JOINT_SAMPLING_ZH.md)。

## 冻结势能及求解器

每中心按方向分成至多四组，每组八点；同一方向会自动退化为一组八点。各点带正参考体积、自己的组内二阶与四阶方向矩。参考变形来自粒子参考位置和逆 F 的 Hermite 二次拟合；速度增量用冻结的 P2+xyz 节点 MLS 梯度：

\[
 b_{qi}=(F_q^n)^T\nabla_x N_{qi},\quad
 F_q(v)=F_q^n+\Delta t\sum_i v_i\otimes b_{qi}.
\]

这里的节点插值与原中心八节点插值不同，不能把固定快照的准确性直接推断为力学边界值问题的准确性。

\[
 \Phi=\tfrac12(v-\hat v)^T M(v-\hat v)
      +\sum_qV_q^0\psi(F_q,A_{2,q},A_{4,q})+E_s(v),
\]
\[
 r_i=M_i(v_i-\hat v_i)+\Delta t\sum_qV_q^0P_qb_{qi}+\nabla_iE_s,
 \quad J=M+\Delta t^2\sum_qV_q^0B_q^T H_q B_q+\nabla^2 E_s.
\]

新分组材料能已经包含四阶矩，代码跳过原中心材料修正；稳定化通过原有势能接口单独组合。残差、精确 matvec、线搜索均访问同一组冻结数据，内层不访问粒子。

对归一化纤维，令 \(C=F^TF\)、\(S=A_4:(C-I)\)，实际使用避免静止状态相消的表达式：

\[
 \psi_f=\tfrac{k_f}{2}(C-I):A_4:(C-I),\qquad P_f=2k_fFS,
\]
\[
 \delta P_f=2k_f[\delta F S+F(A_4:\delta C)],\quad
 \delta C=\delta F^TF+F^T\delta F.
\]

对单位方向，\(A_4:I=A_2\)，因此这与上一轮条件二阶＋四阶矩本构等价。

继续使用**带检查的 PCG**，不能只因对称就认为精确切线正定。材料压缩可能使 \(S\) 有负特征值。回退时将该项改为 \(S_+\)，结合各向同性材料的正定近似、共旋稳定化的 Gauss–Newton 近似和正质量，构造搜索方向；仍对原始 \(\Phi\) 做线搜索。修改后的切线不称为精确 Jacobian。

## 无质量静态检查与组合决策

使用真实 PPC=2³ 粒子云、P2C 体积、相同节点和夹具，装配 \(K\)，**不含质量项**。比较三种稳定化 `quadratic`、`supplemental`、`hourglass` 的强度 0.1/1，以及不稳定化。另设：

- 同一 MLS 插值、每粒子自己的方向与位置的稠密积分参考，用于隔离分组压缩误差。
- 相同 P2C 支撑、体积和方向矩的全积分 Q1，隔离速度插值变化。
- 原物理梁、清晰几何边界的独立全积分 Q1，检查网格趋势；其节点支撑与前两者不同。

加载总力为 \(-10^{-4}\)。力通过材料端面位置的 Lite 插值分配，位移用同一线性泛函测量，保证外力做功共轭。直接均分力给稀疏支撑最外层节点会过分激励低体积外延节点，因此不采用这种加载结果。

| 统一方向静态梁 | grid 17 位移 | grid 33 位移 |
|---|---:|---:|
| group4x8，无稳定化 | -8.13325e-4 | -7.07360e-4 |
| 同 MLS 的稠密粒子积分 | -8.13258e-4 | -7.07356e-4 |
| group4x8 + quadratic，强度 1 | -6.37560e-4 | -6.46798e-4 |
| 相同 P2C 支撑的全积分 Q1 | -4.83039e-4 | -5.52325e-4 |
| 独立物理梁的全积分 Q1 | -5.69794e-4 | -6.06623e-4 |

上述两个网格及粗网格平滑方向场的所有组合均无阈值内零模态，阈值为 \(10^{-9}\max(1,\lambda_{max})\)。实际 GPU 去质量 matvec 与独立装配相对差低于 \(3\times10^{-15}\)。

**暂选 `group4x8 + none` 作研究入口。** 新积分在这些试验中已无须旧稳定化来消除零模态。直接加 `quadratic` 强度 1，会让统一方向梁位移幅值降低约 21.6%/8.6%，平滑方向粗梁降低约 41.2%。预弯曲释放初态中，旧 `quadratic` 还会在新材料能之外再增加约 26.6% 的弹性能。虽然某个静态位移可能因此更接近独立 Q1，不能把它当成没有重复补刚度的证据，也不据此调参。

新积分与同 MLS 稠密粒子积分的统一方向位移差仅约 0.0082%/0.00067%；但相对独立物理梁仍偏软约 **42.7%/16.6%**。平滑方向粗梁的不同插值差异更大。这把主要剩余问题指向插值、材料支撑及夹持表示，不能宣称空间精度已通过。若将来其他场景发现真实零模态，应针对缺失子空间重新构造稳定化。

## 动态能量记账与短程验收

新增 `group_start_energy`、`group_solved_energy`、`group_rebuild_delta`、`particle_reference_elastic` 和 `particle_minus_group_elastic`。定义：

\[
 \Delta U_{rebuild}^{n}=U_{group}^{n}(0)-U_{group}^{n-1}(v^{n-1}).
\]

它包含分组/支撑变化、参考拟合，以及原 Lite 粒子历史更新与新 MLS 材料映射之间的差异。不会把这些差异全部归入隐式积分耗散。稳定化重建仍另记，能量预算闭合只证明记账完整，不证明能量守恒。

本轮保留原速度与粒子 F 传递，没有同时改写另一个关键环节。夹具反力使用新材料项的未投影残差，再加稳定化与惯性，避免误报原中心反力。

最终短测：统一方向梁 8 步、dt=0.0005、总时间 0.004；平滑方向拉伸—卸载 16 步、dt=0.005、总时间 0.08。无非有限状态或求解失败。

| 场景 | 稳定化 | 最小粒子 det(F) | 机械能最终变化 | 最大单步材料重建跳变 / 能量尺度 | 每步中位耗时 |
|---|---|---:|---:|---:|---:|
| 梁释放 | none | 0.999212 | -6.322% | 0.481% | 102 ms |
| 梁释放 | quadratic | 0.999203 | -7.456% | 0.347% | 164 ms |
| 平滑方向拉伸—卸载 | none | 0.996896 | 初始能量为零，不算百分比 | 3.353% | 144 ms |
| 平滑方向拉伸—卸载 | quadratic | 0.997023 | 同上 | 2.671% | 207 ms |

能量尺度为该短程最大机械能；梁为初始能量。预算闭合绝对误差低于 9e-22。梁 `none` 的材料重建累计贡献为 +2.812%，仍有净耗散，不能把 -6.322% 全部称为时间积分损失。拉伸反力峰值约 0.08625/0.08639；这些是短程动态夹具反力，并非慢速材料曲线精度验收。

上述时间包含 CPU 重建、同步诊断，剔除前两步；并非公平性能对照。梁 1280 个材料点、256 粒子；拉伸 3072 个材料点、192 粒子。本轮没有材料评估次数优势。求解器统计的已分配 GPU 数组约 589–592 MiB，包含共用稀疏预留；不等同于显卡峰值，也不包括主机重建数组。

真实 8 个稀疏块、45 个自由方向的混合纤维预应变试验验证了势能有限差分、解析 matvec、边界投影、对称性及材料客观性。精确/修改切线谱与 PCG 压缩保护记录见 `operators.json`。压缩到 F=diag(0.8,1,1) 后，包含质量的精确切线仍有约 -7e-6 的特征值；正定近似的最小特征值约 8–9e-7。负方向触发 `nonpositive_curvature`，修改切线 PCG 返回 `converged`。

诊断中每次重建稀疏网格都重新构造自由子空间，因为节点压缩编号可能改变；随机试验场按物理坐标排序，避免编号重排改变输入。

精确刚体平移/旋转重建试验不做时间积分：固定同一粒子材料状态，平移两格或旋转 45°，取五个快照。粗/细网格平移最大能量变化约 0.00337%/0.00119%；旋转约 0.0325%/0.0406%。旋转结果未显示单调加密收敛，不能进一步推广。真实运动的重建项还包含历史更新误差，与这个受控几何试验分开解释。

## 命令

实验性新积分，先用粗网格短程观察；首次 GPU 编译约需两分钟：

```bash
.venv/bin/python -m demos.aniso --scene beam --grid 17 --device auto \
  --dt .0005 --quadrature group4x8 --direction-model fourth_moment \
  --stabilization none --play
```

平滑方向加载—卸载（两次循环）：

```bash
.venv/bin/python -m demos.aniso --scene tensile --grid 9 --device auto \
  --dt .005 --loading-time .04 --loading-speed .025 --loading-cycles 2 \
  --smooth-loading --fiber-field smooth --quadrature group4x8 \
  --direction-model fourth_moment --stabilization none --play
```

同机浏览器打开 `http://127.0.0.1:8080`。如果程序运行在远程机器，需要 SSH 转发 `ssh -L 8080:127.0.0.1:8080 yin@服务器地址`，然后在本机浏览器打开同一地址。页面显示步间重建 ΔU；形变放大仅用于显示。

```bash
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m benchmarks.aniso_grouped --part all --device auto
```

可按 `static/operators/scenes/rebuild` 分开运行。每轮选择最低显存 GPU，持续执行容量检查：系统盘低于 2 GiB 迁移可再生缓存到数据盘，两盘可用容量合计低于 5 GiB 暂停。本轮初始约 11.2/14.1 GiB，无须迁移。重建在 CPU 上进行，现阶段不是性能优化；采样数可能超过粒子数，不能据此声称加速。

验证记录：63 项相关回归通过，覆盖原中心/粒子积分、二次/共旋稳定化、能量、反力、材料及容量保护；增加压缩检查后再次单独运行新分组测试。Viser 在 8092 端口的 HTTP 返回 200，限时播放正常退出；未进行浏览器截图检查。测试摘要见 `tests.json` 和 `viser-smoke.json`。

下一步应优先统一材料映射、边界约束和粒子历史传递，并用同一加载泛函继续做两个网格的静态比较；先解决这些偏差，再考虑压缩成本或默认启用。
