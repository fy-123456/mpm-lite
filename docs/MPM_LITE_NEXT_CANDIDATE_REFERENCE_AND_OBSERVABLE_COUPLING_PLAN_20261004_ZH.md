## 2. 目标、范围与顺序

本轮顺序为：

```text
S0 再核对基线并建立独立子版本
  → S1 资源记录与候选时间参照
  → S2 初态、稳定化和空间力学归因
  → S3 一个机械响应可观测的研究耦合场景
  → S4 一个重要输出窗口的相位检查
  → S5 一个有依据的组装优化候选
  → S6 按影响范围回归、展示并封存
```

执行时只运行一个数值进程。同一进程原则上只驻留一个大模型；跨空间、跨积分规则的比较先导出物理观测结果，再在独立进程依次计算。子步骤间允许只读分析，不能同时启动多条实验线。

本轮固定以下边界：

- 正式空间、完整质量、原材料与稳定化、252 步正式时间表保持；研究候选不自动晋升。
- S2 以原因诊断为交付，不新增空间训练、不搜索多个映射、不调整稳定化权重来拟合正式轨迹。
- S3 单独定义新研究场景；不得改变旧场景参数后仍引用旧场景精度结论。
- S4 最多增加一个正式空间的局部细时间参照；不启动新的全周期时间表。
- S5 最多实现一个性能候选，优先静态 RT0 元数据复用；收益不足则保留当前实现。
- 混合系统继续使用一般 LU 和原系统残差检查，不能直接套用固体 SPD/CG 假设。
- 不增加阻尼、人工质量或压力裁剪来掩盖误差；不能把位移显示倍率当成物理响应可观测性。

S1 因资源受限而停止时，S2 可以完成已有记录的诊断，但不能签候选时间资格；独立的 S3—S6 仍可顺序推进。S3 未通过时，S5 可在最新发布的既有耦合状态上研究性能，结论必须保持该输入作用域。

## 4. 共同验收口径与实验预算

### 4.1 物理量比较

同一物理量采用绝对与相对混合门槛：

\[
e_y=\|y-y_{\rm ref}\|_W,
\qquad e_y\le a_y+0.05\|y_{\rm ref}\|_W.
\]

`W` 为共同探针或共同积分区域的归一化权重。整体与原有各区域分别报告，不能用全场平均掩盖局部问题。

| 量 | 绝对门槛 `a_y` | 说明 |
| --- | --- | --- |
| 位移 | `5e-5 m` | 使用真实物理位移，去除显示倍率 |
| 速度 | `1e-4 m/s` | 使用物理探针速度，不比较不同空间的裸系数范数 |
| PK1、纤维应力 | `0.02 Pa` | 同位置、同应力定义或同积分均值 |
| 反力 | `1e-4 N` | 使用完整反力，粗细时间比较按同一时间区间冲量平均 |
| 压力 | `1e-3 Pa` | 同物理时间；跨网格先做守恒限制 |
| 流量 `Q` | `1e-10 m³/s` | 面通量要先统一方向、位置及面积意义 |
| 累计流量、储量 | `1e-10 m³` | 与瞬时流量区分单位 |

最低 Jacobian 继续要求 `det(F)>0.1`，场和原始账目必须有限。正式固体能量预算继承 `energy_fraction=0.01` 及 `energy_scale_J=1.1406507535904557e-4`；不通过重新选更大能量尺度改善验收。

同算子的 CPU/GPU 一致性沿用既有 `backend_rtol=2e-5` 及按量纲登记的绝对项；材料压缩仍用约 2%、切线约 3% 的原证书预算。身份、哈希、提交顺序和所有权错误不作为“可放宽的数值误差”。跨重复计算只对已解释的条件数诊断估计允许舍入差，不能把该例外扩展到全部状态。

### 4.2 守恒、相位和可观测性

耦合质量残差、压力交换功和能量账分别检查：

\[
r_m=\alpha\Delta V+C\Delta p+hBQ-hs,
\]
\[
\Delta V=\bar G\,\Delta q,
\qquad
W_{p,s}+W_{p,f}=-\alpha\bar p^T\bar G\Delta q
+\alpha\bar p^T\Delta V\approx0,
\]
\[
E_1-E_0+hQ^TH(F_{mid})Q-W_{ext}-W_{source}-W_{reservoir}\approx0.
\]

压力功采用代码残差记账的符号。必须同时报告路径积分误差、求解残差功与账面闭合，不能只看闭合后极小的剩余数。

固体冲量容差继续按 `h × 力容差 + 舍入项` 分配；质量容差按时间与参考体积分配；时间节点按冻结索引核查。新耦合场景的能量尺度应在运行前由初始储能、规定输入功及初步尺度估算确定，原绝对项和相对预算也同时冻结，不在看见结果后调整。

新场景机械可观测性与数值误差分开登记：默认要求至少两个非相邻观测时刻，整体或预先指定区域的 `u_RMS >= 3×5e-5 m` 或 `v_RMS >= 3×1e-4 m/s`。同时检查压力作用与体积反馈在原方程中确实非零、超过舍入尺度；仅压力曲线变化不授予可观测机械耦合资格。

重要模态仍保留 0、1、615；既有事件预算分别为 `0.00625 s`、`0.00625 s`、`7.534196778150833e-5 s`，反力事件预算为最后一个数值。事件未出现标记 `unobserved`，匹配有歧义标记 `unresolved`；不做时间轴平移或滤波后验收。

- **做什么：** 复用 `OLD` 的两个 h/h/2 窗口、完整正式周期及 `BASE/S4` 的诊断。分离材料、稳定化、惯性和端点项对反力的贡献，记录重要模态与区域应力的关联。
- **为什么：** `q_j=A_j cos(ω_j t+φ_j)` 中的时间相位误差会影响峰值时刻；小位移幅值不能排除 `ω_j² A_j` 量级的惯性作用。旧模态移除实验只有离散采样，没有全区间影响界。
- **如何验收：** 所有重要模式保留；未出现事件保持未观测。以原始输出及已登记事件预算选择 `[1.075,1.078125]` 或 `[1.225,1.228125]` 中一个窗口；选择在新参照运行前冻结，不能两个都跑完再挑好看的结果。
- **交付：** `S4/output-phase-attribution.json`、`S4/window-selection.json`。

#### S4.2 仅在有实质影响时补一个 h/4 参照

- **做什么：** 若已有 h/h/2 差异或事件不确定性会影响重要输出判断，用同一正式初态在所选 0.003125 s 窗口运行 256 步，`h/4=1.220703125e-5 s`。h、h/2 结果直接复用，不重跑。
- **为什么：** 第三级时间分辨率能帮助判断事件匹配是否改善，避免把峰值偏移误认为空间误差。
- **如何验收：** 逐项报告粗→细、细→更细的场量及事件变化，粗细反力仍按区间冲量比较。若细化后仍有歧义，标记受限；不能过滤高频、删掉重要模式或对齐时间轴后签通过。只获得所选短窗结论，不外推全周期。
- **交付：** 条件性的 h/4 轨迹、`S4/local-phase-check.json`；未触发时明确原因和新增步数 0。

#### S4.3 保持本轮正式时间表，提出有条件的后续调整

- **做什么：** 本轮正式周期继续使用 `BASE/S6/final-protocol.json` 的 252 步。若局部细化确有收益，列出未来分段步长应覆盖的时间段、预计代价和需要重新认证的 q5 范围。
- **为什么：** 改正式步长会改变完整轨迹、事件、许可和恢复条件，不能由一个短窗自动推广。
- **如何验收：** 当前正式时间数组哈希不变；不启动新的全周期步数方案。全局时间资格继续 false；局部通过、重要事件未解析和输出影响未知分别记录。
- **交付：** `S4/time-decision.json`。

### S5：只优化实际重复的组装工作

#### S5.1 测两个真实接受步，区分建模、推进与输出

- **做什么：** 选择两个已提交实际状态，一个后继步无需输出、一个后继步恰好需要输出；优先使用 S3 通过的案例，否则使用 BASE 旧耦合并明确作用域。分别计时建模、材料、几何/导数、线性求解、设备传输、场重建、提交。
- **为什么：** 上轮两个样本都没有帧输出，剖析还包含建模；这些记录不足以代表真实输出步的端到端成本。
- **如何验收：** GPU 正确同步，原输出节奏保持；一次性建模和稳态成本分列，预计算成本单列，重叠计时不重复相加。记录真实 LU/Krylov 调用数；有剖析和无剖析计时不得直接相除成加速比。
- **交付：** `S5/profile-protocol.json`、`S5/profile.json`。

#### S5.2 选择并实现最多一个静态 RT0 元数据候选

- **做什么：** 若占比足够，预计算每单元积分点索引、局部面编号/方向、参考面基函数、静态权重乘积及固定迁移率的逆。所有缓存绑定参考积分点、权重、网格、迁移率与模型身份；分块构建以限制内存。
- **为什么：** 当前 `FastTopology.assemble()` 每次重复这些工作。其动态部分为
  `H_ab(q)=integral phi_a^T [F(q)^T mobility^{-1} F(q)/J(q)] phi_b dV0`，参考基函数与索引可以复用，当前 F、J、张量及非线性体积导数仍需更新。
- **如何验收：** 在静止、小制造变形和两个真实状态上核对 H、V、G、离散压力功及原残差；检查不同 q、不同迁移率/网格不会误命中，外部返回值不能污染缓存。新增常驻缓存不超过 `min(256 MiB, 初始可用显存的2%)` 对应的登记预算；CPU 缓存也计入 RSS 上限。若静态部分不足以支持约 5% 端到端收益预期，就记 `not_triggered`。
- **交付：** `S5/performance-candidate.json`、`S5/operator-equivalence.json`。

#### S5.3 用配对顺序判断收益

- **做什么：** 两个状态各运行基线和候选一次，顺序为状态一 A→B、状态二 B→A；每个试验只驻留当前模型。计时不带函数剖析，输出及提交行为相同。最多再用两步复核一个配对，不扩展为参数搜索。
- **为什么：** 编译、缓存冷热和共享设备波动可能大于实际优化收益。
- **如何验收：** 能量、内力、H、原残差、物理场和提交行为在冻结预算内；两个状态均无明显退化。中位端到端收益至少 5%，且高于配对波动才保留；收益不确定时保留旧实现。首次预计算成本与预计摊销步数必须报告，不隐藏到基线外。
- **交付：** `S5/paired-performance.json`、接受或撤回理由。

#### S5.4 冻结最终实现，并清楚标识证据属于哪个实现

- **做什么：** 固定候选开关、静态缓存身份、清理时机、内存数据及最终源码哈希。对性能实现前的 S1—S4 结果保留原实现绑定；若新实现需要重新认证某项而剩余预算不足，则不把它作为该场景的新默认。
- **为什么：** 数学等价需要证据，不能只给旧产物换新源码哈希。S3 的旧轨迹和 S5 的新实现试验属于不同执行记录。
- **如何验收：** 数值来源、物理模型和证据作用域能够逐项追溯；没有跨当前 F 的缓存，没有提高显存比例，没有无依据新增切线缓存。未证明的作用域保持旧实现。
- **交付：** `S5/performance-decision.json`、`S5/final-numeric-lock.json`。

### S6：按实际影响做回归、展示与封存

#### S6.1 做受影响的检查与回归决策

- **做什么：** 对新增恢复入口、参数绑定、资源事件和静态缓存做必要的针对性检查，运行受影响的既有测试；复核 BASE 的 50 项检查记录。区分“新运行通过”和“复用父版证据”。冻结最终数值依赖，不因报告脚本变化反复运行仿真。
- **为什么：** 大量研究诊断或耦合专用缓存修改并不一定影响正式纯固体；验收应匹配实际依赖。
- **如何验收：** 身份、源项、网格、时间错误被拒绝，回滚清理完整。若共享固体算子、数值流程、q5 控制器或新的正式运行入口改变，必须触发 S6.2 的实际周期；否则可以保持父版正式默认，只读引用原轨迹，不伪造子版完成了 252 步。
- **交付：** `S6/tests-result.json`、`S6/regression-impact.json`。

#### S6.2 仅受影响时运行一次正式周期并重新授予 q5 许可

- **做什么：** 触发条件满足时，先运行一次 q7 的原 252 步周期；再用实际状态核查 q7/q8、q5/q7 的材料能、内力、弱应力矩及混合/敏感切线方向。通过后仅运行一次 q5 周期，并做受影响的回退、提交与新进程恢复检查。
- **为什么：** 旧 q5 许可绑定旧数值源码与时间/空间作用域，不能直接给新的数值实现换证书哈希。只读展示父版默认则继续引用父版身份，无须伪造新资格。
- **如何验收：** 完整 M7 不变；全部阶段/区域的位移、速度、应力、区间反力、能量和边界通过原预算；3 个哨兵、整步 q7 重算、试探缓存清理与恢复通过。q5 不通过则采用已通过的 q7 新默认，或保留父版默认并标明研究版状态。故障测试总计不超过 24 次。

## 6. 关键决策表

| 观测结果 | 后续动作 | 必须保留的限制 |
| --- | --- | --- |
| 单模型续算仍触发保护，实际失败读数不足以定位 | 保存原始事件及最后提交，停止候选追加试验 | 不认定显存泄漏已修复，不提高保护比例 |
| 候选 h/h/2 差仍大 | 优先后续时间解析或高频激励诊断 | 不据此直接判空间错误 |
| 候选自身时间差小，跨空间差仍大 | 用分项力与共同物理响应决定后续初态/空间参照 | 正式细轨迹不是连续真解 |
| 新耦合仍低于机械观测门槛 | 发布稳定/守恒结论，停止本轮该分支 | 不事后调参使同一登记案例过关 |
| 新耦合原残差难以收敛 | 检查拟牛顿近似、参数尺度及当前几何；无法验证修复则受限 | 不改用未经证明适用的 SPD/CG 或隐藏残差 |
| 相位事件不出现或有匹配歧义 | 标记未观测/未解析，保持 252 步正式表 | 不删重要模式、不平移时间轴 |
| 组装优化收益低于波动或内存代价过高 | 撤回候选，保留旧实现 | 不声称新增提速 |
| 正式固体路径未受影响 | 只读继承父版默认，明确来源 | 不把继承结果标成新周期 |
