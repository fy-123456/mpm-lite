## 2. 从当前源码确认的具体缺口

本节是只读代码发现，尚未修复；没有将推断写成新实验结果。

1. [coupled_short.py](../benchmarks/research_formal_pressure_next/coupled_short.py)直接构造 `Material(m,7)` 和 `Solver`，没有经过 `Transaction`。单独控制器测试通过不等于日常短窗入口具备回退。
2. 同入口允许 `--alpha 0 --steps 4`，但旧 `DryMidpoint` 对照只从静止态走一次 `.0025`，还使用循环末尾目标。该分支会比较不同时刻的状态；已验收的 `--steps 1` 不受影响。下一轮应修正逐步对照或明确禁止不支持的组合，再做轻量回归。
3. [transaction.py](../engine/aniso_phase1/research_formal_pressure_next/transaction.py)只在候选终点比较整体内力及整体弱应力矩范数；没有逐区域最大误差、独立能量预算或运行时敏感切线检查。整体范数可能掩盖小区域的大误差。
4. 控制器每次试步新建Solver；规则切换时还可能新建旧规则Material以核算能量。当前Material的调用上限属于单对象；若只设置主/备用对象，新增对象和几何评估可能不在共同预算中。需要共享的步级预算与准确分段计时。
5. [solver.py](../engine/aniso_phase1/research_formal_pressure_next/solver.py)令 `H=I`，实际使用 `z=D.T@p_mid`、`L=D@D.T` 和 `dt*z@z`。这些与当前单位流阻完全一致；以后如果只开放H参数而不改残差、Jv、预条件器、耗散和身份，会产生模型不一致。
6. 当前力容差采用全量力/惯性/压力范数，自由方程单独验收；若规定行贡献很大，需要检查是否掩盖自由残差。不能将0.094%的反力差直接与不同量纲或不同范数的求解残差比较。
7. q7短窗实际Jv迭代调用为0。已有Jv方向差分检查与“真实非线性迭代收敛”是不同证据，强工况仍需补充。
8. [material.py](../engine/aniso_phase1/research_formal_pressure_next/material.py)的方向评估仍调用完整张量响应，既计算力也计算切线。Jv是否值得单独优化，须先看真实调用次数；不能在短窗完全不用Jv时把切线缓存当首要性能成果。
9. 生产网格传递维护粒子x/F/APIC状态；当前研究以绝对材料q/v持有运动，两者状态和速度投影合同未统一。不能在生产传递后直接覆盖x/F并宣称兼容。

## 3. 下一轮必须保持的数学合同

### 3.1 固体、边界和积分角色不变

\[
a=Tq+a_0,\qquad x=X+B_{mat}(X)a,\qquad F=I+D_XB_{mat}(X)a.
\]

\[
U_{\mathcal Q_E}(q)=\sum_{r\in\mathcal Q_E}w_r\Psi(F_r)+\tfrac12Y(q)^TK_sY(q).
\]

材料规则 \(\mathcal Q_E\)、质量规则 \(\mathcal Q_M\)、压力几何规则 \(\mathcal Q_G\) 的身份分开。压缩或回退只更换材料规则，完整质量、夹持条件、控制体与q9几何保持不变。原稳定化只加入一次；质量自由—规定交叉项不能省略。

### 3.2 主规则误差既看整体，也看区域

对同状态q、同一材料参数比较候选与充分规则：

\[
e_f=\frac{\|f_{cand}-f_{ref}\|}{\max(\|f_{ref}\|,f_*)},\qquad
 e_{\sigma,c}=\frac{\|W_{cand,c}-W_{ref,c}\|}{\max(\|W_{ref,c}\|,W_{*,c})}.
\]

W为同区域、同应力度量的弱应力矩。分母下限必须有单位与物理依据；常数矩和带长度因子的线性矩先无量纲化或分别报告，不能把不同量纲混在一个范数里。重点记录 `max_c e_sigma,c`，避免大区域盖住小区域。

材料切线方向误差比较同一方向w下的K作用；近零能量使用绝对误差和典型应变能尺度。不要要求参考态能量接近零时仍满足任意相对误差。

规则变化能量为：

\[
\delta U_Q=U_{new}(q_n)-U_{old}(q_n).
\]

它应单列为规则变化账目，不计入Darcy耗散或外力功。拒绝的尝试不累计流出、耗散、时间、帧或规则变化功。

### 3.3 非单位常量流阻必须贯穿整个离散系统

仍先保持常量参考构形流阻模型：

\[
z=H^{-1}D^T\bar p,\quad L=DH^{-1}D^T,
\quad C\Delta p+\alpha\Delta V+\Delta t Dz=0,
\quad\mathcal D=\Delta t z^THz\ge0.
\]

\[
\Delta V=\bar G_f\Delta q_f+\bar G_b\Delta b,
\qquad f_p=\alpha\bar G^T\bar p.
\]

H和C在此阶段不依赖q，因此相应几何导数为零。若未来采用H(q)、C(q)或孔隙率演化，必须另立模型版本，补导数、储能和质量推导；不能以“参数优化”名义混入本轮。

### 3.4 用响应和时间尺度选择短工况

辅助指标为：

\[
\eta_p=\frac{\|f_{p,f}\|}{\max(\|f_{int,f}\|,f_*)},
\qquad
\eta_R=\frac{|R_{closed}-R_{drained}|}{\max(|R_{closed}|,R_*)}.
\]

只看eta_p不足以证明位移或反力改变，必须配合eta_R及场量。固定q的线性压力松弛满足 `C p_dot + L p=0`，可用 `C^{-1}L` 的非零特征值估算压力时间尺度 `tau≈1/lambda`。这是选窗辅助估计，不是完整耦合系统的精确时间尺度；封闭网络的零模态应单独处理。

目标是有限短窗中得到明显超过数值不确定性的机械差异。不能事后调整容差、阻尼或绘图倍率来制造“显著耦合”。

**P3.1 将常量H/C做成完整参数合同。**

- 做什么：先只开放常量正定流阻和储水参数；将H逆作用同步接入流量、L、混合Jv、块预条件器、耗散、检查点和模型身份。保持原参数默认值。非零边界压力若本轮不实现，显式拒绝，不能只修改元数据。
- 为什么：当前简化公式只在H=I时成立；参数化一半会使质量与能量使用不同模型。
- 如何验收：H=I回归原结果；一个非单位正流阻的两区线性压力小问题与独立解析/矩阵解一致；耗散非负；非法参数和外来检查点拒绝。负载依赖H(q)和C(q)不在本步资格内。

**P3.2 预选机械作用更清楚的短工况。**

- 做什么：用固定几何的压力松弛估计和线性化固体成本先筛选，最多选两个候选；优先改变加载时间尺度或幅值，再考虑有明确单位和研究依据的流体参数。登记排水/不排水对照及预期符号，保留同一固体材料和空间。
- 为什么：当前0.094%的反力差偏弱，直接增加帧数或放大绘图并不能证明机械效果。
- 如何验收：用eta_p、eta_R、位移/应力响应和数值不确定性共同判断。可以把反力差约1%作为候选筛选目标，但不当普适物理规律；最终差异应明显大于同工况数值变化。未达到则记录“趋势可见但作用弱”，不篡改门槛或材料模型。

**P3.3 跑一个选定的四步耦合窗口。**

- 做什么：只对筛选后的一个工况运行最多四步主窗口；排水/不排水对照使用关键单步或确有必要的匹配窗口。输出原始反力、压力、位移、分区应力、体积、通量及全部能量项；可视化显示真实比例与显示倍率。
- 为什么：同状态算子合格仍不能替代连续提交与边界加载验证，且压力曲线本身不能证明机械响应准确。
- 如何验收：无翻转/NaN/无依据的夹持漂移，质量和压力交换功闭合，Darcy耗散非负，实际反力与位移趋势满足P3.2预期。只对关键一步做必要的步长减半或更充分材料对照，分别估计时间/积分影响；不能据四步签发长期或空间精度。

### P4：实际非线性迭代及热点〔门槛J〕

**P4.1 验证确实需要修正的求解路径。**

- 做什么：在P3已选状态中寻找按原工程容差需要修正的一步，检查实际GMRES、线搜索及真实残差。保存方向、接受步长、每次Jv/材料/几何调用和停止原因。若没有自然发生修正，额外的受控偏离初猜测试只能标作算法诊断。
- 为什么：当前q7四步全靠块预测通过，不能把已有GMRES代码当作强非线性收敛证据。
- 如何验收：真实未缩放动量及质量残差达到同一预算，J和能量有效，线性内部残差不替代非线性验收。中等状态方向差分核查完整Jv及重要交叉块；不逐列生成稠密有限差分Jacobian。未触发自然修正时保留一般迭代资格为false。

**P4.2 按热点优化尺度、复用和缓存。**

- 做什么：检查全量力尺度是否掩盖自由方程、混合残差是否需要有单位的块缩放；区分预条件近似与精确Jv。根据计时决定是否增加Jv专用路径、复用基函数/因子或改进压力块近似，缓存设置固定上限和完整身份键。
- 为什么：减少点数后热点可能转向几何和迭代；缓存若漏掉规定坐标、规则或H/C，会产生难以发现的错误。
- 如何验收：同输入冷/热缓存结果一致、变更边界/规则/流体参数后正确失效；每次优化只对实际热点做小对照，报告总时间和峰值内存。没有实际Jv调用时不优先重构其缓存；不通过更松容差制造加速。

### P5：生产状态交接〔门槛L〕

**P5.1 明确绝对q/v与粒子/APIC之间的合同。**

- 做什么：列出Prepare/Solve/Load每个量的所有者，明确粒子X/x/F、速度及APIC矩阵如何来自或反馈到有限状态；若需要速度投影，记录动量和动能变化。首版只允许可表示的弹性输入，超出范围明确拒绝。
- 为什么：直接把新绝对场覆盖到旧粒子历史可能形成两个不一致的状态来源；SH点查询恒等式本身不能解决速度/APIC问题。
- 如何验收：静止、刚体、仿射及一个非零局部场在完整调用链内x/F/v相容；边界、跨格和不完整支撑策略明确，投影功可解释。无法保证时保留独立CPU后端，不替换生产路径。

**P5.2 小规模实际入口验证后再决定后端采用。**

- 做什么：在可选研究入口接入合格合同，比较直接原场重建与SH加残差修正的实际成本；CPU先通过，GPU若实施则单独绑定精度、环境和结果，不混改其他场景默认。
- 为什么：显式修正有逐点成本，未必优于直接查询；已有原生产运行能力不能自动授予新耦合接口。
- 如何验收：一个小场景最多四步，同状态场量、反力、动量/能量与提交次数一致。分别列Prepare/Solve/Load及IO，记录后端差异；无实际收益时不发布加速比例，未测试后端维持未认证。

### P6：空间参考及论文证据〔门槛R〕

**P6.1 建立同物理的独立h/p参考。**

- 做什么：保留材料、边界、压力功和稳定化含义，先选一个热点构造两档局部h加密或p提升参考。分别控制材料积分和时间误差，说明稳定化在参考空间如何定义与转移；固体空间与压力控制体精细化分开研究。
- 为什么：q5/q7和q9/q10都不是空间参考；只有两区压力也可能限制局部压力/应力响应。
- 如何验收：在同一材料位置或一致积分均值上比较位移、分区应力、纤维量、反力和压力；两档参考差距应小于待比较方法的差距。不能保持稳定化含义或参考尚未接近时，明确未取得R，不提前调整正式144空间。

**P6.2 补方向分布与历史表示资格。**

- 做什么：在统一耦合版本中比较单方向、交叉方向和空间变化方向，保留位置关联；用离散方向求和验证A2/A4能否充分表示所选本构，并检查能量、力和切线一致性。塑性/损伤若不是研究目标，不顺带加入。
- 为什么：45°单方向成功不能证明多方向泛化；有限阶方向矩并不适用于任意纤维能量函数。
- 如何验收：对所选材料明确矩表示的适用阶次及剩余误差；历史与重启同源，空间变化不被全局平均抹掉。存在额外内部变量时另验其更新/回退，不宣称单靠q能恢复所有历史。

**P6.3 再分配72/144/288预算并做联合消融。**

- 做什么：冻结选区评分、训练与未见算例，考虑重叠函数交叉项、独立性和质量条件性；在同一具有方向变化、局部梯度及压力机械作用的案例中逐项移除方向表示、富集和兼容交换，再在未参与选区的材料/几何/加载上验证。
- 为什么：需要证明三项贡献共同解决同一个问题，不能只给三个各自成功的小演示；选择冗余函数可能增加成本而不改善表达。
- 如何验收：每档记录总自由度、积分点数、分区误差、条件性、总成本及支撑图，公布失败样本。应力/纤维2%、反力1%作为后续研究目标，未达到写明瓶颈；正式空间替换另立版本并重验相关合同。

## 6. 工程验收与试验预算

本轮以整体运行正确、稳定和可解释为主，不追求机器精度；仍必须守住状态身份、物理符号、质量及能量的基本正确性。

| 项目 | 建议起点及限制 |
|---|---|
| 状态有效性 | 有限值、合法身份、正储水/正定流阻；保留已注册J>0.1失效保护，但接近阈值不代表精度合格 |
| 材料筛选 | 约1%—3%工程尺度，局部与整体同时报告；近零量使用有单位下限，不事后追着结果改门槛 |
| 方向导数 | 少量代表方向、两个合适扰动幅度，目标约1e-3相对量级；不要求全部达到1e-10 |
| 动量与质量 | 继承约1e-3相对尺度并核查归一化是否合理；保留原始残差、单位和每区质量缺陷 |
| 能量 | 原始缺陷、路径误差、残差功、规则变化功分列；典型工程目标为实际功/能量变化约1%，不能用很大的静态基准能掩盖缺陷 |
| 机械作用 | 反力/位移/应力变化需超过同工况数值不确定性；约1%反力差仅作候选筛选目标，不作为强行满足的结论 |
| 常规窗口 | 主窗口最多4步，退化/回退优先单步；不默认增加长周期或完整组合矩阵 |
| 初始资源 | 每个正式工况600秒、总材料遍历24次，主/备用/旧规则/Jv共同计数；6次非线性迭代、每轮最多20次Krylov为次级上限，先到者停止 |
| 内存/调整 | 初始峰值上限8GiB且小于实际安全可用量；预算不足先分析成本，必要时另立协议后再运行，不无限延长后台计算 |

P1初始最多两个候选材料规则、少量冻结状态；P3最多两个轻量候选工况，只选择一个正式短窗。P6参考与论文验证另登记资源批次，避免一次铺开大量实验。只有新改动、失败或明确未覆盖风险才补测试，已经通过的重实验不无目的重复。
