## 1. 如何处理上轮的绝对状态问题

采用原正式材料空间`cross-direction-snapshot6`：225个载体标量、144个局部函数，消元后216个自由标量/648个向量分量，另保留150个规定标量行。源包SHA256为`885a2870a9908f5fd5a0904173a5c1244695e4b7e5a80bf953ff445fda644a30`。

由有限的独立坐标q/v持有状态：

\[
u=Pq+u_0,\quad Y=Y_{ref}+u_c,\quad
x=X+B_{mat}(X)u,\quad F=I+D_XB_{mat}(X)u.
\]

q/v数组共17568字节，包含规定行。状态不保存无限增长的时间链；对本轮超弹性材料，可由相同绝对坐标恢复任意合格材料探针的x/F。塑性、损伤等内部变量不在本轮范围，不能据此声称任意材料历史都可由q恢复。

原稳定化仍为`U_s=0.5 Y^T Ks Y`。由于这里Y对q是明确的仿射映射，力和切线分别使用该映射的转置和双侧作用；原物理零方向按原Ks驻值条件消去。未删除稳定化、添加阻尼或换成增量势能。

## 2. SH如何与原物理场一致

先保留裸SH结果，再显式增加原材料载体与SH之间的残差：

\[
\Delta x=SH(x_n)B_{old}d_c+B_\ell d_\ell+
[B_c^{mat}(X)-SH(x_n)B_{old}]d_c.
\]

材料梯度也做对应修正，包含SH空间导数通过当前F变为材料导数的链式项。最终结果等于原材料场，而不是把不同物理场的差异藏在事后粒子钳制中。

静态实测：

| 检查 | 结果 |
|---|---:|
| 裸SH位移与原场最大差 | 约1.99e-7 m |
| 修正后位移最大差 | 约8.67e-19 m |
| 修正后材料梯度最大差 | 约1.39e-17 |
| 参考态原稳定化自由力范数 | 约6.4e-16 |
| 稳定化平移/转动能量差 | 约1e-17 J |
| 相容四次增量后绝对循环位置差 | 当前探针为0 |

这些检查也包含跨网格、独立原张量场对照、材料坐标有限差分及检查点恢复。系数正反循环归零发生在本轮固定材料表示中；没有要求任意更新Eulerian积分都必须可逆。

**上一轮C1更新载体没有被采用。**它的初态质量和本轮原材料空间质量属于不同物理表示，不能混用。本轮原质量缩放条件数约7.33e6，仍偏大；不能沿用C1候选约8.75e5的数值。原材料基函数只依赖X，所以M是常量，继承已认证的完整质量及交叉项有明确依据。

修正目前是CPU点查询合同，尚未进入生产网格传递内核；其计算原场残差的Load成本仍随点数增长，不能称为免费的SH加速或新的Eulerian运动空间。

## 3. 边界与动力学实际验证

先完成4步线性化惯性探针，保留自由—固定质量交叉项及固定行反力；左夹具固定，右夹具沿x移动，位移为`0.1*t^2 m`，时间步长0.001 s。静态和线性化核查约8秒，峰值RSS约1.71GiB。

随后完整q7非线性材料端点检查使用4,917,248个积分点，用时约25秒。非线性内力与小幅线性预测相对差约3.70e-5；这一步仅检验端点，未把线性轨迹直接标成非线性轨迹。

基于测得的成本，预先登记`protocol-v2.json`，再执行4步非线性中点短窗：保留原完整非线性势能，原静止切线只作预测/弦矩阵，验收使用实际非线性残差。不是原AVF完整周期，也没有压力项。

| 指标 | 本轮结果 |
|---|---:|
| 非线性窗口 | 4步，0.004 s |
| 完整材料积分 | q7，每次4,917,248点 |
| 实际材料调用 | 9次 |
| 总耗时 | 约184.7秒 |
| 峰值RSS | 约1.98GiB |
| 最小J（完整材料规则） | 0.9998667821 |

| 最大单步能量缺陷 | 约4.21e-15 J |
| 最大能量账目闭合余差 | 小于1e-24 J量级 |

各步初始弦预测均已满足预登记的非线性工程容差，没有额外修正迭代。这说明该微小短窗可用，不证明大变形Newton收敛或长期稳定。将材料能、稳定化能、动能、夹持功、路径积分误差及残差功分别记录；没有通过提高阻尼隐藏误差。

完整积分得到的最小J低于稀疏探针的最小J，报告采用完整规则值。可视化仅显示165个材料探针，不能把探针极值当作全场极值。

## 6. 下一步顺序和实际瓶颈

1. 将本轮绝对状态映射、规定边界和有限状态身份接入正式压力几何，推导同一完整增量下的体积变化与压力功。
2. 使用已有可验证切线作用或合适的块/矩阵自由求解策略，先避免照搬小模型的稠密有限差分雅可比。正式648自由分量下，仅一轮中心差分就约1296次残差扰动；每次至少一次约20—25秒的完整材料评估会远超短验证预算。这是成本估算，不是已跑的巨型实验。
3. 然后登记正式主/备用材料规则和压力控制体，检验实际欠积分失败、完整回滚、重启，再做正式4步耦合。
4. 后续才进入独立空间参考和函数预算调整。生产SH修正必须单独验证真实内核及成本，不能把本轮CPU公式恒等式当生产集成完成。
