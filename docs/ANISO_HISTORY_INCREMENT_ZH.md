# 固定材料样本的历史＋增量原型

## 本轮结论（2026-09-22）

另建 [history_increment.py](../engine/aniso_phase1/history_increment.py)，保留原 `MaterialQ1.recover()` 的严格检查与既有测试。完成 grid 17/33 的单次内部模板节点移动：位置/F/应力/纤维方向历史保留，势能导数、共同扰动、无质量刚度谱及短程更新均通过已定义的数值检查。

**刚体转动的增量表达检查未通过。** 历史保住不等于新空间能表达旧弯曲形状的刚体运动。结果支持这条历史增量路线的局部可行性，尚不能宣布任意换模板问题解决。本轮没有进入历史压缩、反复切换或 PCG 替换。

这是 CPU/float64、纯弹性、固定材料参考域的诊断实现，不是生产 Eulerian MPM 重划分。保持生产默认。

## 1–3. 历史、材料样本与新增量

`HistoryState.from_nodal()` 从同一个旧位置场读取粒子和材料积分点上的 x/F。`HistoryField` 保存旧位置场及后续完整增量场，在任意参考位置可同时评估位置和参考梯度：

\[
x^{n+1}(X)=x_{\rm hist}^n(X)+\Delta u_h(X),\qquad
F^{n+1}(X)=F_{\rm hist}^n(X)+\nabla_X\Delta u_h(X).
\]

粒子与积分点的 X、参考体积、A0 以及粒子质量采用只读副本；切换只重建新基底的 N、参考梯度与一致质量矩阵。切换时复用同一个历史状态对象，不投影历史位置、不修正 F，也不重建积分点。求解试探不会修改已提交历史。

`commit()` 用同一节点位移 dt·v 对两批点的 x/F 加法更新，并保留对应的完整增量场。负 Jacobian 或违反固定夹具的提交被拒绝。连续使用同一个模板时合并该模板下的增量系数，旧模板场继续保留。测试在采样点之外做位置差分，确认历史梯度一致；采样点上的数组也与完整场重评估相符。

实验配置：

| 源 grid | 运动节点 | 质量粒子 | 固定材料积分点 |
|---|---:|---:|---:|
| 17 | 81 | 864 | 864 |
| 33 | 425 | 6912 | 6912 |

每个旧单元每轴 3 个均匀质量粒子、每轴 3 个 Gauss 材料积分点，两批点数量相同但坐标不同。平滑参考方向场、材料参数 (μ,λ,kf)=(10,20,200)、初始弯曲幅度 0.005 均与旧原型一致。

仅将中央的一个内部 x 结点移动 0.2h，域边界与其他结点保持原位。对于张量积 Q1，这意味着移动该截面的一组模板节点；尚未实现任意扭曲六面体的单顶点移动。旧严格恢复控制在两档网格上均拒绝此非嵌套切换，而新原型能够从保留的历史继续更新。

充分保留旧样本属于隔离状态表示问题的诊断选择，不是低成本采样压缩。新模板的梯度折点一般不与旧积分单元对齐，固定积分规则的连续体积分误差仍存在；当前导数验收针对同一离散势能。

## 4. 势能、恢复力、解析切线与约束

固定步内映射，定义 $Bv=\sum_a v_a\otimes\nabla_XN_a$，全部使用固定材料参考 X 下的导数：

\[
F(v)=F_{\rm hist}+\Delta t Bv,\quad
\Phi(v)=\tfrac12(v-\hat v)^T M(v-\hat v)+\sum_q V_q^0\psi(F_q(v),A_{0,q}),
\]
\[
r=M(v-\hat v)+\Delta t\sum_q V_q^0 B_q^T P_q,\qquad
J=M+\Delta t^2\sum_q V_q^0B_q^T H_qB_q.
\]

M=Nᵀdiag(mₚ)N，预测速度采用同一质量最小二乘投影。左端夹具直接消去增量场的固定节点速度。初始 v=0 时保留的旧应力仍进入恢复力；释放试验验证其作用。

沿用原型带 admissibility/Armijo 回溯的 L-BFGS，按残差收敛，不接 PCG。`material_tangent()` 从 C=FᵀF 的谱导数计算 Hencky＋纤维解析 dP；对数差商采用重根连续极限，保留真实曲率。`tangent()` 和 `stiffness()` 分别提供实际解析作用与去质量弹性矩阵，没有正定裁剪或人工稳定项。

## 5. 验收结果

### 快照与变分导数

两档网格切换瞬间，粒子和材料点上的位置、F、Cauchy 应力、归一化当前纤维方向张量变化均为 **0**；材料能完全相同。这个结果主要说明状态未被改写，不作为总体通过依据。

有限差分 ε 扫描为 10⁻²、10⁻³、10⁻⁴、10⁻⁵，以下列最优相对误差，完整扫描保存在 JSON：

| 项目 | grid 17 | grid 33 |
|---|---:|---:|
| 势能差分 vs r·p | 1.92e-11 | 5.60e-11 |
| 残差差分 vs 解析 Jp | 3.39e-12 | 5.05e-12 |
| 切线相对不对称量 | 3.70e-17 | 9.67e-18 |
| 共同物理扰动的虚功差 | 2.45e-16 | 2.45e-16 |
| 共同物理扰动的刚度双线性型差 | 2.34e-15 | 7.78e-15 |

共同扰动含满足左端夹具的仿射、双线性和三线性场。先检查两模板在同一材料点上的位移和梯度一致，再比较虚功向量及完整 4×4 刚度双线性型；未用同一节点编号代表同一物理扰动。

### 无质量主要谱

检查未变形与预弯曲状态、切换前后四种弹性矩阵的全部特征值。阈值为 10⁻⁹·max(谱半径,1)，两档网格均无新增近零模态或负模态。这里只对固定左端后的空间作判断。

| 预弯曲状态 | grid 17 | grid 33 |
|---|---:|---:|
| 原模板最小特征值 | 0.00283363 | 0.000486862 |
| 新模板最小特征值 | 0.00281481 | 0.000485659 |
| 前 8 个有序特征值的新/旧比值范围 | 0.9894–1.0123 | 0.9973–1.0035 |

这是同节点数下的有序谱比较，不表示已经追踪到每个特征向量的物理身份，也不保证任意形变下不存在真实负曲率。

### 切换后的短程释放

dt=0.0005，共 8 步（总时长 0.004），第 2 步结束后切换。比较不切换、重建相同模板、移动内部结点三条路径；三者使用相同初态、材料样本和求解器。相同模板重建路径与不切换路径的最终位置/F/速度和能量差均为 0。

| 最终结果 | grid 17 | grid 33 |
|---|---:|---:|
| 不切换机械能相对初始变化 | −14.5767% | −19.7876% |
| 移动结点路径机械能相对初始变化 | −14.8660% | −19.8947% |
| 两路径最终位置 RMS 差 | 2.93e-6 | 1.02e-6 |
| ‖δF‖ / ‖F_control−I‖ | 0.7722% | 0.4554% |
| 最终速度相对差 | **9.2033%** | **2.8803%** |
| 移动结点路径相对控制的最终机械能差 | −0.3386% | −0.1336% |

全部路径机械能逐步下降；最大缩放残差小于 1e-9，最小 det F 大于 0.9975，夹具速度为 0，能量账本闭合误差小于 4e-22，最终历史场重评估误差小于 7e-16。账本单列速度投影、惯性余项、弹性余项、求解残差功及动能回读；能量下降不能全部归因于切换。

数值上未出现翻转、残差爆炸或新增零刚度模式，但移动模板后的轨迹并不相同，粗网格速度差约 9.2%。这些是增量空间及固定积分规则变化后的运动差异，不能称为无损动力学。当前短时小变形试验也不能排除长期异常。

## 6. 成本边界与后续门槛

保留全部材料样本、旧位置场和每个已使用模板的累计位移场。同一模板内多步更新不增加场项数量；本轮不切换路径最终保留 2 项，切换路径保留 3 项。切换路径的系数数组为 5832 / 30600 字节（grid 17/33），**仅统计节点系数**，不含历史模板几何、材料状态数组、稀疏映射、质量分解和诊断矩阵，因此不代表总内存。重新构造相同模板目前也增加一项，尚未按相同空间去重。

下一阶段先处理或明确限制刚体运动模式，随后重新验证势能导数、质量秩、夹具、无质量谱与释放轨迹；通过后才研究减少材料样本、相容位置/F 余量压缩、多次切换误差累积和存储维护成本。压缩必须同时维持位置场及其梯度关系，不能只留下任意 F 修正。
