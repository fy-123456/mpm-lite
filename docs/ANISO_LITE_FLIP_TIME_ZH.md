# F45：按物理时间标定 FLIP 混合强度

本轮验证 \(\beta(\Delta t)=0.9^{\Delta t/0.001}\) 是否改善完整 F45 拉伸的时间步一致性。只改变每条轨迹的 `flip_ratio`，不同时修改历史梯度、材料、中心积分、APIC、位置推进、边界冲量修复或加载命令。生产默认保持原样。

## 1. 对照设置

完整冻结协议与源码哈希：[protocol.json](results/lite-aniso-mainline/v5/protocol.json)。参数沿用 v4 的 `baseline`，即原粒子历史梯度、中心积分、particle_resample、variational、mean_tensor、无稳定化、开启边界冲量回传修复、反力停止容差 1e-7 N。网格 9、dx=0.125 m、192 粒子，mu=10、lambda=20、kf=200，纤维方向 45°。

加载时间固定 0.5 s，loading_speed=0.01 m/s，平滑余弦命令终点位移固定 0.005 m。CPU float64，最多两个单线程模拟进程；CUDA 未运行。

## 2. 公式与边界

粒子速度混合为

\[
v_p^{new}=\beta v_p^{FLIP}+(1-\beta)v_p^{PIC}.
\]

在固定 PIC 目标的简化情况下，速度差每步乘以 beta。令

\[
\beta(\Delta t)=\beta_0^{\Delta t/\Delta t_0}
=\exp(-\Delta t/\tau),\qquad
\tau=-\Delta t_0/\log\beta_0,
\]

可以令一个完整时间间隔与分割成多个小间隔具有相同累计倍率：

\[
\prod_k\beta(\Delta t_k)=\beta\!\left(\sum_k\Delta t_k\right).
\]

这里参考 beta0=0.9、dt0=0.001 s，对应 tau 约 0.00949 s。它定义的是数值混合的时间尺度，不是新增物理材料黏性。真实 PIC 目标、粒子几何和 APIC 梯度都会变化，因此完整方法不会因这个公式就自动变成严格时间一致，仍需实测。

## 3. 测试与预定验收

原有 50 项检查加两项时间标定测试，共 52 项。新增测试验证固定目标下 1/2/4/10 个子步的累计混合、非均匀时间划分、beta=0/1 极限，以及非有限/非法参数拒绝。

物理验收沿用 v4：网格 x 合力及粒子三维合力误差 ≤1e-7 N；粒子/网格总动量差 ≤1e-14 kg·m/s；夹具网格速度误差 ≤1e-12 m/s；平均粒子夹具位移误差 ≤0.001 m；J>0；Newton 达到按 dt 缩放的有效残差目标。每条轨迹在 t=0.05、0.1、0.25、0.5 s 保存 4 份冻结诊断。

总反力、弹性项和惯性项均统一到粗时间步的物理时刻，在 t=0.05..0.5 s 用梯形积分计算 RMS。比较两对相邻时间步，分母为较细曲线 RMS，底限 0.001 N。验收要求最细相邻总反力差 ≤5%，且绝对相邻差随加密下降。两对具体数值均报告，不隐藏较粗一对。

\[
D_{01}=\operatorname{RMS}(R_{dt}-R_{dt/2}),\qquad
D_{12}=\operatorname{RMS}(R_{dt/2}-R_{dt/4}),\qquad
\rho=D_{12}/D_{01}.
\]

观测阶 p=-log2(rho) 只是三档趋势指标，不自动证明渐近收敛；时间步间的差异也不是对连续真解的误差。

速度传递动能净变化为 P2C、C2G、G2P 三段账目之和；不同轨迹的加载功与运动也不同，不能将其当作反力误差的独立占比。

**结论：有改善，但单独标定 FLIP 比例不足以通过时间精度验收。**

最细两档绝对总反力差从 0.00317343 N 降至 0.00191549 N，下降约 39.64%；相对差从 15.354% 降至 10.189%。这是时间步间一致性的改善，不是相对连续真解误差下降了同样比例。

标定后三档相邻差仍从 9.299% 增至 10.189%，绝对差缩减比 rho=1.220>1，观测阶约 -0.286。当前三档没有显示收敛，不能将继续减小 dt 当作可靠精度保证。弹性项最细相邻差也仍为 8.757%，说明残余差异不只来自惯性。

全部物理检查通过，最大粒子合力误差 6.789e-10 N；粗档完整复现参考结果。本轮改变的唯一模拟参数是 FLIP 比例，因而可以确认这项数值混合强度调整影响了反力时间步敏感性；但不能把降低的差值简单解释成某一误差来源的独立占比。

速度传递累计动能净变化的绝对值在标定后仍随加密增大，约为 1.021e-5、1.413e-5、1.802e-5 J。细档与最细档的 P2C/G2P 分段量出现更大的正负抵消，因此仅看净量变小不能断言整个传递链已经一致。

下一步应独立检查 APIC 梯度回传、粒子/中心速度差与每步中心重建的频率效应。当前公式只给速度混合的 beta 指定时间尺度，未给整个 APIC 传递状态建立相同的时间一致性。这个方向仍需受控测试，尚不能认定已找到全部根因。生产默认保持不变；本轮参数保留为可复现实验配置，不宣称已完成高精度修复。

本轮冻结验收状态：物理检查 通过，冻结诊断 通过，最细相邻总反力差 ≤5% 否，相邻绝对差随加密下降 否，总体 未通过。

## 5. 复现

在仓库根目录，使用新的输出目录：

```bash
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
.venv/bin/python -m benchmarks.aniso_flip_time freeze --output /tmp/flip-time-repeat
.venv/bin/python -m benchmarks.aniso_flip_time tests --output /tmp/flip-time-repeat
.venv/bin/python -m benchmarks.aniso_flip_time run --jobs 2 --output /tmp/flip-time-repeat
.venv/bin/python -m benchmarks.aniso_flip_time analyze --output /tmp/flip-time-repeat
```

运行器依赖仓库保留的 v4 基线；源码或参考文件变化时拒绝继续，已有案例不会覆盖。分析返回 2 表示冻结验收未全部通过。

单独运行细档演示可直接使用现有参数入口，不需要改生产默认：

```bash
.venv/bin/python -m demos.aniso --headless --scene tensile --grid 9 \
  --device cpu --dt 0.0005 --steps 1000 --fiber-angle 45 \
  --smooth-loading --loading-time 0.5 --loading-speed 0.01 \
  --reaction-force-atol 1e-7 --boundary-impulse-transfer \
  --flip-ratio 0.9486832980505138
```

本轮不提供空间参考真解，不覆盖其他角度、网格、载荷速度或 CUDA。即便时间步一致性改善，仍需区分“固定了数值平滑强度”和“真实反力精度已达标”。
