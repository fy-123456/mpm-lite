## 目标与不变条件

目标是在冻结共同空间上得到可复核的固定材料规则，认证其有限变形适用域，并交付 C 可使用的同源材料接口。四阶是首选待验证候选，不是预定必然通过的结论。

材料积分的区域是不重叠物理材料单元，运动学支撑重叠不产生重复体积。`q` 的完整／自由映射、参考体积、坐标单位、材料参数、硬夹持、原稳定化和质量保持相同。材料求值点减少不能被描述为粒子惯性压缩或完整算法加速。所有 Newton、线搜索、AVF 路径求值使用固定规则；在线重分组和动态空间更新不纳入本轮主要变量。

混合方向属于另立的材料变体：沿用同一运动学空间并绑定 `parent_bundle_sha256`，增加材料来源指纹和新的充分积分证据；不覆盖父包的 F45 材料身份。默认方向场固定在参考构形，随空间旋转的材料方向变化必须遵循原本构约定，不能悄悄换成当前构形方向。

## 执行步骤

### B1 锁定父包及本任务实验协议

**做什么：** 在独立源码副本上验证父包、空间和原源码闭包，登记输入链接目标或解引用副本；冻结线程、机器、dtype、材料不变项、三个数据分组和验收公式。读取现有映射和边界检查作为来源证据，不重建另一套基函数。记录初始快照是右夹持 0.005 m 的静态快照。

**为什么：** 防止将旧离线基底、改动后的工作区或新的 A 包混入本次压缩比较。

**产出：** `baseline-check.json`、`protocol.json`、输入／源码摘要和状态族设计表。

**如何验收：** 父包及空间摘要逐字匹配，657／1107 分量和自由索引一致；既有绑定文件无差异；每个规则结果均能追溯父包、空间、材料来源及状态。协议在首次候选扫描前封存。

**失败处理：** 来源不一致立即拒绝实验；需要新基底或材料时创建明确子版本，不能修改父包后沿用旧验收。

### B2 建立同空间充分积分对照及动态边界适配

**做什么：** 复用 `CommonSpace.nodes/adjoint` 和实际材料势能，在 B 私有 stage2 模块暴露完整位移输入及自由坐标包装。状态展开使用 `expand(q, lift)`，方向展开使用零 lift；返回总能量、材料能量、原稳定化能量、完整／自由能量梯度、完整切线作用、材料弱应力矩和最小 detF。为 C 显式接收时变完整 lift，不隐式读取父包的 0.005 m 固定 lift。记录 `force` 是正能量梯度，机械内力为其负值。

**为什么：** 共同空间的已有 `response` 默认使用静态 lift；材料接口若混淆状态与方向、完整与自由量，会把边界反力或恒等项算错。

**产出：** 同空间充分积分适配器、固定探针数据及导数契约。

**如何验收：** 父包静态状态与既有六阶算子重放一致；非零 lift 下有限差分与切线、虚功伴随一致；固定行反力保留；原 `Ks` 的能量、力和切线分量逐项一致。导数建议相对门槛能量梯度 1e-6、切线 1e-5；步长平台与近零绝对尺度先登记。

**失败处理：** 先区分映射、符号、lift、稳定化和积分误差；不通过扩大压缩预算掩盖接线误差。

### B3 预登记有限变形状态与独立数据分组

**做什么：** 建立训练、开发验证、最终隐藏三个按整族隔离的数据集。训练覆盖零加载平衡、归档快照、载体／局部模式、拉压和剪切组合；开发覆盖更大幅度及近夹持局部模式。分别登记温和、中等和接近有效域边界的状态幅度，并用充分积分探针筛查 detF 与有限响应。最终隐藏至少设置三类未见组合族，每族不少于四个状态、每状态不少于五个预定切线方向；方向包含载体、局部、混合、剪切及敏感模态。实际采样规模在计算前按成本确认并封存。

**为什么：** 首轮两个状态、两个方向不足以支撑有限变形稳健性，随机微扰也可能遗漏局部切线困难方向。

**产出：** `state-families.json`、分组清单、封存隐藏生成器及参数摘要、有效域分层表。

**如何验收：** 同一构型的变幅和旋转近邻不能跨训练／隐藏泄漏；每族有物理或数值覆盖理由；非法态明确作为拒绝测试，不混入误差通过率。隐藏生成及评价程序预先封存，开发者只使用训练和开发结果选择规则。

**失败处理：** 某状态无效时保留失败原因；只能按预登记规则替换，不能查看候选误差后删除困难夹持或局部模式。

### B4 扩展方向场并保存材料来源

**做什么：** 主 F45 分支保持原常方向算子。为混合方向另建同空间点值方向场适配器，支持先固定分区双方向、再连续转向和出平面方向；在每个材料求值点从同一个参考场生成归一化方向及所需方向张量。充分／压缩积分必须共享这个场的定义、分区边界、单位、种子和摘要。对多个纤维族明确权重求和的本构语义，不能把任意二阶平均张量冒充完整非线性混合材料。先做常方向退化与独立公式对照，再接联合位置—方向采样。

**为什么：** 现有 Tensor 路径只支持广播常量 A，简单替换 `space.A` 不能表达空间变化和联合位置—方向相关性。

**产出：** 新材料来源对象、同空间 full／compressed 方向场适配器、常量退化及分区跃变检查。

**如何验收：** 常方向退化恢复 B2；同一位置 full／compressed 的原始材料定义一致；修改方向场、材料参数、分区或坐标约定均改变来源摘要；零应变态换方向也必须被拒绝。非均匀变体独立标记，不能继承父包 F45 已认证能力。

**失败处理：** 来源绑定或独立本构对照失败，停止该变体；F45 主分支继续，不让新材料扩展阻塞固定共同模型。

### B5 重新认证充分材料积分

**做什么：** 在 B3 的训练／开发状态和 B4 的每种材料族上比较六、七阶；对差异较大的单元或方向追加八阶或预登记的局部分裂积分。比较总量及每个夹持、内部、深内部区域，另看各薄材料层，记录能量、组装内力、弱应力矩和切线作用。非光滑方向场必须按物理分界分片，不用跨跳变单元的升阶制造假收敛。

**为什么：** 第一阶段六对七阶只认证小范围状态；未经自检的六阶不能作为大变形误差的真值。

**产出：** `full-reference-certification.json`、困难分区列表、各材料族充分规则身份。

**如何验收：** 建议充分参考预算比候选预算严一个数量级：能量、内力、弱矩相邻差不超过 0.1%，切线不超过 0.2%；困难点追加一档确认趋势。误差使用预登记的物理尺度和绝对下限，同时公开未归一化值。每族仅在已认证状态域内声明充分。

**失败处理：** 积分未收敛时标记 reference_unverified，不把候选接近六阶当通过；可以缩小声明适用域，但保留原计划未通过部分。

### B6 比较四阶候选并定位积分误差

**做什么：** 在训练／开发集同时运行充分、五阶、四阶和三阶；四阶是主候选，三阶用于定位失效界限。逐状态比较材料能量、组装完整及自由内力、分区弱应力矩、预定方向切线作用和局部切线功。单列稳定化，避免总能量中的稳定化掩盖材料误差。计算点数、构造成本、峰值内存及回退比例。

**为什么：** 旧 B 四阶成功不能外推新基；总能量很小的差异也可能伴随局部切线误差或内力抵消。

**产出：** `rule-scan.json`、候选误差—点数表、全部失败规则及分区归因。

**如何验收：** 建议材料能量、组装内力、分区弱应力矩均不超过 1%，切线作用不超过 2%；必须所有预登记关键分区通过，不能仅用全域平均。相同 F 上再次调用同一本构计算 PK1 必然趋同，不属于压缩精度验收；没有应力重建器时只声明弱应力矩和组装内力精度，不声明逐点压缩应力精度。

**失败处理：** 四阶不通过时保留五阶或局部充分积分；降低点数只是候选目标，不以删除敏感方向换取“四阶通过”。

### B7 建立同源固定规则与局部回退接口

**做什么：** 按开发集结果选择一条固定规则，必要时在困难材料分区采用预定高阶。完整／压缩／回退规则都绑定同一材料来源；准备阶段只生成候选值，正式接受由 C 的整步事务控制。为 Tensor 分支新增来源检查，不能直接假定旧 `BoundMaterialFamily` 已覆盖该路径。规则、空间、方向场、边界协议、dtype 和执行后端共同进入缓存身份。整个 Newton 与 AVF 路径内规则不变。

**为什么：** 压缩误差必须与物理换材、空间换基、缓存污染和规则中途变化分离。

**产出：** 固定规则材料包、`material-contract.json`、来源绑定与负例数据、供 C 使用的准备／拒绝接口。

**如何验收：** 错空间、错来源、错材料参数、过期试探、方向场改变均拒绝；局部回退严格恢复同源充分积分，不改变质量矩阵和载体—局部交叉质量。C 尚未就绪时使用值事务驱动器验证准备阶段，不冒称真实动力学提交通过。

**失败处理：** 回退仍不满足误差预算则保持充分积分；发现缓存或来源问题停止该路径并保留可复现输入。

### B8 冻结候选后打开新的隐藏集

**做什么：** 冻结 B7 规则、状态有效域、代码摘要、门槛和误差归一化，再只打开一次 B3 最终隐藏集。先在隐藏状态认证充分参考，再比较候选；分别汇总主 F45、混合方向和近有效域边界子集。不得复用首轮已公开隐藏集作为“新隐藏集”。

**为什么：** 开发扫描与独立验收分离，才能判断候选是否泛化，而不是记住旧空间和少量状态。

**产出：** `hidden-acceptance.json`、逐状态及逐方向原始结果、完整失败清单与封存源码。

**如何验收：** 满足 B5 参考门槛和 B6 候选门槛，并通过有效域保护；任一必要子集未通过则对应能力不认证。协议摘要必须早于解封记录，调参记录不得发生在本次候选封存之后。

**失败处理：** 一旦根据隐藏失败修改规则，本组数据转为开发数据；重新建立独立隐藏族。不能多次试同一隐藏集后只保留最终成功记录。

### B9 验证无副作用试探及失败回滚

**做什么：** 给 C 交付拥有独立值的材料子状态，模拟非法 detF、非有限响应、拒绝线搜索、失效 token、后置验证失败及缓存失配；验证 B 已准备而 C 拒绝的情况。当前固定规则不需要在线切换，但必须拒绝在物理步中途切换。未来重分组的能量跳变字段保持明确未启用，不能填零冒称已测试在线变化。

**为什么：** 第一阶段 `StateTransaction` 只管理拥有的值树，不自动原子提交外部 B/E 对象；旧 B 对象若先提交，会出现 q 回滚而规则已变的错误。

**产出：** 故障注入记录、子状态格式、B/C 准备与整步提交顺序图。

**如何验收：** 所有拒绝路径下 q、v、时间、规则来源、累计账本、预测器和可影响数值的缓存身份保持原值；成功时恰好提交一次。真实对象的整步原子性必须与 C 共同验收，值树模拟只计接口级证据。

**失败处理：** 发现外部对象副作用时改为不可变提案及成功后的单点提交；不能靠捕获异常后“尽量恢复”宣称原子性。

### B10 与 C 做单因素固定积分对照

**做什么：** C 的同空间、充分积分、无传递 CPU 参照通过后，先固定 B/C 同字节的充分积分规则和共同状态域，并通过参与任务中最严格的适用参考门槛，再在完全相同初态、dt、质量、边界、稳定化、时间算法及求解容差下，仅替换 B 材料规则。先短窗，再完整循环；C 使用独立充分积分探针输出应力，压缩轨迹的误差相对于充分轨迹衡量。保存失败、回退和原始反力，不平滑。

**为什么：** 静态算子误差和单次材料核耗时不能证明动力学误差或端到端收益。

**产出：** `C-common-space-comparison.json`、匹配时间点轨迹、规则来源与质量不变校验。

**如何验收：** 建议压缩引入的完整循环、逐阶段和终态反力／充分探针 PK1 增量误差不超过 1%，且两轨迹均满足 C 的物理与时间判据；质量作用和惯性账本逐项不变。不得用不同 A 空间或 C 旧 21 自由分量小模型替代。

**失败处理：** C 未就绪则标记 dependency_pending 并交付 B1—B9，不声称 B10 完成；若压缩增量失败则回退规则或限制认证范围，不能改 C 的 dt 抵消压缩误差。

### B11 在等误差条件下统计成本

**做什么：** 开发期记录材料点数、构造、基求值、材料响应、梯度组装、切线、内存及回退成本；正式性能测量预约独占资源、预热后交错重复至少五次。C 未就绪只给算子成本；C 就绪后统计达到同一误差的完整循环，包括所有 Newton／Krylov、检查和回退。GPU 实现与公平测量由 D 的接口接入，不修改 D 目录。

**为什么：** 首轮 70.37% 点数减少不等于动力学加速，额外准备及更差条件数可能抵消收益。

**产出：** `cost-breakdown.json`、机器环境、重复样本、中位数及波动区间。

**如何验收：** 同一问题、同一容差和完整成本口径；结果同时报告未加速案例。只有确认总耗时降低且大于重复测量波动才声明收益；点数与 kernel 时间只能作为机制证据。

**失败处理：** 无收益仍可交付正确性成果，明确原因；不把其他机器或其他空间的 D 加速倍数移接本任务。

### B12 封存能力边界并交接

**做什么：** 生成子交付包，绑定父共同包、新增源码、状态集、充分规则、候选规则、原始证据和读取链接目标。输出任务级状态：共同空间 F45、混合方向、隐藏验收、真实 C 循环、GPU 各自独立标记。向 D 提供材料接口测试向量，向 C 提供不可变规则和来源拒绝样例。

**为什么：** 一份“B 已完成”不能表示所有变体、后端及联合动力学均已通过。

**产出：** `REPORT_ZH.md`、`acceptance.json`、`handoff-package.json`、源码与成果摘要及复现命令。

**如何验收：** 清洁副本可加载并核验全闭包；每项通过均有原始数据；旧父包摘要不变；其他组可只依赖 B 的显式冻结交付，不读取可变 latest 路径。联合验收未执行时清楚列为 pending／not_run。

**失败处理：** 缺证据、断链或来源冲突时暂不认证对应能力，保留已完成且独立可复核的范围。

## 里程碑及并行边界

| 里程碑 | 内容 | 外部依赖 |
| --- | --- | --- |
| B-M1 | B1—B5 同空间对照与参考认证 | 仅冻结父包；无需 A 新结果 |
| B-M2 | B6—B9 固定规则与新隐藏验收 | D 公共接口可用前先使用 B 私有适配器 |
