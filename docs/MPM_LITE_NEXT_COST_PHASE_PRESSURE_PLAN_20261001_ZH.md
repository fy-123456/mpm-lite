**四、统一验收规则与实验预算**

相同物理位置、相同量纲和相同权重下，分区场误差采用：

\[
e_r(y)=\sqrt{\frac{\sum_{a\in r}w_a\|y_a-y_a^{ref}\|^2}
{\sum_{a\in r}w_a}},
\qquad
e_r(y)\le a_y+0.05\|y^{ref}\|_r.
\]

| 验收类型 | 预登记规则 |
| --- | --- |
| 位移、速度、固体 PK1／纤维、反力 | 分别沿用绝对项 5e-5 m、1e-4 m/s、0.02 Pa、1e-4 N，加 5% 参考尺度 |
| 实现等价、CPU/GPU 算子 | 沿用既有量纲绝对项和约 2e-5 相对预算；不要求改变求和次序后仍逐位相等 |
| 同状态材料规则 | 能量 1e-10 J、内力 1e-8 N 加 2%；切线作用沿用方向归一化与 1e-8 绝对项加 3%；弱矩按各分量原单位与 1e-10 绝对项加 2% |
| 求解及几何 | 沿用真实残差条件；有限数值；min det(F)>0.1；边界误差≤1e-8。相对约 0.99 的当前基线出现明显下降时仍须分析，不能只看大于 0.1 |
| 能量 | 材料、Ks、动能、边界功、路径误差、求解误差与规则切换分账；沿用已登记能量尺度的 1% 数值误差预算 |
| 压力、总 PK1 | 对独立可靠参照采用 1e-5 Pa＋5%、0.02 Pa＋5%；压力过冲另设物理检查，不能被这条一般 RMS 门槛掩盖 |
| 每单元流体含量、能量闭合 | 1e-12 m³、1e-9 J 绝对项加预登记物理尺度的 1%；含量未乘密度，不标成 kg |
| 来源与事务 | 哈希、坐标身份、提交代次、失败后已提交状态不变不放宽；恢复的浮点场按同实现一致性验收 |

位移用 u=x−X，压力用共同参考体积上的均值，固体 PK1 与总 PK1 分别输出。全域、夹持、过渡、内部区域分开检查；空间应力验收使用共同单元积分，不用少量显示探针替代。不同规则各自 Gauss 点上的最小 det(F) 不直接相减当作几何误差。

不同步长的反力使用同区间冲量平均：

\[
\bar R_{[a,b]}=\frac{\sum_i \Delta t_iR_i}{b-a}.
\]

所有预算在看候选结果前登记。近零参考用绝对项；不改归一化、移动评价位置或平滑图像来制造通过。2% 应力／纤维与 1% 反力保留为长期研究目标，不是本轮每项必须达到的结束条件。

| --- | --- |
| 入口兼容 | 2—4 步，含一次新进程恢复；不重跑旧版完整周期 |
| 性能 | 至多两个串行实现候选；两个代表状态、每个两步、两组交替配对；构建每版先测一次，仅结果接近噪声时追加一次 |

**P1：先降低当前空间的实际使用成本**

- **如何验收：**共享对象的密集和稀疏数组均不可写；材料规则相关布局、响应、临时缓冲、预测器、试算状态及事务容器分别拥有。q5 失败后 q7 从同一已提交状态出发；错误包／设备／布局不能命中缓存。每个新进程仍验证所加载的实际文件，禁止仅凭路径或 mtime 跳过完整性校验。

- **做什么：**比较基函数值／梯度、仿射场、完整质量、Ks、能量、组装内力和两个归一化方向的切线作用。随后做有限动态配对和一次压缩失败回退；使用非零变形状态，避免只测静止零值。

**P1.5｜按实际收益选择默认实现。**

- **做什么：**两个代表状态各做两组交替配对，分别报告构建、两步推进、显示、IO 和内存；归档生成成本单列。最多保留一个最终组合实现，完整周期成本留到 P6。

**P2：在当前物理空间上改善时间相位**

**P2.1｜复用已有轨迹，先定位未通过的物理量。**

- **做什么：**对组合变换 T 验证完整质量和刚度，向量刚度使用相应 \(T_3=T\otimes I_3\)：
  \[
  M_c=T^TM_RT,\qquad K_{0,c}=T_3^TK_{0,R}T_3.
  \]
  检查物理零空间消元、边界迹、刚体／仿射响应和 q7/q8 充分积分，然后才求候选非线性静态状态。
- **为什么：**144 函数相同不代表质量、约化坐标或稳定化自动正确；候选退化必须能与欠积分、丢失交叉项区分。

- **如何验收：**不跨空间直接复制 q/v 或改写状态身份。确需场转移时显式记录投影、动量和动能差，最终动态资格优先从静止重新加载。联合时间门槛失败则保留该空间下 0.0125 s 并记录限制；材料资格暂设未认证，交由 P5 处理。
- **交付：**selected-space.json、P3/dynamic-qualification.json、最终 time-decision.json 及更新的性能适用范围。

**P4：先解决最小压力瞬态问题，再考虑扩大耦合**

**P4.1｜复核已定位的半离散过冲，建立独立判据。**

- **做什么：**先读取最新解析诊断，独立重建固定固体、无源项、初始压力 0.01 Pa、右储库 0.002 Pa 的两单元小矩阵。当前矩阵为：
  \[
  H=\begin{pmatrix}40&10\\10&20\end{pmatrix},\quad
  B=\begin{pmatrix}1&0\\-1&1\end{pmatrix},\quad
  C=0.0046875I.
  \]
  消去通量后检查 \(C\dot p+Lp=b\)，其中 \(L=BH^{-1}B^T\)、\(b=s+BH^{-1}g_\partial\)。
- **为什么：**最新精确半离散解在 0.01 s 的上游压力约 0.01018639 Pa，已证明只减时间步不能消除该空间离散的过冲。
- **如何验收：**核对初始内部流量约 -1.142857e-4 m³/s，以及独立矩阵指数解。新增判据只用于这个无源、固定固体、标量排水问题：压力应保持在储库／初值范围内，并检查明显非物理反向流；不把该单调性要求错误套到有源、骨架压缩的一般耦合场景。
- **交付：**P4/transient-baseline.json；此小矩阵分析不需要重跑三维长场景。

**P4.2｜比较有限的压力分辨率与一种相容离散。**

- **做什么：**先检查一致 RT0/P0 的 2／4 单元半离散响应，必要时追加一次廉价 8 单元诊断。若仅加密仍不能满足目标，再研究一个明确的新方案：在当前沿 x、横向零流量的限定问题中，按单元中心到面距离推导守恒面传输系数，而非任意删除原 H 非对角项。
- **为什么：**现有 H 是特定弱形式的完整阻力矩阵。换成独立面阻力属于新的离散，必须说明与连续通量的关系，不能声称原算子完全等价。
- **如何验收：**参考迁移率保持 \(A=(k/\mu)JF^{-1}F^{-T}\)。横向零流量时使用 \(a_{\rm eff}=1/(A^{-1})_{xx}\)，不能误用 \(A_{xx}\)。对本轮单元常值的一维测试，可推导每面 \(R_f=\sum_K\ell_{Kf}(A_K^{-1})_{xx}/A_f\)，其中 \(\ell_{Kf}\) 为中心到面距离、\(A_f\) 为面面积；变系数和变形场则明确采用对应积分／近似并做充分性检查。
- **交付：**P4/discretization-derivation.md、至多一个新离散候选的算子身份。两点传输方案只声明此限定几何／通量子空间，不宣称任意三维各向异性网格正确。

**P4.3｜分别验收空间单调性和时间推进。**

- **做什么：**对候选固定固体模型检查正容量、通量耗散、零源平衡、线性压力解析通量以及 \(-C^{-1}L\) 的非对角符号；比较半离散精确解与现有中点时间推进。边界平滑只可作为诊断另列，默认排水条件保持不变。
- **为什么：**半离散无过冲也不保证任意大步长的中点更新无过冲；仅修改空间或仅修改边界都有可能掩盖另一类误差。
- **如何验收：**在正对角 C、合适 M 矩阵结构的限定问题中，检查中点更新 \(G=(C+hL/2)^{-1}(C-hL/2)\) 的正性及边界响应。可用 \(h\le2\min_i(C_i/L_{ii})\) 作该结构下的保守充分检查，不能当成一般混合系统定理。无源两单元上游过冲目标≤1e-5 Pa，所有结果输出未裁剪；必要时只增加一次半步对照。不得直接更换流体时间方法而不重新推导交换功和耗散。
- **交付：**P4/monotonicity-and-time.json，分别列出半离散、离散时间、正性、局部守恒和耗散结果。

**P4.4｜在最终固体空间恢复四步耦合验证。**

- **做什么：**仅合格压力方案进入 P3 最终固体空间，使用充分材料积分。保持同一个体积定义：
  \[
  m_k=\alpha(V_k-V_{0,k})+C_kp_k,\quad
  \bar g_k^T\Delta q=\Delta V_k,\quad
  f_p=-\alpha\sum_kp_k\nabla_qV_k.
  \]
  检查固体极限、固定固体极限，封闭／排水各四步，并比较正常和小储存参数下的混合可解性。
- **为什么：**修正压力趋势不能以破坏固液功交换、完整惯性或张量通量为代价。
- **如何验收：**逐单元 \(\Delta m+hB\bar z-hs\) 闭合；固液交换功抵消，\(h\bar z^TH\bar z\ge0\)。输出固体 PK1 与 \(P_{\rm total}=P_s-\alpha pJF^{-T}\)。一般混合求解仍按真实残差验收，不把固体 SPD／CG 假设移植到整个压力系统；有限矩阵满秩不写成一般 inf-sup 认证。
- **交付：**P4/coupled-checks.json、四步原始场、压力／流量／能量分账。

**P4.5｜验证完整事务并决定耦合能力。**

- **做什么：**检查 q、v、预测器、压力、含量、面通量和累计源／边界历史的共同提交；在第 2 步退出后恢复至第 4 步。针对新实现实际风险检查提交前失败与指针发布后观察错误，避免重复接受。
- **为什么：**压力离散改变后，原固体回退测试无法独立证明新的流体状态与累计历史安全。
- **如何验收：**恢复与连续轨迹一致，已提交状态不因失败污染。如果压力过冲仍未解决，明确保留 pressure_monotonicity=false 与 production_C_E_integration=false，跳过扩大耦合范围，继续 P5 的纯固体交付。
- **交付：**P4/rollback-restart.json、P4/coupling-decision.json，分别声明算子、场景、单调性和连续压力精度范围。

**P5：在最终空间和时间方案上完善日常资格与回退**

**P5.1｜冻结最终配置并判定哪些证据可继承。**

- **做什么：**固定 P3 的空间、质量、原 Ks、材料、边界、P2/P3 的最终时间数组和 P1 实现。将“物理模型身份”“实现身份”“试验来源”分开登记；判断旧 q5 证据是否仍适用。
- **为什么：**改变实现、物理空间或时间路径的影响不同；原空间、不同峰值或另一时间表的证书不能只复制字段后使用。
- **如何验收：**纯等价实现经 P1 核对可引用旧数值证据，并补少量新实现对照；新空间、材料或实际轨迹发生变化则使用该配置的真实充分轨迹重新检查。不能只凭 max_dt 没变就宣称新路径已覆盖。
- **交付：**P5/qualification-scope.json、最终模型与协议身份。

**P5.2｜先确认充分规则，再确认 q5。**

- **做什么：**使用最终配置的实际代表状态，覆盖加载、卸载、一个未用于资格选择的检查状态以及主导切线方向。先比较 q7/q8，再比较 q5/q7；优先复用最新 0、0.5、1.1 s 和独立 0.8 s 的匹配状态。有新路径时只生成缺少的充分状态。
- **为什么：**需要同时排除充分积分不足和压缩误差。旧状态缩放或更换材料后的同状态算子检查不能冒充新场景动力学验证。
- **如何验收：**能量、组装内力、分区弱应力矩、混合方向及敏感方向切线通过既定预算；全部规则使用相同完整质量。如果 q7 不充分，最多一次 q8/q9 检查，并同步实际重试模型、配置、身份和显示元数据；不能仅把 full_order 改成数字。
- **交付：**P5/full-rule-qualification.json、P5/q5-qualification.json；q5 未通过则日常配置使用已通过的充分规则。

**P5.3｜完善范围拒绝与固定规则回退。**

- **做什么：**在主入口显示请求规则、实际规则和资格范围；不匹配的空间、峰值、材料或时间路径默认选择充分规则，非法身份直接拒绝。试算过程中不切规则；明确可归类的压缩失败才整步回滚后重算，并记录规则切换能量。
- **为什么：**入口范围判定、数值失败和编程错误需要有不同处理；自动回退不能吞掉 KeyError、维度错误或来源损坏。
- **如何验收：**试算前、准备后、提交前的必要故障点恢复整步；双规则失败保留旧提交并报告失败。检查点指针发布后异常不会重复推进；新进程恢复包括规则状态、失败历史和累计切换能量。q5/q7 共享只读资源时补一次污染拒绝检查。
- **交付：**P5/runtime-policy.json、P5/fault-and-restart.json、经过实际调用验证的 CLI 说明。

**P5.4｜只扩展一个有实际需求的敏感范围。**

- **做什么：**默认优先补 F45／0.0075 m 在最终空间的资格；总预算不足、主场景未稳定或存在未解异常时不开展。先做有限同状态充分性检查，再用充分规则到达实际受载状态，仅做 4—8 步短窗的 q5 对照。
- **为什么：**新空间的 0.0075 m 目前是未认证范围，具有明确增量价值；但无需为覆盖更多名字跑多个完整周期。
- **如何验收：**短窗资格只标注该状态／窗口范围。若没有足够真实轨迹覆盖，完整 1.6 s 敏感场景仍使用充分规则，不能根据四步检查颁发全周期 q5 资格。跨角度、跨几何和耦合 q5 留作后续独立范围，不与本轮敏感幅值混合。
- **交付：**P5/sensitive-scope.json，明确 qualified_window／full_only／not_attempted；未开展不写成数值失败。

**P6：完成有限整体验收与可复现交付**

**P6.1｜冻结最终数值代码并运行针对性回归。**

- **为什么：**最终场景必须绑定实际交付的数值代码；不能在跑完后修改求解器再沿用旧结果。
- **如何验收：**原始来源链不变，新文件全部纳入清单，序列化／恢复和实际 CLI 可用。若后续只修报告，保留运行时源码并证明数值代码不变；数值修改则仅重跑受影响的必要检查与场景。
- **交付：**P6/final-source-sha256.json、P6/tests-result.json、依赖与环境记录。

**P6.2｜只做最终必要的完整场景与图像检查。**

- **为什么：**短窗和同状态检查无法保证整个周期都没有累计错误，但无需更多帧或长时间扫描。
- **如何验收：**共同时间的分区位移、速度、PK1、纤维和同区间反力通过工程预算；几何无翻转、振动和能量无明显异常增长；核对回退次数、真实残差、原始能量账。图像不平滑掩盖峰值，显示倍率明确。报告实际总时间、构建、推进／显示／发布、RSS 和 GPU 内存；新空间准确性收益与成本增加分开说明。
- **交付：**P6/final-scene.json、P6/physical-review.json、完整周期成本与已提交帧可视化。

**六、实施期间如何记录和处理异常**

每个阶段结束更新新进展文档，写明输入身份、改动、验证、实际耗时／内存、已知限制和下一步。候选失败、参考超预算或改变时间／空间决策时立即记录，不等到最后汇总。

普通路径、类型、报告格式或来源明确的小问题可以自行修复后重查。出现明显压力过冲、能量无故增长、质量秩变化、缓存污染、身份错配或需要改变物理含义的方案时，先做有限根因分析。若无法在预算内定位，停止该候选、保留已通过基线，并继续不依赖它的工作；不把异常场景写成通过，也不因一个压力分支受限而放弃已完成的纯固体改进。

持续保留三类不同结果：数值实现一致性、工程场景可用性、连续物理精度证据。稳定或守恒不能自动推出单调性；q5/q7 接近不能自动推出空间准确；函数数目相同不能自动推出性能相同。
