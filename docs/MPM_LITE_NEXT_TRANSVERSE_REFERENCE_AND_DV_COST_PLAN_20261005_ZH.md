## 3. 冻结的数学问题、参考定义和验收标准

### 3.1 主工况与时间范围

主工况选择 **YZ128**，网格 `(32,2,2)`。直接复用 BASE 网格数组，尤其 x 方向薄层坐标，不按文档小数重新生成。

| 参数 | 固定值或来源 |
|---|---|
| 压力域 | `[0.125,0.875] × [0.375,0.625]²` |
| alpha / storage | `0.8 / 0.0002` |
| 库压力 / 源项 | `0.002 Pa / 显式零` |
| 迁移率 | 原 `MOBILITY × 1e-7`，保留全部非对角项 |
| 初始固体状态 | BASE 认证的 rest q0、零速度；不另做平衡改变初态 |
| 初压 | 原 YZ128 连续初压的参考单元平均值，128 项逐项绑定 |
| 时间协议 | 原 U4 完整 0～200 微秒时间数组及残差归一窗口 |
| theta | 到 25 微秒为 1，之后为 1/2；复用原节点判定语义 |

初压定义仍为：

\[
\eta_y=2(y-0.5)/0.25,\quad \eta_z=2(z-0.5)/0.25,
\qquad p_0=0.2[1+0.2(\eta_y+0.5\eta_z)]\ \mathrm{Pa}.
\]

YZ128 单元初压应为 0.17/0.19/0.21/0.23 Pa。Y128 对照将 z 项设为零，复用同一拓扑和算子，不新增 GPU 轨迹。不得拿两种不同初态的差异当作网格误差。

零均值初压扰动保持总初始含量，但增加 `0.5*delta_p.T@C@delta_p` 储能。恢复旧检查点时继承其完整初态和累计历史，不重新用均匀压力的 E0 起账。

### 3.2 固定骨架半离散参考

首先仅在认证 rest 状态固定 `F=I`、`V=V0`，令 `C=storage*diag(V0)`。方程为：

\[
C\dot p+Bz=0,\qquad Hz-B^Tp+g_b=0.
\]

通过线性求解构造 `Z=H^{-1}B^T` 和 `z_b=-H^{-1}g_b`，实现时不显式求 H 的逆。于是：

\[
z=Zp+z_b,\quad L=BZ,\quad b=-Bz_b,
\qquad C\dot p+Lp=b.
\]

本工况源项严格为零；历史 CPU helper 的 `source_density_s_inv` 必须显式传零并校验，不能借用其他旧算例的非零源项。

令 `D=diag(sqrt(C_cc))`，采用对称容量缩放：

\[
A=D^{-1}LD^{-1}=Q\Lambda Q^T,\quad Lp_\infty=b,
\]

\[
p(t)=p_\infty+D^{-1}Qe^{-\Lambda t}Q^TD(p_0-p_\infty).
\]

先检查 H、L、A 的对称性和边界约束，再使用对称分解；不能通过强行对称化或截断负特征值掩盖组装错误。固定排水边界下预计没有压力常数零模态，若实测不符先查边界和秩。

累计面交换必须直接积分：

\[
Q_f(t)=\int_0^t z(s)\,ds=Z\int_0^t p(s)\,ds+t z_b,
\qquad \bar z_{[a,b]}=\frac{Q_f(b)-Q_f(a)}{b-a}.
\]

指数积分采用 `expm1` 等稳定求值方式。小特征值按解析极限处理，不任意给扩散率加下限。面流量本身已是 m³/s，不再乘一次面积。

这个参考只消除了**固定骨架、当前压力网格**的时间离散误差。它不是连续空间真解，也不能直接用于判定运动固体耦合轨迹的总误差。固定骨架与耦合轨迹之差同时包含固体运动影响，应独立标为“模型差异诊断”。

### 3.3 模式、时间尺度与小信号判定

继续使用 BASE 的参考体积加权模式：

\[
\bar p_V=\frac{\sum_cV_{0c}p_c}{\sum_cV_{0c}},\qquad
A_y=\frac{\sum_cV_{0c}\eta_{y,c}(p_c-\bar p_V)}{\sum_cV_{0c}\eta_{y,c}^2},
\]

Az 同理。初始应为 `Ay=0.04 Pa, Az=0.02 Pa`。迁移率有非对角项，单个方向模式未必单调，Y128 也可能产生 z 响应，不能强制要求它为零。

从 `lambda_i` 和初态在各特征向量上的投影共同判断可观察时间尺度 `tau_i=1/lambda_i`，不能只看最慢特征值。预先计算 0～200 微秒内 Ay/Az 的变化，判断 125 或 175 微秒是否能提供额外信息；必要时可计算最多三个更长时刻的廉价谱解，仅用于时间尺度诊断，不启动长耦合轨迹。

为了防止初始幅值掩盖微小演化，除了原绝对场量指标，再报告 `Delta A(t)=A(t)-A(0)`。固定骨架数值积分相对于谱解的模式增量预算预登记为：

\[
\max_t|\Delta A_{\rm num}(t)-\Delta A_{\rm ref}(t)|
\le 10^{-5}\ \mathrm{Pa}+0.10\max_t|\Delta A_{\rm ref}(t)|.
\]

若参考变化幅度不超过绝对下限的 5 倍，即 `5e-5 Pa`，报告“时间信号未充分分辨”；即使上式通过，也不宣称相对衰减精度。这是新增的信号诊断标准，不回写或重新解释 BASE 的旧验收结果。

### 3.4 分层验收，不追逐无意义的小误差

| 层次 | 指标 | 判定方法 |
|---|---|---|
| 来源与事务 | 输入哈希、初态、状态、帧、累计账本 | 完整一致；不得用数值宽容差放过错载、错步或半提交 |
| 算子/实现等价 | V、G、H 作用、压力功、真实残差、状态 | 继承 BASE 逐量纲代数预算；具体取 `performance.py::static` 与 `trajectory.py::equivalence`，不改成 5% |
| CPU 谱参考自检 | 初态恢复、平衡方程、谱解与独立矩阵指数压力 | 初态绝对差≤`1e-10 Pa`；两实现压力差≤`1e-8 Pa + 1e-6*max|p|`；方程检查采用量纲缩放相对残差≤`1e-8` |
| 压力与模式场值 | 同网格、同时间的数值解与参考 | `0.001 Pa + 5%*参考尺度`，并独立检查上节模式增量 |
| 含量/累计交换 | 全局、分区、六侧 | `1e-10 m³ + 5%*参考尺度` |
| 区间流量 | 同一物理时间区间的积分均值 | `1e-10 m³/s + 5%*参考尺度`，原始微步峰值另列诊断 |
| 位移/速度 | 相同实体探针、分量和区域 | 绝对下限分别 `5e-5 m / 1e-4 m/s`，各加 5% 参考尺度；报告信号与下限比 |
| 骨架/总应力 | PK1、Cauchy、纤维、区域统计 | `0.02 Pa + 5%*参考尺度`，统一评价位置与权重 |
| 反力 | 相同区间的原始冲量平均 | `1e-4 N + 5%*参考尺度` |

场量比较只用于物理条件相同且具有参考的配对。扩窗没有同工况动态真值时只评价稳定性、守恒和趋势，不把固定骨架解套用成位移/应力参考。

所有实际耦合推进保留硬条件：有限值、`detF>0.1`、本场景原压力下限、原真实残差、原子提交；累计含量缺口≤`1e-10 m³`，累计能量缺口≤`1e-9 J + 1%*|该分支真实E0|`。检查逐步和累计记录，不允许正负误差相消后掩盖单步异常。

能量分别记账：

\[
E=\tfrac12v^TMv+U(q)+\tfrac12p^TCp,
\quad D_{\rm Darcy}=h z^THz,
\quad D_{\rm num}=(\theta-\tfrac12)\Delta p^TC\Delta p.
\]

物理耗散和数值耗散分别报告。不能为了让响应平顺增加 theta 或阻尼，也不能在 theta 切换处清空耗散历史。

- **如何验收：** 128 项初压可独立重建，Ay/Az 初值和总含量/储能正确；来源能追到不可变代次。交付 `S0/physical-contract.json`、`S0/observation-contract.json`、`S0/checkpoint-sources.json`。

**S0.3｜冻结新目录、资源与尝试预算。**

- **做什么：** 创建独立子版本目录及新进度文档，建立第 5 节预算计数；缓存和大结果默认写数据盘。单个时刻仅持有一个 GPU 模型，各进程串行启动。
- **为什么：** 控制实验规模，同时保持旧成果可复查。
- **如何验收：** 预算在首次实验前落盘；系统盘低于 5 GiB 时才按第 5 节迁移闲置数据。交付 `S0/experiment-budget.json`、`S0/resource-policy.json`、`S0/storage-migration.json` 和冻结计划副本。

### S1：先建立同网格固定骨架压力参考，4 步

**S1.1｜构造独立 CPU 算子与向量初态入口。**

- **做什么：** 从锁定 cuts 构造 ReferenceTopology，显式固定 F=I，以每单元每轴 2 点 Gauss 积分组装完整张量 H；构造 C、B、gb、L、b。新接口接受形状严格为 `(128,)` 的自有 p0 数组。记录源项为零，并检查边界面方向和体积总和。
- **为什么：** 非均匀初压能暴露均匀场不敏感的轴顺序、符号和广播错误；不应把旧均匀初压或历史源项带进新参考。
- **如何验收：** 拓扑、V0、初压、完整 H 方向作用复现 BASE 已有静止证据；检查矩阵尺寸、对称性、秩和边界约束。Y128/YZ128 共用同一算子而分别绑定初态。交付 `S1/reference-input.json`、`S1/operator-check.json`。此步不构造大型 GPU 固体模型。

**S1.2｜实现谱参考、累计交换和独立自检。**

- **做什么：** 按第 3.2 节容量缩放求谱解；同时输出所有面的累计交换和区间均值。用不超过两个非零时刻的增广矩阵指数独立核对压力，检查 t=0 恢复、平衡残差以及含量变化和净边界交换相抵。
- **为什么：** 只比较两个共享同一实现的时间推进器，无法排除共同错误；瞬时 Darcy 流量也不能代替区间平均流量。
- **如何验收：** 满足参考自检预算，源功严格为零；累计交换可按区间相加，六侧和全局含量闭合；记录最小压力，发现负值先查离散算子与边界，不裁剪压力。交付 `S1/reference-self-check.json`、`S1/reference-YZ128.npz` 和 Y128 CPU 对照。

**S1.3｜用真实 theta 协议分离时间误差。**

- **做什么：** 在相同固定骨架系统计算原 h 和登记的 h/2 时间表，使用
  `(C+theta*h*L)*p_new=(C-(1-theta)*h*L)*p_old+h*b`，保留原 theta 切换。与谱解分别比较压力、Ay/Az 增量、区间流量、累计交换与能量分账。
- **为什么：** 这是廉价识别当前步长是否足够的直接方法，可避免没有证据就启动更多 GPU 子步。
- **如何验收：** 报告 h 和 h/2 各自相对谱解的实际误差及预算比；区间按积分聚合，不拿半步瞬时值与整步平均比较。未通过时给出明确时间误差证据；不得把此处通过写成完整耦合时间精度通过。交付 `S1/fixed-skeleton-time-review.json`。

**S1.4｜登记可分辨时间尺度与唯一扩窗决定。**

- **做什么：** 计算初态投影和 Ay/Az 对各特征模态的权重，报告 75、125、175、200 微秒的预测变化及信号/下限比；决定先扩 4 步是否有信息价值。预登记追加 4 步和触发耦合 h/2 的条件。
- **为什么：** 扩窗应服务于可观察响应，不为了更多帧而计算；最慢特征值不一定对应当前初态可激发的模式。
- **如何验收：** 交付 `S1/window-and-time-decision.json`，明确 `extend4 / extend8_if_needed / limited_signal` 及理由。参考失效时暂停依赖它的物理结论；资源允许时仍可独立验证既有检查点上的实现等价。

### S2：显式使用 DV，并验证一个有限耦合窗口，4 步

**S2.1｜建立来源完整的 DV 研究工厂。**

- **做什么：** 在新命名空间复用原物理构造，显式安装 DV；绑定 DV 源码和实现标识，保留完整方程、初态和检查点身份。新来源审计必须认识本子版本，旧 `verify()` 不直接用于新运行目录。复用 SafePublication 和 frame_builder 的原子提交语义。
- **为什么：** 当前工厂默认仍走 D3；只更改显示名称不能保证实际启用最新后端。实现身份变化也不应被伪装为完全相同的执行来源。
- **如何验收：** 构造后断言实际后端类型及实现 digest，检查 P/质量/材料/初态完全一致，错初态和错网格恢复被拒绝；旧源码和旧文档哈希保持。交付 `S2/backend-binding.json` 与最小 CPU 身份合同结果。

**S2.2｜完成一个已知状态的推进桥接与恢复。**

- **做什么：** 从 BASE 的 YZ128 第 8 步认证状态，在新目录用 DV 推进一步，和 BASE 第 9 步状态及账本比较。验证新进程只读恢复。若新工厂/缓冲区生命周期改变了失败路径，再补一次提交前资源拒绝和一次重算；否则引用 BASE 已通过的对应故障证据。
- **为什么：** 把“已有 DV 算子通过”落实到本轮实际入口，防止恢复、帧生成或来源适配引入新差异。
- **如何验收：** 状态、反力、压力功、含量、耗散历史、真实残差、同位置场统计满足 BASE 实现等价预算。父代次只读；资源不足时不得推进，待设备校验通过后才重算。交付 `S2/bridge-check.json`、`S2/recovery-scope.json`。桥接 1 次；条件故障及重算最多 2 次，全部计数。

**S2.3｜只延长 YZ128 一个工况。**

- **做什么：** S1 认为可获得信息且 S2.2 通过后，从 BASE 第 18 步/75 微秒恢复，原时间协议继续到 125 微秒。若参考预示追加区间有可分辨变化、前 4 步硬条件通过且仍有预算，再到 175 微秒。先后分支均使用 DV。
- **为什么：** 保持初态、材料和空间一致，可以观察更明显的耦合响应，同时控制成本。
- **如何验收：** 每步检查第 3.4 节硬条件，记录 Ay/Az、分量位移、分区应力、内部流量、六侧交换和原始反力；同时报告全历史累计平衡和以 75 微秒为起点的区间平衡。新 store 必须显式链接父历史，不能把累计耗散清零或把第 18 步改成第 0 步。固定骨架差异仅作诊断。交付 `S2/extension-review.json`；最多 8 个新耦合步、2 个新物理帧。

**S2.4｜仅在证据触发时做一条启动 h/2 对照。**

- **做什么：** 触发条件为固定骨架时间误差超登记预算且可能影响耦合判断，或实际耦合出现无法由已核查输入/观察定义解释的时间相位迹象。仅细分原 0～37.5 微秒的 12 个区间，形成 24 个半步；后续时间节点保持原值，残差归一仍为 200 微秒。新分支从同一认证初态启动，不强行恢复时间身份不匹配的旧检查点。
- **为什么：** 用一次短对照分离时间影响，避免自动增加长周期或无限细分。
- **如何验收：** 对齐 12.5、25、37.5 微秒的场与区间积分；和 BASE 同初态粗步轨迹比较前，确认 S2.2 的后端等价及物理身份。报告原始微步峰值和工程均值，二者不混用；误差仍大则标受限，不自动 h/4。交付 `S2/time-review.json` 或 `S2/time-not-triggered.json`。24 次推进计入上限。

### S3：按 DV 的新热点选择一个性能候选，4 步

**S3.1｜测量当前 DV，区分真实热点与计时重叠。**

- **做什么：** 复用桥接和扩窗计数；必要时在 BASE 第 8、16 步状态各补一个 DV 单步。细分 F 构造、体积归约/下载、局部 gather、梯度伴随、下载/P 映射、H、材料路径、混合求解、检查点与 IO。GPU 计时明确同步，嵌套计时标注包含关系。
- **为什么：** D3 的旧占比不能直接用于 DV；合并的局部梯度计时也不能直接断言某个 kernel 占主导。
- **如何验收：** 给出独立段及未能分离部分，记录几何调用、求解次数、冷/热缓存、分配量、完整进程成本。性能决策用统一低开销计时，细粒度 profiling 只用于归因。交付 `S3/DV-profile.json`，额外动态步≤2；不得把同步仪器自身开销当成待优化物理计算。

**S3.2｜登记一个可解释的候选，或决定不改。**

- **做什么：** 若局部梯度路径确为主要热点，在批量单元处理、缓冲区复用、设备上 P 映射中只选一个最小候选。写明其作用于 `G_c=partial V_c/partial q` 的哪一部分、预期节省、构造成本和内存。若没有有价值的热点，直接保留 DV。
- **为什么：** 用 Amdahl 关系 `S=1/[(1-f)+f/r]` 判断投入价值；不能因 H 理论上可优化就优先处理占比很小的部分。
- **如何验收：** 候选不改公式、积分、P、缓存所有权、当前状态 H/G、原残差或 LU；不生成全域节点×自由度稠密表。交付 `S3/candidate-protocol.json` 或 `S3/no-candidate.json`；候选源码在首次数值测试前冻结。

**S3.3｜验证算子等价和临时状态生命周期。**

- **做什么：** 若候选登记，在第 8、9、16 步和第 8/9 步中点共 4 个状态上比较 DV 与候选的 V、G、H 作用、minJ。检查 Simpson 体积链 `G_bar:Delta q=Delta V`、压力功相抵、返回数组所有权、不同 q 缓存、元数据/P 所有者变化后的拒绝或重建。新增持久缓冲区需验证失败后无脏值影响。
- **为什么：** 局部梯度和 P 映射决定压力广义力，错误可能不立即导致崩溃，却会破坏能量交换。
- **如何验收：** 使用 BASE 的代数等价预算；不通过则定位修复，根因不明时停止候选采用并保留 DV。交付 `S3/operator-check.json`、`S3/buffer-lifecycle.json`。大规模候选静态状态最多 4 组。

**S3.4｜公平单步测速，入选后补四步连续检查。**

- **做什么：** 对第 8、16 步两输入，在独立进程依次运行 `DV0、候选0、候选1、DV1`。探针、IO、JIT 状态和起始 q 缓存策略一致；设置成本单列。候选满足选择标准后，从第 8 步继续 4 步，与 BASE 第 9～12 步比较完整状态和账本。
- **为什么：** 微基准快不一定整步快；连续状态和缓存生命周期可能产生单步测试看不到的问题。
- **如何验收：** 两组物理等价通过，单组耗时不倒退，中位耗时下降≥5%，两组降幅差≤5 个百分点；新增设置/JIT 成本按实测节省回收≤16 步。资源竞争或计时噪声导致不能判断则记受限，不反复测速凑门槛。连续 4 步硬条件、代数等价、恢复/缓存检查通过才入选。交付 `S3/paired-performance.json`、`S3/continuous-check.json`、`S3/backend-decision.json`。不宣称完整周期加速。

### S4：决定空间与后续耦合的进入条件，2 步

### 5.1 小规模实验预算

| 工作 | 基础/条件工作 | 上限 |

- GPU 相关完整进程累计≤900秒，CPU 参考与分析累计≤600秒；小型合同检查单列耗时。到限时停止可选分支并交付受限结论。
