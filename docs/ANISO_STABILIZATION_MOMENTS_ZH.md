# 空间稳定化、四阶方向矩与组合迁移验证

> 后续验证见[预弯曲梁旋转、耗散与慢速拉伸](ANISO_ROTATION_DISSIPATION_ZH.md)：supplemental 大转动朝向误差已经量化，不能作为通用有限转动模式。新增粒子基线诊断与混合方向稳定化修正；本页性能数据是该修正前的统一方向实验，不代表最新混合纤维成本。

本轮基于粒子历史重采样和统一增量势能版本继续。完成可选空间稳定化、生产 GPU 四阶方向矩、非均匀预弯曲梁平移，以及相同条件的粒子积分对照。新增功能均保留显式开关：默认仍为 `stabilization=none`、`direction_model=mean_tensor`。

**建议：小变形、小转动梁场景选择 `supplemental`；包含混合方向的当前二次纤维材料选择 `fourth_moment`。** 继续采用带曲率检查、正定近似回退和原势能线搜索的 PCG。不能把本轮小应变稳定化当作任意有限变形下已经验证的客观稳定化，也不宣称能量耗散已消除。

实现见 [enhancements.py](../engine/aniso_phase1/enhancements.py)、[solver.py](../engine/aniso_phase1/solver.py)。原始数据和可复现实验见 [结果目录](results/stabilization-moments/) 与 [实验入口](../benchmarks/aniso_stabilization_moments.py)。

## 1. 稳定化如何提供持续刚度

仅对当前步速度波动加惩罚，可能只抑制增量，不能代表持续的变形能。本轮让粒子额外携带材料参考位置 $X_p$，每步通过当前位置和 $F_p^{-1}$ 重建节点位移：

$$
u_i^n=x_i-\frac{\sum_p m_p w_{pi}[X_p+F_p^{-1}(x_i-x_p)]}{\sum_p m_pw_{pi}}.
$$

其中 $w_{pi}$ 使用现有 P2C/C2G 两层传递的组合权重。参考位置与方向一样随粒子保存；上述重建仅发生在步间，Newton/PCG 不遍历粒子。

在每个占用中心对应的 Q1 单元中，使用 2×2×2 Gauss 点梯度 $g_{qi}$ 与中心梯度 $g_{ci}$ 的差：

$$
D_{cq}(v)=\sum_i (u_i^n+\Delta t\,v_i)\otimes(g_{qi}-g_{ci}),\qquad
E_{stab}(v)=\frac{\eta}{2}\sum_c\frac{V_c^0}{8}\sum_q D_{cq}:H_{0,c}:D_{cq}.
$$

两种可选 $H_0$：

- `supplemental`：同一本构在 F=I 处的小应变弹性切线，包含各向异性纤维；
- `hourglass`：$H_0[D]=2\mu D$，作为简单各向同性小时玻璃对照。

附加残差与 Jacobian 从这个势能直接求导：

$$
r_{stab}=\eta\Delta t\sum_{c,q}\frac{V_c^0}{8}\mathcal D_{cq}^T H_{0,c}D_{cq},\qquad
J_{stab}=\eta\Delta t^2\sum_{c,q}\frac{V_c^0}{8}\mathcal D_{cq}^T H_{0,c}\mathcal D_{cq}.
$$

这里 $\mathcal D$ 是梯度差映射。对于本轮材料参数，$H_0$ 半正定，附加 Jacobian 对称半正定；原本的精确材料 Jacobian 在有限压缩下仍可能不正定，因此保留 PCG 曲率检查与回退。

仿射位移场的 $D_{cq}=0$，所以不会改变均匀拉伸、剪切或纯仿射刚体运动的响应。在小应变、冻结几何、η=1 时，`supplemental` 补上的正是全积分与中心积分之间的刚度差。**它不是对有限应变非线性本构重新执行八点全积分**：强变形、非均匀大转动下的一致客观性尚未建立，默认不开启。

预变形状态若启用稳定化，必须提供一致的 `reference_positions`；不能同时给非单位 F 并把变形后位置随意当作未变形材料坐标。生产入口已检查这一条件。能量 CSV 包含 `stabilization_energy`，反力包含附加势能的贡献。当前增强模式只支持变分残差、粒子历史重采样、最终 damping=1。

## 2. 梁参考与短程动态结果

参考仍为同一 Hencky 基体＋二次纤维模型在 F=I 处的独立 Q1 小应变有限元。梁长 .5、截面 .125×.125、固定一端、端部总横向力 −1e−4。η=1；材料 μ=10、λ=20、kf=200，纤维沿梁轴。

| 网格 | 原中心积分零模态 | 补充积分零模态 | 小时玻璃零模态 | 全积分/补充积分端位移 | 小时玻璃端位移相对参考误差 |
|---|---:|---:|---:|---:|---:|
| 17³ | 32 | 0 | 0 | −5.69794e−4 | 13.46% |
| 33³ | 64 | 0 | 0 | −6.06623e−4 | 4.06% |

实际生产 matvec 减去质量项并除以 dt²，与上述独立刚度的相对差约 3e−16–5e−16。端位移来自该冻结小应变刚度的静力求解；不是声称做完了有限应变移动网格的静态平衡验收。补充积分与全积分在这里一致是公式构造的结果，实际 matvec 对照用于验证代码是否实现了该公式。

均匀拉伸/简单剪切各做 4 步：附加势能约 1e−33 或更小，解析应力对照通过。另有混合方向下的势能有限差分、解析 matvec、边界投影、对称性和正定近似检查。

### 预弯曲梁释放

给定小弯曲形状和一致的 F/参考位置，夹持左端后自由释放；比较无稳定化、补充积分、小时玻璃。模拟 T=.008 s，每组 8 或 16 步；9 组全部收敛，最小粒子 det F> .999，无明显几何爆炸或求解失败。

| 网格/dt | 无稳定化 ΔE/E₀ | 补充积分 ΔE/E₀ | 小时玻璃 ΔE/E₀ |
|---|---:|---:|---:|
| 17³ / .001 | −5.69% | −7.67% | −5.77% |
| 17³ / .0005 | −2.60% | −4.45% | −2.68% |
| 33³ / .001 | −13.81% | −14.27% | −13.83% |

这些是可见的数值耗散，不能叫作已经足够小的能量误差。细网格同 dt 下隐式积分对较高频模式的耗散加重；无稳定化也出现相近现象。账本中 33³ 补充积分的隐式步约贡献 −17.24% E₀，状态/体积重映射合计约 +3.81%，两次向网格传递约 −1.36%，回传约 +.55%。这支持“主要来自现有积分及传递”的解释，不能仅凭预算阶段拆分证明唯一机制。

17³ 网格减半时间步后耗散减小。因为验收以短程整体稳定为主，本轮没有继续跑长周期或严格外推收敛阶。稳定化解决的是零刚度模式，不能代替低耗散时间积分和更精确的历史重建。

## 3. 四阶方向矩已进入实际求解路径

保存

$$
A^{(2)}=\sum_p\omega_pA_p,\quad M^{(4)}=\sum_p\omega_p\operatorname{vec}(A_p)\operatorname{vec}(A_p)^T.
$$

当前二次纤维模型在共同 F 下的平均能量、应力为

$$
\bar\psi_f=\frac{k_f}{2}[C:M^{(4)}:C-2C:A^{(2)}+1],\qquad
\bar P_f=2k_fF S,\quad S=M^{(4)}:C-A^{(2)}.
$$

精确切线作用为

$$
\delta\bar P_f=2k_f[\delta F S+F(M^{(4)}:\delta C)],\qquad
\delta C=\delta F^TF+F^T\delta F.
$$

生产代码以“平均张量响应＋方差修正”实现，能量、残差、matvec、诊断和反力使用相同修正。正定近似把对称 S 的负特征值截断，保留第二个本来半正定的项；与基体的正定近似组合，仅用于搜索方向，线搜索仍检查原势能。它是修改切线，不称为精确 Jacobian。

矩阵用完整 9×9 表示，但**只为占用中心分配**；稀疏块仅存紧凑索引。每步 GPU 前缀和建立索引，粒子散射一次四阶矩，随后迭代不访问粒子。尚未进一步利用张量对称性压缩每个中心的分量数。

实际多块网格、共同 F=diag(1.1,1,1)，与逐粒子同一本构求和比较；下面为**含基体的整体响应误差**，不是此前单独纤维能量的 50% 案例：

| 方向场 | 平均张量能量误差 | 平均张量应力误差 | 平均张量切线误差 | 四阶矩结果 |
|---|---:|---:|---:|---|
| 统一方向 | 舍入误差 | 舍入误差 | 参考差分误差 | 与旧表示一致 |
| 0°/90° 混合 | 9.11% | 12.38% | 12.34% | 能量/应力约舍入误差，切线约 1e−10 |
| 平滑方向场 | 6.52% | 7.89% | 7.45% | 能量/应力约舍入误差，切线约 1e−10 |

切线参考来自独立 PK1 有限差分；实际应力/切线由生产节点残差和 matvec 的仿射虚功提取。每个中心的方向权重不完全相同，因此此表不能套用“所有中心均严格 50/50 混合”的结果。

精确恢复仅限**共同 F、当前双边二次纤维能量**。非均匀 F 的平均误差、仅受拉模型或指数模型不因此自动解决。

## 4. 非均匀预弯曲梁平移

固定 2048 粒子、相同材料体积 .5×.125²，使用非均匀预弯曲 F 和材料参考位置。所有节点规定平移速度，T=.08 s 内移动 .13，隔离几何历史迁移；同时测试无稳定化/补充积分，均使用四阶矩。

| 配置（补充积分） | 最终弹性能变化 | 最大跨步跳变 / 初始弹性能 | 中心应力与加权粒子应力差 |
|---|---:|---:|---:|
| 33³ / dt=.01 | +.00709% | .00255% | .00917% |
| 65³ / dt=.01 | −.00329% | .000592% | .00152% |
| 33³ / dt=.005 | +.00305% | .0182% | .00916% |

弹性能包含稳定化项。F 历史误差、平移后的形状误差约舍入误差；最小 det F>.999。空间加密降低了应力平均误差；减小 dt 没有单调降低最大单步能量跳变，因为采样穿越单元的时刻也改变了。不能因此报告虚假的时间收敛阶。该试验是规定运动，不是自由弯曲解的验证。

## 5. 公平性能对照

采用同一 GPU、同一物理立方体（边长 .25）、密度 1、总体积/质量 .015625、同一初始仿射速度、dt=.001、T=.007 s、相同求解容差与 `supplemental` 稳定化。PPC 为 2³ 与 4³，分别 512/4096 粒子；每粒子体积随粒子数调整。诊断关闭，前两步不计时，后五步同步 GPU 后取中位数。

粒子基线逐粒子评估相同本构并使用相同两层传递、相同附加稳定化。它无需压缩方向；本次性能场景为统一方向。另存位置与 F 误差，不把两种 quadrature 的结果假定为完全相同。

| 粒子数 | 中心平均张量 (ms/步) | 中心四阶矩 (ms/步) | 粒子积分 (ms/步) |
|---|---:|---:|---:|
| 512 | 12.77 | 14.26 | 12.02 |
| 4096 | 13.14 | 14.48 | 11.91 |

三种方案多数步均为 3 次线性迭代。**当前短程小规模实验没有显示中心方案的加速优势**；增加正确性所需的步间重建、矩散射和修正核有开销。不能用旧版本的速度数字代替本轮结果，也不能用这六个短样本推断大规模性能。

终点中心方案相对同 PPC 粒子基线的位置 RMS 差为 1.04e−7 / 9.14e−8；相对于实际位移的误差为 1.24% / 1.09%，相对于 F−I 的应变变化误差为 2.60% / 2.28%。统一方向下平均张量与四阶矩结果一致。报告 F−I 归一化是为了避免完整 F 中的单位阵掩盖小应变误差；粒子基线也是数值方法，不把它等同于解析真解。

本例四阶矩在平均张量增强模式上新增约 264 KiB 设备数组；4096 粒子时，中心四阶矩与粒子积分持有的数组分别约 1534.2 MiB、1537.2 MiB，共同稀疏预留占绝大部分。`owned_array_bytes` 是求解器持有的设备数组字节数；不是 `nvidia-smi` 进程峰值，也不包含 CUDA 上下文和内存池缓存。因此只作同一实现基础上的存储对照，不代表高度优化的传统 MPM 最低显存。

## 6. 最新 CLI 与复现

项目根目录下，小变形预弯曲梁释放：

```bash
.venv/bin/python -m demos.aniso --scene beam --grid 17 --device auto \
  --dt .0005 --stabilization supplemental --direction-model fourth_moment --play
```

0°/90° 混合方向，平滑加载—卸载—重新加载：

```bash
.venv/bin/python -m demos.aniso --scene tensile --grid 9 --device auto \
  --dt .005 --loading-time .08 --loading-speed .025 --loading-cycles 2 \
  --smooth-loading --fiber-field crossed --direction-model fourth_moment \
  --stabilization supplemental --play
```

浏览器打开终端显示的地址，默认 http://127.0.0.1:8080。`--fiber-field smooth` 为平滑方向场；`--stabilization hourglass/none`、`--direction-model mean_tensor` 可切换对照。Viser 纤维短线使用各粒子自己的参考方向，不再把混合方向画成统一方向。形变放大只影响显示，可在界面设置为 1。

```bash
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m benchmarks.aniso_stabilization_moments --device auto
# 可使用 --part beam / moments / migration / performance 分开执行
MPLCONFIGDIR=/tmp/mpm-matplotlib .venv/bin/python -m benchmarks.aniso_stabilization_plot
ANISO_TEST_DEVICE=cuda:0 OPENBLAS_NUM_THREADS=1 .venv/bin/python -m unittest discover -s tests -v
```

资源：系统盘约 18 GiB、数据盘约 59 GiB；本轮未触发迁移或暂停。GPU 0 初始占用最低，主实验固定在该卡，性能实验避免与自己的其他 GPU 工作同时运行。

本轮没有启用新的默认稳定化，也没有加入大变形下未经证明的稳定化。接下来应优先完善其有限转动客观性、位移历史重建和低耗散时间积分，再扩大到强弯曲/接触/长时间场景。
