**本次代码核查发现的实施边界：**

1. 最新 provenance.py 的 APP 仍指向 cost-phase，它描述的是该命名空间的历史父版；直接运行其 freeze 会冻结旧计划与原输入。publication.fork 会附加 phase-stress continuation 并继承部分配置，适合原实现的继续使用，但不会自动创建本轮优化命名空间、绑定本文或迁移全部研究证据。新实现必须显式以 phase-stress 为直接父版。
2. 现有候选已经使用完整应力 Gram，含非对角项；下一轮不能把“改为应力评分”重新算作新增优化。未改变的删除名单、候选张成范围和设计采样，需要分别诊断。原设计采用实际 x 单元 Gauss3、横向整体 Gauss3，仅是评分近似；最终应力验收使用共同单元 Gauss7。
3. time_study.candidate_finish 对实际相关频段计算了速度误差，但事件检查仍传入模态 4；反力事件另有记录。新事件诊断应追加实际输出相关信号，并保留原场量、反力和旧模态失败记录。
4. 0.0075 m 的 [0.5,0.55]、[0.6,0.65]、[0.7,0.75] s 是已通过的研究短窗。主 CLI 却读取 S5/inherited-peak0075.json，其中 qualified=false，因此当前该幅值的 q5 请求仍会转成 full_only。该文件的历史 reason 已滞后于研究成果，不能据其文字否认新短窗，也不能据新短窗声称 CLI 已开放或完整周期已认证。
5. 压力独立诊断中，正常储存四单元的 selected dt 是 0.009375 s；现有正常储存两单元耦合实际用 0.01 s。小储存两单元耦合实际用 3.75e-5 s，四单元固定固体用 9.375e-6 s；原四步终点不同，不能直接作为同一物理时刻的空间收敛比较。
6. warm.py 的计时器现在记录主机经过时间，不能把它当成独立 GPU 分区成本。旧 performance_study 还绑定旧 APP 和 q5 配置，新空间无资格时不得原样调用。

**三、研究目标、公式与统一验收**

空间目标是用同一 144 函数预算得到更可信的应力。给定候选空间 \(\mathcal V\)，先求真实平衡 \(q_s^*(\mathcal V)\)，再评价：

\[
\nabla_{q_f}\Pi_s(q_s^*;\mathcal V)=0,\qquad
J(\mathcal V)=\sum_{s,r}w_r\left[
\frac{\|P(q_s^*)-P_s^{ref}\|_r^2}{s_{P,r}^2}
+\eta\frac{\|a_0^T(P(q_s^*)-P_s^{ref})a_0\|_r^2}{s_{f,r}^2}
\right].
\]

权重、尺度和设计工况在观察新候选结果前固定。局部近似 \(\delta P\approx\mathbb A:\nabla\delta u=D\alpha\) 与 \(D^TWD\) 可以筛选，但不能替代平衡求解。

完整坐标质量存在已知载体零方向。必须沿用 \(q=P_cw+q_0\) 的既有消零与固定边界关系，在独立坐标上求投影／灵敏度；不得对冗余完整质量直接求逆。候选的完整算子保持：

\[
M_{\mathcal V}=T^TM_RT,\qquad
K_{0,\mathcal V}=(T\otimes I_3)^TK_{0,R}(T\otimes I_3).
\]

时间诊断使用 \(K_0\phi_j=\omega_j^2M\phi_j\)、\(\Phi^TM\Phi=I\)，以及线性中点关系：

\[
\omega_{\rm num}=\frac2h\arctan\frac{\omega h}{2},\qquad
\Delta\varphi=(\omega-\omega_{\rm num})t.
\]

这些只解释线性相位，不将其比例写成非线性整场误差。空间改变时重新识别模态，不能硬编码“模态 72／501”继续使用旧向量。

统一工程判据采用 \(\|a-b\|\le a_{\rm tol}+r_{\rm tol}\|b\|\)，正常非零场默认 \(r_{\rm tol}=5\%\)，近零量主要看绝对尺度：

| 项目 | 预算或原则 |
| --- | --- |
| 位移／物理速度 | 5e-5 m／1e-4 m/s 的绝对尺度，再加 5% 参考尺度 |
| PK1／纤维 PK1 | 0.02 Pa 的绝对尺度，再加 5%；共同位置、分区积分误差为主 |
| 区间反力 | 1e-4 N，再加 5%；不同步长先比较同区间冲量，不移相 |
| 压力均值 | 5e-4 Pa，再加 5%；同体积、同物理时间；正性夹具另用 1e-5 Pa 超调观察尺度 |
| 材料积分 | 能量／组装内力／弱矩相对 2%，切线作用相对 3%，保留既有近零绝对预算 |
| 实现等价 | 采用已有 backend 预算；相同算子还需匹配非零状态、原始场、完整提交与恢复 |
| 几何与物理 | 不放宽当前 min_detF>0.1、约束、真实残差、质量秩与能量分账；无 NaN／翻转／明显增长 |
| 空间晋级收益 | 主区域 PK1 和纤维误差改善超过 max(当前误差的15%，2倍该区域经验参考不确定性) |
| 时间晋级收益 | 预登记输出相关误差改善至少20%，可辨识事件偏移目标≤0.00625 s，其他场及反力通过 |

主静态内部参考不确定性继续约取 0.003487 Pa，而非只取最后 R3/R4 的较小差。因此内部改善约需超过 0.006975 Pa，才可作为可分辨收益。这个门槛用于防止误选空间；当前场景是否工程稳定另行判断。长期 2% 应力、1% 反力目标不要求靠增加实验强行完成。

任何身份、完整质量、能量账或事务失败都不能通过调宽相对误差掩盖。若参考／信号不可辨，记录“未决”；条件未触发就记录“未开展”，不将其写成数值失败。

- **为什么：**当前两／四单元原四步终点不同，直接相减会混合空间与时间差；半离散精确解还不是连续压力真解。
- **如何验收：**初压0.01 Pa、右储库0.002 Pa、固定固体无源、S=0.0002不变；使用同时间、体积加权均值，输出原始压力／通量。分别报告时间误差、两／四单元敏感性，不因两层接近就宣布连续空间收敛。
- **交付：**S5/common-time-protocol.json、pressure-time-vs-space.json；普通同态复用无需重跑旧夹具。

**S5.2｜在最终选定固体空间复核交换功和完整历史。**

- **做什么：**空间或实现影响压力接口时，在该空间充分材料下补正常储存封闭／排水四步，以及必要小储存排水分支。核对实际几何V0与源项单位，消除新适配中依赖旧固定体积常数的隐含假设；空间完全相同且接口未变的证据可以继承。
- **为什么：**固体空间变化会改变体积梯度和压力作用，不能只继承旧压力系数或几何缓存。
- **如何验收：**检查
  \[
  \bar g_k^T\Delta q=\Delta V_k,\quad
  \Delta m+hB\bar z=hs,\quad
  W_s+W_f=-\alpha\bar p^T\Delta V+\alpha\bar p^T\Delta V=0,
  \quad D=h\bar z^TH\bar z\ge0.
  \]
  同时输出固体PK1和总PK1 \(P_s-\alpha pJF^{-T}\)，核对真实混合残差、局部／累计含量、全部流体历史与第2步后的新进程恢复；不把带源耦合压力超过初压自动认作单调性失败。
- **交付：**S5/coupled-closure.json、原始场、rollback-restart.json。小储存失败可保留正常受限资格；不调整storage、裁剪压力或吞掉混合求解错误。

**S5.3｜写清一般三维压力的最小数学接口。**

- **做什么：**定义压力单元、全局面朝向、局部关联B、参考体积、边界储库功和完整张量迁移率
  \[
  \mathcal K=J F^{-1}(k/\mu)F^{-T}.
  \]
  明确哪些横向流量约束将解除，以及新的面通量试空间／质量矩阵H。与现有x向半单元公式逐项对照。
- **为什么：**现有 \(1/(\mathcal K^{-1})_{xx}\) 依赖横向零流量约束，不能直接复制成任意三维网格上的两点通量。
- **如何验收：**维度、面方向、局部守恒和边界功一致；H具有所需耗散性质，但完整压力—通量—固体系统不因此成为SPD，不能直接沿用固体CG。新的空间形式单独命名、单独身份，不复用旧x向认证。
- **交付：**S5/three-dimensional-interface.md、block-layout.json、manufactured-protocol.json；本步骤不默认接入生产主场景。

**S5.4｜只在接口闭合后做一个独立三维制造解夹具。**

- **做什么：**若S5.3能够在预算内形成一致的最小离散，先固定固体，用一个小单元／小网格、线性压力和非对角张量迁移率，核对解析流量、每面方向、压力功及总守恒。若必须引入尚未推导的新方法，则交付具体缺口与协议，保留现有方案。
- **为什么：**三维推广需要直接检验交叉流量；现有独立六面RT0检查只能证明其自身离散，不能替新半单元推广背书。
- **如何验收：**三向交叉项确实参与计算，原始流量与制造解满足预登记工程预算；求解按真实混合残差验收。通过单夹具仅记manufactured_3D_scoped，不声明任意网格稳定性、连续压力精度或生产耦合可用。
- **交付：**S5/three-dimensional-manufactured.json，或S5/three-dimensional-gap.md；最多一个夹具，不开启材料／网格扫描或长周期三维实验。

**S5.5｜冻结物理范围与失败后的交付基线。**

- **做什么：**分别汇总固定固体时间行为、两／四单元空间敏感性、实际三维固体耦合、三维制造夹具及生产入口的状态。
- **为什么：**这些结论适用条件不同；某项通过不能自动扩展其他能力。
- **如何验收：**明确storage、单元数、时间数组、源与边界、固体空间和材料规则。未证明的pressure_spatial_accuracy、pressure_general_monotonicity、production_C_E_integration继续false；纯固体日常配置不因独立压力研究变化。
- **交付：**S5/coupling-decision.json、scope-matrix.json、限制与下一轮需求；压力方向有限失败不阻断已通过纯固体版本交付。

**S6.1｜冻结最终数值源码，完成唯一充分周期与最终材料资格。**

- **做什么：**完成所有数值代码调整后，解析源码、运行适用的现有21项及必要新风险回归，冻结最终数值清单。执行一条选定空间／时间／实现的充分轨迹到1.6 s、≤256步／≤12帧；如有完全匹配且来源可证明的已有轨迹则认证复用。用实际0、0.5、1.1和独立0.8 s状态补齐q7/q8、q5/q7及共同弱矩／敏感切线检查。
- **为什么：**最终资格必须对应真实轨迹与最后的实现；S3的局部资格不够支持完整日常路径。
- **如何验收：**新时间表须预先包含上述资格时刻和原加载转换；规则升阶时使用对应相邻规则，M7独立不变。旧数值源码下的检查点不通过改写身份续算；若实现等价允许复用，提交显式来源桥接及非零状态证明。冻结后若发现数值实现缺陷，撤回受影响候选，先评估剩余预算，不静默追加完整周期。
- **交付：**S6/final-model-lock.json、tests-result.json、充分轨迹或复用证明、full-rule-qualification.json、main-q5-qualification.json。充分规则本身不合格时不发布该新配置。

**S6.2｜运行日常周期并核查实际场景与最新CLI。**

- **做什么：**主q5通过后最多再运行一条日常周期；若日常为充分规则，复用S6.1。使用所有原始积分步比较分区场、区间反力、能量、det(F)、材料哨兵及回退记录；在最终代码上做一次必要的两步回退／新进程恢复，或认证同源码既有记录。渲染已提交12帧以内的HTML、PNG、GIF和压力图。
- **为什么：**局部收益不能证明完整周期累计行为；显示帧也不能代替逐步验收。
- **如何验收：**场量与反力满足工程预算，形变无翻转，能量无明显异常增长，回滚及发布完整。空间／时间相同的等价优化才与旧坐标作等价比较；空间变化则比较共同位置的物理场和已验证参照，不能要求原q数组相等。成本分别列构建、推进／输出／发布、RSS和GPU峰值，缺失细分计时明确写未独立测量。显示倍率标注，原始压力与反力不平滑。
- **交付：**S6/final-scene.json、physical-review.json、cost-comparison.json、已验证的运行／恢复／可视化CLI；不能给尚未实现的新命名空间提供“已可用”命令。

**S6.3｜逐步结案与新版本封存。**

- **做什么：**逐项核对本计划30步，记录“采用”“保留基线”“条件未触发”“有限诊断后未定位”与证据；整理能力矩阵、文档、源码快照和完整成果清单，最后生成新release并完整审计祖先。
- **为什么：**下一轮必须区分新正式发布、未完成实验、研究窗口与可运行许可，也必须知道哪些误差仍未解决。
- **如何验收：**所有生效配置与数值来源一致；逐项声明scene_stability、spatial_accuracy、temporal_accuracy、material_scope、pressure_monotonicity_scope、pressure_spatial_accuracy、production_C_E_integration。数据盘链接和所有哈希可验证；旧封存文档与代码不变。未证明的能力保持false／not_assessed，未运行的条件分支不写成通过。
- **交付：**新release.json、requirement-audit.json、capability-matrix.json、独立实施记录及完整审计结果。封存后新增说明另立文件，不回写已绑定文档。

**六、阶段结束时的明确决定**

| 观察／条件 | 下一步动作 |
| --- | --- |
| 设计评分随采样明显改变 | 先修评分代表性，在同一候选上限内继续；不把增加非线性候选当补救 |
| 最多两个空间候选都无可辨收益 | 保留swap6，不访问保留幅值、不新增R5或第三候选；继续时间、接口与性能 |
| 主状态合格，但保留幅值参考不足或收益消失 | 不晋级空间；保留失败和幅值范围记录 |
| 新空间无法通过基本动力学／质量检查 | 回到已通过空间；不从静态通过推导动态通过 |
| 事件定义变化只改善事件表，原始场仍失败 | 记录诊断进展，时间方案不晋级 |
| 预算内时间参考不足或新方案与旧失败方案等价 | 保留0.0125 s与temporal_accuracy=false；不继续扫更小步长 |
| 敏感研究窗有证据但主CLI没有许可 | 补明确窗接口与来源桥接；未完成前继续full_only |
| 启动波动没有稳定热点或候选收益不足 | 保留当前共享／无压缩／粗计时实现；不拿单次最快结果下结论 |
| 小储存或三维夹具无法闭合守恒／耗散 | 停止该分支，保留正常受限耦合与纯固体；不更改物理参数掩盖 |
| 最终q5未通过但充分规则通过 | 日常交付使用充分规则；不降低质量积分或放松材料许可 |
| 数值代码在最终冻结后需要修改 | 先标记相关证据失效并检查剩余预算；只补必要检查，不能继续旧身份或无限追加周期 |

每阶段结束更新新实施文档，至少说明：输入版本、已知事实、诊断推断、实际决定、已用预算、当前可运行命令和待完成项。发生路线变化立即记录，保持原始协议与失败文件可追溯。结果“不晋级”也可以是正确结案，但不能在可以正常推进时以“研究困难”为由跳过一般问题。
