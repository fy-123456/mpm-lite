# 后续共同空间孔弹性：方程、接口与最小验收

本文属于五项顺序优化的 S5.5—S5.6 交付。当前三维固体和二维孔弹性仍是不同空间；本文没有宣称已把 C 与 E 做成三维物理耦合。已有二维模型是真实的位移—压力—流量耦合，可以用于检查压力功、质量和事务含义。

## 本轮实际验证的二维共同问题

使用现有4×4单元、Q2位移、P0压力、RT0流量及GeneralBiot一般稀疏直接求解器。材料沿用现有E模型，左端位移固定、右端压力为零、其余边界零通量，右端压缩牵引0.05 Pa，显式体积源0.001；按0.01/0.015/0.005/0.01 s顺序推进四步。仅验证闭合和接口，不用这张粗网格认证应力精度。

实际方程为：

\[
Au-G^Tp=f,\qquad G\Delta u+C_p\Delta p+hBz=h s_V,\qquad Hz-B^Tp=b_p.
\]

其中G由同一位移基函数的体积应变积分得到，C_p包含物理储存，B为带符号的面通量散度，H为Darcy阻力。时间离散采用原E后向Euler，机械惯性为零，原E的数值耗散单独报告。

压力功的两个贡献为
\[
W_{p,u}=-\Delta u^TG^Tp,\qquad W_{p,m}=p^TG\Delta u,
\]
二者应相消。逐单元质量（这里按流体体积含量记账）检查
\[
e_m=G\Delta u+C_p\Delta p+hBz-hs_V.
\]
Darcy耗散为h z^T H z，必须非负。采用同一G是必要条件，仍需检查实际载荷、边界通量和完整离散能量账本，不能仅用一个转置恒等式代替物理验收。

完整矩阵为[A,-G^T,0; G,C_p,hB; 0,-B^T,H]。它不能直接套用固体SPD/CG假设；本轮检查实际矩阵秩、真残差，拒绝未支持的CG模式。事务外层同时持有位移、压力、流量、时刻和历史，未提交的候选全部回滚。

## 三维有限变形的拟议共同模型

下一轮可从当前固体参考域、原144函数或后续明确晋级的固体空间开始。先固定常参考流体密度、Biot系数alpha、正储存系数S及正定渗透率，定义m为单位参考体积的流体体积含量增量；若研究需要可压缩流体质量，应显式增加密度演化，不把m直接改名为质量。

一个可推导一致压力功的候选自由能密度为
\[
\Psi(F,m)=\Psi_s(F)+\frac{[m-\alpha(J-1)]^2}{2S},\quad J=\det F,
\]
从而
\[
p=\frac{m-\alpha(J-1)}{S},\quad P=P_s-\alpha p JF^{-T},\quad
\dot m=\alpha\dot J+S\dot p.
\]
原固体稳定化仍按原载体坐标加入总势能；质量使用已经资格确认的完整矩阵及交叉项。压力作用和质量方程中的体积变化必须来自同一离散J和积分权重，使压力功共轭。有限变形的耦合导数随F变化，不能拿二维线性模型的常量G直接代入。

若空间渗透张量为k，忽略重力的参考通量候选为
\[
Q=-\frac{J}{\mu}F^{-1}kF^{-T}\nabla_Xp.
\]
需要在J>0、k正定范围核对参考／当前构形的单位和通量Piola变换，再增加重力或质量源。这个模型是下一轮可审查的起点；尚未接入当前三维场景。

## 共同离散与最小接口

| 内容 | 必需字段和约束 |
| --- | --- |
| 固体空间 | 几何、基函数、T与offset、完整质量、原Ks及自由／约束映射，全部有哈希 |
| 压力／流量空间 | 独立明确的基函数、支撑、积分和边界；不能把E二维编号视为C三维编号 |
| 耦合核 | 同状态压力势能、固体压力力、流体体积含量、J变化及双向导数；说明每个权重只乘一次 |
| 单步输入 | 已提交u/v/p/流量／历史、实际dt、载荷、压力／通量边界、源项和模型身份 |
| 候选输出 | 自有数组、各残差块、压力功对、质量缺陷、耗散、边界功和来源身份 |
| 提交规则 | 固体、压力和流量全部通过才发布同一代次；任一失败均从同一基态重算 |
| 材料压缩 | 第一版共同耦合采用充分积分；q5对固体通过不等于压力功与储存积分通过 |

首先在小三维补丁上核查压力零空间和混合秩。现有固体独立自由度有限，不能把大量逐单元压力自由度直接拼接后期待稳定。压力网格、储存趋零极限和位移—压力相容性需要实际诊断；不以未经推导的压力罚项掩盖秩亏。

## 下一轮三维开工的判据

必须先明确目标几何、加载、排水边界、m的物理含义、alpha/S/k及压力空间。随后依次验证：零压力恢复当前固体；固定固体恢复独立流动；有限变形压力力与势能方向导数一致；统一功和质量在封闭／排水边界上闭合；失败后的整步回滚；最后才做少量完整场景。
