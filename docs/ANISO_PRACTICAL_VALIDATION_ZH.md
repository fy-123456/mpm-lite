## 本轮范围与验收

按本次要求缩短轨迹，保留原初态、完整网格、本构、夹持和历史。
局部 Y24、均匀 Y24 使用同样单元数/自由度/材料点数；Y48 是较细比较网格，不能视为收敛真解。
释放时长预设 0.125 ms，粗/细步长 1.953125/0.9765625 μs（64/128 步）。
时间相邻差以 F-I、应力、速度自身的体积 RMS 为尺度，目标 2%；空间差以同样物理量尺度给出，工程筛选目标 5%。
这些是单独的短程工程协议，不能替代旧 3 ms、候选差异尺度的严格门槛。
终态对能量、节点力和切线作用做 Gauss 5/7 独立复核（目标相对差 1e-5）。
局部/均匀与 Y48 的差异分别报告整梁、预定 Y 条带和条带外，粗细时间步均检查排序。

第二部分新增 GPU 参考的可选 consistent_pic 闭环：同一 Q1 基函数负责粒子速度读回、完整一致质量投影、材料梯度和历史增量提交。
保留原历史场，不覆盖为新网格拟合值。验证非均匀网格、CPU/GPU 对照、能量预算、材料/粒子历史和失败不提交。
这是材料携带参考路径的完整闭环；尚不是原 Eulerian Lite/MLS/APIC 的直接替换。

### 时间与查看器验收

六条轨迹共 576 步全部完成，数值检查全部通过。三组 F/P/v 时间相邻差最大为 0.2306%，低于预设 2%，无需追加更小时间步。细步下与 Y48 的整梁 F/P/v 差：局部 Y24 为 0.2918%/2.8399%/4.2418%，均匀 Y24 为 0.2787%/2.6118%/3.9725%。粗细排序和最终积分汇总尚在进行。

查看器 HTTP 200、正常退出通过；真实 WebSocket 验证了 2048 点加密终态、相对 Y48 的位置差和方案显隐。点云使用 float32，避免微小差异被默认 float16 精度抹去。见 `results/practical-validation/v1/viewer-interaction.json`。

### 方案排序已核对

整梁局部/均匀差异比 G_F=1.04714、G_P=1.08734、G_v=1.06779，粗细时间步排序一致；整梁优劣差的时间变化低于 0.35%。预定条带内也未发现反转（G_F≈1.598、G_P≈1.127、G_v≈1.017）。因此本轮短程条件下优先保留均匀 Y24，不采用该局部 Y24 分配。较细 Y48 的终态及差异指标高阶复核正在收尾；此结论不能直接外推到旧 3 ms 轨迹。

当前结果不足以支持增加局部余量模式，保留已有整体模式。参考 X/Z 的共同收敛与原 Eulerian MLS/Lite 接入仍是独立的后续研究，不把本轮工程检查包装成它们已完成。
