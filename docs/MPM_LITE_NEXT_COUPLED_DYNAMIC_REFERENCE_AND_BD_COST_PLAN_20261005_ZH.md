## 3. 数学目标：让参考包含真正造成压力变化的部分

### 3.1 当前计算的物理量

实体位移由基函数系数组合：

\[
u(X,t)=\sum_i\phi_i(X)q_i(t).
\]

系数范数不是实体位移。机械验收必须用相同实体位置的位移、速度、应力和反力，不能把系数的微小或巨大数值直接解释为场误差。

令 q、v 表示消去固定边界后的向量，M 表示含交叉项的完整自由质量矩阵，C 为原储存矩阵，V(q) 为各压力格体积，G(q)=∂V/∂q，B 为有符号面通量散度，H(q) 为原 RT0 Darcy 阻力矩阵。保持相同符号约定，连续半离散问题为：

\[
\dot q=v,\qquad
M\dot v=f_{ext}-f_{int}(q)+\alpha G(q)^Tp,
\]
\[
C\dot p=s-\alpha G(q)v-Bz,\qquad
H(q)z=B^Tp-g_b.
\]

通俗地说，压力既因为流体流出而降低，也因为骨架变形腾出了空间而降低。只固定骨架求压力，会漏掉第二项。

实际离散推进仍使用现有方程：

\[
q_1=q_0+hW,\quad v_1=2W-v_0,\quad
\bar p=(1-\theta)p_0+\theta p_1,
\]
\[
C(p_1-p_0)+\alpha[V(q_1)-V(q_0)]+hBz-hs=0.
\]

W 是该步平均速度未知量，不是终态速度。压力功必须成对：

\[
W_{s,p}=-\alpha\bar p^T\bar G\Delta q,\quad
W_{f,p}=\alpha\bar p^T\Delta V,\quad
\bar G\Delta q=\Delta V.
\]

保留数值耗散 `D_num=(theta-1/2) ΔpᵀCΔp` 与 Darcy 耗散 `D_Darcy=h zᵀHz` 的独立账本。不能把启动算法耗散算作材料物理耗散。

### 3.2 建立局部耦合参考时必须保留什么

选择认证状态 `y*=(q*,v*,p*)`，对上面的真实半离散方程 `ydot=f(y)` 作局部线性化：

\[
\dot\xi=A_*\xi+r_*,\quad \xi=y-y_*,\quad
A_*=Df(y_*),\quad r_*=f(y_*).
\]

初始固体静止不代表耦合平衡。即使 `v*=0`，非均匀压力也可能导致非零加速度和 Darcy 流量，因此 **r* 不能省略**。常系数参考可用增广矩阵指数计算：

\[
\begin{bmatrix}\xi(t)\\1\end{bmatrix}
=\exp\!\left(t\begin{bmatrix}A_*&r_*\\0&0\end{bmatrix}\right)
\begin{bmatrix}\xi(0)\\1\end{bmatrix}.
\]

还要核对两类容易遗漏的导数：

\[
K_*=D_q[f_{int}(q)-\alpha G(q)^Tp_*]_{q_*},
\]
\[
D_q(Bz)[\delta q]=-BH_*^{-1}(DH_*[\delta q])z_*
\]

（B 和边界项保持当前参考拓扑约定）。若 `v*≠0`，含量方程还包含 `alpha (DG*[δq])v*`。`rest_K` 只在验证适用后用于骨架刚度部分，不能替代压力几何导数；不能因为 F 接近 I 就默认 Darcy 几何导数为零。

矩阵作用采用线性求解，不显式形成 M 或 H 的逆。优先使用已有切线作用和可复用分解；不一次性对所有自由度做昂贵差分，也不直接对大型稠密耦合矩阵求完整谱。

**参考的能力边界：**矩阵指数消除的是所构造线性模型的时间积分误差，不消除线性化、投影或连续空间误差。只有局部有效性检查通过的窗口才允许用它分析真实轨迹。若完整空间参考超预算，可建立低维诊断参考，但必须单列投影误差；它不能直接给完整空间时间精度或 144 函数预算背书。

## 4. 实用验收标准

场景验收以正确性、稳定性和能解释的趋势为主，不追求机器精度或强制达到旧科研精度目标。工程场量、实现等价和物理硬条件分开判断。

| 类别 | 本轮判据 |
| --- | --- |
| 压力工程误差 | 同位置/同单元均值：`1e-3 Pa + 5% × 参考尺度` |
| 含量、累计交换 | `1e-10 m³ + 5% × 参考尺度`，全局、分区、六侧分别报告 |
| 流量 | 同一物理区间积分均值：`1e-10 m³/s + 5% × 参考尺度`；原始微步峰值另列 |
| 位移、速度 | 同探针绝对下限 `5e-5 m`、`1e-4 m/s`，各加 5% 参考尺度；标注信号/下限比 |
| 反力 | 相同区间的冲量平均：`1e-4 N + 5% × 参考尺度`，保留逐步原始反力 |
| 应力 | 同位置、同分量、同骨架/总应力定义；沿用 BASE 观察合同的绝对下限及 5% 工程相对项，在首次比较前冻结具体数值和单位 |
| 横向模式增量 | 沿用 `1e-5 Pa + 10% × |参考增量|`；参考变化未超过 `5e-5 Pa` 时只能报告信号受限 |
| 实现等价 | BD 与新候选沿用 BASE 的逐量纲算子和轨迹等价预算，不能用 5% 工程容差掩盖代数实现错误 |
| 实际推进硬条件 | 有限值、`detF>0.1`、本正压场景压力不小于 0、原真实残差通过、正确固定边界、事务原子提交 |
| 守恒及能量 | 沿用逐步账本；累计含量缺口≤`1e-10 m³`，累计能量缺口≤`1e-9 J + 1% × |真实分支E0|`；不允许正负抵消掩盖单步异常 |

采用统一误差形式 `|a-b| ≤ atol + rtol × scale`，输出绝对差、尺度、预算比及信号是否充分。模式必须同时报告 `A(t)` 与 `ΔA(t)=A(t)-A(t0)`，不能用较大的初始压力掩盖很小的演化误差。

线性参考自检以初态恢复、方程残差、独立算法一致和局部误差为准。导数方向检查用两档扰动，量纲归一后目标约 `1e-3` 的相对一致性并给出差分消减噪声；噪声主导时记为未分辨，不无限缩小扰动。参考的数值求解误差宜低于对应工程预算的 1/10；线性化及投影造成的可观测差异宜分别低于工程预算的 1/3。预算通过但信号仍过小时，不宣称相对精度通过。

上述比例是未来实验的预登记目标，不是现有结果。不得对截断线性参考直接要求原非线性离散能量恒等式成立；需分别检查参考自身方程和真实模拟账本。

- **如何验收：** 压力力与体积交换符号符合功抵消关系；对照真实方程计算 `r*`，禁止把非平衡初态强行设为平衡。输出 `S1/equation-map.md`、`S1/reference-protocol.json`。

**S1.2｜先核对导数作用和成本。**

- **做什么：** 使用 `evaluate(q,direction)` 验证骨架切线；核对静止刚度的适用范围；对体积、压力几何和 Darcy 几何导数作至多 4 个有物理意义的方向检查，包含横向耦合和已观察运动方向。各取两档扰动，复用静态几何，记录调用次数和成本。
- **为什么：** 现有准 Newton 矩阵用于收敛加速，不保证是完整物理切线；先检查几个方向能避免昂贵的错误全矩阵装配。
- **如何验收：** 各块作用与真实残差差分相符，结果不靠缩放、裁剪或遗漏项通过。超预算或导数无法可靠核实时，标明哪一块受限，停止该参考的精度认证。交付 `S1/derivative-check.json`、`S1/reference-cost-decision.json`。

**S1.3｜实现预算内的耦合线性参考。**

- **做什么：** 优先使用完整自由空间的算子作用和增广指数作用算法，复用 M/H 分解与可用静止刚度。预估 Krylov 作用次数、内存和耗时后才计算。若不可承受，改作显式标注的诊断子空间：从真实压力力响应、运动快照及残差方向构造质量正交基，最多比较 r=8 与 r=12，压力仍保留 128 格。
- **为什么：** 要将骨架运动纳入参考，同时避免重新开展大规模谱分析。诊断子空间可定位机制，但会额外引入投影误差。
- **如何验收：** 完整空间路线保留所有耦合块；诊断路线保留投影后的完整质量和交叉项，报告全空间残差作用及同位置可观测差异。r=8/12 接近不能单独证明全空间准确；未控制投影影响则标记 `diagnostic_only`。交付参考算子、输入哈希、成本及能力标记，不修改正式 144 空间。

**S1.4｜独立自检与局部有效性检查。**

- **做什么：** 核对初态、非零仿射驱动、瞬时含量和流量方向；固定骨架退化时恢复已有压力参考。对至多两个时刻使用独立 CPU 时间求解方式交叉检查；结合已有真实短窗状态检查非线性余项和同位置场差异。
- **为什么：** 指数计算正确不代表线性模型足以代表非线性运动。利用已有状态可先避免新 GPU 轨迹。
- **如何验收：** 区分数值求解误差、线性化误差和投影误差；不得将与旧粗时间轨迹的差异全归为线性化误差，需同时报告真实方程余项。只有误差来源可控且信号充分的区间进入时间精度判断；其余保留“稳定性可评估、相对精度未知”。输出 `S1/reference-self-check.json`、`S1/local-validity.json`。

**S1.5｜选择一个有信息量的窗口。**

- **做什么：** 对 Ay/Az 增量、实体位移/速度、体积交换和边界累计流量比较信号尺度；优先选择已有 25～37.5 微秒窗口。若它不能回答问题，才评估 75→125 微秒追加窗口。
- **为什么：** 多跑帧不能弥补参考错配或信号低于误差下限。
- **如何验收：** 在新动态计算之前写明选定窗口、要回答的问题、预期信号和触发理由。参考受限时不据此开展空间替换；若信号不足但 BD 性能问题独立可研究，可跳转 S3。交付 `S1/window-decision.json`。

### S2：只运行被触发的短窗对照

**S2.1｜桥接新工厂与原状态。**

- **做什么：** 从认证第 8 步恢复，推进到第 9 步，对照已封存结果，验证新工厂仍使用 BD；检查错误来源、错误网格和状态身份拒绝。若引入新的持久状态或缓冲区，再做一次提交前受控失败及原步重算。
- **为什么：** 数学未变也可能因恢复、缓存或累计历史接线错误而改变场景。
- **如何验收：** 使用 BASE 实现等价预算检查状态、实体场、账本和真实残差；失败后状态摘要及提交代次不变。桥接 1 次，条件故障及重算最多 2 次；它们均计尝试。输出 `S2/bridge-check.json`、`S2/recovery-scope.json`。

**S2.2｜优先做局部 h / h/2 对照。**

- **做什么：** 仅当 S1 判断时间差异可分辨、或真实轨迹出现可定位的时间相位问题时，从相同认证第 8 步物理状态比较 25～37.5 微秒的 4 个原步与 8 个半步。新细网格分支使用新身份和显式来源转换，不直接篡改旧状态里的网格签名。
- **为什么：** 同起点短窗可以判断局部时间误差，成本小于重跑整个启动阶段；它不能证明此前启动误差已消除。
- **如何验收：** 在共同物理时刻比较压力增量、速度及实体位移；反力和流量按共同区间积分；theta 切换仍在原物理时刻，残差窗口仍为 200 微秒。输出误差与参考不确定度，最多 12 个实际推进。若已有粗步证据完全同输入，可只读复用，但性能配对不能复用历史计时。

**S2.3｜有条件扩窗，或直接保持现状。**

- **做什么：** 只有运动骨架参考预示可分辨变化且仍处于有效区间时，从认证第 18 步/75 微秒恢复，到 125 微秒追加 4 步；只有新证据明确支持时再到 175 微秒追加 4 步。与 S2.2 优先二选一；第二分支必须有第一分支产生的新理由。
- **为什么：** 过去固定骨架“信号不足”的结论不能代替运动固体判断，但也不应默认延长实验。
- **如何验收：** 逐步硬条件通过，报告全历史及本窗口增量账本、分区场、Ay/Az 和六侧交换。父历史、耗散及真实 E0 不清零；参考有效性失效后只报告稳定性。最大 8 步，最多 2 个新物理帧。交付 `S2/window-review.json`；未触发须写清原因，不写“通过动态精度”。

### S3：按 BD 的实际热点选择一个性能候选

**S3.1｜重新采样 BD 成本。**

- **做什么：** 优先复用 S2 正在执行的有效步骤计时，分开构造、材料、局部伴随梯度、P 映射、H 装配、传输、场重建和 IO；记录几何与切线实际调用次数。若 S2 未触发，最多独立运行两个代表性 BD 单步。
- **为什么：** 上一轮 DV 的约 57% 梯度合并占比含特定计数范围，不能当新 BD 的热点占比；性能优化应针对当前实际耗时。
- **如何验收：** 初始化和推进分账，CUDA 计时同步边界明确，端到端耗时与子项计数可解释。输出 `S3/BD-profile.json`；无明确热点时结束性能分支。

**S3.2｜登记并实现唯一候选。**

- **做什么：** 仅选当前占比最高、可保持数学等价的一项，例如局部伴随工作批处理、完整 P 变换布局或 H 装配复用。若切线实际调用很少，不以切线缓存作为默认任务。预先登记修改范围、缓存键、失效条件、内存增量和退出条件。
- **为什么：** 同时改变多个计算环节会让速度收益和错误来源难以归因。
- **如何验收：** 候选不更换材料/质量积分、空间、theta、容差或阻尼；完整 P 和非对角迁移率保持。不得用压力裁剪、矩阵强制对称化或丢弃自由度换取速度。输出 `S3/candidate-protocol.json`；预计收益不能覆盖构造和内存成本时不实施。

**S3.3｜先算子与缓冲区，再完整单步。**

- **做什么：** 选最多 4 个已有几何状态检查 V/G/H 作用、离散体积链和压力功；验证返回数组所有权、元数据变化后的缓存失效和局部失败后重建。通过后用两个认证输入分别运行 BD 与候选各一完整单步，顺序交错，保持相同预热条件。
- **为什么：** 算子等价是采用性能候选的前提；只报告 kernel 时间无法证明整体收益。
- **如何验收：** 沿用 BASE 代数和轨迹等价预算；输出真实残差、非线性迭代数、几何调用数、整步时间、构造时间与峰值内存。两配对共 4 次推进。收益参考目标为两组整步均降低至少约 5%，如与抖动相当只能记收益不确定，不追加大量重复实验。

**S3.4｜有限连续验证与采用决定。**

- **做什么：** 只有 S3.3 等价且收益明确时，从认证状态连续运行候选 4 步；同位置对照已有 BD 连续结果，检查累计账本和恢复可加载性。
- **为什么：** 单步快且正确不保证缓存跨步使用正确。
- **如何验收：** 四步硬条件和实现等价通过；计算构造额外成本的回收步数 `N_break-even=ΔT_setup/(T_BD−T_candidate)`，分母非正时不采用。若不能在适用窗口内回收成本，保留 BD；新后端只能按实际验证范围入选。输出 `S3/backend-decision.json`、`S3/continuous-check.json`。

### S4：明确空间与生产接入的下一道门槛

**S4.1｜判断是否具备重分配 144 函数的证据。**

- **做什么：** 将误差拆为时间、参考线性化、诊断投影、压力空间和固体空间；按区域列出位移、骨架/总应力、反力与信号尺度。
- **为什么：** 参考自身误差或时间误差未排除时，重新分配函数可能只是在拟合错误。
- **如何验收：** 本轮不替换正式空间。只有可靠同工况机械参考、可分辨机械误差和明确空间瓶颈同时具备，才形成下一轮局部 h/p 参考与 144 重分配方案；仍保留载体—局部交叉评分。输出 `S4/spatial-entry-decision.json`，未满足即明确“不进入”。

**S4.2｜列清尚未获得的耦合能力。**

- **做什么：** 更新完整周期、耦合 q5、生产 C/E、混合求解器、真实驱动丢失恢复各项状态；确定下一项最小独立任务。
- **为什么：** 当前短窗研究后端的通过不能自动升级为生产完整耦合能力。
- **如何验收：** 每项标为新验证、继承、诊断受限或未执行，链接证据。固体 q5 的已有成功不等于耦合 q5；后者必须另验压力功、整步回滚和充分规则重算。混合系统继续采用适用的一般求解器。输出 `S4/capability-matrix.json`。

### S5：最小回归、可视化与独立交付

**S5.1｜运行与改动相关的最小检查。**

- **做什么：** 按实际改动选 4～6 项有意义的合同测试：来源拒绝、仿射驱动、导数/退化参考、区间流量、事务及缓存。新进程构造实际入选后端，加载本轮最终状态；只读检查继承纯固体正式终态。
- **为什么：** 交付必须实际可加载；重复运行未改动的完整场景不会增加同等价值。
- **如何验收：** 报告命令、退出码、源码哈希、唯一测试数和未重跑项；构造、成功、故障、重算、已提交后分析失败分别计数。加载时零推进，产物写新目录。输出 `S5/test-report.json`、`S5/load-check.json`、`S5/attempt-accounting.json`。

**S5.2｜用原始曲线展示结论。**

- **做什么：** 页面同时展示固定骨架参考、运动骨架参考和真实结果，并明确每条曲线的模型和数据来源；给出 Ay/Az 增量、同位置位移/速度、分区应力、共同区间流量、六侧交换及能量分账。实际新物理帧最多 2 个，已有 75 微秒场只引用。
- **为什么：** 放大纳米级位移或把不同参考混画，容易夸大振荡或制造“精度已通过”的印象。
- **如何验收：** 不平滑原始曲线；单位、位移放大倍数和信号下限明确；实际查看图像，核对页面实际资源可读。只验证 HTTP 时不能宣称浏览器交互已验收。输出 `S5/visual-review.json` 和实际可运行的 CLI。

**S5.3｜先核对证据再封存新发布。**

- **做什么：** 更新新进度文档，逐项核对步骤、条件跳过、未解决异常、来源和资源预算；生成新来源/产物清单、选择记录及发布索引。
- **为什么：** 结果可复查、限制不被遗漏，比增加帧数更重要。
- **如何验收：** 新发布审计通过，祖先源码与封存文档保持原字节；只有已通过条件的候选才写入选择结果。未完成能力保持 false/limited，不复制旧 true 标记。交付新发布路径、哈希、文档与 CLI；无性能候选通过时也可交付参考结果并继续选 BD。

## 6. 成本、磁盘与异常处理

### 6.1 小规模上限，不要求用完预算

| 项目 | 上限或规则 |
| --- | --- |
| S2 桥接 | 1 次动态推进 |
| 条件受控故障与重算 | 共 2 次动态尝试 |
| 局部 h / h/2 | 最多 4+8=12 次推进 |
| 扩窗 | 最多 8 次；优先不与 h/2 同时执行 |
| 独立 BD 采样 | 最多 2 次；优先复用正常步骤 |
| 两输入性能配对 | 4 次推进 |
| 候选连续验证 | 4 次推进 |
| 一般问题修复后重算预留 | 最多 3 次尝试 |
| 总动态尝试 | **硬上限 36 次**，上述分项相加即上限；失败也计入 |
| 导数方向检查 | 最多 4 个方向、各两档扰动；静态调用逐项计数 |
| 参考路线 | 只选择完整空间或受限诊断路线之一；最多 2 个时刻独立自检 |
| 新物理帧 | 最多 2 帧；参考曲线采样不冒充新物理帧 |
| GPU 相关完整进程 | 累计≤900 秒，包含构造、静态探针、预热和失败 |
| CPU 参考与分析 | 累计≤600 秒；小合同测试单列 |
| 新结果预算 | 默认≤2 GiB；大型矩阵/重复快照先估算再写入 |

始终只持有一个 GPU 模型，进程串行。每次运行先估算剩余预算；不能等整批超限后才记账。完整空间参考的算子作用次数受实测单次成本约束；不能用“CPU 参考”名义隐藏 GPU 导数调用。预算不足时停止可选分支并交付受限分析，不改变物理条件或验收定义以凑结果。

### 6.2 磁盘策略

本次核查系统盘剩余约 **7.55 GiB**，数据盘约 **22.77 GiB**，未触发迁移。本轮只写文档，没有迁移操作。

未来实施前和每次大输出前重新检查。系统盘低于 5 GiB 时，仅迁移已确认不用的可重建缓存或不重要旧临时产物；先核对目标空间，复制后验证数量/哈希，再替换路径并验证链接，最后释放旧副本。不得迁移活动缓存、未提交状态或删改封存索引。对通过数据盘符号链接引用的祖先结果尤其不能重复搬运。记录源/目标、原因、校验和迁移前后容量；没有合适对象或数据盘不足时暂停大输出，保留已有安全结果。

### 6.3 异常决策

| 情况 | 先分析什么 | 后续动作 |
| --- | --- | --- |
| 一般路径、维度、单位、序列化错误 | 最小输入、实际类型和来源映射 | 原因明确可自行修复，运行对应最小检查并继续 |
| 相同状态恢复后不同 | 方程身份、执行后端、网格索引、累计历史和缓存所有权 | 不篡改签名绕过验证；修正桥接再继续 |
| 参考明显偏离实际 | 仿射驱动、压力几何项、DH 项、局部有效区间和投影残差 | 区分模型错配与时间误差；不能用加阻尼消除差异 |
| 负压、体积异常或账本失衡 | 原始残差、P/G、压力功、theta、源项、最后安全代次 | 停止受影响物理分支；明确原因可修复重算，难以定位则跳过该分支并保留失败证据 |
| 混合求解异常 | 缩放、原矩阵残差、边界和压力零空间 | 不默认 SPD，不裁剪特征值或更换方程掩盖问题 |
| 性能改善不明显 | 同输入、同步、构造分账、实际调用数和抖动 | 保留 BD，不反复增加帧数追求正收益 |
| 已提交但后处理失败 | 提交记录、状态可读性、分析脚本 | 已执行步照常计数，优先只读重做分析 |
| 真正设备丢失 | 设备健康及状态可恢复性 | 停止 GPU 分支；不把局部缓冲区故障测试当设备恢复通过 |

明显异常需要记录假设、证据、根因、修复影响和验证结果。难以定位时仅停止依赖该问题的分支；独立文档、已有证据分析和安全交付继续。一般可定位问题不能用“允许跳过”作为不处理的理由。
