> 后续更新：[中心历史迁移及独立参考结果](ANISO_HISTORY_REFERENCE_RESULTS_ZH.md)。下文实验采用此前网格固定历史；现默认改为粒子历史逐步重采样，单步冻结势能与 PCG 策略保持一致。新的能量、反力及梁欠积分结论以新报告为准；本页历史性能不含新增重采样成本。

已完成冻结中心积分结构的变分残差与切线、PCG 曲率检查、正定近似回退、原势能线搜索，以及新旧离散的能量和反力复测。**推荐默认使用带检查的 PCG；检测到负曲率、线性未收敛或非下降方向时，使用正定材料近似重新求解。** 对称性已经验证，但精确 Jacobian 在压缩工况下确实可能不正定。

本轮数据与旧 Kirchhoff 离散的历史数据分别保存在 `results/variational/`、`results/quantitative/`，不混用。本报告默认以 GPU 数据为准。

## 1. 改动后的方程

每个时间步内冻结插值梯度、质量、参考体积、参考结构张量和上一步状态：

\[
F_c(v)=(I+\Delta t\,G_c(v))F_c^n,\qquad
\Phi(v)=\tfrac12(v-\hat v)^TM(v-\hat v)+\sum_c V_c^0\psi(F_c(v),A_{0,c}).
\]

`grid_v + dt * gravity` 是实现中的预测速度；速度约束在 Newton 初始化和更新时施加。新的内力残差与精确 Jacobian 为

\[
r_i^{\mathrm{int}}=\Delta t\sum_cV_c^0P(F_c)(F_c^n)^T\nabla w_{ic},\qquad
J=M+\Delta t^2\sum_cV_c^0B_c^TH_cB_c,
\]
\[
B_cp=G_c(p)F_c^n,\qquad H_c=\partial^2\psi/\partial F^2.
\]

因此切线中使用 `dP @ F_n.T`，不再使用旧力形式的 `dP @ F_trial.T + P @ dF.T`。固定/滑移约束两侧都投影，实现 `Q J Q`；其完整存储空间含约束零方向，正定性和 PCG 适用性指**自由子空间**的 `Z.T @ J @ Z`，不指含约束零行的全矩阵。

生产中心路径仍是矩阵自由，不在每次残差/切线计算中访问粒子本构。粒子 quadrature 基线同步改成相同变分形式。反力使用本步冻结的 `F_n`，包含 C2G 边界投影惯性冲量；不能在步后用已经提交的 `F_{n+1}` 替代回拉因子。

`force_discretization="variational"` 为默认；`"legacy_kirchhoff"` 保留原残差和 BiCGSTAB/GMRES 求解，供对照。拒绝在旧非对称离散上选择 PCG。早期稠密参考/独立中心内核仍用于历史 Kirchhoff 路径测试，不能当作新生产残差。

## 2. 精确切线与正定近似分别是什么

先尝试精确切线，逐次检查 PCG 的 `p.T @ J @ p`，并检查求解后的真实线性残差和 `r.T @ dv < 0`。遇到非正曲率或求解失败时，重新从零初值求解修改后的切线。PCG 成功只说明所探索方向通过检查，**不是运行时完整谱的正定证明**。

正定近似只改变搜索方向，不改变残差、材料能量或最终求解目标。各向同性 Hencky Hessian 在奇异向量基中的一个 3×3 块和三个 2×2 块分别平移至正定；纤维部分的精确二次型为

\[
D^2\psi_f[dF,dF]=2k_f(I_4-1)\operatorname{tr}(dF A_0 dF^T)
+4k_f\big((FA_0):dF\big)^2.
\]

由于 `A0` 半正定、`k_f >= 0`，将第一项系数替换为 `max(2 k_f (I4-1),0)` 即得到半正定纤维近似。记两部分之和为 `H_tilde`，则

\[
\widetilde J=M+\Delta t^2\sum_cV_c^0B_c^T\widetilde H_c B_c\succ0
\]

在质量为正的自由子空间成立。于是解 `J_tilde dv = -r` 有

\[
r^Tdv=-r^T\widetilde J^{-1}r<0.
\]

这给出了原势能的下降方向，但 **`J_tilde` 是修改后的 Newton 切线，不是精确 Jacobian**。当前仍用对称质量预条件器，没有把各向异性块预条件器的潜在收益当作已完成结果。

线搜索使用原始势能的 Armijo 条件 `Phi(v+alpha*dv) <= Phi(v)+1e-4*alpha*r.T@dv`，回溯步长为 `1,1/2,...`。近零应变时，SVD/log 误差相对能量值会放大；只按 `eps*Phi` 设容差曾使严格收敛附近误拒步长。现依据惯性计算尺度、材料能量对奇异值的敏感度以及归约长度估计浮点容差；若只在此容差内通过，还要求残差减小。每次接受记录原势能、容差、方向导数、步长及残差。**不放宽非线性残差标准**，也不把容差内的上浮说成严格单调下降。

为避免奇异值截断导致能量/导数不一致，非有限变形、非正行列式或最小奇异值不大于 `1e-6` 的 trial 被拒绝，不进入原有应力截断区。

## 3. 真实稀疏网格导数和谱验证

65³ 网格，跨 8 个稀疏块，8 个活动中心、27 个活动节点；固定面和斜法向滑移面共同留下 45 个自由度。检查非单位 `F_n`、非零非均匀 trial 速度。中心积分扫描 `k_f=0,200,20000`、`dt=.0005,.005,.05`，分别使用拉伸/剪切状态与压缩状态 `F_n=diag(.65,.85,1)`，另检查一组粒子积分，共 **19 组**。

- 势能方向导数与残差内积：每组取四个扰动尺度中的最佳相对误差，最坏约 **5.3e-10**。
- 残差有限差分与精确 matvec：相同统计口径最坏约 **7.2e-11**。
- 完整自由度矩阵相对不对称范数：最大约 **2.2e-16**。
- 精确切线：18 个中心工况中 7 个压缩工况出现负特征值；小时间步的质量项有时足以使局部非凸材料对应的全局算子正定。
- 正定近似：19 组全部正定；质量归一化最小特征值约不低于 1，数值误差约 1e-11。

## 4. 能量与加载反力复测

新旧离散都重新运行，固定块体和仿射场保持 `T=.02 s`；扫描三个时间步、FLIP=0/.9/1、松/默认/紧容差。另比较三种角度的加载—卸载，合计 **34 条轨迹**。所有轨迹通过既定残差验收，正常轨迹未触发正定近似，最大能量预算闭合误差小于 **2.5e-17**。

|---|---:|---:|
| 固定块体 | +0.83488185 | +0.83493046 |
| 仿射场 | +0.02375225 | +0.02375688 |

固定块体全过程最大绝对相对变化仍约 **2.70508%**。新离散在 `dt=.0005/.001/.002` 时分别为 `-0.16381354% / +0.83493046% / +1.68391690%`；FLIP=0 与 1 分别为 `-6.71427372% / +3.74383476%`。紧容差默认工况为 `+0.834930463%`，与默认容差一致到此处显示精度。

## 5. 为什么推荐 PCG 加条件回退

对于正常的近单位变形，质量项加上材料项使精确自由算子正定，PCG 可以利用对称性，使用短递推和较少向量。对于压缩负曲率，正定近似既使 PCG 适用，又给原势能提供下降方向。默认精确、必要时修改，避免在每次迭代都丢弃精确曲率。

同一拉伸/剪切自由算子、同一制造解、相同相对容差 `1e-8`、真残差验收；预热后同步计时三次取中位数：

| k_f / dt | PCG | BiCGSTAB（含必要的 GMRES 回退） | GMRES(63) |
|---|---:|---:|---:|
| 200 / .005 | 39 次，22.61 ms | 35 次，36.99 ms | 63 次，29.68 ms |
| 20000 / .05 | 123 次，70.74 ms | 500 次，533.26 ms | 63 次，36.86 ms |

这不是“PCG 始终最快”的证明。高条件数的小问题中 GMRES 更快，且 restart=63 已大于本探针的 45 个自由度，接近完整 Krylov 空间，不能据此预测大规模网格性能。BiCGSTAB 和 PCG 单次迭代的工作量与检查频率不同，不能直接用迭代数比值宣称加速。当前 PCG 每步同步检查曲率，也有额外开销。

压缩时精确 PCG 被正确终止，修改切线 PCG 收敛。**修改切线与精确切线是不同线性系统**，相关时间不应当作相同方程的加速比。

如果研究目标要求每次都解原始的对称不定 Newton 系统，下一候选是 MINRES；但 MINRES 只解决线性系统，所得 Newton 方向仍可能不是势能下降方向，仍需信赖域或其他非凸全局化策略。本轮没有实现或测试 MINRES，因此默认采用已验证的正定近似回退。旧非对称离散仍使用 BiCGSTAB＋GMRES 回退。

算法适用条件参考：[PETSc 的 PCG 文档](https://petsc.org/release/manualpages/KSP/KSPCG/)、[Netlib 的 MINRES/SYMMLQ 说明](https://www.netlib.org/linalg/old_html_templates/subsection2.6.3.2.html)。本项目的对称性、特征值与耗时结论来自上述实际算子测试，而非仅依据算法的一般性质。

## 6. 使用与复现

```python
solver = AnisotropicLiteImplicitSolver(..., force_discretization="variational")
solver.step(linear_solver="pcg", max_iters=16)  # 精确优先，必要时正定近似回退
solver.step(linear_solver="pcg_projected", max_iters=16)  # 始终使用修改切线
# apply_tangent(p, Ap) 默认始终是精确 Jacobian；显式 project_pd=True 才是修改切线。
```
